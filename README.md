# 社労士試験 学習ハブ（2026年度・第58回）

社会保険労務士試験のための学習用Webアプリと資料。**本試験の過去問9年分を実データとして解析**し、
出題傾向の統計と整理資料を機械的に生成している。推測や体感ではなく、すべて過去問データに基づく。

**公開版** → https://syaroushi-study.vercel.app

## 中身

| | 内容 |
|---|---|
| **ドリル** | 3,524問。本試験の**択一630問・選択式72問**（第49〜57回）＋そこから導いた肢別○×2,580問＋法改正の自作問題 |
| **資料** | 23件・約35万字。全10科目＋横断整理・数値暗記・判例・条文素読・正文集ほか |
| **傾向** | 7画面。設問形式の年次推移、合格基準点の履歴、論点マップ、誤り肢の分析、自分の弱点 |
| **模試** | 年度を選んで本番と同じ形式・時間で解く。基準点割れの判定つき |

出題形式は本試験に合わせてある。択一は5肢択一（個数問題・組合せ問題を含む）、
選択式はA〜Eの5空欄で、20語の共通語群から選ぶ形式と空欄ごとに選択肢が出る形式の両方に対応。

## 分かったこと（過去問の解析結果）

- **組合せ問題は2肢の正誤が分かれば98.5%で正解が確定する**（66問を解析）。全肢を読む必要はない
- 個数問題は5肢すべての判断が必要。飛ばす候補はこちらだけ
- 選択式の**正答語が再び正答になる割合は7%**。語の丸暗記はほぼ無意味
- 直近2年の選択式は**条文4問／判例3問／統計1問**で安定
- ある年に出た論点が**翌年も出る割合は44.7%**。「出たばかりだから出ない」は成立しない
- 誤り肢の**主体（誰がやるのか）の書き換え**は健保78%・厚年62%・国年54%
- 選択式の基準点引下げは9年で7回。ただし**労基安衛と厚年は一度もない**

## 動かす

そのまま `drill/index.html` をブラウザで開けば動く。サーバは要らない。

デプロイは Vercel。

```
cd drill && vercel --prod
```

端末間で学習データを同期したい場合のみ、Vercel の管理画面で Storage → KV を作る。
未設定なら同期機能は表示されず、ローカル保存のまま動作する。

## 出題構成

### 選択式（8問40点 / 各5点）
労基安衛／労災／雇用／労一／社一／健保／厚年／国年
→ **徴収法は選択式では出題されない**
→ 各問とも **A〜Eの5空欄**。語群は「20語の共通語群から選ぶ」形式と「空欄ごとに選択肢が用意される」形式の2種類がある。

### 択一式（70問70点 / 7科目各10問）
労基安衛／労災（徴収含む）／雇用（徴収含む）／一般常識（労一5・社一5）／健保／厚年／国年
→ 全問**5肢択一**。「正しいものはどれか」「誤っているものはどれか」のほか、**個数問題**（正しいものはいくつあるか＝一つ〜五つ）と**組合せ問題**がある。

### 目標得点（基準点ギリギリを狙わない）

| | 合格基準 | **狙う点** |
|---|---|---|
| 択一 | 42〜45点（年により変動） | **50点** |
| 選択 | 各科目3点 | **各科目4点** |

択一の基準点は**42〜45点と変動**します。42点狙いでは基準点が45だった年に落ちます。
一方**選択式は上振れが作れない**（各科目5点が上限）ので、**バッファは択一でしか作れません**。
科目別の配分は `notes/96-得点源リスト.md` にあります。

### 合格基準（例年の枠組み）
- 選択式：総得点が基準点以上 **かつ 各科目3点以上**（科目により1点／2点に補正されることがある）
- 択一式：総得点が基準点以上 **かつ 各科目4点以上**（科目により3点に補正されることがある）
- → **1科目でも基準点割れで不合格**。総得点より「基準点割れをゼロにする」ことが最優先。

参考：直近の第57回（令和7年度）は選択式22点以上・択一式42点以上（労災／労一／社一は選択2点以上、雇用は択一3点以上に補正）。

### ドリルの機能
- **出題形式**：本試験形式／択一のみ／選択式のみ／肢別○×のみ
- **年度フィルタ**：全年度・直近5年・直近3年・直近1年
- **出題範囲**：復習期限がきた問題／苦手のみ／未出題のみ／法改正論点のみ／全問
- **間隔反復（SRS）**：正解すると出題間隔が延び、間違えると当日中に再出題。直前期向けに最大7日に圧縮
- キーボード操作（`1`〜`5` で解答、`Enter` で次へ）

### 模試の使い方
`PLAN.md` では 8/9 と 8/16 に本試験シミュレーションを置いています。
模試タブで年度を選び、本番と同じ制限時間で通してください。採点後に
**基準点割れ科目**が出たら、翌日以降の学習をその科目に全振りします
（結果画面の「間違えた問題を復習する」でそのまま演習に入れます）。

### 肢別○×について
「正しいものはどれか」「誤っているものはどれか」型の設問は、**正答肢以外の4肢の正誤も確定する**ため、機械的に○×へ分解しています。組合せ問題・個数問題・没問は各肢の正誤が確定しないため除外（110問）。

## この教材だけで受かるのか（過去問データによる検証）

過去問9年分を集計した結果、**選択式の正答語のうち、それ以前の過去問に既出だったのは平均47.1%**でした。
つまり**約53%は過去問だけでは初見**です。この教材だけで選択式を取り切ることはできません。

一方で、**9年中7回、いずれかの科目で基準点が引き下げ補正**されています（社一4回・労一4回・健保2回・国年2回）。
誰も解けない問題は救済される仕組みなので、狙うべきは満点ではなく**「みんなが取れる問題を落とさないこと」**です。

| 領域 | この教材でカバーできるか |
|---|---|
| 択一（42/70で合格） | **できる**。過去問630問＋自作242問の反復で到達可能 |
| 選択式の既出論点 | **できる**。過去問72問＋科目別ノートの目的条文・条文文言 |
| 選択式の初見問題 | **手順で対処**（`92-選択式の解き方.md`）＋**条文素読で型を体に入れる**（`95`）。ただし確実ではない |
| 令和8年度の法改正 | **できる**（`00-法改正-令和8年度.md`。ただし数値は要照合） |
| 白書・統計の最新数値 | **令和7年版の副題・主要数値は収録**（`99`）。ただし細部は書籍で照合を推奨 |
| 未知論点への耐性 | **カバー外**。市販の直前予想模試を1〜2冊やるのが最も効果的 |

手持ちのテキスト（社労士24等）は、残り期間では**通読ではなく、模試で基準点割れした科目をピンポイントで引く辞書**として使うのが合理的です。

## ⚠️ このドリルの限界（重要）

1. **過去問には解説が付いていません。** 公表されているのは問題文と正答のみです。根拠は必ずお手持ちの過去問集・基本テキストで確認してください。自作問題（法改正・労基・安衛）には解説を付けています。

2. **過去問は出題当時の法令に基づいています。** 第49〜56回の問題には、その後の法改正で**現在は答えが変わるもの**が含まれます。特に雇用保険（給付制限・高年齢雇用継続給付・新設給付）、厚年（在職老齢年金）、育介法まわりは要注意。判断に迷ったら `drill/data/00-kaisei.js` の法改正問題と照合してください。

3. **数値には誤りの可能性があります。** 一次情報で検証を進めており、`91-数値暗記.md` は**68項目が✅（複数出典で確認済み）／15項目が⚠️（未照合）**です。
   実際、検証の過程で**私の誤りが3件見つかりました**（老齢基礎年金の年額、介護補償給付の最高限度額、20歳前傷病の所得制限の欠落）。
   **`⚠️` が付いた項目は必ず教材で照合してください。食い違ったら教材を信じてください。**

4. **これは主教材ではありません。** 主軸は市販の過去問集＋模試です。このドリルは「弱点の可視化」と「スキマ時間の回転」に使うのが最も効果的です。

## データの検証

過去問データは、生成結果ではなく**PDFから独立に再解析した結果**と突き合わせて検証しています。

```bash
cd /Users/tani/roushi/kakomon
python3 verify.py 10 40   # 無作為抽出10ラウンド × 40問を原典と照合
python3 audit.py          # 10観点の多角監査
```

`verify.py` が確認するもの:
1. 問題文・選択肢が原典テキストに実在するか（捏造・欠落・混入の検出）
2. 正答が正答PDFの再解析結果と一致するか
3. 肢別○×の正誤が、親設問の設問文と正答から論理的に導かれる値と一致するか

`audit.py` の10観点: 没問・複数正答と脚注の整合／設問番号の充足（9年×7科目×10問）／選択式の科目充足／空欄A〜Eの昇順初出／語群の重複と正答の実在／制御文字・文字化け／**各肢の直後が原典上で次の肢記号（末尾欠落の検出）**／設問の重複登録／肢別○×の網羅性と正誤比／採点ロジックの整合。

現状：**全3,282問が原典と一致、10観点すべて合格**。

### 資料の品質チェック

```bash
cd kakomon
python3 review_notes.py   # 過去問との突き合わせで10観点の欠落を検出
python3 gen_trend.py      # 出題傾向を最新データで再生成
python3 gen_notes.py      # アプリ用に再埋め込み
```

`review_notes.py` は「思いつきで加筆する」のではなく、**過去問で実際に問われているのにノートに無いもの**を機械的に洗い出します。

資料はアプリの「資料」タブからも読めます（`kakomon/gen_notes.py` で埋め込み。
`notes/*.md` を編集したら再実行してください）。

### なぜ横断整理が要るか
本試験の引っかけは「**数字と主体の入替え**」でできている。
科目別に縦に学んだ知識は、横に並べ替えないと入替えに気づけない。
基準点割れの主因はここなので、直前期の投資対効果が最も高い。
