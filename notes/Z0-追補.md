## 労基

### 総則の罰則 — 拘禁刑だけでなく罰金もある（→ 労働基準法「総則の7原則」）

「6か月以下の拘禁刑等」と「等」で伏せていました。労基法の罰則は**すべて「拘禁刑または罰金」の選択刑**です。

| 条 | 内容 | 罰則 |
|---|---|---|
| **1条** | 労働条件の原則 | **なし**（訓示規定） |
| **2条** | 労使対等の原則 | **なし**（訓示規定） |
| 3条 | 均等待遇 | 6か月以下の拘禁刑／**30万円以下の罰金**（119条） |
| 4条 | 男女同一賃金 | 同上 |
| **5条** | 強制労働の禁止 | **1年以上10年以下**の拘禁刑／**20万円以上300万円以下**の罰金（117条）＝最重 |
| 6条 | 中間搾取の排除 | 1年以下の拘禁刑／**50万円以下の罰金**（118条） |
| 7条 | 公民権行使の保障 | 6か月以下の拘禁刑／30万円以下の罰金（119条） |

> ★**5条だけが下限つき**（「1年以上」「20万円以上」）。労基法でここだけの形です。
> ★**1条・2条には罰則がありません**。7原則のうち罰則があるのは**3条〜7条の5つ**。

**罰則の段**

| 条 | 刑 | 主な対象 |
|---|---|---|
| 117条 | 1年以上10年以下の拘禁刑／20万円以上300万円以下の罰金 | 5条 |
| 118条 | 1年以下の拘禁刑／50万円以下の罰金 | 6条、56条、63条、64条の2 |
| 119条 | 6か月以下の拘禁刑／30万円以下の罰金 | 3条・4条・7条、16条〜20条、32条〜39条 ほか |
| **120条** | **30万円以下の罰金のみ**（拘禁刑なし） | 14条、15条、23条〜27条、**89条**、**106条** ほか |

> ★**120条だけ拘禁刑がありません**。就業規則の作成届出（89条）、法令等の周知（106条）はここ。

### 寄宿舎（94条〜96条の3）（→ 労働基準法に新しい節）

**9年で2回出ています**（令和2年度の選択式で空欄A、令和6年度の択一）。条文は5つだけです。

| 条 | 内容 |
|---|---|
| **94条** | **私生活の自由を侵してはならない**／**寮長・室長等の役員の選任に干渉してはならない** |
| **95条** | **寄宿舎規則**の作成・届出（下記） |
| **96条** | 換気、採光、照明、保温、防湿、清潔、避難、定員の収容、就寝に必要な措置その他**健康・風紀・生命の保持**に必要な措置 |
| **96条の2** | 設置・移転・変更の**届出**（下記） |
| **96条の3** | 基準違反のとき、行政官庁は**使用の停止・変更等を命ずる**ことができる。**労働者に対しても命令できる** |

**95条 寄宿舎規則の5事項**

| 号 | 事項 | 過半数代表者の同意 |
|---|---|---|
| 1号 | 起床、就寝、外出及び外泊 | **必要** |
| 2号 | 行事 | **必要** |
| 3号 | 食事 | **必要** |
| 4号 | 安全及び衛生 | **必要** |
| **5号** | **建設物及び設備の管理** | **不要** |

> ★同意が要るのは**1号〜4号**だけ。**5号には要りません**。ここが最頻出。
> ★届出には**同意を証明する書面を添付**します（95条3項）。
> ★**使用者だけでなく、寄宿する労働者にも遵守義務**があります（95条4項）。

**96条の2 届出（令和2年度の選択式で出題）**

> 常時**10人以上**の労働者を就業させる事業、危険な事業又は衛生上有害な事業の附属寄宿舎を設置・移転・変更しようとする場合、計画を**工事着手14日前まで**に行政官庁に届け出る。

> ★正答が「**工事着手14日前まで**」でした。安衛法88条の計画届（**30日前**／14日前）と混同しないこと。

### 36協定の上限は2段（→ 36協定と上限規制）

```
① 原則の枠（限度時間・36条4項）  1か月45時間 ／ 1年360時間
        │ 臨時的な特別の事情があるときだけ超えられる
        ↓
② 特別条項の絶対的上限（36条6項） 年720時間／月100時間未満／2〜6か月平均80時間以内
                                  45時間を超えてよいのは年6回まで
```

**数えるのは「法定労働時間（1日8時間・1週40時間）を超えた時間」**です。所定を超えた時間ではありません。

| 所定 | 実労働 | 扱い |
|---|---|---|
| 7時間 | 8時間 | **法定内残業**。36協定も上限規制も割増賃金も不要 |
| 7時間 | 9時間 | 8時間を超えた**1時間**だけが時間外労働 |

**休日労働を含むか**

| 上限 | 休日労働 |
|---|---|
| 月45時間・年360時間 | 含まない |
| **年720時間** | **含まない** |
| 月100時間未満 | **含む** |
| 2〜6か月平均80時間以内 | **含む** |

**45時間を超えたらどうなるか**

| 状況 | どうなるか |
|---|---|
| 特別条項がないのに超えた | 免罰効果が及ばず **32条違反** |
| 特別条項があり枠内 | **適法**。月60時間超の分は**5割以上**の割増賃金 |
| 特別条項があっても枠外 | **36条6項違反** |

> ★限度時間そのものには直接の罰則がありません。36条3項が「協定で定める延長時間は**限度時間を超えない時間に限る**」としているので協定が無効になり、結果として32条違反になります。
> ★36条6項は**使用者を直接縛る**規定なので、協定が適法でも実際の労働時間が超えれば違法です。
> ★**1日の上限はありません**。ただし**坑内労働その他健康上特に有害な業務**は**1日2時間**まで（36条6項1号）。

### 賃金の相殺 — 3つの判例と調整的相殺（→ 賃金の相殺）

| 事件 | 場面 | 結論 |
|---|---|---|
| **シンガー・ソーイング・メシーン**（昭48.1.19） | 退職金債権の**放棄** | 有効 |
| **日新製鋼**（平2.11.26） | 退職金からの**相殺の合意** | 有効 |
| **山梨県民信用組合**（平28.2.19） | **就業規則の不利益変更**への同意 | **認められず** |

いずれも「**自由な意思に基づくと認めるに足りる合理的な理由が客観的に存在するか**」で判断します。**山梨県民信用組合事件だけが同意を認めませんでした**（不利益の内容を具体的に説明していなかったため）。

**調整的相殺に同意が要らない理由**（福島県教組事件・昭44.12.18）

24条1項が禁じるのは、賃金と**別口の債権**をぶつけることです。過払いの清算は**賃金額を正しく計算し直しているだけ**なので、同意を要する相殺に当たりません。

| | 同意 | 判断基準 |
|---|---|---|
| **調整的相殺**（過払いの清算） | **不要** | **時期・方法・金額** → 経済生活の安定を脅かさないか |
| **別口の債権との相殺** | **必要** | 自由な意思に基づく合理的な理由が客観的に存在するか |

### 金品の返還（23条）（→ 賃金支払の5原則）

> 使用者は、労働者の**死亡又は退職**の場合において、**権利者の請求**があつた場合においては、**7日以内**に賃金を支払い、…**労働者の権利に属する金品を返還**しなければならない。

| | |
|---|---|
| きっかけ | **権利者の請求**（請求がなければ通常の支払日で足りる） |
| 期限 | **7日以内** |
| 争いがあるとき | **異議のない部分**を7日以内に（2項） |
| 罰則 | **120条**（30万円以下の罰金のみ） |

> ★**解雇予告手当は23条の「金品」に当たりません**。ここが択一で問われています。
> ★退職金は、就業規則等で支払時期が定められていればその時期で足ります。

### 出来高払制の保障給（27条）（→ 賃金支払の5原則）

> 出来高払制その他の請負制で使用する労働者については、使用者は、**労働時間に応じ**一定額の賃金の保障をしなければならない。

> ★**令和元年度の選択式**で「**労働時間**」が空欄でした。「**出来高に応じ**」ではありません。
> ★休業手当（26条）は**使用者の責めに帰すべき休業**、27条は**仕事はしたが出来高が少ない**とき。額は通達で平均賃金の60%程度が目安。

### 定額残業代（→ 労働時間該当性）

**37条が定めているのは割増賃金の「額」だけで、支払い方は決めていない**ので許されます。

| | 要件 |
|---|---|
| ① | **判別できること**（通常の労働時間の賃金と割増賃金の部分） |
| ② | **対価性**（時間外労働の対価であること） |
| ③ | **差額の支払**（定額を超えたら必ず払う） |

②の判断要素は**契約書等の記載・労働者への説明・実際の勤務状況**（**日本ケミカル事件** 平30.7.19）。

> ★同事件は**「何時間分か」の明示までは求めていません**（原審の判断を否定）。
> ★**国際自動車事件**（令2.3.30）は、**歩合給から割増賃金相当額を差し引く**しくみを割増賃金の支払と認めませんでした。
> ★**求人では時間数の明示が必要**です（職業安定法5条の3と省令・指針）。労基法上は不要なのと対照的。

### 労働者の定義 — 労組法はなぜ広いか（→ 労働者性）

| 法律 | 条文 |
|---|---|
| **労基法9条** | 職業の種類を問わず、**事業に使用される者で、賃金を支払われる者** |
| **労働契約法2条** | **使用者に使用されて労働し、賃金を支払われる者** |
| **労組法3条** | 職業の種類を問わず、**賃金、給料その他これに準ずる収入によつて生活する者** |

労組法3条には「**使用される**」が入っていません。だから**失業者も労組法上は労働者**です。

**労組法上の労働者性の判断要素**（平成23年 労使関係法研究会報告）

| | 要素 |
|---|---|
| **基本** | ① 事業組織への**組入れ** ② 契約内容の**一方的・定型的決定** ③ 報酬の労務対価性 |
| **補充** | ④ 業務の依頼に応ずべき関係 ⑤ **広い意味での**指揮監督・時間的場所的拘束 |
| **否定** | ⑥ **顕著な事業者性** |

**最高裁**：CBC管弦楽団（昭51.5.6）、**新国立劇場運営財団**・**INAXメンテナンス**（どちらも平23.4.12）、ビクターサービスエンジニアリング（平24.2.21）。いずれも労組法上の労働者性を認めています。

**規模の要件は一つもありません。**「常時10人以上」「常時100人以上」と付いていたら誤りです。

| 項 | 周知するもの |
|---|---|
| 1項 | この法律及びこれに基づく命令の**要旨** |
| 2項 | **産業医の業務の内容**その他産業医の業務に関する事項（**産業医への健康相談の申出の方法**を含む） |
| 3項 | 2項を、産業医を選任しない50人未満の事業場の医師等に準用（**努力義務**に読み替え） |
| 4項 | 57条の2で通知された事項（**SDS**） |

- **安全管理者・衛生管理者**の業務内容の周知義務は**ありません**。101条にあるのは**産業医だけ**。
- **労働災害の発生状況・原因**の周知義務も101条には**ありません**。

### 不正受給者からの費用徴収（労災12条の3）（→ 支給制限と第三者行為）

31条（**事業主**から取る）とは**別の条**です。

- 1項 偽りその他不正の手段により保険給付を受けた者から、費用の**全部又は一部**を徴収できる。
- 2項 **事業主が虚偽の報告又は証明をした**ためその給付が行われたときは、事業主に対し、**受給者と連帯して**納付すべきことを**命ずることができる**。

事業主だけから取るのではなく、**本人と連帯**です。徴収法27条・29条・30条・41条が準用されます。

### 就職への努力（雇保10条の2）（→ 基本手当の受給要件）

> **求職者給付**の支給を受ける者は、必要に応じ**職業能力の開発及び向上**を図りつつ、**誠実かつ熱心に求職活動**を行うことにより、職業に就くように努めなければならない。

選択式で「誠実かつ熱心に」が空欄になり得ます。対象は**求職者給付**の受給者に限られます。

### 特定作業従事者の細目（労災則46条の18）（→ 特別加入）

第2種の「特定作業従事者」は省令が**5種類**を列挙しています。**数値が引っかけ**です。

| 号 | 作業 | 押さえる点 |
|---|---|---|
| 1号 農業 | 動力機械／**高さ2メートル以上**／酸欠危険場所／農薬散布／牛・馬・豚に接触 のいずれか（特定農作業従事者）、厚労大臣が定める機械を使うもの（指定農業機械作業従事者） | **2メートル**。「1メートル」は誤り |
| 2号 職業訓練 | **求職者**を作業環境に適応させる訓練、求職者の技能習得の職業訓練で事業主等に委託されたもの | 在職者ではない |
| 3号 家内労働者 | 家内労働者**及び補助者**が行うプレス機械・研削盤・有機溶剤・粉じん・動力織機・木工機械等の作業 | 補助者も対象 |
| 4号 労働組合等の一人専従役員 | **常時労働者を使用しない**労働組合等の**常勤の役員**の活動に係る作業（**必要な移動を含む**） | |
| 5号 介護・家事支援従事者 | 炊事・洗濯・掃除・買物・**児童の日常生活上の世話及び必要な保護**等 | |

### 事業所の届出（雇用則141条・142条）（→ 被保険者と適用）

| 届出 | 期限 |
|---|---|
| 事業所の**設置・廃止**（記載事項＝名称及び所在地／**事業の種類**／被保険者数／理由／年月日） | その日の**翌日から起算して10日以内** |
| 事業主の**氏名・住所**、事業所の**名称及び所在地**、**事業の種類**の**変更** | 変更の日の**翌日から起算して10日以内** |

### 遺族補償一時金の順位（労災16条の7）（→ 障害・遺族給付）

**年金**の順位とは**別**です。

| 順位 | 遺族 |
|---|---|
| 1 | **配偶者**（生計維持を問わない） |
| 2 | 生計を**維持していた** 子・父母・孫・祖父母 |
| 3 | 生計を維持していなかった 子・父母・孫・祖父母 **及び兄弟姉妹** |

> 「生計を維持していた父母は、生計を維持していなかった配偶者より先順位」は**誤り**。配偶者は常に第1順位。**兄弟姉妹は第3順位のみ**。

### 傷病等級に変更があったとき（労災18条の2）（→ 療養・休業給付）

新たに他の傷病等級に該当するに至ったときは、**新たな等級に応ずる傷病補償年金を支給するものとし**、従前のものは支給しない。「所轄労働基準監督署長が**裁量により**決定できる」は**誤り**（**義務**であり、**職権**で行う）。

### 雇用保険の行政庁の権限（78条・79条・79条の3）（→ 雇用保険法）

| 条 | 中身 | 主体 |
|---|---|---|
| 78条 診断 | 証明書による失業の認定を受ける者・受給期間延長の申出をした者・**傷病手当**を受けようとする者に、**指定する医師の診断**を命じられる | **行政庁** |
| 79条 立入検査 | 事業主の事業所・**労働保険事務組合**の事務所へ立入り、質問・帳簿検査。身分証を携帯し提示。**犯罪捜査のためのものと解してはならない** | **行政庁** |

| 示談で賠償を受けた | その**限度で保険給付を行わない** |

> ★**通勤中の事故は労災**なので健康保険からは給付されません。

### 保険料の一部納付があったときの按分（健保159条の2・厚年86条の2）（→ 標準報酬と保険料）

### 国民年金基金の年金の支給停止（国年131条）（→ 遺族基礎年金と独自給付）

基金の年金は原則として**止められません**。止められるのは①**老齢基礎年金が全額支給停止**されているとき、②**200円×加入員期間の月数を超える部分**、のいずれか。

> **200円**です。「400円」は誤り。付加年金の「200円×納付月数」と同じ数字です。

### 国民健康保険組合の清算人（国保法32条の4）（→ 国民健康保険と高齢者医療）

組合が解散したとき（破産手続開始の決定による解散を除く）、清算人になるのは**理事**です。「**監事**がその清算人となる」は**誤り**。規約に別段の定めがあるとき、組合会が理事以外を選任したときは別です。

### 社労士法人の設立と登録拒否事由（14条の7・25条の11）（→ 社会保険労務士法）

- **設立**は、社員になろうとする社労士が**定款を定め**、主たる事務所の所在地で**設立の登記をすることによって成立**します。**厚生労働大臣の認可は要りません**（準則主義）。成立後**2週間以内**に社労士会経由で連合会へ届出。
- **登録拒否事由**の1号は、懲戒処分により**弁護士・公認会計士・税理士・行政書士**の業務を停止され、**現にその処分を受けている**者。**司法書士・中小企業診断士は入りません**。

### 確定給付企業年金の基金の分割・解散と連合会（77条・85条・91条の5）（→ 企業年金と社会保険審査）

### 国保の保険給付の一時差止め（国保63条の2）（→ 国民健康保険と高齢者医療）

- **1項**（納期限から**1年6か月**経過するまでの間に勧奨等をしてもなお納付しない）＝「**するものとする**」＝**原則として義務**。**災害その他特別の事情**があれば行わない。
- **2項**（期間が経過していない場合）＝「**できる**」＝**任意**。
- **3項** 差し止められた給付から**滞納保険料額を控除**するには、**あらかじめ通知**が必要。

### 健康保険組合への国庫負担金（健保152条）（→ 保険者と費用負担）

**被保険者数を基準**として厚生労働大臣が算定し、**概算払をすることができる**。「保険料収入を基準」は誤り。

### 受給権取得後に配偶者を有するに至ったとき（厚年50条の2第3項）（→ 障害・遺族厚生年金）

障害厚生年金（1級・2級）の受給権を**取得した日の翌日以後**に、生計維持されている**65歳未満の配偶者**を有するに至ったときは、**その日の属する月の翌月**から額を改定します。平成23年4月からの取扱いです。障害基礎年金の**子の加算**も同じ考え方（国年33条の2第3項）。

### 受給権者の行為による支給停止（厚年77条）（→ 給付の通則と受給権の保護）

**額の全部又は一部につき支給を停止することができる**（＝**任意**）。①受給権者が**正当な理由がなくて**命令に従わず、又は職員の**質問に応じなかった**とき ②障害の状態にある者・加算対象の**子**が命令に従わず、又は**診断を拒んだ**とき ③②の者が故意・重過失等により**障害の回復を妨げた**とき。

### 過料の横断（→ 横断整理）

**過料**は行政上の秩序罰で、**前科になりません**。**科料**（刑罰・1,000円以上1万円未満）とは別物です。

### 国民年金基金が支給する年金・一時金の下限（国年130条）（→ 遺族基礎年金と独自給付）

**200円**は付加年金と、**8,500円**は死亡一時金の付加保険料加算と同じ数字です。131条（支給停止の限度）と混同しないこと。

### 支払基金の業務方法書（高確法141条）（→ 企業年金と社会保険審査）

支払基金は、高齢者医療制度関係業務について、**業務の開始前に業務方法書を作成し、厚生労働大臣の認可**を受けます。変更も同様。**届出ではありません**。

### 協会の重要な財産の処分（健保7条の34）（→ 保険者と費用負担）

省令で定める**重要な財産**を譲渡し、又は担保に供しようとするときは、**厚生労働大臣の認可**が必要です。届出ではありません。

### 企業年金連合会の業務報告（DB法100条の2）（→ 企業年金と社会保険審査）

連合会は**毎事業年度終了後6か月以内**に業務についての報告書を作成し、厚生労働大臣に提出します。

- **142条の2** 基金に係る厚生労働大臣の権限は、一部を**地方厚生局長**に委任でき、さらに**地方厚生支局長**に委任できます。

### 匿名診療等関連情報と収納職員（健保150条の10・則158条の27）（→ 不服申立て・時効・雑則）

- **手数料**は**実費を勘案して政令で定める額**を**国**（基金等が提供事務の全部を行う場合は**基金等**）に納めます。政令では提供に要する時間**1時間までごとに4,350円**。**都道府県**等は減免されることがあります。
- **収納職員の交替**では、前任者は**交替の日の前日**をもって収納簿を締め切ります。「交替の日をもって」は**誤り**。検査員は**機構の理事長**が年金事務所ごとに機構職員から命じます。

### 船長等の代理（厚年則29条の2）（→ 適用事業所と被保険者）

船員被保険者の資格取得・喪失等の届出について、**船舶所有者は船長又は船長の職務を行う者を代理人として処理させることができます**。「機関長」ではありません。義務ではなく**できる**規定です。

### 基金の徴収金に係る罰則と裁定請求の特例（国年111条の3・則16条の5）（→ 届出・時効・不服申立て）

- **111条の3** 解散した基金・連合会が責任準備金相当額を督促状の期限までに納付しないとき、**違反行為をした者**は**6月以下の拘禁刑又は50万円以下の罰金**。**両罰規定**で法人にも罰金。
- **則16条の5** 特別支給の老齢厚生年金の受給権者が**65歳に達する日の属する月の前月まで**に繰上げ支給の老齢基礎年金を請求するときは、**記載事項の簡略化された請求書**でよい。

### 特定疾病の特例（長期高額疾病）（→ 高額療養費と傷病手当金）

毎月必ず高額の治療費がかかる病気は、**自己負担限度額が月1万円**に据え置かれます。

| 対象 | 限度額 |
|---|---|
| **人工腎臓**を実施する**慢性腎不全** | **10,000円**。ただし**70歳未満**で**標準報酬月額53万円以上**は**20,000円** ⚠️要確認 |
| **血友病**（先天性血液凝固因子障害） | **10,000円** |
| **抗ウイルス剤を投与している後天性免疫不全症候群** | **10,000円** |

**2万円になるのは人工透析だけ**です。**70歳以上**は人工透析でも1万円。**特定疾病療養受療証**の交付を受けて窓口に提示します。

### 第3種被保険者期間の特例（坑内員・船員）（→ 老齢厚生年金）

| 実際の期間 | 数え方 |
|---|---|
| 昭和61年3月31日以前 | **3分の4倍** ⚠️要確認 |
| 昭和61年4月1日〜平成3年3月31日 | **5分の6倍** ⚠️要確認 |
| 平成3年4月1日以後 | **実期間のまま** |

「必ず3分の4倍又は5分の6倍される」は**誤り**。**平成3年4月1日以後は実期間**で、**経過的加算の計算では割り増しません**。

### 他の法令による給付との調整（健保55条・128条）（→ 療養の給付と一部負担金）

| 相手 | 扱い |
|---|---|
| **労災保険・国家公務員災害補償法・地方公務員災害補償法** | 健保は**行わない**。「**受けることができる場合**」なので、**請求していなくても**出ません |
| **公害健康被害の補償等に関する法律** | 支給された**価額の限度で**、健保の相当する給付を行わない |
| 他の医療保険各法（国保を除く）・介護保険法 | 日雇特例被保険者について二重に受けられる場合は行わない（128条） |

**出産育児一時金・出産手当金は55条1項の列挙に入っていません**（日雇特例被保険者の128条には入っています）。

### 療養の給付の対象にならないもの（→ 療養の給付と一部負担金）

**健康診断・予防接種・正常な妊娠出産・経済上の理由による人工妊娠中絶・美容整形・単なる疲労**は対象外です。業務災害・通勤災害は労災から出ます（55条）。

> **定期健康診断で初めて結核症と診断された患者**について、そのときの**ツベルクリン反応・血沈検査・エックス線検査等の費用も対象外**です。異常が見つかった**後の治療**からが保険給付です。

逆に、**不妊治療**は**令和4年4月**から**一般不妊治療**（タイミング法・人工授精）と**生殖補助医療**（体外受精・顕微授精）が保険適用になりました。ただし**医療上必要と認められず、患者の都合による**ものは対象外です。

### 保険者算定（健保44条）（→ 標準報酬と保険料）

通常の計算では**著しく不当**になるときに、保険者が別の方法で算定します。

| 場面 | 扱い |
|---|---|
| 4〜6月に**季節的に報酬が変動**（定時決定） | **年間平均**で算定（**被保険者の同意と事業主の申立て**が必要） |
| 給与計算期間の**途中で入社**した月 | その月を**除く** |
| **低額の休職給**・**ストライキによる賃金カット**があった月 | その月を**除く** |
| **さかのぼって昇給・降給**（随時改定） | **差額調整が行われた月を起算月**として、それ以後継続した3か月で算定。**遡及分（超過支給分・降給差額分）はその月の報酬から除く** |

遡及分をそのまま含めると等級が跳ねるので、**遡及分を除いた本来の月額**で3か月を見ます。**支払基礎日数17日以上**の要件は保険者算定でも同じです。

### 国民年金の適用除外 — 短期滞在の外国人（→ 被保険者と資格得喪）

**日本国籍を有しない者**で、入管法に基づき**法務大臣が定める活動**のうち**本邦において1年を超えない期間滞在**し、**観光、保養その他これらに類似する活動**を行うものは、国内に住所があっても**第1号被保険者になりません**。

> **1年を超えない**期間です。1年を超えて滞在するなら**被保険者になります**。**日本国籍を有する者には適用されません**。

### 脱退一時金相当額の移換（ポータビリティ）（→ 企業年金と社会保険審査）

確定給付企業年金の**中途脱退者**は、**転職先の規約にあらかじめ定めがあり本人が申し出た**ときに、他のDB・確定拠出年金・企業年金連合会・中小企業退職金共済へ移換できます。移換の申出をすると、移換元での**脱退一時金の支給を受ける権利は消滅**します。「本人が希望すれば必ず移換できる」は誤りです。

### 休職と被保険者資格（→ 適用事業所と被保険者）

**使用関係が続いているか**で判断します。賃金が出ているかどうかではありません。

| 場面 | 資格 |
|---|---|
| **病気休職**（賃金の支払停止は一時的、使用関係は存続） | **喪失しない**。**保険料はかかります**（休職直前の標準報酬月額で計算） |
| **長期にわたる休職状態が続き実務に服する見込がない** | **喪失する** |
| **公務に就任しこれに専従する** | **喪失する** |

「報酬がないから保険料も生じない」は**誤り**。休職により**標準報酬月額は下がりません**（固定的賃金の変動ではない）。ただし**一時帰休**で休業手当が継続して支払われる場合は随時改定の対象になります。

### 「同一性質を有するもの」も報酬（健保3条5項）（→ 標準報酬と保険料）

**名称が異なっても、同一性質を有すると認められるもの**は報酬に含めます。逆に、名称が「手当」でも**実費弁償や恩恵的給付**は含めません。**現物給与**（食事・住宅・定期券）も報酬で、価額は**事業所の所在地の都道府県**について厚生労働大臣が定めるものによります。

### 海外赴任に同行する家族の被扶養者認定（→ 被扶養者とその他の給付）

国内居住要件の例外に当たるかは、**「家族帯同ビザ」の確認により判断することを基本**とし、渡航先国で家族帯同ビザの**発行がない**場合は、発行されたビザが**就労目的でないこと**を確認して判断します。**両親が同行する場合**も同じです。

## 国年・厚年

### 積立金の運用の目的（国年75条・厚年79条の2）（→ 年金額の改定とマクロ経済スライド）

> 積立金の運用は、積立金が**被保険者から徴収された保険料の一部**であり、かつ、**将来の給付の貴重な財源**となるものであることに特に留意し、**専ら被保険者の利益のために、長期的な観点から、安全かつ効率的に**行うことにより、将来にわたつて、**事業の運営の安定**に資することを目的として行うものとする。

> ★**令和3年度の選択式で出ています。**「将来の給付の貴重な財源」「専ら…被保険者の利益のために」「長期的な観点から、安全かつ効率的に」「事業の運営の安定」が空欄になりました。
> ★「**専ら被保険者の利益のために**」であって、国の財政のためではありません。

### 全額免除申請の事務手続の特例（国年109条の2）（→ 保険料と免除）

| | |
|---|---|
| 誰が指定するか | **厚生労働大臣**（本人からの申請に基づく） |
| 何ができるか | 委託を受けて**全額免除申請を行う**（**指定全額免除申請事務取扱者**） |
| 効果 | **委託をした日に申請があったものとみなす** |

> ★学生納付特例にも同じ形があります（**指定学生納付特例事務取扱者**・109条の2の2）。学校等が指定を受けます。
> ★**委託した日**にみなされます。取扱者が実際に手続をした日ではありません。

### 市町村への交付金（厚年86条5項）（→ 標準報酬と保険料）

保険料等を**市町村税の例によって処分**した場合、厚生労働大臣は**徴収金の100分の4**を当該市町村に交付しなければなりません。国民年金にも同じしくみがあります（国年95条・96条）。

### 社会保障協定（→ 老齢基礎年金）

| | |
|---|---|
| **二重加入の防止** | 派遣が**5年以内**の見込みなら**派遣元の国**の制度にのみ加入 |
| **期間の通算** | 協定相手国の加入期間を**受給資格期間に通算**できる |
| 通算した期間の扱い | **合算対象期間（カラ期間）**。**年金額には反映されない** |
| 通算の規定がない協定 | **イギリス・韓国・イタリア・中国** |

> ★通算されるのは**受給資格期間だけ**。相手国に納めた保険料が日本の**年金額の計算に入ることはありません**（令和7年度の択一）。

### 「離婚等」に何が入るか（→ 離婚時分割と脱退一時金）

| | 合意分割 | 3号分割 |
|---|---|---|
| 離婚（届出） | ○ | ○ |
| 婚姻の取消し | ○ | ○ |
| **事実婚の解消**（第3号被保険者であった期間に限る） | ○ | ○ |
| **事実上の離婚**（届出はないが共同生活が営まれていない） | ○ | ○ |

> ★**届出がなくても、事実上離婚したと同様の事情があれば請求できます**（択一で出題）。

### 死亡の推定（国年18条の3・厚年59条の2）（→ 遺族基礎年金と独自給付／障害・遺族厚生年金）

| 場面 | 死亡したものと推定される日 |
|---|---|
| **船舶**が沈没・転覆・滅失・行方不明となった際に乗っていた者の**生死が3か月間わからない** | **その船舶が沈没等をした日** |
| 船舶に乗っていて**航行中に行方不明**となった者 | **その者が行方不明となった日** |
| **航空機**が墜落・滅失・行方不明となった際に乗っていた者 | **その航空機が墜落等をした日** |
| 航空機に乗っていて航行中に行方不明となった者 | **その者が行方不明となった日** |

死亡が**3か月以内に明らかとなり、かつ死亡の時期がわからない**場合も同じです。

- 推定される日は**事故の日／行方不明になった日**です。**3か月が経過した日ではありません**。ここが引っかけの定番。
- 船舶は**沈没・転覆・滅失・行方不明**の4つ、航空機は**墜落・滅失・行方不明**の3つ（航空機に「転覆」はない）。
- 国年は「**死亡を支給事由とする給付**」＝遺族基礎年金・寡婦年金・死亡一時金すべて。厚年は「**遺族厚生年金**の支給に関する規定の適用について」と限定。
- **失踪宣告**（民法30条・普通失踪7年）とは別のしくみです。

### 先取特権の順位（厚年88条）（→ 給付の通則と受給権の保護）

厚年88条・健保182条・国年96条4項・徴収法29条は**すべて「国税及び地方税に次ぐ」**で同じです。「優先する」「同順位」はいずれも誤りです。

### 生計維持の年収要件 — 850万円

遺族給付・加給年金額などの「**生計を維持していた**」の認定は、**生計同一**であることに加えて、**収入が将来にわたって年収850万円未満（所得655万5千円未満）**であることが基準です。

| 場面 | 扱い |
|---|---|
| 死亡当時は850万円以上だったが、**おおむね5年以内に850万円未満になると認められる**とき | **生計維持あり**とされる |
| 死亡当時850万円以上で受給権を得られず、**その後に収入が下がった** | **さかのぼって受給権は生じない** |

> ★**過去9年で6回**、健保・厚年・国年をまたいで出ています。
> ★「あとから収入が下がれば受給権が発生する」は**誤り**です。判定は**死亡当時**を基準にします。
