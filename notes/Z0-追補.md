## 労基

### 総則の罰則 — 拘禁刑だけでなく罰金もある（→ 労働基準法「総則の7原則」）

「6か月以下の拘禁刑等」と「等」で伏せていました。労基法の罰則は**すべて「拘禁刑または罰金」の選択刑**です。

| 条 | 内容 | 罰則 |
|---|---|---|
| **1条** | 労働条件の原則 | **なし**（訓示規定） |
| **2条** | 労使対等の原則 | **なし**（訓示規定） |
| 3条 | 均等待遇 | 6か月以下の拘禁刑／**30万円以下の罰金**（119条） |
| 4条 | 男女同一賃金 | 同上 |
| **5条** | 強制労働の禁止 | **1年以上10年以下**の拘禁刑／**20万円以上300万円以下**の罰金（117条）＝最重 |
| 6条 | 中間搾取の排除 | 1年以下の拘禁刑／**50万円以下の罰金**（118条） |
| 7条 | 公民権行使の保障 | 6か月以下の拘禁刑／30万円以下の罰金（119条） |

> ★**5条だけが下限つき**（「1年以上」「20万円以上」）。労基法でここだけの形です。
> ★**1条・2条には罰則がありません**。7原則のうち罰則があるのは**3条〜7条の5つ**。

**罰則の段**

| 条 | 刑 | 主な対象 |
|---|---|---|
| 117条 | 1年以上10年以下の拘禁刑／20万円以上300万円以下の罰金 | 5条 |
| 118条 | 1年以下の拘禁刑／50万円以下の罰金 | 6条、56条、63条、64条の2 |
| 119条 | 6か月以下の拘禁刑／30万円以下の罰金 | 3条・4条・7条、16条〜20条、32条〜39条 ほか |
| **120条** | **30万円以下の罰金のみ**（拘禁刑なし） | 14条、15条、23条〜27条、**89条**、**106条** ほか |

> ★**120条だけ拘禁刑がありません**。就業規則の作成届出（89条）、法令等の周知（106条）はここ。

### 寄宿舎（94条〜96条の3）（→ 労働基準法に新しい節）

**9年で2回出ています**（令和2年度の選択式で空欄A、令和6年度の択一）。条文は5つだけです。

| 条 | 内容 |
|---|---|
| **94条** | **私生活の自由を侵してはならない**／**寮長・室長等の役員の選任に干渉してはならない** |
| **95条** | **寄宿舎規則**の作成・届出（下記） |
| **96条** | 換気、採光、照明、保温、防湿、清潔、避難、定員の収容、就寝に必要な措置その他**健康・風紀・生命の保持**に必要な措置 |
| **96条の2** | 設置・移転・変更の**届出**（下記） |
| **96条の3** | 基準違反のとき、行政官庁は**使用の停止・変更等を命ずる**ことができる。**労働者に対しても命令できる** |

**95条 寄宿舎規則の5事項**

| 号 | 事項 | 過半数代表者の同意 |
|---|---|---|
| 1号 | 起床、就寝、外出及び外泊 | **必要** |
| 2号 | 行事 | **必要** |
| 3号 | 食事 | **必要** |
| 4号 | 安全及び衛生 | **必要** |
| **5号** | **建設物及び設備の管理** | **不要** |

> ★同意が要るのは**1号〜4号**だけ。**5号には要りません**。ここが最頻出。
> ★届出には**同意を証明する書面を添付**します（95条3項）。
> ★**使用者だけでなく、寄宿する労働者にも遵守義務**があります（95条4項）。

**96条の2 届出（令和2年度の選択式で出題）**

> 常時**10人以上**の労働者を就業させる事業、危険な事業又は衛生上有害な事業の附属寄宿舎を設置・移転・変更しようとする場合、計画を**工事着手14日前まで**に行政官庁に届け出る。

> ★正答が「**工事着手14日前まで**」でした。安衛法88条の計画届（**30日前**／14日前）と混同しないこと。

### 36協定の上限は2段（→ 36協定と上限規制）

```
① 原則の枠（限度時間・36条4項）  1か月45時間 ／ 1年360時間
        │ 臨時的な特別の事情があるときだけ超えられる
        ↓
② 特別条項の絶対的上限（36条6項） 年720時間／月100時間未満／2〜6か月平均80時間以内
                                  45時間を超えてよいのは年6回まで
```

**数えるのは「法定労働時間（1日8時間・1週40時間）を超えた時間」**です。所定を超えた時間ではありません。

| 所定 | 実労働 | 扱い |
|---|---|---|
| 7時間 | 8時間 | **法定内残業**。36協定も上限規制も割増賃金も不要 |
| 7時間 | 9時間 | 8時間を超えた**1時間**だけが時間外労働 |

**休日労働を含むか**

| 上限 | 休日労働 |
|---|---|
| 月45時間・年360時間 | 含まない |
| **年720時間** | **含まない** |
| 月100時間未満 | **含む** |
| 2〜6か月平均80時間以内 | **含む** |

**45時間を超えたらどうなるか**

| 状況 | どうなるか |
|---|---|
| 特別条項がないのに超えた | 免罰効果が及ばず **32条違反** |
| 特別条項があり枠内 | **適法**。月60時間超の分は**5割以上**の割増賃金 |
| 特別条項があっても枠外 | **36条6項違反** |

> ★限度時間そのものには直接の罰則がありません。36条3項が「協定で定める延長時間は**限度時間を超えない時間に限る**」としているので協定が無効になり、結果として32条違反になります。
> ★36条6項は**使用者を直接縛る**規定なので、協定が適法でも実際の労働時間が超えれば違法です。
> ★**1日の上限はありません**。ただし**坑内労働その他健康上特に有害な業務**は**1日2時間**まで（36条6項1号）。

### 賃金の相殺 — 3つの判例と調整的相殺（→ 賃金の相殺）

| 事件 | 場面 | 結論 |
|---|---|---|
| **シンガー・ソーイング・メシーン**（昭48.1.19） | 退職金債権の**放棄** | 有効 |
| **日新製鋼**（平2.11.26） | 退職金からの**相殺の合意** | 有効 |
| **山梨県民信用組合**（平28.2.19） | **就業規則の不利益変更**への同意 | **認められず** |

いずれも「**自由な意思に基づくと認めるに足りる合理的な理由が客観的に存在するか**」で判断します。**山梨県民信用組合事件だけが同意を認めませんでした**（不利益の内容を具体的に説明していなかったため）。

**調整的相殺に同意が要らない理由**（福島県教組事件・昭44.12.18）

24条1項が禁じるのは、賃金と**別口の債権**をぶつけることです。過払いの清算は**賃金額を正しく計算し直しているだけ**なので、同意を要する相殺に当たりません。

| | 同意 | 判断基準 |
|---|---|---|
| **調整的相殺**（過払いの清算） | **不要** | **時期・方法・金額** → 経済生活の安定を脅かさないか |
| **別口の債権との相殺** | **必要** | 自由な意思に基づく合理的な理由が客観的に存在するか |

### 定額残業代（→ 労働時間該当性）

**37条が定めているのは割増賃金の「額」だけで、支払い方は決めていない**ので許されます。

| | 要件 |
|---|---|
| ① | **判別できること**（通常の労働時間の賃金と割増賃金の部分） |
| ② | **対価性**（時間外労働の対価であること） |
| ③ | **差額の支払**（定額を超えたら必ず払う） |

②の判断要素は**契約書等の記載・労働者への説明・実際の勤務状況**（**日本ケミカル事件** 平30.7.19）。

> ★同事件は**「何時間分か」の明示までは求めていません**（原審の判断を否定）。
> ★**国際自動車事件**（令2.3.30）は、**歩合給から割増賃金相当額を差し引く**しくみを割増賃金の支払と認めませんでした。
> ★**求人では時間数の明示が必要**です（職業安定法5条の3と省令・指針）。労基法上は不要なのと対照的。

### 労働者の定義 — 労組法はなぜ広いか（→ 労働者性）

| 法律 | 条文 |
|---|---|
| **労基法9条** | 職業の種類を問わず、**事業に使用される者で、賃金を支払われる者** |
| **労働契約法2条** | **使用者に使用されて労働し、賃金を支払われる者** |
| **労組法3条** | 職業の種類を問わず、**賃金、給料その他これに準ずる収入によつて生活する者** |

労組法3条には「**使用される**」が入っていません。だから**失業者も労組法上は労働者**です。

**労組法上の労働者性の判断要素**（平成23年 労使関係法研究会報告）

| | 要素 |
|---|---|
| **基本** | ① 事業組織への**組入れ** ② 契約内容の**一方的・定型的決定** ③ 報酬の労務対価性 |
| **補充** | ④ 業務の依頼に応ずべき関係 ⑤ **広い意味での**指揮監督・時間的場所的拘束 |
| **否定** | ⑥ **顕著な事業者性** |

**最高裁**：CBC管弦楽団（昭51.5.6）、**新国立劇場運営財団**・**INAXメンテナンス**（どちらも平23.4.12）、ビクターサービスエンジニアリング（平24.2.21）。いずれも労組法上の労働者性を認めています。

## 国年・厚年

### 積立金の運用の目的（国年75条・厚年79条の2）（→ 年金額の改定とマクロ経済スライド）

> 積立金の運用は、積立金が**被保険者から徴収された保険料の一部**であり、かつ、**将来の給付の貴重な財源**となるものであることに特に留意し、**専ら被保険者の利益のために、長期的な観点から、安全かつ効率的に**行うことにより、将来にわたつて、**事業の運営の安定**に資することを目的として行うものとする。

> ★**令和3年度の選択式で出ています。**「将来の給付の貴重な財源」「専ら…被保険者の利益のために」「長期的な観点から、安全かつ効率的に」「事業の運営の安定」が空欄になりました。
> ★「**専ら被保険者の利益のために**」であって、国の財政のためではありません。

### 全額免除申請の事務手続の特例（国年109条の2）（→ 保険料と免除）

| | |
|---|---|
| 誰が指定するか | **厚生労働大臣**（本人からの申請に基づく） |
| 何ができるか | 委託を受けて**全額免除申請を行う**（**指定全額免除申請事務取扱者**） |
| 効果 | **委託をした日に申請があったものとみなす** |

> ★学生納付特例にも同じ形があります（**指定学生納付特例事務取扱者**・109条の2の2）。学校等が指定を受けます。
> ★**委託した日**にみなされます。取扱者が実際に手続をした日ではありません。

### 生計維持の年収要件 — 850万円

遺族給付・加給年金額などの「**生計を維持していた**」の認定は、**生計同一**であることに加えて、**収入が将来にわたって年収850万円未満（所得655万5千円未満）**であることが基準です。

| 場面 | 扱い |
|---|---|
| 死亡当時は850万円以上だったが、**おおむね5年以内に850万円未満になると認められる**とき | **生計維持あり**とされる |
| 死亡当時850万円以上で受給権を得られず、**その後に収入が下がった** | **さかのぼって受給権は生じない** |

> ★**過去9年で6回**、健保・厚年・国年をまたいで出ています。
> ★「あとから収入が下がれば受給権が発生する」は**誤り**です。判定は**死亡当時**を基準にします。

## この追補の作り方

各科目の資料と本試験データ（過去9年）を次の観点で突き合わせて、抜けを見つけたものです。

| 観点 | 道具 | 結果 |
|---|---|---|
| 出題された条が資料にあるか | `cover_all.py` | 0件 |
| 条番号は出るが**解説が無い**もの | 同上（後から追加した観点） | 0件 |
| 選択式の正答語（302語） | `cover2.py` | 0件 |
| 択一に4回以上出た**数値** | 数値の突き合わせ | **850万円**を発見 |
| 書いた数値が条文どおりか | `factcheck.py` | 169件すべて一致 |

> 寄宿舎が抜けていたのに検査が0件と言っていたのは、**自動生成の傾向表に条番号が載っていた**ためです。生成部分を除いて数えるよう直しました。
