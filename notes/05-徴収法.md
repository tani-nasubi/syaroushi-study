## 目的条文（1条）

> この法律は、労働者災害補償保険及び雇用保険（以下「労働保険」という。）の事業の**効率的な運営**を図るため、
> 労働保険の**保険関係の成立及び消滅**、労働保険料の**納付の手続**、労働保険事務組合等に関し必要な事項を定めるものとする。

**キーワード**：「**効率的な運営**」「**保険関係の成立及び消滅**」「**納付の手続**」

> 労災保険法・雇用保険法の目的条文と違い、**労働者の保護ではなく「事務の効率化」**が目的である点が特徴です。
> 徴収法は選択式の独立科目ではありませんが、**労災・雇用の選択式で目的条文が問われた実績があります**
> （令和6年度 労災、令和元年度 労災、令和7年度 雇用）。

## 1. 保険関係の成立・消滅

### 成立（3条〜5条）
保険関係は**適用事業が開始された日に法律上当然に成立**する（届出は確認的なもの）。

| 手続 | 期限 | 提出先 |
|---|---|---|
| **保険関係成立届** | 成立の日から**10日以内** | 労働基準監督署長／公共職業安定所長 |
| 名称・所在地等変更届 | 変更の日の翌日から**10日以内** | 同上 |
| 概算保険料申告書（成立時） | 成立の日から**50日以内** | 同上 |

### 任意加入（暫定任意適用事業）

| 保険 | 加入の同意 | 脱退 |
|---|---|---|
| **労災** | 労働者の**過半数**の希望があれば申請しなければならない | 労働者の**4分の3以上**の同意＋厚生労働大臣の認可 |
| **雇用** | 労働者の**2分の1以上**の同意（**2分の1以上**の希望があれば申請義務） | 労働者の**4分の3以上**の同意 |

### 消滅
事業の廃止・終了の日の**翌日**に消滅する（届出不要）。

## 2. 一元適用と二元適用

| 区分 | 内容 |
|---|---|
| **二元適用事業** | 労災と雇用の保険関係を**別個に**取り扱う。**「都・市・港・農・建」** |
| 一元適用事業 | それ以外すべて |

**二元適用事業**
① 都道府県及び市町村の行う事業（これに準ずるものを含む）
② 港湾労働法による**港湾運送**の行為を行う事業
③ **農林水産**の事業（一定のものを除く）
④ **建設**の事業

## 3. 事業の一括

| 制度 | 対象 | 手続 |
|---|---|---|
| **請負事業の一括**（8条1項） | **建設の事業**が数次の請負で行われる場合。**労災のみ** | **法律上当然**（認可・届出不要）。元請負人のみが事業主 |
| 下請負人を事業主とする特例（8条2項） | 上記の例外 | 書面契約＋**厚生労働大臣の認可**。成立の日の翌日から**10日以内**に申請 |
| **有期事業の一括**（7条） | 小規模な有期事業 | **法律上当然**（認可不要） |
| **継続事業の一括**（9条) | 継続事業 | **厚生労働大臣の認可**が必要 |

> **雇用保険は請負事業の一括の対象外**（元請・下請それぞれで保険関係が成立）。

### 有期事業の一括の要件（すべて満たすこと）
① 事業主が同一
② それぞれが有期事業
③ **労災保険**に係る保険関係が成立
④ **小規模**であること
　・概算保険料 **160万円未満** かつ
　・建設の事業：請負金額 **1億8,000万円未満**
　・立木の伐採：素材の見込生産量 **1,000立方メートル未満**
⑤ 事業の種類が同じ
⑥ 労働保険事務が一の事務所で処理される

### 継続事業の一括の要件
① **事業主が同一**
② それぞれが継続事業
③ 保険関係が同一（労災のみ／雇用のみ／両保険）
④ **事業の種類が同じ**

> 「労災保険率が同一であること」という要件は**ない**（事業の種類が同じなら結果的に同率）。
> 認可されると、指定事業以外の事業に係る保険関係は**消滅**する。

## 4. 労働保険料

### 種類

| 保険料 | 内容 | 負担 |
|---|---|---|
| 一般保険料 | 賃金総額 ×（労災保険率＋雇用保険率） | 労災は事業主全額／雇用は労使 |
| 第1種特別加入保険料 | 中小事業主等 | 事業主 |
| 第2種特別加入保険料 | 一人親方等 | 本人 |
| 第3種特別加入保険料 | 海外派遣者 | 事業主 |
| **印紙保険料** | 日雇労働被保険者 | **労使折半** |
| 特例納付保険料 | 雇用保険の未手続期間の遡及 | 事業主 |

### 賃金総額

| 含む | 含まない |
|---|---|
| 賞与、**通勤手当（非課税分も含む）**、住宅手当、家族手当、**休業手当（労基法26条）**、大入袋、社会保険料の被保険者負担分を事業主が負担する場合 | 退職金、結婚祝金・死亡弔慰金・災害見舞金、**休業補償費（労災）**、傷病手当金、解雇予告手当、出張旅費・宿泊費、制服・作業衣、役員報酬 |

> **★定番の引っかけ**：休業**手当**（労基法26条）は含む／休業**補償費**（労災）は含まない。

### 保険料率

| 項目 | 令和8年度 ⚠️要確認 |
|---|---|
| 労災保険率 | 事業の種類ごと。最高**1000分の88**／最低**1000分の2.5**。原則**3年ごと**に改定 |
| 雇用保険率（一般の事業） | **13.5/1000**＝労働者**5**＋事業主**8.5**（うち二事業**3.5**） |
| 雇用保険率（農林水産・清酒製造） | **15.5/1000**＝労働者**6**＋事業主**9.5**（うち二事業**3.5**） |
| 雇用保険率（**建設**） | **16.5/1000**＝労働者**6**＋事業主**10.5**（うち二事業**4.5**） |

> **雇用保険二事業に充てる部分は事業主が全額負担** → だから労使折半にならない。
> ★二事業分は一般・農林水産が**3.5/1000**、**建設のみ4.5/1000**。建設だけ高い点が引っかけ。
> **労災保険率は全額事業主負担**。

### 申告・納付の期限 ★最頻出

| 内容 | 期限 |
|---|---|
| 概算保険料（**年度更新**） | 保険年度の**6月1日から40日以内**（＝**7月10日**） |
| 概算保険料（年度中途の成立） | 成立の日から**50日以内** |
| 確定保険料（継続事業） | 次の保険年度の**6月1日から40日以内** |
| 確定保険料（保険関係消滅） | 消滅の日から**50日以内** |
| 有期事業の概算保険料 | 保険関係成立の日から**20日以内** |

**確定保険料の精算**：概算 > 確定 なら**還付請求**又は**次年度への充当**（請求しなければ充当）。概算 < 確定 なら不足額を同期限までに納付。

### 延納（分割納付）

| 事業 | 要件 | 期数 |
|---|---|---|
| **継続事業** | 概算保険料**40万円以上**（労災・雇用の一方のみなら**20万円以上**）、又は**事務組合に委託** | **最大3期** |
| **有期事業** | 概算保険料**75万円以上**、又は事務組合に委託。かつ**事業期間が6か月を超える** | — |

**継続事業の納期限**

| 期 | 通常 | 事務組合委託 |
|---|---|---|
| 第1期 | 7月10日 | 7月10日 |
| 第2期 | 10月31日 | **11月14日** |
| 第3期 | 翌年1月31日 | **翌年2月14日** |

## 5. メリット制

保険料負担の公平を図るため、**労災保険率**（雇用保険率には適用されない）を災害の発生状況に応じて増減する。

### 継続事業のメリット制

**適用要件**
- 連続する**3保険年度**中の最後の保険年度に属する3月31日において、保険関係成立後**3年以上**経過
- 3保険年度中の各保険年度において、次のいずれかを満たす
　・**100人以上**の労働者を使用
　・**20人以上100人未満**で、**災害度係数が0.4以上**

**増減幅**

| 区分 | 幅 |
|---|---|
| 継続事業（原則） | **±40％** |
| 立木の伐採の事業 | ±35％ |
| 20人以上100人未満で災害度係数0.4以上の**中小事業** | **±30％** |
| **特例メリット制**（安全衛生措置を講じた中小事業主） | **±45％** |
| 有期事業（建設・立木の伐採） | ±40％ |

## 9. 労働保険事務組合（S級・9年で5〜6年出題）

### 制度の位置づけ
中小事業主が労働保険の事務処理を委託できる団体。**事業主団体（商工会・商工会議所・事業協同組合等）**が
**厚生労働大臣の認可**を受けて事務組合となる。労働保険料の**申告・納付**を代わって行う。

### 委託できる事業主の規模

| 業種 | 常時使用する労働者数 |
|---|---|
| 金融業、保険業、不動産業、**小売業** | **50人以下** |
| **卸売業**、サービス業 | **100人以下** |
| その他の事業 | **300人以下** |

> **★引っかけ**：**小売業（50人）と卸売業（100人）の入替え**。「金・保・不・小＝50」で覚える。

### 委託できる事務／できない事務

| できる | **できない** |
|---|---|
| 概算・確定保険料等の**申告・納付**／保険関係成立届・任意加入の申請／雇用保険の被保険者に関する届出／労災保険の特別加入の申請／その他労働保険に関する申請・届出・報告 | **印紙保険料**に関する事項（**帳簿の備付けを除く**）／**労災保険の保険給付に関する請求書等の提出**／雇用保険の**保険給付に関する請求** |

> 「**保険給付の請求は委託できない**」が最重要。給付は労働者本人の権利だから。

### 事務組合に委託した場合の効果

| 項目 | 効果 |
|---|---|
| **延納** | 概算保険料の額にかかわらず**延納できる**（通常は継続40万円・有期75万円以上が必要） |
| 納期限 | 第2期**11月14日**・第3期**翌年2月14日**（通常は10月31日・翌年1月31日） |
| **特別加入** | **中小事業主等（第1種）の特別加入は事務組合への委託が前提** |
| 通知・還付 | 政府からの通知は事務組合に、還付金も事務組合に |
| **報奨金** | 委託事業主の常時使用労働者が**30人以下**で、納付すべき保険料を完納した場合に交付 |

### 責任の所在

- 事務組合が**故意又は重大な過失**により納付を怠り、**追徴金・延滞金**が課された場合は、**事務組合が納付**する責めに任ずる
- ただし**保険料本体**の納付義務は**事業主**にある（事務組合が納付しなかった場合、政府は事業主に請求できる）
- 事務組合は**労働保険事務等処理委託事業主名簿**・**労働保険料等徴収及び納付簿**等を備える

## 10. 増加概算保険料・追加徴収・還付

| 制度 | 内容 |
|---|---|
| **増加概算保険料** | 賃金総額の見込額が**2倍を超えて増加**し、かつ増加後の概算保険料と申告済額との差額が**13万円以上**となる場合、**30日以内**に申告・納付 |
| 概算保険料の**減額** | 賃金総額の見込額が**2分の1以下に減少**し、差額が13万円以上のとき、**都道府県労働局歳入徴収官の認可**を受けて減額できる |
| **追加徴収** | 保険料率が引き上げられた場合、政府は追加徴収する。**30日以上**の期限を指定して通知 |
| **認定決定** | 申告書を提出しない・記載に誤りがあるとき、政府が保険料額を決定し通知。この場合**追徴金（100分の10）**を徴収（印紙保険料は**100分の25**） |
| **還付** | 確定保険料が概算保険料を下回るとき、**還付請求**又は**次年度への充当**（請求しなければ充当） |

> **13万円**という数字は増加・減少の両方で共通。「2倍を超えて増加」「2分の1以下に減少」もセットで。

---

## 11. 納付の実務

| 項目 | 内容 |
|---|---|
| 納付先 | **都道府県労働局歳入徴収官**（実務上は日本銀行・金融機関等） |
| 納付書 | 申告書と一体（**納入告知書**によらず自主申告・自主納付が原則） |
| **口座振替** | 概算・確定保険料について利用可。振替日は各期の納期限より後に設定される |
| 電子申請 | 一定の法人は**電子申請が義務**（資本金1億円超等） |
| **督促** | 督促状の指定期限は発する日から起算して**10日以上**経過した日 |
| **延滞金** | 年**14.6％**（納期限の翌日から3か月を経過する日までは年**7.3％**）。保険料額**1,000円未満**は徴収しない |
| 先取特権 | 労働保険料等の徴収金は、**国税及び地方税に次ぐ順位**の先取特権を有する |

## 直前チェック（徴収）

- [ ] 保険関係は**事業開始の日に当然成立**（届出は確認的）
- [ ] 二元適用事業＝**都・市・港・農・建**
- [ ] 請負事業の一括は**建設業・労災のみ・当然一括**／雇用は対象外
- [ ] 有期事業の一括は**当然**、継続事業の一括は**認可必要**
- [ ] 有期事業の一括：160万円・1億8,000万円・1,000立方メートル
- [ ] 賃金総額：休業**手当**は含む／休業**補償費**は含まない／通勤手当は**非課税分も含む**
- [ ] 二事業分は**事業主のみ負担**
- [ ] 年度更新は6月1日から**40日以内**、年度中途成立は**50日以内**
- [ ] 延納：継続**40万円・3期**／有期**75万円・6か月超**
- [ ] メリット制は**労災保険率のみ**。±40％、中小±30％、特例±45％
- [ ] 事務組合：小売**50**／卸売**100**／その他**300**
- [ ] 追徴金：印紙**25％**／一般**10％**
- [ ] 徴収金の時効は**2年**、不服申立ては**行政不服審査法**
- [ ] 事務組合に**保険給付の請求**は委託できない（印紙保険料も帳簿以外は不可）
- [ ] 事務組合に委託すれば**金額にかかわらず延納可**／納期限は**11/14・2/14**
- [ ] 報奨金は常時使用労働者**30人以下**
- [ ] 増加概算保険料＝**2倍超**かつ差額**13万円以上**→**30日以内**
- [ ] 追徴金は一般**10％**／印紙**25％**
