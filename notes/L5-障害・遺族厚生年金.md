# 障害厚生年金と遺族厚生年金｜厚年の深掘り

## 障害厚生年金

### 受給要件（47条）

1. **初診日**において厚生年金保険の**被保険者**であること
2. **障害認定日**（初診日から1年6か月）に**障害等級1級・2級・3級**に該当すること
3. **保険料納付要件**を満たすこと（国民年金と同じ：**3分の2以上**、または令和8年3月31日までは**直近1年間に未納なし**）

> ★障害基礎年金は1級・2級だけですが、**厚生年金には3級と障害手当金**があります。
> ★**初診日に被保険者であること**が必要です。退職後に初診日があると障害厚生年金は出ません。

### 事後重症（47条の2）・基準障害（47条の3）

| 種類 | 内容 |
|---|---|
| **事後重症** | 障害認定日に該当しなかったが、**65歳に達する日の前日**までに1級〜3級に該当したとき。**請求した日**に受給権発生 |
| **基準障害**（初めて2級） | 基準傷病以外の障害と**併合して初めて2級以上**になったとき。**65歳に達する日の前日**までに該当することが必要（請求は65歳以後でもよい） |

> ★事後重症は「**請求も65歳前**」、基準障害は「**該当が65歳前なら請求は65歳以後でもよい**」。この差が問われます。

### 年金額（50条）

```
障害厚生年金 ＝ 報酬比例の額（老齢厚生年金と同じ計算式）
　1級：報酬比例の額 × 1.25 ＋ 配偶者加給年金額
　2級：報酬比例の額 ＋ 配偶者加給年金額
　3級：報酬比例の額（最低保障額あり）
```

| ポイント | |
|---|---|
| **被保険者期間の月数** | **300月未満**のときは**300月とみなす**（最低保障） |
| **配偶者加給年金額** | **1級・2級のみ**。**65歳未満の配偶者**が対象 |
| **3級の最低保障額** | 障害基礎年金2級の額の**4分の3**に相当する額 |
| 障害認定日の属する月後の被保険者期間 | **年金額の計算に算入しない** |

> ★**300月みなしは短期要件のみ**ではなく、**障害厚生年金は常に300月みなし**です（遺族厚生年金は短期要件のときだけ）。
> ★**3級には配偶者加給年金額がありません**。
> ★障害認定日以後の被保険者期間は計算に入らないので、**その後働いても額は増えません**（65歳到達等による改定を除く）。

### 受給権取得後に配偶者を有するに至ったとき（50条の2第3項）

> 受給権者がその権利を**取得した日の翌日以後**に、その者によって生計を維持している**65歳未満の配偶者**を有するに至ったことにより加給年金額を加算することとなったときは、**当該配偶者を有するに至った日の属する月の翌月**から、障害厚生年金の額を**改定する**。

- 平成23年4月からの取扱いです。それ以前は**受給権取得時に配偶者がいなければ加算されませんでした**。
- 老齢厚生年金の加給年金額も同様に、**在職老齢年金の受給権取得後**に要件を満たせば改定されます（44条）。

> ★改定は「**有するに至った日の属する月の翌月**」からです。「その日から」「翌年度から」は誤りです。
> ★**障害基礎年金の子の加算**も同じ考え方で、受給権取得後に生まれた子について**その月の翌月**から改定されます（国年法33条の2第3項）。

### 障害手当金（55条・57条）

| 要件 | |
|---|---|
| ① | 初診日に被保険者であること |
| ② | **初診日から5年以内**に傷病が**治り**、政令で定める程度の障害（**3級より軽い**）にあること |
| ③ | 保険料納付要件を満たすこと |

```
障害手当金 ＝ 報酬比例の額 × 2（最低保障は3級の最低保障額 × 2）
```

> ★**傷病が治っていること**が必要です。障害厚生年金3級は治っていなくても支給されます。
> ★**年金たる給付の受給権者**には支給されません。

### 併合・改定・失権

| | |
|---|---|
| **併合認定**（48条） | 障害基礎年金と同様 |
| **額の改定**（52条） | 職権による改定と受給権者の改定請求（**1年経過後**。明らかに増進した場合は待たずに請求可） |
| **3級不該当** | **支給停止**（**65歳到達**かつ**3年経過**で失権） |
| **失権**（53条） | 死亡、併合認定、3級不該当が3年継続かつ65歳到達 |

> ★障害厚生年金**3級**の受給権者が65歳になっても、**支給停止中でなければ失権しません**。

## 遺族厚生年金

### 死亡者の要件（58条）

| 要件 | 内容 | 区分 |
|---|---|---|
| 1号 | **被保険者**が死亡したとき | **短期** |
| 2号 | 被保険者であった者が、**被保険者期間中に初診日**がある傷病により、**初診日から5年以内**に死亡したとき | **短期** |
| 3号 | **障害等級1級・2級**の障害厚生年金の受給権者が死亡したとき | **短期** |
| 4号 | **老齢厚生年金の受給権者**（受給資格期間**25年以上**）または受給資格期間を満たした者が死亡したとき | **長期** |

**保険料納付要件**は1号・2号について必要です（3分の2以上、または令和8年3月31日までは直近1年間に未納なし）。

> ★**4号（長期要件）は25年**が必要です。老齢基礎年金の10年短縮は遺族には及びません。

### 短期要件と長期要件の違い

| | 短期要件（1〜3号） | 長期要件（4号） |
|---|---|---|
| 被保険者期間 | **300月みなし**あり | **実期間**で計算 |
| 生年月日による**給付乗率の読替え** | **しない**（新乗率のまま） | **する**（生年月日に応じた乗率） |
| 中高齢寡婦加算の**要件** | 被保険者期間を問わない | **240月以上**が必要 |

> ★短期・長期の**両方に該当**するときは、**遺族が有利なほうを選択**できます（請求時に申し出がなければ短期要件）。

### 死亡の推定（59条の2）

遺族厚生年金は「死亡」が支給事由なので、**死亡が確認できないとき**に備えた規定があります。

| 場面 | 推定される日 |
|---|---|
| **船舶**が沈没・転覆・滅失・行方不明となった際、現にその船舶に乗っていた者の**生死が3か月間わからない** | **その船舶が沈没等をした日** |
| 船舶に乗っていて**航行中に行方不明**となった者の生死が3か月間わからない | **その者が行方不明となった日** |
| **航空機**が墜落・滅失・行方不明となった際、現に乗っていた者の生死が3か月間わからない | **その航空機が墜落等をした日** |
| 航空機に乗っていて航行中に行方不明となった者 | **その者が行方不明となった日** |

**死亡が3か月以内に明らかとなり、かつ死亡の時期がわからない場合**も同じ日に死亡したものと推定します。

> ★推定される日は「**事故があった日／行方不明になった日**」です。**3か月が経過した日ではありません**。ここが引っかけの定番です。
> ★船舶は**沈没・転覆・滅失・行方不明**の4つ、航空機は**墜落・滅失・行方不明**の3つ（航空機に「転覆」はありません）。
> ★国民年金にも**同じ規定**があります（国年法18条の3）。厚年は「**遺族厚生年金の支給に関する規定の適用について**」、国年は「**死亡を支給事由とする給付**の支給に関する規定の適用について」と書き分けられています。
> ★**失踪宣告**（民法30条・普通失踪7年）とは別のしくみです。

### 遺族の範囲と順位（59条）

**死亡当時、その者によって生計を維持していた**次の者。

| 順位 | 遺族 | 要件 |
|---|---|---|
| ① | **配偶者・子** | **妻**は要件なし。**夫**は**55歳以上**（支給は60歳から。ただし**遺族基礎年金を受けられる夫**は60歳前でも支給）。**子**は18歳年度末まで（または20歳未満で1・2級）で未婚 |
| ② | **父母** | **55歳以上**（支給は60歳から） |
| ③ | **孫** | 子と同じ |
| ④ | **祖父母** | **55歳以上**（支給は60歳から） |

> ★**転給はありません**（労災の遺族補償年金にはあります）。先順位者が失権しても次順位者に移りません。
> ★**兄弟姉妹は遺族厚生年金の対象外**です（労災・遺族補償年金には含まれます）。
> ★**30歳未満で子のない妻**は、受給権取得から**5年**で失権します（63条）。

### 年金額（60条）

```
遺族厚生年金 ＝ 死亡した者の報酬比例部分 × 4分の3
```

### 中高齢寡婦加算（62条）

| 要件 | |
|---|---|
| 妻の年齢 | 夫の死亡当時**40歳以上65歳未満**であること（または40歳に達した当時、遺族基礎年金の対象となる子がいたこと） |
| 期間 | **40歳から65歳**になるまで |
| 額 | **老齢基礎年金の満額 × 4分の3** |
| 長期要件の場合 | 死亡した夫の被保険者期間が**240月以上**であること |

> ★**妻だけ**の制度です。夫には中高齢寡婦加算がありません。

### 経過的寡婦加算（昭和60年改正法附則73条）

**昭和31年4月1日以前生まれ**の妻について、**65歳**で中高齢寡婦加算が終わった後に、**生年月日に応じた額**が加算されます。

> ★昭和31年4月2日以後生まれの妻には**経過的寡婦加算がありません**（老齢基礎年金が満額に近づくため）。

### 失権（63条）

死亡、**婚姻**（事実婚を含む）、**直系血族・直系姻族以外の者の養子**となったこと、**離縁**、**30歳未満で子のない妻**が受給権取得から5年を経過したこと、子・孫が18歳年度末に達したこと等。

> ★**父母・孫・祖父母**は、**受給権者となった後に配偶者・子が受給権を取得**しても失権しません（そもそも先順位者がいれば受給権を取得しません）。

### 令和10年4月からの改正（未施行）

**20〜30歳代で子のない配偶者**への遺族厚生年金が、**男女差を解消**したうえで**5年間の有期給付**に変わります。

### 生計維持の認定 — 年収850万円

「**その者によって生計を維持していた**」といえるには、**生計同一**であることに加えて、収入が**将来にわたって年収850万円未満**（所得655万5千円未満）であることが必要です。

| 場面 | 扱い |
|---|---|
| 死亡当時は850万円以上だが、**おおむね5年以内に850万円未満**になると認められる | **生計維持あり** |
| 死亡当時850万円以上で受給権を得られず、**その後に収入が下がった** | **さかのぼって受給権は生じない** |

> ★**過去9年で6回**、健保・厚年・国年をまたいで問われています。
> ★判定は**死亡当時**が基準です。「あとから下がれば受給権が発生する」は誤りです。
> ★**加給年金額・振替加算**の生計維持の判定も同じ基準です。
