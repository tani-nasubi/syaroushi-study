# 平均賃金｜労基の深掘り

### 何のための制度か

**解雇予告手当・休業手当・年休の賃金・災害補償**などの計算基礎です。「その労働者の通常の生活賃金」を表すことを狙っています。

### 計算

```
平均賃金 ＝ 算定事由発生日以前3か月間の賃金総額 ÷ その期間の総日数（暦日数）
```

**分母は労働日数ではなく暦日数**です。ここが最頻出の引っかけです。

### 起算日（12条1項・2項）

条文は「算定すべき事由の発生した日**以前**三箇月間」ですが、行政解釈で**当日は含まず前日からさかのぼる**とされています。事由発生日は休業等で算定に適さないためです。

**賃金締切日があれば、前日ではなく直前の賃金締切日から起算**します（12条2項）。

### 控除するもの（期間と賃金の両方）

次の期間は**分母からも分子からも除きます**。

1. 業務上負傷・疾病による**療養のための休業**期間
2. **産前産後**の休業期間
3. **使用者の責めに帰すべき事由**による休業期間
4. **育児・介護休業**期間
5. **試みの使用**期間

> 控除期間が3か月以上にわたる場合は、**都道府県労働局長**が決定します（施行規則4条）。
> ★この主体を「厚生労働大臣」に書き換える誤り肢が定番です。

### 最低保障

日給・時給・出来高払の場合、通常の計算額と次の額の**高いほう**を採ります。

```
賃金総額 ÷ 労働日数 × 60/100
```

### 賃金総額から除くもの

| 除く | 理由 |
|---|---|
| **臨時に支払われた賃金**（結婚手当、私傷病手当など） | 通常の生活賃金を表さない |
| **3か月を超える期間ごとに支払われる賃金**（賞与） | 同上 |
| **通貨以外のもので支払われた賃金**で一定の範囲に属しないもの | 評価が困難 |

> ★**通勤手当・家族手当・住宅手当は含まれます**。「手当だから除く」は誤りです。
> ★**休業手当**は賃金なので含まれます。**休業補償**（労基法76条）は賃金ではないので含まれません。

### 雇入れ後3か月に満たない場合

**雇入れ後の期間**とその期間中の賃金総額で算定します（施行規則3条）。

**日々雇い入れられる者**については、**厚生労働大臣の定める金額**を平均賃金とします（施行規則3条後段・4条）。

### 平均賃金を使う場面

| 場面 | 額 |
|---|---|
| **解雇予告手当**（20条） | 30日分以上 |
| **休業手当**（26条） | 1日につき**60%以上** |
| **年次有給休暇**の賃金（39条9項） | 平均賃金／所定労働時間労働した場合の通常の賃金／**標準報酬日額**（労使協定が必要）の3択 |
| **災害補償**（76条〜82条） | 休業補償60%、障害補償・遺族補償など |
| **減給の制裁**（91条） | 1回の額が平均賃金の**1日分の半額**を超えず、総額が**一賃金支払期の賃金総額の10分の1**を超えないこと |

> ★年休の賃金で**標準報酬日額**を選ぶときだけ**労使協定**が要ります。他の2つは就業規則の定めで足ります。

### 減給の制裁との関係（91条）

```
1回の額 ≦ 平均賃金の1日分の半額
総額     ≦ 一賃金支払期における賃金総額の10分の1
```

> ★「1回の額」は**1つの事案について**の額です。複数の事案があれば、それぞれについて半額まで科せます（総額の制限は別にかかります）。
> ★**遅刻・早退による不就労分の控除**は制裁ではないので、91条の制限を受けません。
