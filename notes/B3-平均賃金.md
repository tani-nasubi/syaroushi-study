# 平均賃金｜労基の深掘り

### 何のための制度か

**解雇予告手当・休業手当・年休の賃金・災害補償**などの計算基礎です。「その労働者の通常の生活賃金」を表すことを狙っています。

### 計算

```
平均賃金 ＝ 算定事由発生日以前3か月間の賃金総額 ÷ その期間の総日数（暦日数）
```

**分母は労働日数ではなく暦日数**です。ここが最頻出の引っかけです。

### 起算日（12条1項・2項）

条文は「算定すべき事由の発生した日**以前**三箇月間」ですが、行政解釈で**当日は含まず前日からさかのぼる**とされています。事由発生日は休業等で算定に適さないためです。

**賃金締切日があれば、前日ではなく直前の賃金締切日から起算**します（12条2項）。

### 控除するもの（期間と賃金の両方）

次の期間は**分母からも分子からも除きます**。

1. 業務上負傷・疾病による**療養のための休業**期間
2. **産前産後**の休業期間
3. **使用者の責めに帰すべき事由**による休業期間
4. **育児・介護休業**期間
5. **試みの使用**期間

> 控除期間が3か月以上にわたる場合は、**都道府県労働局長**が決定します（施行規則4条）。
> ★この主体を「厚生労働大臣」に書き換える誤り肢が定番です。

### 最低保障

日給・時給・出来高払の場合、通常の計算額と次の額の**高いほう**を採ります。

```
賃金総額 ÷ 労働日数 × 60/100
```
