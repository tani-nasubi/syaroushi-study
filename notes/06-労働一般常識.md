## 1. 労働契約法

罰則も行政取締規定も**ない**（民事的な裁判規範）。これが労基法との決定的な違い。

### 5つの基本原則（3条）
① **労使対等**の原則
② **均衡考慮**の原則
③ **仕事と生活の調和**への配慮の原則
④ **信義誠実**の原則
⑤ **権利濫用の禁止**の原則

### 主要条文

| 条 | 内容 |
|---|---|
| 6条 | 労働契約は、労働者が使用者に使用されて労働し、使用者がこれに対して賃金を支払うことについて、労働者及び使用者が**合意**することによって成立する |
| 7条 | 合理的な労働条件が定められている就業規則を**周知**させていた場合、労働契約の内容はその就業規則で定める労働条件による |
| 9条 | 労働者と合意することなく、就業規則の変更により労働者の不利益に労働条件を変更することはできない |
| **10条** | ただし、変更後の就業規則を**周知**させ、かつ変更が**合理的**なものであるときは、労働条件は変更後の就業規則による |
| 12条 | 就業規則で定める基準に達しない労働契約は、その部分について**無効**（就業規則の基準による） |
| **16条** | **解雇**は、客観的に合理的な理由を欠き、社会通念上相当であると認められない場合は、その権利を濫用したものとして**無効**とする |
| **17条1項** | 使用者は、有期労働契約について、**やむを得ない事由**がある場合でなければ、契約期間が満了するまでの間において労働者を解雇することができない |
| 17条2項 | 必要以上に短い期間を定めることにより、契約を反復して更新することのないよう配慮しなければならない |
| **18条** | **無期転換ルール**（下記） |
| **19条** | **雇止め法理**（下記） |
| 20条 | （旧・期間の定めによる不合理な労働条件の禁止 → パート有期法8条へ移設） |

> **17条1項の「やむを得ない事由」は、16条の解雇より厳格な要件**。ここは頻出。

### 10条の合理性の判断要素
① 労働者の受ける不利益の程度
② 労働条件の変更の必要性
③ 変更後の就業規則の内容の相当性
④ **労働組合等との交渉の状況**
⑤ その他の就業規則の変更に係る事情

### 無期転換ルール（18条）

| 項目 | 内容 |
|---|---|
| 要件 | 同一の使用者との間の2以上の有期労働契約の通算契約期間が**5年を超える** |
| 効果 | 労働者の申込みにより、使用者は**承諾したものとみなされる**（拒否できない） |
| 労働条件 | **別段の定め**がある部分を除き、従前と同一（＝無期になるだけで正社員化ではない） |
| **クーリング** | 契約がない期間が**6か月以上**あると通算リセット（直前の契約期間が1年未満の場合はその**2分の1以上**） |
| 特例 | **有期雇用特別措置法**により、高度専門的知識等を有する有期雇用労働者は**10年**、定年後継続雇用の高齢者は申込権が発生しない（**都道府県労働局長の認定**が必要） |

> 令和6年4月から、無期転換申込権が発生する更新時に、使用者は**無期転換申込機会**と**無期転換後の労働条件**を明示しなければならない（労基則5条）。

### 雇止め法理（19条）

適用される2類型：
① **実質無期型**：反復更新により、雇止めが無期労働契約の解雇と社会通念上同視できる場合（東芝柳町工場事件）
② **期待保護型**：契約期間の満了時に更新されるものと期待することについて**合理的な理由がある**場合（日立メディコ事件）

労働者が更新の申込みをし、使用者の拒絶が客観的に合理的な理由を欠き社会通念上相当でないときは、**従前と同一の労働条件で承諾したものとみなす**。

## 2. 短時間労働者及び有期雇用労働者の雇用管理の改善等に関する法律（パート有期法）

### 均衡と均等 ★超頻出

| 条 | 名称 | 内容 |
|---|---|---|
| **8条** | **均衡待遇** | 職務の内容、職務の内容及び配置の変更の範囲、その他の事情のうち、待遇の性質・目的に照らして適切と認められるものを考慮して、**不合理と認められる相違を設けてはならない** |
| **9条** | **均等待遇** | 職務の内容と変更の範囲が通常の労働者と**同一**の短時間・有期雇用労働者については、**差別的取扱いをしてはならない** |

> **均衡＝違いは許されるが不合理はダメ／均等＝違い自体が許されない**。

### 明示（6条）
労基法15条の明示事項に加え、次の4つを**文書等で明示**（**特定事項**）：
**① 昇給の有無 ② 退職手当の有無 ③ 賞与の有無 ④ 相談窓口**

### 説明義務（14条）

| 時期 | 内容 |
|---|---|
| **雇入れ時** | 実施する雇用管理の改善等の措置の内容（求めがなくても） |
| **求めがあったとき** | 通常の労働者との**待遇の相違の内容及び理由**。説明を求めたことを理由とする**不利益取扱いは禁止** |

## 3. 労働者派遣法

### 適用除外業務（4条）— **「港・建・警・医」＋士業**
① 港湾運送業務
② 建設業務
③ 警備業務
④ 病院等における医療関係業務（紹介予定派遣、産前産後・育児介護休業の代替、へき地等は可）
⑤ 弁護士・社会保険労務士等の**士業**の一部

> ⚠️令和8年度改正で**オンライン診療を受ける施設**が対象に追加（要確認）。

### 期間制限 ★超頻出

| 単位 | 期間 | 延長 |
|---|---|---|
| **事業所単位** | 3年 | 過半数労働組合等からの**意見聴取**により**3年ずつ延長可** |
| **個人単位**（同一の組織単位＝課等） | 3年 | **延長不可** |

**期間制限の対象外**
① 派遣元で**無期雇用**されている派遣労働者
② **60歳以上**の者
③ 有期プロジェクト業務
④ 日数限定業務（1か月の勤務日数が通常の労働者の半分以下かつ**10日以下**）
⑤ 産前産後休業・育児休業・介護休業の**代替要員**

### 待遇決定の2方式

| 方式 | 内容 |
|---|---|
| **派遣先均等・均衡方式**（30条の3） | 派遣先の通常の労働者との均等・均衡待遇 |
| **労使協定方式**（30条の4） | 過半数労働組合等との労使協定により、同種業務の一般労働者の平均的な賃金額（**局長通達**で毎年公表）以上とする |

> **労使協定方式でも例外**：**教育訓練（40条2項）**と**福利厚生施設（給食施設・休憩室・更衣室）**は派遣先の労働者と同様の取扱いが必要。

### 日雇派遣の原則禁止
30日以内の日雇派遣は原則禁止。例外：① 政令で定める業務 ② **60歳以上** ③ **昼間学生** ④ 副業として従事（生業収入**500万円以上**）⑤ 主たる生計者でない者（世帯収入**500万円以上**）

## 8. 労働組合法

### 不当労働行為（7条）

| 号 | 類型 |
|---|---|
| 1号 | **不利益取扱い**（組合員であること等を理由とする解雇その他の不利益取扱い）、**黄犬契約** |
| 2号 | **団体交渉の拒否**（正当な理由のない団交拒否） |
| 3号 | **支配介入・経費援助** |
| 4号 | **報復的不利益取扱い**（労働委員会への申立て等を理由とする不利益取扱い） |

**経費援助の例外**：① 労働時間中の協議・交渉に賃金を支給 ② 厚生資金・福利基金への寄附 ③ **最小限の広さの事務所**の供与

### 労働協約
- **書面**に作成し、両当事者が**署名又は記名押印**することによって効力を生ずる（14条）
- 有効期間は**3年**を超えることができない（期間を定めない場合は90日前の予告で解約可）
- **一般的拘束力**：一の工場事業場の同種の労働者の**4分の3以上**に適用されるに至ったときは、他の同種の労働者にも適用（17条）
- 地域的の一般的拘束力：労働委員会の決議＋厚生労働大臣又は都道府県知事の決定（18条）

### 労働委員会
公益委員・労働者委員・使用者委員の**三者構成・同数**。中央労働委員会と都道府県労働委員会。

## 9. 最低賃金法

| 項目 | 内容 |
|---|---|
| **地域別最低賃金** | すべての労働者に適用（産業・職種を問わない） |
| **特定最低賃金** | 産業別。地域別を**上回る額**でなければならない |
| **減額特例** | 精神・身体の障害により著しく労働能力が低い者等について、**都道府県労働局長の許可** |
| **派遣労働者** | **派遣先**の地域別最低賃金が適用される |
| 効力 | 最低賃金額に達しない部分は**無効**となり、最低賃金額と同様の定めをしたものとみなす |

**最低賃金額に算入しない賃金**
精皆勤手当、通勤手当、家族手当、臨時に支払われる賃金、1か月を超える期間ごとに支払われる賃金、時間外・休日・深夜の割増賃金

### 令和7年度の数値
- 全国加重平均 **1,121円**（前年1,055円、**＋66円**）
- 引上げ額66円は昭和53年度の目安制度開始以降で**最高額**
- **全都道府県で1,000円を突破**
- 令和8年度の改定（10月頃）は試験後なので、試験対象は令和7年度

## 10. その他の労働法規

| **高年齢者雇用安定法** | 65歳までの**雇用確保措置**（定年引上げ・継続雇用制度・定年廃止）は**義務**／70歳までの**就業確保措置**は**努力義務** |

| **次世代育成支援対策推進法** | 101人以上に一般事業主行動計画の策定・届出義務。**くるみん**認定 |
| **若者雇用促進法** | 職場情報の提供、**ユースエール**認定、青少年雇用情報の提供 |

| **労働審判法** | **原則3回以内**の期日で審理。労働審判官1人＋労働審判員2人 |
| **個別労働関係紛争解決促進法** | 都道府県労働局長の助言・指導、紛争調整委員会の**あっせん** |
