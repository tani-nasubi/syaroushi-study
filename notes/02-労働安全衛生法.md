## 1. 目的と概念

### 目的（1条）— 選択式の定番

> この法律は、**労働基準法と相まって**、労働災害の防止のための**危害防止基準**の確立、**責任体制**の明確化及び**自主的活動**の促進の措置を講ずる等その防止に関する**総合的計画的な対策**を推進することにより職場における労働者の安全と健康を確保するとともに、**快適な職場環境**の形成を促進することを目的とする。

**比較：労基法1条**は「労働条件の**最低**基準」。「最低基準＝労基法／危害防止基準＝安衛法」を取り違えないこと。

### 事業者と労働者

| 用語 | 定義 |
|---|---|
| **事業者**（2条3号） | 事業を行う者で、労働者を使用するもの。法人企業は**法人そのもの**、個人企業は**事業主個人** |
| 労基法の使用者 | 事業主＋経営担当者＋労働者に関する事項について事業主のために行為をする者 |

→ 安衛法の「事業者」の方が**狭い**（安全衛生責任の所在を明確にするため）。

### 責務

| 主体 | 内容 |
|---|---|
| 事業者（3条1項） | 最低基準を守るだけでなく、**快適な職場環境の実現と労働条件の改善**を通じて安全と健康を確保。国の施策に協力 |
| 労働者（4条） | 労働災害防止のため必要な事項を守るほか、事業者等が実施する措置に**協力するよう努める** |
| 労働者（26条） | 事業者が講ずる措置に応じて必要な事項を守らなければならない（**罰則あり・50万円以下の罰金**） |

## 2. 安全衛生管理体制 ★最重要

### 選任の要件

| 者 | 人数要件 | 業種限定 | 選任期限 | 監督署長へ報告 |
|---|---|---|---|---|
| 総括安全衛生管理者 | **100／300／1,000**人以上 | あり | 14日以内 | 必要 |
| **安全**管理者 | 50人以上 | **あり** | 14日以内 | 必要 |
| **衛生**管理者 | 50人以上 | **なし** | 14日以内 | 必要 |
| 産業医 | 50人以上 | **なし** | 14日以内 | 必要 |
| 安全衛生推進者・衛生推進者 | **10人以上50人未満** | — | 14日以内 | **不要**（周知でよい） |
| 作業主任者 | 作業の区分ごと | — | — | **不要**（周知でよい） |

> **覚え方**：「安全」がつくものは業種限定あり、「衛生」がつくものは全業種（総括安全衛生管理者・安全衛生推進者は別枠）。

### 総括安全衛生管理者の業種別人数

| 人数 | 業種 |
|---|---|
| **100人以上** | 林業、鉱業、建設業、運送業、清掃業 |
| **300人以上** | 製造業、電気業、ガス業、熱供給業、水道業、通信業、各種商品卸売業・小売業、家具建具じゅう器小売業、燃料小売業、旅館業、ゴルフ場業、自動車整備業、機械修理業 |
| **1,000人以上** | その他の業種 |

- **資格要件はない**（工場長・支店長等、事業の実施を統括管理する者を充てる）
- **都道府県労働局長**は、必要があると認めるとき事業者に**勧告**できる

### 衛生管理者

**選任数**

| 事業場の規模 | 人数 |
|---|---|
| 50〜200人 | 1人 |
| 201〜500人 | 2人 |
| 501〜1,000人 | 3人 |
| 1,001〜2,000人 | 4人 |
| 2,001〜3,000人 | 5人 |
| 3,001人以上 | 6人 |

**専任・衛生工学**

| 要件 | 内容 |
|---|---|
| **専任**の衛生管理者 | 常時**1,000人超**、又は常時500人超で坑内労働・一定の有害業務に**30人以上** |
| **衛生工学衛生管理者免許** | 常時500人超で一定の有害業務（高熱物体・多量の低温物体・有害放射線・粉じん・異常気圧等）に30人以上 |

### 産業医

| 要件 | 内容 |
|---|---|
| 選任 | 常時**50人以上** |
| **専属** | 常時**1,000人以上**、又は一定の有害業務に常時500人以上 |
| **2人以上** | 常時**3,000人超** |

**権限強化（平成31年改正）**
- 事業者は産業医に対し、①月80時間超の時間外・休日労働をした労働者の**氏名と超過時間** ②その他健康管理に必要な情報 を提供する義務
- 産業医の**勧告**を受けたときは、その内容等を**衛生委員会等に報告**
- 産業医の辞任・解任時はその旨と理由を衛生委員会等に報告
- 勧告を理由とする**解任・不利益取扱いは禁止**

### 巡視の頻度 ★超頻出

| 者 | 頻度 |
|---|---|
| **衛生管理者** | **毎週1回** |
| **産業医** | **毎月1回**（所定の情報提供＋事業者の同意があれば**2か月に1回**） |
| 安全管理者 | 「作業場等を巡視し」（**頻度の定めなし**） |

### 委員会

| 委員会 | 設置要件 | 委員に含まれる者 |
|---|---|---|
| **安全**委員会 | **業種により50人／100人**以上 | 安全管理者 |
| **衛生**委員会 | **全業種50人**以上 | **産業医**、衛生管理者 |

- 双方を設けるべきときは**安全衛生委員会**として一体設置できる
- **毎月1回以上**開催、議事の概要を労働者に周知、記録を**3年間保存**
- 議長：総括安全衛生管理者又は事業の実施を統括管理する者（事業者が指名）
- 議長を除く委員の**半数**は過半数労働組合（ないときは過半数代表者）の**推薦に基づき指名**

### 混在作業の体制（建設業・造船業）

| 者 | 選任者 | 要件 |
|---|---|---|
| **統括安全衛生責任者** | 特定元方事業者 | 建設業：原則**50人以上**（ずい道等・圧気工法・一定の橋梁は**30人以上**）、造船業：50人以上 |
| **元方安全衛生管理者** | 統括安全衛生責任者を選任した事業者（**建設業のみ**） | 一定の資格が必要 |
| **店社安全衛生管理者** | 建設業の元方事業者 | 統括の選任義務がない中小規模現場（20人以上） |
| **安全衛生責任者** | **関係請負人** | 統括安全衛生責任者との連絡等 |

> **★引っかけ**：安全衛生責任者を選任するのは**関係請負人（下請）**。主体の入替えが定番。

## 4. 機械等・危険物

### 特定機械等（37条〜41条）
ボイラー、第一種圧力容器、クレーン、移動式クレーン、デリック、エレベーター、建設用リフト、ゴンドラ

```
製造許可（都道府県労働局長）→ 製造時等検査 → 落成検査（労働基準監督署長）
 → 検査証の交付 → 性能検査（有効期間の更新）→ 変更検査 → 使用再開検査
```

> **★引っかけ**：**製造許可＝都道府県労働局長／落成検査・検査証＝労働基準監督署長**。

### 譲渡等の制限（42条）
政令で定める機械等は、厚生労働大臣の定める規格・安全装置を具備しなければ、**譲渡し、貸与し、又は設置**してはならない。

| 検定 | 対象の例 |
|---|---|
| **個別検定** | 防爆構造電気機械器具、ゴム練用ロール機の急停止装置 等 |
| **型式検定** | プレス機械の安全装置、防じんマスク、防毒マスク、**保護帽**、電動ファン付き呼吸用保護具、絶縁用保護具 等 |

## 5. 就業にあたっての措置

### 教育の3段階

| 教育 | 対象 | 記録保存 |
|---|---|---|
| **雇入れ時教育**（59条1項） | **全ての労働者**（期間・労働時間を問わない） | 法定の保存義務なし |
| **作業内容変更時教育**（59条2項） | 同上 | — |
| **特別教育**（59条3項） | 危険又は有害な業務に就かせるとき | **3年間** |
| **職長等教育**（60条） | 建設業、製造業（一部除く）、電気業、ガス業、自動車整備業、機械修理業。**作業主任者は除く** | — |

> 雇入れ時教育・作業内容変更時教育の教育事項は、令和6年4月から**全業種で全8項目**が必要（従前は一部業種で省略可）。
> 安全衛生教育は**所定労働時間内に行うのが原則**で、法定時間外に行えば**割増賃金が必要**（通達）。

### 資格の段階（危険度が高い順）

```
免許 ＞ 技能講習 ＞ 特別教育
```

- **就業制限（61条）**：免許・技能講習修了者等でなければ就業させてはならない。従事するときは**免許証等を携帯**
- **作業主任者（14条）**：免許を受けた者又は技能講習を修了した者から、**作業の区分ごと**に選任。氏名と行わせる事項を**掲示等により周知**

| 雇入れ時健診 | 雇入れの際（3か月以内に受診し証明書を提出した者は該当項目を省略可） |
| **定期健診** | **1年以内ごとに1回** |
| 特定業務従事者健診 | 配置替えの際及び**6か月以内ごとに1回** |
| 海外派遣労働者健診 | 6か月以上派遣する際及び帰国後 |
| 給食従業員の検便 | 雇入れの際及び配置替えの際 |
| 特殊健康診断 | 原則**6か月以内ごとに1回**（じん肺は管理区分により1〜3年） |

**事後措置の流れと期限**

| 手順 | 期限 |
|---|---|
| 結果の**本人への通知** | 遅滞なく（**異常所見の有無にかかわらず全員**） |
| **医師等の意見聴取** | 健診が行われた日から**3か月以内** |
| 就業場所の変更・作業の転換・労働時間の短縮等 | 意見を勘案し必要に応じて |
| **保健指導** | 努力義務 |
| **監督署長への報告** | 常時**50人以上**の事業場（**特殊健診は人数を問わず報告**） |
| 健康診断個人票の保存 | **5年間** |

> 労働者にも**受診義務**がある（他の医師の健診を受けて結果を提出してもよい）。

### 面接指導（66条の8〜66条の8の4）

| 対象 | 時間の基準 | 申出 |
|---|---|---|
| 一般の労働者 | 月**80時間**超＋疲労の蓄積 | **必要** |
| 研究開発業務従事者 | 月**100時間**超 | **不要（義務）** |
| 高度プロフェッショナル対象者 | 健康管理時間が月**100時間**超 | **不要（義務）** |

- 事業者は**労働時間の状況を客観的な方法で把握**する義務（管理監督者・裁量労働制対象者も含む）
- 月80時間を超えた労働者本人に、**速やかに超過時間を通知**
- 結果の記録は**5年間**保存、**遅滞なく**医師の意見を聴く

### ストレスチェック（66条の10）

| 項目 | 内容 |
|---|---|
| 義務 | 常時**50人以上**の事業場（50人未満は当分の間**努力義務**） |
| 頻度 | **1年以内ごとに1回** |
| **労働者の受検義務** | **なし**（健康診断との決定的な違い） |
| 実施者 | 医師、保健師、一定の研修を受けた歯科医師・看護師・精神保健福祉士・公認心理師 |
| 結果 | **実施者から直接本人へ通知**。**本人の同意なく事業者に提供してはならない** |
| 面接指導 | 高ストレス者から**申出**があれば実施。申出を理由とする不利益取扱いは禁止 |
| 記録の保存 | **5年間** |

> ★50人未満への義務化は改正法成立済みだが、施行は**令和10年5月まで**の政令で定める日＝令和8年度試験では**未施行**。

### 受動喫煙（68条の2）
安衛法上は**努力義務**。健康増進法では原則禁止の**義務**。

## 作業環境測定（65条）— 頻度の暗記表

> ★令和7年度の択一 問10 は**5肢中3肢がこの頻度**でした。ここは直接得点になります。

### 頻度で覚える

| 頻度 | 対象となる作業場 |
|---|---|
| **半月以内**ごとに1回 | **暑熱・寒冷・多湿**の屋内作業場／坑内の**気温**／坑内の**通気量** |
| **1月以内**ごとに1回 | 坑内の**炭酸ガス**が停滞する場所／**放射線**業務（線量当量率・空気中の放射性物質濃度） |
| **2月以内**ごとに1回 | **中央管理方式**の空気調和設備を設けた建築物の室（事務所則） |
| **6月以内**ごとに1回 | **特定粉じん**作業／**著しい騒音**（等価騒音レベル）／**特定化学物質**（第1類・第2類）／**石綿**／**有機溶剤**（第1種・第2種） |
| **1年以内**ごとに1回 | **鉛**業務を行う屋内作業場 |
| **作業開始前** | **酸素欠乏**危険場所（その日の作業を開始する前） |

**覚え方**
- **半月**＝体に直接くる環境（暑い・寒い・湿気・坑内の空気）
- **1月**＝放射線と坑内の炭酸ガス
- **6月**＝有害物質の本丸（粉じん・騒音・特化物・石綿・有機溶剤）が全部ここ
- **1年**＝**鉛だけ**。ここが引っかけの定番です
- 酸欠は測定「頻度」ではなく**その日の作業開始前**

> ⚠️ **鉛を「6月以内」と書き換える誤り肢**が定番です。有害物質のグループで唯一1年である点を押さえてください。

### 作業環境測定士に行わせなければならないもの（指定作業場）

| 対象 |
|---|
| **特定粉じん**作業を行う屋内作業場 |
| **放射性物質**取扱作業室 |
| **特定化学物質**（第1類・第2類）を製造・取り扱う屋内作業場 |
| **石綿**等を取り扱い、又は試験研究のため製造する屋内作業場 |
| **鉛**業務を行う屋内作業場 |
| **有機溶剤**（第1種・第2種）を製造・取り扱う屋内作業場 |

事業者は、**作業環境測定士**に測定させるか、**作業環境測定機関**に委託しなければなりません。
上記以外（暑熱・騒音・坑内・事務所等）は、**作業環境測定士でなくても測定できます**。

### 記録の保存期間

| 期間 | 対象 |
|---|---|
| **3年** | 原則（粉じん・騒音・鉛・有機溶剤 等） |
| **7年** | **特定化学物質**（第1類・第2類）のうち一定のもの |
| **30年** | **特別管理物質**／**石綿** |
| **5年** | **放射線**業務（電離則） |
