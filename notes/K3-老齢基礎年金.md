# 老齢基礎年金｜国年の深掘り

### 受給要件（26条）

**保険料納付済期間＋保険料免除期間＋合算対象期間**が**10年以上**あり、**65歳**に達したとき。

> ★平成29年8月から**25年→10年**に短縮されました。
> ★**合算対象期間（カラ期間）だけでは10年になりません**——というのは誤りで、合算対象期間も**受給資格期間に算入されます**。ただし**年金額には反映されません**。

### 年金額（27条）

```
　　　　　　　　　　保険料納付済月数 ＋ 免除月数×反映率
年金額 ＝ 満額 × ─────────────────────────────
　　　　　　　　　　　　　480（40年×12）
```

満額は**780,900円 × 改定率**（令和8年度の額は [`09-国民年金法.md`](09-国民年金法.md) の一覧を見てください）。

| 分母 | 480月（**20歳以上60歳未満**の40年） |
|---|---|
| 20歳前・60歳以後の**第2号**被保険者期間 | **老齢基礎年金には反映されない**（厚生年金の**経過的加算**で調整される） |

> ★分母は**常に480**です。加入可能年数が480月に満たない世代（昭和16年4月1日以前生まれ）には経過措置があります。

### 繰上げ支給（附則9条の2）

**60歳以上65歳未満**の間に請求できます。

| | |
|---|---|
| 減額率 | **1月あたり0.4%**（昭和37年4月1日以前生まれは**0.5%**） |
| 最大 | 60歳0か月で請求＝**24%減**（60月×0.4%） |
| 減額 | **一生続く**（65歳になっても戻らない） |

**繰上げの効果（不利益）**。

1. **障害基礎年金**を請求できなくなる（事後重症等による請求ができない）
2. **寡婦年金**が受けられなくなる（既に受給中なら失権）
3. **任意加入**できなくなる
4. **遺族厚生年金**との併給ができない（65歳までは選択）
5. 老齢厚生年金も**同時に繰り上げ**なければならない

> ★2は「寡婦年金の受給権が消滅する」。1は「事後重症による障害基礎年金は請求できない」。この2つが最頻出です。

### 繰下げ支給（28条）

**66歳に達した日以後**に申し出ます。

| | |
|---|---|
| 増額率 | **1月あたり0.7%** |
| 上限 | **75歳**（昭和27年4月2日以後生まれ）＝120月×0.7%＝**84%増** |
| 要件 | 65歳に達したときに**老齢基礎年金の受給権を有していた**こと、かつ**66歳に達する前に請求していない**こと |

> ★**66歳になる前に請求すると繰下げできません**。「65歳から66歳の間は繰下げ待機期間」です。
> ★65歳に達した日から**66歳に達した日までの間**に、**他の年金給付**（障害・遺族）の受給権者となったときは繰下げできません。
> ★**繰下げ待機中に死亡**した場合、遺族は**未支給年金**として65歳からの分を受け取れます（増額はされません）。
> ★令和5年4月から、**70歳以後に請求**する場合、請求の**5年前**に繰下げ申出があったものとみなす「**特例的な繰下げみなし増額制度**」があります。

### 老齢基礎年金と老齢厚生年金の繰上げ・繰下げ

| | 繰上げ | 繰下げ |
|---|---|---|
| 基礎と厚生 | **同時**でなければならない | **別々**にできる |

> ★繰上げは同時、繰下げは別々。この非対称が問われます。

### 振替加算（昭和60年改正法附則14条）

**老齢厚生年金の加給年金額**の対象となっていた配偶者が**65歳**に達すると、加給年金額が打ち切られ、代わりにその配偶者の**老齢基礎年金に振替加算**が行われます。

| 要件 | |
|---|---|
| 生年月日 | **大正15年4月2日から昭和41年4月1日まで**に生まれた者 |
| 加算額 | 生年月日により逓減（**昭和41年4月2日以後生まれには振替加算がない**） |
| 状況 | 加給年金額の対象となっていたこと |

> ★**昭和41年4月2日以後生まれには振替加算がありません**（新法で20歳から国民年金に加入できる世代のため）。
> ★振替加算は、老齢基礎年金を**繰り上げても65歳になるまで支給されません**。逆に**繰り下げると振替加算も繰り下がりますが、増額はされません**。

### 支給の繰上げ・繰下げと他の給付

| 制度 | 繰上げ | 繰下げ |
|---|---|---|
| 付加年金 | **同時に繰上げ**（同率で減額） | **同時に繰下げ**（同率で増額） |
| 振替加算 | 繰り上がらない（65歳から） | 繰り下がる（**増額なし**） |

### 支払期月（18条）

年金給付は、**毎年2月・4月・6月・8月・10月・12月**の**6期**に、それぞれの**前月までの分**を支払います。

| | |
|---|---|
| 支給開始 | 受給権が発生した日の属する月の**翌月**から |
| 支給終了 | 権利が消滅した日の属する月**まで** |
| 支給停止 | 停止事由が生じた日の属する月の**翌月**から、消滅した日の属する月**まで** |

> ★**翌月から、その月まで**。この非対称が問われます。

### 社会保障協定

外国で働くときに、**保険料の二重負担**と**保険期間の掛け捨て**を防ぐための二国間協定です。

| | |
|---|---|
| **二重加入の防止** | 派遣期間が**5年以内**の見込みなら**派遣元の国**の制度にのみ加入（原則） |
| **期間の通算** | **協定相手国**の年金加入期間を、日本の受給資格期間に通算できる |
| 通算した期間の扱い | **合算対象期間（カラ期間）**として扱う。**年金額には反映されない** |
| 通算の規定がない協定 | **イギリス、韓国、イタリア、中国**は二重加入の防止のみで**期間通算がない** |

> ★通算されるのは**受給資格期間だけ**です。相手国に納めた保険料が日本の**年金額の計算に入ることはありません**。ここが令和7年度の択一で問われました。
> ★脱退一時金を受けると、その期間は**日本の被保険者期間でなかったもの**とみなされるため、協定による通算もできなくなります。
