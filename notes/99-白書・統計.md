## 1. 令和7年版 労働経済の分析（労働経済白書）

### 労働経済白書の副題 ★選択式で狙われる
> **労働力供給制約の下での持続的な経済成長に向けて**

分析の柱は3つ：
1. **労働生産性の向上**に向けた課題
2. 生活に密接に関係する分野の**人材確保**
3. 終身雇用・年功賃金といった**日本的雇用慣行の変化**と働く意識の変化に対応した雇用管理

### 主要数値（2024年＝令和6年 年平均）

| 指標 | 数値 | 備考 |
|---|---|---|
| **完全失業率** | **2.5%** | 前年比 −0.1pt |
| **有効求人倍率** | **1.25倍** | 前年比 −0.06倍（正社員は1.01倍） |
| **就業者数** | **6,781万人** | 前年比 +34万人・**過去最高** |
| **雇用者数** | **6,123万人** | 前年比 +47万人・**過去最高** |
| **労働力人口** | **6,957万人** | **過去最高** |
| 労働力率 | **63.3%** | — |
| **名目賃金**（現金給与総額） | **+2.9%**（月額 348,182円） | **4年連続増加** |
| **実質賃金** | **−0.2%** | **3年連続マイナス**（ただし一般労働者・パートともにマイナスを脱却） |
| **春闘賃上げ率** | **5.10%** | **33年ぶりの5%台** |
| 名目GDP | 初の**600兆円超え** | — |

> **★覚え方**：「**失業率2.5／求人倍率1.25／賃上げ5.10%**」の3つは最優先。
> 「労働力人口・就業者数・雇用者数がそろって**過去最高**」も頻出の言い回しです。

### 白書独自のキーワード
- **社会インフラ関連職**（医療・介護・保育・運輸・建設等、生活に不可欠な分野）
  - 非社会インフラ関連職と比べ**月額賃金が約5万円低い**
  - 過去10年で 非社会インフラ関連職は**322万人増**、社会インフラ関連職は**58万人**の増加にとどまる
- **労働力供給制約** — 人口減少下で労働投入量が制約される状況
- **労働生産性** — 供給制約下で成長を続けるための鍵

> 白書独自の造語（今回は「社会インフラ関連職」）は**選択式の空欄になりやすい**。

## 2. 令和7年版 厚生労働白書

### 厚生労働白書の副題 ★選択式で狙われる
> **次世代の主役となる若者の皆さんへ ─ 変化する社会における社会保障・労働施策の役割を知る ─**

| 項目 | 内容 |
|---|---|
| 公表 | 2025年（令和7年）7月29日・**24冊目** |
| 構成 | 第1部＝テーマ／第2部＝厚生労働行政の施策 |
| 想定読者 | **高校生・大学生・社会人になったばかりの人**。高校生が1人で読める平易さ |
| 特色 | **社会保障教育と労働法教育をワンセット**で取り上げたのは初 |

### 第1部の流れ
1. 社会保障・労働施策の役割と方向性
2. 社会保障・労働施策に関する**若者の意識**と知ることの意義
3. **社会保障教育・労働法教育**の取組

> **副題と「若者」「社会保障教育・労働法教育」というキーワード**を押さえれば十分です。
> 内容の細部より、**何をテーマにした年か**が問われます。

## 4. 主要統計の「何を測る調査か」

数値を覚えていなくても、**どの調査が何を測るか**を知っていれば消去法が効きます。

| 調査 | 実施 | 測るもの |
|---|---|---|
| **労働力調査** | 総務省・**毎月** | 完全失業率、就業者数、労働力人口、労働力率 |
| **毎月勤労統計調査** | 厚労省・毎月 | 現金給与総額、**実質賃金**、労働時間、常用雇用指数 |
| **賃金構造基本統計調査** | 厚労省・年1回 | 男女間賃金格差、年齢階級別賃金、企業規模別賃金 |
| **就労条件総合調査** | 厚労省・年1回 | **年次有給休暇の取得率**、所定労働時間、退職給付制度 |
| **雇用動向調査** | 厚労省・年2回 | 入職率・離職率、転職入職者の状況 |
| **能力開発基本調査** | 厚労省・年1回 | 教育訓練費、OFF-JT、自己啓発 |
| **労働組合基礎調査** | 厚労省・年1回 | **推定組織率**、組合員数、パート組合員 |
| **国民医療費** | 厚労省 | 医療費の総額・財源・診療種類別・年齢階級別 |
| **社会保障費用統計** | 国立社人研 | 社会保障給付費の部門別・機能別 |
| 人口動態統計 | 厚労省 | 出生数、合計特殊出生率、死亡数 |

> **★引っかけ**：「完全失業率＝毎月勤労統計」（誤り。**労働力調査**）のように、
> **調査名と指標の組合せ**を入れ替えるのが定番です。

## 5. 数値を覚えていなくても答えられる「順位と傾向」

| 統計 | 押さえどころ |
|---|---|
| 国民医療費の財源 | **保険料 ＞ 公費 ＞ 患者負担** |
| 国民医療費の診療種類別 | **医科診療医療費が最大** |
| 国民医療費の年齢階級別 | **65歳以上が6割超** |
| 社会保障給付費の部門別 | **年金 ＞ 医療 ＞ 福祉その他** |
| 社会保障給付費の機能別 | **高齢 ＞ 保健医療 ＞ 家族** |
| 労働組合の推定組織率 | **低下傾向**（17%前後）。**パート組合員は増加** |
| 年次有給休暇の取得率 | **上昇傾向**（6割超） |
| 女性の労働力率 | **M字カーブは解消傾向** |
| 医療施設数 | 一般診療所 ＞ 歯科診療所 ＞ **病院（減少傾向）** |
| 介護保険の認定者数 | 増加傾向。**要介護1・2が多い** |

**「何が一番大きいか」「増えているか減っているか」**を問う形が多く、実数の暗記は不要です。

## 6. この領域の戦い方

> ★**労一と社一で扱いを分けてください。** 労一の統計は持ち回りの実態調査で初見が前提（→ [`H6-労働統計と実態調査.md`](H6-労働統計と実態調査.md)）、社一の統計は毎年同じ顔ぶれで**覚える価値がある**（→ [`I5-社会保障の統計と財政.md`](I5-社会保障の統計と財政.md)）。下の「投じる時間は数時間まで」は**労一の統計について**の話です。


`92-選択式の解き方.md` に書いたとおり、**労一・社一は9年中4回ずつ基準点が補正**されています。
つまり**白書・統計で失点しても救済されうる**領域です。

| やる | やらない |
|---|---|
| 副題・テーマを覚える | 白書の全文を読む |
| 上の主要数値10個を覚える | 細かい実数を網羅する |
| 調査名と指標の対応を覚える | 過去の年度の数値を追う |
| 順位・傾向を覚える | グラフの細部を覚える |

**投じる時間は数時間まで。** その分を健保・厚年・国年（択一30問）に回すほうが得点効率は高くなります。

### 国民生活基礎調査（厚生労働省）

労一・社一の統計問題で繰り返し引かれます。**調査の名前と何を測るか**を結びつけておきます。

| 項目 | 押さえどころ |
|---|---|
| **相対的貧困率** | 等価可処分所得の**中央値の半分**に満たない世帯員の割合 |
| **子どもの貧困率** | **17歳以下**の相対的貧困率 |
| 傾向 | 1985年以降おおむね上昇していたが、**直近では低下** |
| **1世帯当たり平均所得金額** | 減少傾向。背景は**高齢者世帯の割合の増加** |
| 世帯構造 | **単独世帯**が最も多く増加傾向。**高齢者世帯**も増加 |
| 有効な統計名 | 貧困率・世帯の所得・世帯構造・**介護の状況**（要介護者の性別・同居の主な介護者） |

> ★**相対的貧困率は「国民生活基礎調査」**です。**国民生活基礎調査は「厚生労働省」**の調査です。総務省の「家計調査」「就業構造基本調査」と取り違える肢が出ます。
> ★**等価可処分所得**は、世帯の可処分所得を**世帯人員の平方根**で割ったものです。
