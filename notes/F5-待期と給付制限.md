# 待期と給付制限｜雇用の深掘り

### 待期（21条）

> 基本手当は、受給資格者が離職後最初に公共職業安定所に**求職の申込み**をした日以後において、**失業している日**（疾病または負傷のため職業に就くことができない日を含む）が**通算して7日**に満たない間は、支給しない。

| ポイント | |
|---|---|
| 起算 | **求職の申込みをした日**以後（離職日ではない） |
| 日数 | 通算**7日** |
| 連続 | **不要**（通算でよい） |
| 疾病・負傷の日 | **含まれる** |

> ★待期は**すべての受給資格者に共通**です。給付制限の有無にかかわらず必要です。
> ★1日の労働時間が**4時間以上**の日は失業していないため、待期に算入されません。

### 給付制限（32条・33条）

| 事由 | 制限 |
|---|---|
| **正当な理由なく**公共職業安定所の紹介する職業に就くこと、または指示された公共職業訓練等を受けることを**拒んだ**とき（32条1項） | **その日から1か月間** |
| **正当な理由なく**、再就職を促進するために必要な**職業指導**を受けることを拒んだとき（32条2項） | **その日から1か月を超えない範囲**で定める期間 |
| **自己の責めに帰すべき重大な理由**によって解雇された（重責解雇）（33条） | 待期満了後**3か月**（一部は1か月） |
| **正当な理由がなく自己の都合**によって退職した（33条） | 待期満了後**1か月** |
| 5年間に**3回以上**の正当な理由のない自己都合離職 | 待期満了後**3か月** |

> ★令和7年4月1日から、自己都合離職の給付制限が**2か月→1か月**に短縮されました。ただし**5年間に3回以上**の場合は**3か月**です。
> ★**離職期間中または離職日前1年以内に、自ら教育訓練を受けた場合**は、給付制限が**解除**されます（給付制限なし）。

### 紹介拒否の「正当な理由」

次の場合は、拒んでも給付制限を受けません（32条1項ただし書）。

1. 紹介された職業・受けることを指示された訓練が、**受給資格者の能力からみて不適当**であるとき
2. 就職しようとする地域の**賃金水準に比べて不当に低い**賃金であるとき
3. 職業安定機関の**紹介する職業が労働争議の行われている事業所**に関するものであるとき
4. その他**正当な理由**があるとき

> ★「賃金が前職より低い」だけでは正当な理由になりません。**地域の賃金水準**との比較です。

### 不正受給（34条）

**偽りその他不正の行為**により求職者給付・就職促進給付を受け、または受けようとした者には、

| 効果 | |
|---|---|
| 支給停止 | **その日以後**、基本手当を支給しない |
| 例外 | やむを得ない理由があるときは、**支給を制限しないことができる** |
| **返還命令**（10条の4） | 支給を受けた額の**全部または一部**の返還を命ずることができる |
| **納付命令** | さらに、受けた額の**2倍**に相当する額以下の金額の納付を命ずることができる |

合計すると最大で受給額の**3倍**（返還1倍＋納付2倍）です。

> ★**事業主・職業紹介事業者等が偽りの届出・報告・証明**をしたためであるときは、これらの者に対し**連帯して**返還・納付を命ずることができます。
> ★不正受給による返還金・納付金は、**国税徴収の例により徴収**されます。

### 受給権の保護

| 条文 | 内容 |
|---|---|
| 11条 | 失業等給付を受ける権利は、**譲渡・担保・差押えができない** |
| 12条 | **租税その他の公課**は、失業等給付として支給を受けた金銭を標準として課することができない |

> ★ただし、**未支給の失業等給付**を受ける権利や、不正受給による返還金債権には別の扱いがあります。

### 時効・不服申立て

| | |
|---|---|
| **時効**（74条） | 失業等給付の**支給を受ける権利**、返還・納付を命じられた金額を徴収する権利は**2年** |
| **不服申立て**（69条） | 被保険者資格・給付に関する処分 → **雇用保険審査官**に審査請求 → **労働保険審査会**に再審査請求 |
| 審査請求の期間 | 処分があったことを知った日の翌日から**3か月以内** |
| みなし棄却 | 審査請求をした日から**3か月**を経過しても決定がないとき |

> ★処分の取消しの訴えは、**審査請求に対する決定を経た後**でなければ提起できません（審査請求前置）。
