# 不服申立て・時効・雑則｜健保の深掘り

### 不服申立て（189条・190条）

| 対象となる処分 | 手続 |
|---|---|
| **被保険者の資格**、**標準報酬**、**保険給付**に関する処分 | **社会保険審査官**に審査請求 → **社会保険審査会**に再審査請求（**2審制**） |
| **保険料**その他この法律の規定による**徴収金**に関する処分 | **社会保険審査会**に審査請求（**1審制**） |

| 期間 | |
|---|---|
| 審査請求 | 処分があったことを**知った日の翌日**から起算して**3か月以内** |
| みなし棄却 | 審査請求をした日から**2か月**以内に決定がないとき |
| 再審査請求 | 決定書の謄本の送付を受けた日の翌日から起算して**2か月以内** |

> ★**給付は2審・保険料は1審**。厚年・国年と同じ形ですが、**国民年金法では保険料も社会保険審査官（2審制）**である点だけが違います。
> ★**処分の取消しの訴え**は、**審査請求に対する裁決を経た後**でなければ提起できません（審査請求前置）。
> ★**日雇特例被保険者の資格**に関する処分も同じ扱いです。

### 時効（193条）

| 対象 | 時効 |
|---|---|
| **保険料**その他この法律の規定による徴収金を徴収し、または還付を受ける権利 | **2年** |
| **保険給付**を受ける権利 | **2年** |

> ★健保は**給付も保険料も2年**です。**厚年・国年は給付5年・保険料2年**なので、ここが横断で問われます。

**起算日**の例。

| 給付 | 起算日 |
|---|---|
| 療養費 | 療養に要した費用を支払った日の翌日 |
| 傷病手当金・出産手当金 | 労務不能であった日ごとにその翌日 |
| 出産育児一時金 | 出産日の翌日 |
| 埋葬料 | 死亡した日の翌日 |
| 埋葬費 | 埋葬を行った日の翌日 |
| 高額療養費 | 診療月の翌月1日（自己負担額を支払った日の翌日） |

**保険料等の徴収金についての督促は、時効の更新の効力**を生じます（193条3項）。

### 受給権の保護と公課（61条・62条）

| 条 | 内容 |
|---|---|
| **61条** | 保険給付を受ける権利は、**譲り渡し、担保に供し、または差し押さえることができない** |
| **62条** | **租税その他の公課**は、保険給付として支給を受けた金品を標準として課することができない |

> ★**出産育児一時金・埋葬料**も非課税です。傷病手当金・出産手当金も非課税です。

### 届出と書類の保存

| 届出 | 期限 |
|---|---|
| 被保険者資格取得届・喪失届 | **5日以内** |
| 報酬月額算定基礎届 | **7月10日**まで |
| 報酬月額変更届 | 速やかに |
| 賞与支払届 | **5日以内** |
| 被扶養者（異動）届 | **5日以内** |
| 事業所関係変更（訂正）届 | **5日以内** |
| **任意継続被保険者の申出** | 資格喪失日から**20日以内** |

事業主は、**健康保険に関する書類**を**その完結の日から2年間**保存しなければなりません（則34条）。

> ★労基法は5年（当分の間3年）、徴収法は3年、健保は**2年**。混同しやすいところです。

### 罰則と検査

| 条 | 内容 |
|---|---|
| 198条 | 厚生労働大臣は、**事業主に報告を命じ**、**当該職員に事業所へ立ち入り検査**をさせることができる |
| 199条 | 被保険者・被保険者であった者・被扶養者に対する**文書の提出等の命令** |
| 200条 | 保険給付を受ける者に対する**診断命令**（保険者は、必要があると認めるときは、医師の診断を受けさせることができる） |
| 207条〜 | 報告をせず虚偽の報告をした事業主等への罰則（**6か月以下の拘禁刑または50万円以下の罰金**） |

> ★立入検査の権限は**犯罪捜査のために認められたものと解してはならない**とされています。

### 二以上の事業所に使用される場合

被保険者が同時に2以上の適用事業所に使用される場合、**被保険者は保険者を選択**し、**10日以内**に届け出ます。報酬月額は**各事業所の報酬月額を合算**して標準報酬月額を決め、保険料は**各事業所の報酬月額の比**であん分します。

> ★**選択するのは被保険者**です。事業主が決めるものではありません。

### 匿名診療等関連情報の提供と手数料（150条の2〜150条の10）

厚生労働大臣は、**匿名診療等関連情報**（レセプト等を特定の個人を識別できないように加工した情報）を、国の他の行政機関・大学・医療分野の研究開発に資する分析を行う者などに**提供することができます**。

| | |
|---|---|
| **利用者の義務** | 情報の**照合の禁止**、**安全管理措置**、**利用目的外の利用禁止** |
| **手数料**（150条の10） | 利用者は、**実費を勘案して政令で定める額**の手数料を**国**に納める（基金等が提供事務の全部を行う場合は**基金等**に納める） |
| **減免** | 厚生労働大臣は、**都道府県**その他国民保健の向上のために特に重要な役割を果たす者については、政令で定めるところにより**手数料を減免**できる |

> ★納付先は**国**（委託されている場合は**基金等**）です。
> ★具体の額は政令で「提供に要する時間**1時間までごとに4,350円**」と定められています。

### 収納職員の交替（則158条の27）

日本年金機構の**収納職員**が交替するときの引継ぎの手続です。

- **前任**の収納職員は、**交替の日の前日**をもって、その月分の**保険料等収納簿の締切り**をし、**検査**を受けた上、引継ぎの年月日を記入し、**後任の収納職員とともに記名して認印**を押す。
- 前任者は**現金現在高調書**と、引き継ぐべき帳簿・証拠書類の**目録各2通**を作成し、**後任の立会いの上**で引き継ぐ。

> ★締切りは「**交替の日の前日**」です。「交替の日をもって」は**誤り**（令和5年に出ました）。
> ★検査を命じるのは**機構の理事長**で、**年金事務所ごとに機構の職員のうちから検査員**を命じます（則158条の26）。
