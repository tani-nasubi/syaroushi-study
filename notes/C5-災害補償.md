# 災害補償｜労基の深掘り

### 労災保険との関係

**労災保険から給付が行われるべき場合、使用者は補償の責を免れます**（84条）。実務上は労災保険で処理されますが、試験では労基法の補償が問われます。

| 補償 | 内容 |
|---|---|
| **療養補償**（75条） | 必要な療養を行い、又は費用を負担。**期間の制限なし** |
| **休業補償**（76条） | 平均賃金の**100分の60**。待期期間なし（労災保険は3日の待期あり） |
| **障害補償**（77条） | 障害の程度に応じ平均賃金に別表の日数を乗じた額 |
| **遺族補償**（79条） | 平均賃金の**1,000日分** |
| **葬祭料**（80条） | 平均賃金の**60日分** |
| **打切補償**（81条） | 療養開始後**3年**を経過しても治らない場合、平均賃金の**1,200日分**を支払えば以後の補償を打ち切れる |

### 打切補償と解雇制限

19条の解雇制限は、**打切補償を支払えば解除**されます。労災保険の**傷病補償年金**を受けている場合も、療養開始後3年を経過した日に打切補償を支払ったものとみなされます。

### 補償を受ける権利

- **譲渡・差押えができない**（83条2項）
- 労働者の**重大な過失**による負傷等で、使用者がその過失について行政官庁の**認定**を受けたときは、**休業補償・障害補償を行わなくてよい**（78条）

### 労基法の災害補償（75条〜88条）

| 条 | 補償 | 内容 |
|---|---|---|
| **75条** | **療養補償** | 業務上負傷・疾病にかかった場合、使用者が**必要な療養**を行い、または療養の費用を負担する |
| **76条** | **休業補償** | 療養のため労働できず賃金を受けない場合、**平均賃金の60%** |
| **77条** | **障害補償** | 治ったのち障害が残った場合、障害の程度に応じ平均賃金に別表第2の日数を乗じた額 |
| **79条** | **遺族補償** | 死亡した場合、遺族に**平均賃金の1,000日分** |
| **80条** | **葬祭料** | 葬祭を行う者に**平均賃金の60日分** |
| **81条** | **打切補償** | 療養開始後**3年**を経過しても治らない場合、**平均賃金の1,200日分**を支払えば、以後の補償を行わなくてよい |
| **82条** | **分割補償** | 使用者が支払能力を証明し、補償を受ける者の**同意**を得た場合、障害補償・遺族補償を**6年**にわたり分割して支払える |

> ★労基法の災害補償は**無過失責任**です。使用者に過失がなくても補償義務があります。
> ★**通勤災害は労基法の災害補償の対象外**です（労災保険では給付されます）。

### 労災保険との関係（84条）

> この法律に規定する災害補償の事由について、**労働者災害補償保険法**またはその他の法令に基づいてこの法律の災害補償に相当する給付が行なわれるべきものである場合においては、使用者は、補償の責を免れる。

| 場面 | 誰が負担するか |
|---|---|
| 労災保険から給付される部分 | **使用者は免責** |
| **休業補償の待期3日間** | **使用者が労基法76条の休業補償**（平均賃金の60%）を行う |
| 通勤災害の待期3日間 | 使用者に補償義務は**ない** |

> ★待期3日間の扱いが**業務災害と通勤災害で違う**理由は、労基法の災害補償が**業務上のもの**だけを対象にしているからです。

### 休業補償と休業手当の違い

| | 休業補償（76条） | 休業手当（26条） |
|---|---|---|
| 原因 | **業務上**の負傷・疾病 | **使用者の責めに帰すべき事由** |
| 額 | 平均賃金の**60%** | 平均賃金の**60%以上** |
| **賃金か** | 賃金**でない** | **賃金である** |
| 平均賃金の算定基礎 | 含まれ**ない** | **含まれる** |
| 労働保険料の賃金総額 | 含まれ**ない** | **含まれる** |
| 所得税 | **非課税** | 課税 |

> ★額はどちらも60%ですが、**性質がまったく違います**。ここが最頻出の対比です。

### 審査・仲裁（85条・86条）

業務上の負傷・疾病・死亡の**認定**、療養の方法、補償金額の決定その他補償の実施に関して**異議**のある者は、**行政官庁（所轄労働基準監督署長）**に対して**審査または事件の仲裁**を申し立てることができます。

行政官庁の審査・仲裁の結果に不服のある者は、**労働者災害補償保険審査官**に対して審査・仲裁を申し立てることができます（86条）。

> ★**民事訴訟が提起された後**は、行政官庁は審査・仲裁をすることができません（85条4項）。

### 補償を受ける権利（83条）

| 項 | 内容 |
|---|---|
| 1項 | 補償を受ける権利は、**労働者の退職によって変更されることはない** |
| 2項 | 補償を受ける権利は、**譲渡し、または差し押えてはならない** |

> ★労災保険法12条の5と同じ規定です。

### 休業補償の免責（78条）

**労働者が重大な過失によって業務上負傷し、または疾病にかかり**、かつ使用者がその過失について**行政官庁の認定**を受けた場合においては、**休業補償または障害補償**を行わなくてもよいとされています。

> ★免責されるのは**休業補償と障害補償だけ**です。療養補償・遺族補償・葬祭料は免責されません。
