# 災害補償｜労基の深掘り

### 労災保険との関係

**労災保険から給付が行われるべき場合、使用者は補償の責を免れます**（84条）。実務上は労災保険で処理されますが、試験では労基法の補償が問われます。

| 補償 | 内容 |
|---|---|
| **療養補償**（75条） | 必要な療養を行い、又は費用を負担。**期間の制限なし** |
| **休業補償**（76条） | 平均賃金の**100分の60**。待期期間なし（労災保険は3日の待期あり） |
| **障害補償**（77条） | 障害の程度に応じ平均賃金に別表の日数を乗じた額 |
| **遺族補償**（79条） | 平均賃金の**1,000日分** |
| **葬祭料**（80条） | 平均賃金の**60日分** |
| **打切補償**（81条） | 療養開始後**3年**を経過しても治らない場合、平均賃金の**1,200日分**を支払えば以後の補償を打ち切れる |

### 打切補償と解雇制限

19条の解雇制限は、**打切補償を支払えば解除**されます。労災保険の**傷病補償年金**を受けている場合も、療養開始後3年を経過した日に打切補償を支払ったものとみなされます。

### 補償を受ける権利

- **譲渡・差押えができない**（83条2項）
- 労働者の**重大な過失**による負傷等で、使用者がその過失について行政官庁の**認定**を受けたときは、**休業補償・障害補償を行わなくてよい**（78条）
