# 被保険者と適用｜雇用の深掘り

### 適用事業（5条）

> 労働者が雇用される事業を**適用事業**とする。

**業種・規模を問わず**、労働者を1人でも雇用すれば適用事業です。事業主の意思や届出とは関係なく、**当然に**適用されます。

例外は**暫定任意適用事業**（個人経営の農林水産の事業で常時**5人未満**の労働者を雇用するもの）だけです。

> ★「常時5人以上の労働者を使用する事業に適用される」は誤りです。

### 4種類の被保険者

| 種類 | 対象 |
|---|---|
| **一般**被保険者 | 下の3つ以外 |
| **高年齢**被保険者 | **65歳以上**の被保険者（短期雇用特例・日雇を除く） |
| **短期雇用特例**被保険者 | **季節的**に雇用される者（4か月以内の期間を定めて雇用される者、週所定20時間未満の者を除く） |
| **日雇**労働被保険者 | 日々雇用される者、**30日以内**の期間を定めて雇用される者 |

> ★65歳以上でも**適用除外ではなく高年齢被保険者**です。平成29年からの取扱いです。

### 適用除外（6条）

| 号 | 除外される者 |
|---|---|
| 1号 | 1週間の所定労働時間が**20時間未満**である者（日雇労働被保険者に該当する者を除く） |
| 2号 | **同一の事業主に継続して31日以上**雇用されることが見込まれない者 |
| 3号 | **季節的**に雇用される者のうち、4か月以内の期間を定めて雇用される者・週20時間以上30時間未満の者 |
| 4号 | **学校教育法**の学生生徒等（**昼間学生**）。ただし**休学中**、**卒業見込みで卒業後も引き続き雇用される**者などは被保険者となる |
| 5号 | **船員**であって、漁船に乗り組むため1年を通じて雇用される場合を除く者 |
| 6号 | **国・都道府県・市町村等**の事業に雇用される者のうち、離職した場合に求職者給付等を超える給付が受けられる者 |

> ★令和10年10月1日から、**週10時間以上**に適用が拡大されます（未施行）。
> ★**法人の役員**は原則として被保険者になりませんが、**取締役であって同時に部長等の従業員としての身分を有する者**は、雇用関係が明確なら被保険者となります。

### 二重に雇用される場合

原則として、**主たる賃金を受ける一の雇用関係**についてのみ被保険者となります。

**65歳以上**の者については、令和4年から**雇用保険マルチジョブホルダー制度**があります。

| 要件 | |
|---|---|
| 年齢 | **65歳以上** |
| 事業所 | **2つ**の事業所（1つの事業所での週所定労働時間が**5時間以上20時間未満**） |
| 合計 | 2つの事業所の週所定労働時間の合計が**20時間以上** |
| 雇用見込み | 各事業所で**31日以上** |
| 申出 | 本人の**申出**が必要（申出た日から被保険者となる） |

> ★**本人の申出**が必要で、事業主の届出だけでは資格取得しません。名称は「**マルチ高年齢被保険者**」です。

### 資格の得喪（7条〜9条）

| 届出 | 期限 |
|---|---|
| **資格取得届** | 資格を取得した日の属する月の**翌月10日**まで |
| **資格喪失届** | 資格を喪失した日の**翌日から起算して10日以内** |
| 離職証明書 | 資格喪失届に添える（本人が59歳以上の場合は**必ず**添える） |

| 資格取得日 | 資格喪失日 |
|---|---|
| 雇用された日／適用事業に該当するに至った日 | 離職した日の**翌日**／死亡した日の翌日／適用除外に該当した日 |

> ★取得は「その日」、喪失は「**翌日**」。健保・厚年と同じ考え方です。

### 確認（9条）

厚生労働大臣は、**届出もしくは請求により、または職権で**、被保険者となったこと・でなくなったことの**確認**を行います。

労働者は、**いつでも**確認の請求ができます（8条）。事業主が届出を怠っていても、確認によって被保険者であったことが認められます。

**確認の効力**：資格取得の確認は、原則として**確認があった日の2年前の日**まで遡ります。ただし、**被保険者負担分の保険料が賃金から控除されていたことが明らかである期間**については、**2年を超えて**遡ることができます（22条5項）。

> ★この「2年を超えてさかのぼる」場合に、徴収法の**特例納付保険料**（26条）が問題になります。
