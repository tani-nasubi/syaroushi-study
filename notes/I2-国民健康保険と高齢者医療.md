# 国民健康保険法と高齢者医療確保法｜社一の深掘り

## 国民健康保険法

### 保険者（3条）

| 保険者 | 内容 |
|---|---|
| **都道府県**（当該都道府県内の市町村とともに） | **財政運営の責任主体**（平成30年4月〜）。**国保事業費納付金**の決定、**標準保険料率**の算定 |
| **市町村**（特別区を含む） | **資格管理、保険給付、保険料の賦課徴収、保健事業** |
| **国民健康保険組合** | 同種の事業・業務に従事する者で**300人以上**により組織。**都道府県知事の認可** |

> ★平成30年4月から**都道府県が財政運営の責任主体**になりました。市町村がなくなったわけではありません。

### 被保険者（5条・6条）

**都道府県の区域内に住所を有する者**は、当該都道府県が当該市町村とともに行う国民健康保険の被保険者とします。

**適用除外**（6条）の主なもの。

| 号 | 除外 |
|---|---|
| 1号 | **健康保険**の被保険者（日雇特例被保険者を除く） |
| 2号 | **船員保険**の被保険者 |
| 3〜5号 | **国家公務員共済・地方公務員共済・私学共済**の組合員・加入者 |
| 6〜8号 | 上記の**被扶養者** |
| 9号 | **後期高齢者医療**の被保険者 |
| 10号 | **生活保護**を受けている世帯に属する者 |
| 11号 | **国民健康保険組合**の被保険者 |

> ★**被扶養者という概念がありません**。世帯の全員がそれぞれ被保険者になります。ここが健保との最大の違いです。

### 国民健康保険組合の清算人（32条の4）

> 組合が解散したときは、**破産手続開始の決定による解散の場合を除き**、**理事**がその清算人となる。ただし、**規約に別段の定めがある**とき、又は**組合会において理事以外の者を選任**したときは、この限りでない。

> ★清算人になるのは**理事**です。「**監事**がその清算人となる」は**誤り**（令和6年に出ました）。

### 保険料（保険税）

| | |
|---|---|
| 賦課 | **世帯主**に対して賦課（**擬制世帯主**：世帯主が被保険者でなくても賦課される） |
| 構成 | **基礎賦課額**（医療分）＋**後期高齢者支援金等賦課額**＋**介護納付金賦課額**（40〜64歳） |
| 算定方式 | **所得割・資産割・被保険者均等割・世帯別平等割**の組合せ（4方式・3方式・2方式） |
| 徴収 | **普通徴収**（納付書等）と**特別徴収**（**年金からの天引き**。年額18万円以上の年金受給者等） |

### 給付

| 給付 | 内容 |
|---|---|
| **療養の給付**（36条） | 健保と同じ。一部負担金は**義務教育就学前2割／就学後70歳未満3割／70歳以上75歳未満2割（現役並み3割）** |
| **入院時食事療養費・入院時生活療養費・保険外併用療養費・療養費・訪問看護療養費・特別療養費・移送費** | 健保と同じ枠組み |
| **高額療養費・高額介護合算療養費** | 健保と同じ |
| **出産育児一時金**（58条） | **条例・規約**で定める（**任意給付**だが実際にはほぼ全市町村が実施） |
| **葬祭費・葬祭の給付** | **条例・規約**で定める（**任意給付**） |
| **傷病手当金・出産手当金** | **任意給付**（条例・規約で定めることができる。**実施している保険者はほとんどない**） |

> ★**傷病手当金・出産手当金は任意給付**です。「国保には傷病手当金がない」は正確には誤りで、「**任意給付であり、通常は行われていない**」が正解です。

### 保険給付の一時差止め（63条の2）

保険料を滞納した世帯主・組合員への段階的な措置です。

| 段階 | 中身 |
|---|---|
| **1項** | 保険料を滞納し、**納期限から省令で定める期間（1年6か月）**が経過するまでの間に、**納付の勧奨等**を行ってもなお納付しない場合、**災害その他政令で定める特別の事情**があると認められる場合を除き、保険給付の**全部又は一部の支払を一時差し止めるものとする** |
| **2項** | その期間が経過していなくても、勧奨等を行ってもなお滞納している場合には、**一時差し止めることができる** |
| **3項** | 1項により差し止められている場合に、なお滞納しているときは、**あらかじめ通知して**、差し止められている保険給付の額から**滞納保険料額を控除**することができる |

> ★1項は「**するものとする**」＝**原則として義務**、2項は「**できる**」＝**任意**です。ここが分かれ目です。
> ★**特別の事情**（災害等）があれば差し止めません。
> ★滞納保険料への充当（3項）には**あらかじめの通知**が必要です。

### 資格証明書・短期被保険者証（9条）

保険料を**1年以上**滞納している世帯主に対しては、**被保険者証の返還を求め、被保険者資格証明書を交付**します（特別の事情がある場合を除く）。資格証明書の場合、いったん**医療費の全額**を支払い、後で**特別療養費**として払戻しを受けます。

> ★令和6年12月のマイナ保険証への移行に伴い、資格確認書の運用に変更があります。

### 国民健康保険団体連合会（83条・84条）

| | |
|---|---|
| **設立** | **都道府県若しくは市町村又は組合**が、共同してその目的を達成するため設立できる（**任意**） |
| **法人格** | 法人とする。名称中に「国民健康保険団体連合会」の文字を用いる |
| **認可** | **都道府県知事**の認可。**認可を受けた時に成立**する |
| **強制加入** | 都道府県の区域を区域とする連合会に、その区域内の都道府県・市町村・組合の**3分の2以上**が加入したときは、**その他のすべてが会員となる** |

> ★**3分の2以上**です。「2分の1以上」は**誤り**（令和4年に出ました）。
> ★認可は**都道府県知事**です。厚生労働大臣ではありません。
> ★成立は**登記した時**ではなく**認可を受けた時**です。

主な業務は**診療報酬の審査支払**（介護給付費・障害福祉サービス等の審査支払も受託）です。

## 高齢者の医療の確保に関する法律

### 目的（1条）

> **国民の共同連帯**の理念等に基づき、**前期高齢者に係る保険者間の費用負担の調整**、**後期高齢者に対する適切な医療の給付**等を行うために必要な制度を設け、もつて国民保健の向上及び高齢者の福祉の増進を図る。

### 特定健康診査・特定保健指導（18条〜）

| | |
|---|---|
| 実施主体 | **保険者**（健保組合、協会けんぽ、国保、共済等） |
| 対象 | **40歳以上75歳未満**の加入者 |
| 内容 | **メタボリックシンドローム**に着目した健康診査と保健指導 |
| 特定保健指導の区分 | **動機付け支援**／**積極的支援** |

> ★**40歳以上75歳未満**。特定健診の実施主体は**保険者**であり、事業者（安衛法の健康診断）とは別です。

### 後期高齢者医療制度（47条〜）

| | |
|---|---|
| **運営主体** | **後期高齢者医療広域連合**（都道府県の区域ごとに**すべての市町村**が加入して設ける） |
| **被保険者**（50条） | ① 広域連合の区域内に住所を有する**75歳以上**の者<br>② **65歳以上75歳未満**で、**一定の障害の状態**にあり広域連合の**認定**を受けた者 |
| **適用除外** | **生活保護**を受けている世帯に属する者等 |

> ★**75歳になると自動的に**（届出不要で）後期高齢者医療の被保険者になり、それまでの医療保険の資格を失います。
> ★65〜74歳の障害認定は**本人の申請と広域連合の認定**が必要で、**いつでも撤回できます**。

### 事務の分担

| 広域連合 | 市町村 |
|---|---|
| **保険料率の決定、資格の管理、医療給付、財政運営** | **保険料の徴収、被保険者証の引渡し、各種申請の受付** |

> ★**保険料の徴収は市町村**、**保険料率の決定は広域連合**。ここが最頻出です。

### 保険料

| | |
|---|---|
| 賦課 | **被保険者本人**に賦課（世帯主ではない） |
| 構成 | **均等割額 ＋ 所得割額** |
| 保険料率 | **広域連合の条例**で定め、**2年**を通じ財政の均衡を保つことができるものでなければならない。**広域連合の区域内で均一**であることが原則 |
| 徴収 | **特別徴収**（年額18万円以上の年金からの天引き）が原則。**普通徴収**の場合、**世帯主および配偶者が連帯納付義務**を負う |

> ★保険料率は**2年ごと**に見直されます。

### 一部負担金（67条）

| 区分 | 割合 |
|---|---|
| 一般 | **1割** |
| **一定以上の所得**がある者 | **2割**（令和4年10月〜） |
| **現役並み所得者** | **3割** |

### 財源

| 財源 | 割合 |
|---|---|
| **公費** | **約5割**（国：都道府県：市町村＝**4：1：1**） |
| **後期高齢者支援金**（現役世代の保険料） | **約4割** |
| **後期高齢者の保険料** | **約1割** |

> ★**5：4：1**。この比率が問われます。

### 前期高齢者財政調整（32条〜）

**65歳以上75歳未満**の前期高齢者について、**各保険者の加入率の差による負担の不均衡**を調整します。**制度間の財政調整**であり、独立した医療制度ではありません。

> ★前期高齢者は**それまでの医療保険に加入したまま**です。「前期高齢者医療制度」という独立の制度はありません。ここが最頻出です。

### 移送費（国保法54条の4）

被保険者が療養の給付（保険外併用療養費・特別療養費に係る療養を含む）を受けるため**病院・診療所に移送**されたときは、**世帯主または組合員に対し**、移送費を支給します。

> ★**市町村・組合が必要であると認める場合に限り**支給されます。健保の移送費と同じ枠組みです。
> ★国保では、給付は**被保険者ではなく世帯主・組合員に対して**支給される形をとります。

### 普通徴収に係る保険料の納期（高齢者医療確保法109条）

> 普通徴収の方法によつて徴収する保険料の**納期は、市町村の条例**で定める。

> ★保険料**率**は**広域連合の条例**、普通徴収の**納期**は**市町村の条例**。決める主体が違います。
