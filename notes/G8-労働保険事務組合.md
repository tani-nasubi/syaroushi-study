# 労働保険事務組合｜徴収の深掘り

### 位置づけ（33条）

**中小事業主**の労働保険事務処理の負担を軽くするため、**事業主の委託**を受けて事務を処理する団体です。**厚生労働大臣の認可**を受けます。

認可を受けられるのは、**事業主の団体またはその連合団体**です。

| | |
|---|---|
| 認可 | **厚生労働大臣**（実際は都道府県労働局長に委任） |
| 認可の申請 | 主たる事務所の所在地を管轄する**都道府県労働局長**を経由 |
| 法人格 | **不要**（法人でない団体でも、代表者の定めがあり規約があればよい） |

> ★「法人でなければならない」は誤りです。

### 委託できる事業主の規模（33条1項、則20条の2）

| 業種 | 常時使用する労働者数 |
|---|---|
| **金融業・保険業・不動産業・小売業** | **50人以下** |
| **卸売業・サービス業** | **100人以下** |
| **上記以外**（製造業・建設業・運輸業など） | **300人以下** |

> ★労災保険の**第1種特別加入**（中小事業主等）と同じ区分です。セットで覚えます。
> ★「常時使用する」なので、一時的に超えても直ちに委託できなくなるわけではありません。

### 委託できる事務／できない事務

| 委託できる | 委託できない |
|---|---|
| **概算・確定保険料**等の申告・納付 | **印紙保険料**に関する事項 |
| 保険関係**成立届**、任意加入の申請、事業廃止等の届出 | **雇用保険二事業**に係る事務 |
| **雇用保険の被保険者**に関する届出等 | **労災保険の保険給付**に関する請求 |
| **労災保険の特別加入**の申請 | **雇用保険の給付**に関する請求 |

> ★**印紙保険料**は委託できません。日雇労働被保険者の手帳への貼付・消印は事業主自身が行います。
> ★**保険給付の請求**は労働者本人が行うものなので、委託の対象外です。

### 委託した場合の効果

| 事項 | 効果 |
|---|---|
| **政府からの通知** | 事務組合に対して行えば、**事業主に対して行ったものとみなす** |
| **納入告知書・納付書** | 事務組合に交付 |
| **納期限の延長** | 延納の第2期・第3期が**11月14日・2月14日**（通常は10月31日・1月31日） |
| **延納の要件** | 概算保険料の額にかかわらず**延納できる** |
| **報奨金** | 一定の要件を満たすと国から交付される |

### 責任の所在（35条）

ここが最頻出です。

| 場面 | 責任 |
|---|---|
| 事務組合が**政府に納付すべき徴収金**を納付しない | **事務組合**が納付の責めに任ずる |
| 事業主から**交付を受けた金額の限度**で、事務組合が滞納 | 事務組合が**その限度で**責任を負い、政府はまず**事務組合**に対して滞納処分をする |
| **事務組合の財産**につき滞納処分をしてもなお不足 | **事業主**から徴収する |
| **追徴金・延滞金**のうち、事務組合の**責めに帰すべき理由**によるもの | **事務組合**が負担する |

> ★事業主が事務組合に金銭を交付していれば、**その限度で事業主は義務を免れる**わけではなく、事務組合の財産で不足する場合には事業主から徴収されます。「事業主は一切責任を負わない」は誤りです。
> ★逆に、事業主が**金銭を交付していない**場合は、事務組合は納付の責任を負いません。

### 報奨金（附則）

| 要件 | |
|---|---|
| 対象 | 常時**15人以下**の労働者を使用する事業主から委託を受けた事務組合 |
| 納入率 | 前年度の労働保険料について、**5月15日までに95%以上**を納付していること |
| 額 | 納付額の**一定割合**（年度により定められる） |

### 認可の取消し（33条4項）

厚生労働大臣は、事務組合が**この法律・命令に違反**したときは、**認可を取り消す**ことができます。取消し後は、委託していた事業主が自ら事務を処理することになります。
