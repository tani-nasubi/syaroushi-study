# 機械等と化学物質の規制｜安衛の深掘り

### 危険物・有害物に関する規制の3段階

| 段階 | 条 | 内容 |
|---|---|---|
| **製造禁止** | 55条 | **黄りんマッチ、ベンジジン、石綿**など。**製造・輸入・譲渡・提供・使用**が禁止 |
| **製造許可** | 56条 | **ジクロルベンジジン、ベリリウム**など。製造しようとする者は**厚生労働大臣の許可** |
| **表示・通知** | 57条・57条の2 | 名称等を**表示**（ラベル）、**文書の交付**（SDS）等により通知 |

> ★製造禁止物質でも、**試験研究**のため製造・輸入・使用する場合は、**あらかじめ都道府県労働局長の許可**を受ければ可能です。
> ★製造許可の申請先は**厚生労働大臣**（禁止物質の試験研究の許可は**都道府県労働局長**）。ここが入れ替えられます。

### ラベル表示（57条）と SDS（57条の2）

| | ラベル表示（57条） | 通知（57条の2） |
|---|---|---|
| 場面 | **容器・包装**に入れて譲渡・提供するとき | 譲渡・提供するとき |
| 内容 | 名称、人体に及ぼす作用、貯蔵・取扱い上の注意、表示をする者の氏名等、**注意喚起語、絵表示** | 名称、成分・含有量、物理的・化学的性質、人体に及ぼす作用、貯蔵・取扱い上の注意、**流出その他の事故が発生した場合の応急措置**、通知を行う者の氏名等 |
| 方法 | 容器・包装に表示 | 文書の交付、磁気ディスクの交付、**FAX・電子メール**など相手方が承諾した方法 |

> ★SDS の記載事項のうち「**人体に及ぼす作用**」は、**5年以内ごとに1回**、最新の知見に基づき**確認・変更**しなければなりません（令和5年4月〜）。

### リスクアセスメント（57条の3）

**表示・通知対象物**について、事業者は**危険性または有害性等の調査**を行わなければなりません（**義務**）。

| 実施時期 |
|---|
| ① 対象物を**新規に採用**し、または**変更**するとき |
| ② 対象物を製造・取り扱う**業務の作業方法・作業手順を新規に採用・変更**するとき |
| ③ 対象物による危険性・有害性等について**変更が生じ、または生ずるおそれがある**とき |

調査の結果に基づき、**労働者の危険または健康障害を防止するため必要な措置**を講ずるよう**努めなければなりません**（努力義務）。

> ★**調査そのものは義務**、**調査結果に基づく措置は努力義務**。この非対称が問われます。
> ★28条の2の**機械等・作業に関するリスクアセスメント**は、対象業種が限定され、**調査自体が努力義務**です。57条の3（化学物質）とは別ものです。

### 化学物質の自律的管理（令和6年4月〜）

従来の**個別規制**（特化則・有機則等）から、**事業者による自律的な管理**へ移行が進んでいます。

| 制度 | 内容 |
|---|---|
| **化学物質管理者** | リスクアセスメント対象物を製造・取扱う**すべての事業場**で選任（**業種・規模を問わない**） |
| **保護具着用管理責任者** | リスクアセスメントの結果、**保護具を使用させる**場合に選任 |
| **濃度基準値** | 厚生労働大臣が定め、**屋内作業場**では労働者のばく露を基準値以下にすることが義務 |
| **がん原性物質の記録** | 作業記録を**30年間**保存 |

> ★化学物質管理者は**規模にかかわらず**選任が必要です。「50人以上」ではありません。

### 特定機械等（37条・38条）

| 対象 | ボイラー、第一種圧力容器、つり上げ荷重3トン以上の**クレーン**、つり上げ荷重3トン以上の**移動式クレーン**、つり上げ荷重2トン以上の**デリック**、積載荷重1トン以上の**エレベーター**、ガイドレール高さ18メートル以上の**建設用リフト**、**ゴンドラ** |
|---|---|

| 手続 | 主体 |
|---|---|
| **製造の許可**（37条） | **都道府県労働局長** |
| **製造時等検査**（38条） | 都道府県労働局長または**登録製造時等検査機関** |
| **検査証の交付**（39条） | 都道府県労働局長等 |
| **設置届**（88条） | **所轄労働基準監督署長**（工事開始の日の**30日前**まで） |
| **落成検査**（38条3項） | 所轄労働基準監督署長 |
| **性能検査**（41条2項） | 登録性能検査機関 |

> ★**検査証を受けていない特定機械等は、譲渡・貸与・設置してはなりません**（40条）。
> ★検査証の**有効期間**は原則**1年**（ボイラー・第一種圧力容器等）。性能検査を受けて更新します。

### 計画の届出（88条）

| 届出 | 期限 | 届出先 |
|---|---|---|
| **一定の機械等の設置・移転・変更** | 工事開始の日の**30日前**まで | **所轄労働基準監督署長** |
| **大規模建設業等の仕事**（高さ300メートル以上の塔、堤高150メートル以上のダム等） | 仕事開始の日の**30日前**まで | **厚生労働大臣** |
| **一定の建設・土石採取の仕事** | 仕事開始の日の**14日前**まで | 所轄労働基準監督署長 |

> ★**30日前が厚生労働大臣と監督署長の両方**にあり、**14日前は監督署長**だけです。数字と届出先の組合せで問われます。
> ★労働安全衛生**マネジメントシステム**を導入し、所轄労働基準監督署長の**認定**を受けた事業者は、**88条1項の届出が免除**されます。
