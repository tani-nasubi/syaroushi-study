# 特別加入｜労災の深掘り

### 制度の趣旨

労災保険は本来**労働者**のための制度ですが、業務の実態が労働者に準じ、保護するのが適当な者について、**任意に加入**を認めています（33条〜37条）。

### 4つの種別

| 種別 | 対象 | 加入手続 |
|---|---|---|
| **第1種**（33条1号・2号） | **中小事業主等**とその事業に従事する者 | **労働保険事務組合に事務処理を委託**していることが要件 |
| **第2種**（33条3号〜5号） | **一人親方その他の自営業者**とその事業に従事する者、**特定作業従事者** | **特別加入団体**を通じて申請 |
| **第3種**（33条6号・7号） | **海外派遣者** | 派遣元の団体・事業主が申請 |

### 第1種の「中小事業主」の規模

| 業種 | 労働者数 |
|---|---|
| 金融業・保険業・不動産業・小売業 | **50人以下** |
| 卸売業・サービス業 | **100人以下** |
| **上記以外**（製造業・建設業・運輸業など） | **300人以下** |

> ★労働保険事務組合への**委託が要件**なのは第1種だけです。第2種・第3種には要件ではありません。
> ★事業主が加入する場合、**その事業に従事する家族従事者等も包括して加入**しなければなりません（事業主だけの加入は不可）。

### 第2種の主な対象

**一人親方等**（労災則46条の17。**令和6年11月1日から12号**まで）

| 号 | 事業 |
|---|---|
| **1** | 自動車を使用して行う**旅客又は貨物の運送**の事業、**原動機付自転車又は自転車**を使用して行う**貨物**の運送の事業（個人タクシー・個人貨物運送業者） |
| **2** | 土木・建築その他の**工作物の建設・改造・保存・原状回復・修理・変更・破壊・解体**又はその準備の事業 |
| **3** | **漁船**による水産動植物の採捕の事業（7号の船員を除く） |
| **4** | **林業**の事業 |
| **5** | **医薬品の配置販売**の事業 |
| **6** | **再生利用**の目的となる廃棄物等の収集・運搬・選別・解体等の事業 |
| **7** | 船員法1条に規定する**船員**が行う事業 |
| **8** | **柔道整復師**が行う事業 |
| **9** | 高年齢者雇用安定法10条の2第2項の**創業支援等措置**に基づき高年齢者が行う事業 |
| **10** | **あん摩マッサージ指圧師・はり師・きゅう師**が行う事業 |
| **11** | **歯科技工士**が行う事業 |
| **12** | **特定受託事業者**（フリーランス法2条1項）が業務委託事業者から**業務委託**を受けて行う事業（＝**特定受託事業**）、及び業務委託事業者以外から委託を受けて行う同種の事業で労働基準局長が定めるもの |

> ★**12号は令和6年11月1日**から。それまで個別に置かれていた**芸能関係作業従事者・アニメーション制作作業従事者・自転車配達員・ITフリーランス**は、この**特定受託事業者**にまとめられました。古いテキストの号立てのままだと誤ります。
> ★**歯科技工士（11号）**も令和6年11月1日に加わりました。
> ★**柔道整復師（8号）・創業支援等措置（9号）・あん摩等（10号）**は12号とは別に**個別に残っています**。

**特定作業従事者**

- 特定農作業従事者、指定農業機械作業従事者
- 職場適応訓練従事者
- 事業主団体等委託訓練従事者
- 家内労働者およびその補助者
- 労働組合等の一人専従役員
- 介護作業従事者・家事支援従事者
- **歯科技工士**

### 特定作業従事者の細目（労災則46条の18）

第2種のうち「特定作業従事者」は、**省令が5種類を列挙**しています。数値が引っかけになります。

| 号 | 作業 | 押さえる点 |
|---|---|---|
| **1号** 農業 | 厚生労働大臣が定める規模の事業場での耕作・開墾・栽培・採取、家畜（**家きん・みつばちを含む**）や蚕の飼育のうち、①**動力**により駆動される機械を使用②**高さ2メートル以上**の箇所③**酸素欠乏危険場所**④**農薬の散布**⑤**牛・馬・豚**に接触するおそれ、のいずれかに当たるもの（＝**特定農作業従事者**）。／耕作・開墾・栽培・採取で**厚生労働大臣が定める種類の機械**を使うもの（＝**指定農業機械作業従事者**） | **2メートル**。「1メートル以上」は**誤り** |
| **2号** 職業訓練 | 国又は地方公共団体が実施する訓練のうち、**求職者を作業環境に適応させる**ための訓練、**求職者の就職を容易にする技能習得**の職業訓練で事業主等に委託されたもの | 「**求職者**」であって在職者ではない |
| **3号** 家内労働者 | 家内労働法2条2項の**家内労働者**、同条4項の**補助者**が行う、プレス機械・研削盤・有機溶剤・粉じん・動力織機・木工機械などを使う作業 | 家内労働者は**補助者も**対象 |
| **4号** 労働組合等の一人専従役員 | 労組法2条・5条2項に適合する労働組合等（**常時労働者を使用するものを除く**）の**常勤の役員**が行う、集会の運営・団体交渉その他の活動に係る作業（**必要な移動を含む**） | 常時労働者を使用する組合は除外 |
| **5号** 介護作業従事者・家事支援従事者 | 日常生活を円滑に営めるようにするための援助として行う**炊事・洗濯・掃除・買物・児童の日常生活上の世話及び必要な保護**その他家庭で日常生活を営むのに必要な行為 | 児童の世話も入る |

> ★令和2年に、この列挙にあるかどうかを問う択一が1問まるごと出ました。**高さ2メートル**が最も狙われます。

### 海外派遣者（第3種）

**海外の事業に派遣される労働者**、および**海外の中小規模の事業に派遣される事業主等**が対象です。

| 区分 | 特別加入 |
|---|---|
| **海外出張** | **不要**（国内の労災保険がそのまま適用） |
| **海外派遣** | **必要** |

区別は「国内の事業場に所属し、その事業場の使用者の指揮に従って勤務するか」です。

> ★「海外出張者も特別加入しなければ保護されない」は誤りです。

### 給付基礎日額（労災則46条の20）

特別加入者には賃金がないので、**申請に基づき厚生労働大臣が定める額**を給付基礎日額とします。**平均賃金は使いません**。

**3,500円・4,000円・5,000円・6,000円・7,000円・8,000円・9,000円・10,000円・12,000円・14,000円・16,000円・18,000円・20,000円・22,000円・24,000円・25,000円**の**16段階**から選びます。

> ★**最低は3,500円、最高は25,000円**です。「最低額が2,000円」は**誤り**（令和7年に出ました）。
> ★スライド（8条の2・8条の5）は、この定めた額を給付基礎日額とみなして適用します。

### 給付の内容

原則として労働者と同じ保険給付が行われますが、次の違いがあります。

| | 特別加入者 |
|---|---|
| 給付基礎日額 | 平均賃金ではなく、**3,500円〜25,000円**から選択し**厚生労働大臣が定める額** |
| **二次健康診断等給付** | **行われない** |
| 通勤災害 | 原則として対象。ただし**一部の一人親方**（自宅と作業場の区別がない者など）は**対象外** |
| 業務災害の範囲 | 「**特別加入者の業務災害の認定基準**」により、労働者より狭く限定される |

### 申請の経路（労災則46条の19・労災則46条の23）

| 種別 | 申請の名義 | 経路 |
|---|---|---|
| **第1種**（中小事業主等） | **事業主**（労働保険事務組合に事務委託していることが前提） | 労働保険事務組合を通じ、**所轄労働基準監督署長を経由**して**都道府県労働局長**へ |
| **第2種**（一人親方・特定作業従事者） | **特別加入団体** | 団体の主たる事務所の所在地を管轄する**労働基準監督署長を経由**して、**都道府県労働局長**へ |
| **第3種**（海外派遣者） | **派遣元の事業主** | 同上 |

- 承認するのは**都道府県労働局長**です。労働基準監督署長は**経由**するだけです。
- **保険給付に関する事務**は、第2種では**特別加入団体の主たる事務所の所在地を管轄する労働基準監督署長**が行います。

> ★**「承認は都道府県労働局長、経由は労働基準監督署長」**が固定の型です。

### 加入の効力と脱退

| 場面 | 効力発生 |
|---|---|
| 加入申請の承認 | **申請日の翌日から起算して30日以内**で申請者が希望する日（承認があった日の翌日以後） |
| 脱退の申請 | **申請日の翌日**に効力を失う |

**保険料の滞納**があると、その期間中の事故について**支給制限**（給付額の全部または一部を行わないことができる）を受けます。

> ★政府の**職権**による特別加入の**取消し**もあります（労働保険料の滞納、法令違反など）。
