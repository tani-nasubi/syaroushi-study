# 督促・延滞金・時効｜徴収の深掘り

### 督促（27条）

労働保険料その他の徴収金を納付しない者があるときは、政府は**期限を指定して督促**しなければなりません。

| | 内容 |
|---|---|
| 督促状 | **納付すべき期限を指定**して発する |
| 指定期限 | 督促状を**発する日から起算して10日以上**経過した日 |
| 期限までに納付しないとき | **国税滞納処分の例**によって処分する（差押え等） |

> ★「10日以内」ではなく「**10日以上経過した日**」を指定します。事業主に猶予を与える趣旨です。
> ★督促は**保険料の徴収の前提**であるとともに、**延滞金**発生と**時効の更新**の効果を持ちます。

### 延滞金（28条）

**督促をしたとき**に徴収します。督促をしなければ延滞金は発生しません。

```
延滞金 ＝ 労働保険料の額 × 期間の日数 × 率
```

| 期間 | 率 |
|---|---|
| 納期限の翌日から**2か月**を経過する日まで | **年7.3%** |
| それ以後 | **年14.6%** |

期間は**納期限の翌日から、完納または財産差押えの日の前日まで**です。

延滞金を徴収しない場合。

1. 労働保険料の額が**1,000円未満**であるとき
2. 納付すべき労働保険料の額に**1,000円未満の端数**があるとき（その端数は切り捨て）
3. 延滞金の額が**100円未満**であるとき
4. 労働保険料について**滞納処分の停止**をしたとき
5. **納付義務者の住所・居所が国内にない**ため公示送達の方法で督促したとき
6. **天災その他やむを得ない理由**があるとき

> ★起算日は**督促状の指定期限の翌日ではなく、本来の納期限の翌日**です。ここが最頻出の引っかけです。

### 追徴金（21条）との違い

| | 追徴金 | 延滞金 |
|---|---|---|
| 発生原因 | **確定保険料**の**認定決定** | **督促** |
| 率 | **10%**（印紙保険料は**25%**） | 年7.3%／年14.6% |
| 性格 | **制裁**（申告義務違反） | **利息**（納付遅延） |
| 概算保険料の認定決定 | **かからない** | 督促すればかかる |

### 先取特権（29条）

労働保険料その他の徴収金の先取特権の順位は、**国税および地方税に次ぐ**ものとされています。

### 時効（41条）

| 対象 | 時効 |
|---|---|
| **労働保険料**その他この法律の規定による**徴収金**を徴収し、またはその**還付**を受ける権利 | **2年** |

> ★労災の保険給付は2年・5年、雇用の給付は2年ですが、**徴収法上の徴収金・還付はすべて2年**です。

**政府が行う徴収金の告知または督促**は、**時効の更新**の効力を生じます（民法の規定にかかわらず）。

### 書類の保存

| 書類 | 保存期間 |
|---|---|
| 労働保険に関する**書類**（一般） | 完結の日から**3年間** |
| **雇用保険**に関する書類（被保険者に関するものを除く） | 完結の日から**2年間** |
| 雇用保険の**被保険者**に関する書類 | 完結の日から**4年間** |
| **雇用保険印紙**の受払簿 | 翌年度の初日から**3年間** |

> ★労基法の**記録の保存は5年（当分の間3年）**。徴収法は3年。混同しやすいところです。

### 報告・立入検査（42条・43条）

行政庁は、事業主・労働保険事務組合に対し、**労働保険料に関する事項について報告・文書の提出・出頭**を命ずることができ、**当該職員に立入検査**をさせることができます。

立入検査の職員は**その身分を示す証票を携帯**し、関係者に提示しなければなりません。この権限は**犯罪捜査のために認められたものと解してはならない**とされています。

### 罰則（46条）

事業主が次のいずれかに該当すると、**6か月以下の拘禁刑または30万円以下の罰金**に処せられます。

1. **雇用保険印紙を貼らず、または消印しなかった**とき（23条2項違反）
2. **帳簿**を備えず、記載せず、虚偽の記載をし、または**報告**をせず、虚偽の報告をしたとき（24条違反）
3. **報告徴収**（42条）の命令に違反して報告をせず、虚偽の報告をし、文書を提出せず、虚偽の文書を提出したとき
4. **立入検査**（43条1項）の質問に答弁せず、虚偽の答弁をし、検査を拒み・妨げ・忌避したとき

**労災保険法35条1項の団体**（特別加入団体）が3号・4号に該当する場合は、**違反行為をした団体の代表者・代理人・使用人その他の従業者**も同様に処罰されます。

> ★徴収法の罰則は**保険料の未納そのものには科されません**（滞納処分で対応）。**印紙・帳簿・報告・検査**に関する義務違反が対象です。
