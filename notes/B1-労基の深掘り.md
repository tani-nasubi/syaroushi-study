## 賃金の全額払いと相殺

### 前提となる原則

労基法24条1項の**全額払いの原則**は、使用者が労働者に対して持つ債権（貸付金・損害賠償など）と賃金を**一方的に相殺すること**を禁じています。

> 賃金全額払の原則の趣旨は、使用者が一方的に賃金を控除することを禁止し、労働者に賃金の全額を確実に受領させ、**労働者の経済生活を脅かすことのないようにしてその保護を図る**ことにある

### では労働者が同意したら？（日新製鋼事件）

**事案**は住宅ローンの清算でした。

1. 労働者が会社の提携ローンで住宅資金を借りた
2. 「退職するときは**退職金で残債務を一括返済する**」と約束していた
3. 退職時、会社が退職金から借入金分を差引いて金融機関に払った
4. その後この労働者が**破産**し、破産管財人が「全額払い違反で無効、退職金を返せ」と主張

**判旨**

> 労働者がその**自由な意思**に基づき当該相殺に同意した場合において、その同意が労働者の自由な意思に基づいてされたものであると認めるに足りる**合理的な理由が客観的に存在する**ときは、その同意を得てした相殺は24条1項に違反しない

### 「合理的な理由が客観的に存在」とは具体的に何か

最高裁が挙げた事実がそのまま判断材料になります。

| 認定された事実 |
|---|
| 相殺の合意が**労働者から自発的に**なされた |
| 会社による**強要にわたる事情がなかった** |
| 労働者が関係書類への署名押印に**異議なく応じていた** |
| 借入金は住宅取得という**労働者自身の利益**になるものだった |
| 退職時に退職金で一括返済する約束を**十分認識していた** |

**同意書にハンコがあるだけでは足りません。** その同意が本当に自発的だったと外から見て言えるかを、事情を総合して**厳格かつ慎重に**判断します。

### 同じ枠組みが3か所で使われる

ここが本番で効きます。**言い回しの型**として覚えてください。

| 場面 | 判例 |
|---|---|
| 賃金債権の**放棄** | シンガー・ソーイング・メシーン事件 |
| 賃金の**相殺**への同意 | 日新製鋼事件 |
| **就業規則の不利益変更**への同意 | 山梨県民信用組合事件 |

いずれも「**自由な意思に基づくと認めるに足りる合理的な理由が客観的に存在するか**」で判断します。

### 混同しやすい別枠：調整的相殺

過払賃金の清算のための相殺は、**労働者の同意が要りません**。基準が違います。

> **時期・方法・金額**等からみて労働者の**経済生活の安定**を脅かすおそれがないときは許される

「自由な意思」の話と混ぜないでください。

### 試験での問われ方

- 択一の誤り肢：「使用者は労働者の同意なく相殺できる」→ **誤り**
- 択一の誤り肢：「労働者の同意があれば**直ちに**有効」→ **誤り**（合理的な理由が客観的に必要）
- 選択式：「**自由な意思**」「**合理的な理由が客観的に存在**」が空欄

## 労働時間とは何か

### 判示の核

> 労働基準法上の労働時間とは、**労働者が使用者の指揮命令下に置かれている時間**をいい、労働契約・就業規則・労働協約等の定めのいかんにより決定されるべきものではない

後半が重要です。**当事者の合意で「これは労働時間ではない」と決めても無効**であり、**客観的に**定まります。

### なぜ争いになるか

「働いている」とも「休んでいる」とも言いにくい時間があるからです。

| 場面 | 結論 | 理由 |
|---|---|---|
| 始業前の**作業服・保護具の着脱** | 使用者から**義務付けられ、又は余儀なくされた**ときは労働時間 | 使用者の指揮命令下にある |
| **仮眠時間**（不活動時間） | **労働からの解放が保障されていない**ときは労働時間 | 現に作業していなくても、必要が生じれば直ちに対応すべき状態なら指揮命令下 |
| **手待時間** | 労働時間 | 同上 |
| 移動時間（通勤） | 原則として労働時間でない | 指揮命令下にない |
| 移動時間（業務命令による物品運搬等） | 労働時間 | 指揮命令下にある |

### 覚えるキーワード

「**指揮命令下**」「**労働からの解放**」「**客観的に定まる**」

★令和6年度の選択式で「指揮命令下」「労働からの解放」が正答になっています。

## 平均賃金

### 何のための制度か

**解雇予告手当・休業手当・年休の賃金・災害補償**などの計算基礎です。「その労働者の通常の生活賃金」を表すことを狙っています。

### 計算

```
平均賃金 ＝ 算定事由発生日以前3か月間の賃金総額 ÷ その期間の総日数（暦日数）
```

**分母は労働日数ではなく暦日数**です。ここが最頻出の引っかけです。

### 起算日（12条1項・2項）

条文は「算定すべき事由の発生した日**以前**三箇月間」ですが、行政解釈で**当日は含まず前日からさかのぼる**とされています。事由発生日は休業等で算定に適さないためです。

**賃金締切日があれば、前日ではなく直前の賃金締切日から起算**します（12条2項）。

### 控除するもの（期間と賃金の両方）

次の期間は**分母からも分子からも除きます**。

1. 業務上負傷・疾病による**療養のための休業**期間
2. **産前産後**の休業期間
3. **使用者の責めに帰すべき事由**による休業期間
4. **育児・介護休業**期間
5. **試みの使用**期間

> 控除期間が3か月以上にわたる場合は、**都道府県労働局長**が決定します（施行規則4条）。
> ★この主体を「厚生労働大臣」に書き換える誤り肢が定番です。

### 最低保障

日給・時給・出来高払の場合、通常の計算額と次の額の**高いほう**を採ります。

```
賃金総額 ÷ 労働日数 × 60/100
```

## 解雇

### 3つの層を分けて考える

混乱しやすいので、**層が3つある**ことを先に押さえてください。

| 層 | 内容 | 根拠 |
|---|---|---|
| ① できるか | 客観的に合理的な理由・社会通念上の相当性がなければ**権利濫用で無効** | 労働契約法16条 |
| ② 手続 | **30日前の予告**、または**30日分以上の平均賃金**（解雇予告手当） | 労基法20条 |
| ③ 時期の制限 | 業務上災害の療養休業中と産前産後休業中＋**その後30日間**は解雇できない | 労基法19条 |

### 解雇予告の除外

**予告も手当も不要**になるのは次の2つで、いずれも**所轄労働基準監督署長の認定**が必要です。

- 天災事変その他やむを得ない事由のために**事業の継続が不可能**となった場合
- **労働者の責めに帰すべき事由**による場合

> 認定は**効力要件ではなく確認行為**とされていますが、試験では「認定を受けなければならない」で出ます。

### 予告日数の短縮

予告手当を支払った日数分だけ予告期間を短縮できます。

```
20日前に予告 ＋ 10日分の平均賃金 ＝ 適法
```

### 解雇が無効だったときの中間収入

解雇期間中の賃金を支払うが、労働者が他で得た収入（中間収入）は**平均賃金の6割を超える部分から控除**できます。**6割は必ず保障**されます。

★令和元年度の選択式で「平均賃金の6割」が問われています。

## 就業規則

### 作成・届出・周知

| 項目 | 内容 |
|---|---|
| 義務 | 常時**10人以上**の労働者を使用する使用者 |
| 手続 | 労働者の過半数代表の**意見を聴く**（同意は不要）→ 意見書を添えて**所轄労働基準監督署長**に届出 |
| 周知 | 掲示・備付け・書面交付・電子的方法のいずれか |

> **意見を「聴く」だけでよい**のが引っかけの定番です。反対意見でも届出は受理されます。

### 不利益変更（労働契約法9条・10条）

原則は「労働者の合意なく不利益に変更できない」（9条）ですが、例外として10条があります。

> 変更後の就業規則を**周知**させ、かつ変更が**合理的**なものであるときは、労働条件は変更後の就業規則による

**合理性の判断要素**

1. 労働者の受ける**不利益の程度**
2. 労働条件の変更の**必要性**
3. 変更後の内容の**相当性**
4. **労働組合等との交渉の状況**
5. その他の事情

### 労働者が同意していた場合

就業規則の不利益変更に労働者が同意していても、それだけでは足りません。**賃金の相殺と同じ枠組み**が使われます。

> 同意が労働者の**自由な意思**に基づいてされたものと認めるに足りる**合理的な理由が客観的に存在**するか

→ [賃金の全額払いと相殺](#賃金の全額払いと相殺) と同じ型です。

### 効力の順序

```
法令 ＞ 労働協約 ＞ 就業規則 ＞ 労働契約
```

就業規則の基準に達しない労働契約は、その部分が無効となり、**就業規則の基準による**（労働契約法12条）。

## 年次有給休暇

### 発生要件

**雇入れの日から6か月継続勤務**し、全労働日の**8割以上出勤**で10日。以後1年ごとに加算し、6年6か月で**20日**が上限です。

### 出勤率の計算で「出勤したものとみなす」もの

1. 業務上負傷・疾病による**療養のための休業**期間
2. **産前産後**の休業期間
3. **育児・介護休業**期間
4. **年次有給休暇**を取得した日

> 「使用者の責めに帰すべき事由による休業」は**全労働日から除く**（分母から外す）扱いで、
> 「出勤したものとみなす」のとは処理が違います。ここが引っかけです。

### 時季変更権（2回出題）

労働者の時季指定に対し、使用者は「**事業の正常な運営を妨げる場合**」に限って時季を変更できます。

> **代替勤務者の確保**が客観的に可能な状況にあるにもかかわらず、使用者が**通常の配慮**をしなかったときは、時季変更権の行使は違法

長期かつ連続の休暇については、使用者にある程度の**裁量的判断**の余地が認められます。

★平成29年度の選択式で「事業の正常な運営」「裁量的判断」が正答です。

### 自由利用

> 年次有給休暇の**利用目的は労基法の関知しないところ**であり、休暇をどのように利用するかは**使用者の干渉を許さない労働者の自由**である

### 年5日の時季指定義務

10日以上付与される労働者に対し、使用者は**年5日**について時季を定めて与えなければなりません。労働者が自ら取得した日数と計画年休の日数は、その5日から**控除**します。

## 労働者性

### なぜ争いになるか

労基法の保護を受けるかどうかが決まるからです。**契約の名称（請負・委任）ではなく実態**で判断します。

### 判断の枠組み（使用従属性）

| 要素 | 具体的な判断材料 |
|---|---|
| **指揮監督下の労働** | ① 仕事の依頼・業務従事の指示等に対する**諾否の自由**の有無 ② 業務遂行上の**指揮監督**の有無 ③ **時間的・場所的な拘束**の有無 ④ **代替性**の有無 |
| **報酬の労務対償性** | 報酬が**時間給を基礎として計算される**等、労務の対価としての性格が強いか |
| 補強要素 | **事業者性**（機械・器具の負担、報酬の額）、**専属性**の程度、**公租公課の負担** |

### 具体例

| 事例 | 結論 |
|---|---|
| 自己所有のトラックで運送する運転手 | 労働者性を**否定** |
| 工務店の大工 | 労働者性を**否定** |
| 研修医 | 病院の指揮監督下で医療行為に従事する以上、**労働者に当たる** |

**判示のキーワード**：「諾否の自由」「時間的、場所的な拘束」「報酬の支払方法、公租公課の負担」

## 労働契約の期間

### 上限（14条）

| 区分 | 上限 |
|---|---|
| 原則 | **3年** |
| **専門的知識等**を有する労働者 | **5年** |
| **満60歳以上**の労働者 | **5年** |
| 一定の事業の完了に必要な期間を定めるもの | その期間（上限なし） |

> 期間の定めの**ない**契約は対象外です。「一定の事業の完了に必要な期間」は
> 有期でも上限がかからない点が引っかけになります。

### 途中解約

原則3年の契約で1年を超えた労働者は、**いつでも退職できます**（附則137条）。専門的知識等・60歳以上の5年契約にはこの規定が**適用されません**。
