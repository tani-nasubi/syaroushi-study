# 適用事業所と被保険者｜健保の深掘り

### 適用事業所（3条3項）

| 区分 | 内容 |
|---|---|
| **強制**適用事業所 | ① **法人**の事業所（業種・人数を問わず、**代表者1人でも**適用）<br>② **個人**経営で、**常時5人以上**の従業員を使用する**法定17業種**の事業所 |
| **任意**適用事業所 | 上記以外。**従業員の2分の1以上の同意**を得て事業主が申請し、**厚生労働大臣の認可**を受ける |

**法定17業種に含まれないもの**（個人経営なら5人以上でも強制適用にならない）。

- **農林水産業**
- **飲食店、旅館などのサービス業**（ただし令和4年10月から**士業**は追加された）
- **宗教業**（神社、寺院、教会）

> ★令和4年10月から、**弁護士・公認会計士・税理士・社会保険労務士などの士業**が法定業種に加わりました。
> ★任意適用事業所の**取消し**には、**従業員の4分の3以上の同意**と厚生労働大臣の認可が必要です。加入は2分の1、脱退は4分の3。

### 被保険者（3条1項）

適用事業所に使用される者は、**国籍・性別・賃金の額を問わず**被保険者となります。

**適用除外**（3条1項但書）。

| 号 | 除外される者 |
|---|---|
| 1号 | **船員保険**の被保険者 |
| 2号 | 臨時に使用される者で、**日々雇い入れられる者**（1か月を超えて引き続き使用されるに至った場合を除く） |
| 3号 | 臨時に使用される者で、**2か月以内**の期間を定めて使用される者（所定の期間を超えて引き続き使用されることが**見込まれる**場合を除く） |
| 4号 | **季節的業務**（4か月以内）に使用される者 |
| 5号 | **臨時的事業の事業所**（6か月以内）に使用される者 |
| 6号 | **所在地が一定しない**事業所に使用される者 |
| 7号 | 国民健康保険組合の事業所に使用される者 |
| 8号 | **後期高齢者医療の被保険者**等 |
| 9号 | 厚生労働大臣等の**承認**を受けた者（**任意適用事業所の取消し**等） |

> ★3号は令和4年10月改正。**当初から2か月を超えて使用される見込みがある場合**は、**最初から被保険者**になります。「2か月経過してから」は誤りです。

### 短時間労働者の適用拡大

| 要件 | 内容 |
|---|---|
| ① 週の所定労働時間 | **20時間以上** |
| ② 賃金 | 月額**8.8万円以上**（賞与・残業代・通勤手当を除く） |
| ③ 雇用期間 | **2か月を超えて**使用される見込み |
| ④ 学生 | **学生でない**こと |
| ⑤ 企業規模 | 被保険者の総数が常時**50人を超える**（令和6年10月〜） |

**特定適用事業所**に該当しない企業でも、**労使合意**（被保険者の2分の1以上の同意）により**任意特定適用事業所**として適用できます。

> ★通常の被保険者は「**4分の3基準**」（週の所定労働時間および月の所定労働日数が、通常の労働者の**4分の3以上**）で判定します。4分の3未満の者について上の5要件を見ます。

### 任意継続被保険者（3条4項・37条）

| 要件 | |
|---|---|
| 資格喪失前の被保険者期間 | **継続して2か月以上** |
| 申出 | 資格を喪失した日から**20日以内**に保険者に申し出る（**正当な理由**があれば期間経過後も可） |
| 期間 | **2年間** |
| 保険料 | **全額自己負担**（事業主負担なし）。**前納**もできる |

**資格喪失事由**（38条）。

1. 任意継続被保険者となった日から起算して**2年**を経過したとき
2. **死亡**したとき
3. 保険料を**納付期日までに納付しなかった**とき（**納付期日の翌日**に喪失。正当な理由があれば除く）
4. **被保険者**となったとき
5. **船員保険**の被保険者となったとき
6. **後期高齢者医療**の被保険者等となったとき
7. **任意継続被保険者でなくなることを希望**する旨を保険者に申し出た場合において、その申出が受理された日の属する**月の末日が到来**したとき

> ★7号は令和4年1月から。**本人の希望で脱退できる**ようになりました。
> ★保険料の基礎となる標準報酬月額は、**資格喪失時の標準報酬月額**と**全被保険者の平均標準報酬月額**の**いずれか低い額**です（保険者が定める場合はその額）。

### 特例退職被保険者

**特定健康保険組合**（厚生労働大臣の認可）の組合員であった者で、**老齢厚生年金等の受給権者**が対象です。**後期高齢者医療の被保険者となるまで**（75歳まで）継続できます。

> ★任意継続の2年制限がありません。ここが違いです。

### 資格の得喪と確認

| | |
|---|---|
| 取得 | 適用事業所に**使用されるに至った日**、適用事業所となった日、適用除外に該当しなくなった日 |
| 喪失 | 死亡した日の**翌日**、事業所に使用されなくなった日の**翌日**、適用除外に該当した**その日**、任意適用事業所の取消しの認可があった日の**翌日** |
| 確認 | 保険者等の**確認**によって効力を生ずる（**任意継続被保険者・特例退職被保険者を除く**） |

> ★**適用除外に該当したときだけ「その日」**に喪失します（翌日ではありません）。

### 休職と被保険者資格

**使用関係が続いているか**で判断します。賃金が出ているかどうかではありません。

| 場面 | 資格 |
|---|---|
| **病気休職**（賃金の支払停止は一時的、使用関係は存続） | **喪失しない**。事業主は**保険料を納付する義務を負う**（報酬がなくても、休職直前の標準報酬月額で計算） |
| **長期にわたる休職状態が続き実務に服する見込がない**場合 | **喪失する** |
| **公務に就任しこれに専従する**場合 | **喪失する** |
| **一時帰休（レイオフ）** | 喪失しない。休業手当等が支払われれば、その額で随時改定の対象になり得る |

> ★病気休職中も**保険料はかかります**。「報酬がないから保険料も生じない」は**誤り**です。
> ★休職により**標準報酬月額は下がりません**（固定的賃金の変動ではないため随時改定の対象外）。ただし**一時帰休**で休業手当が継続して支払われる場合は別で、随時改定の対象になります。
