# 老齢厚生年金｜厚年の深掘り

### 受給要件（42条）

1. **老齢基礎年金の受給資格期間**（10年）を満たしていること
2. 厚生年金保険の被保険者期間が**1か月以上**あること
3. **65歳**に達したこと

> ★厚年の被保険者期間は**1か月**でよく、受給資格期間の10年は**国民年金全体**で見ます。

### 特別支給の老齢厚生年金（附則8条）

**60歳から65歳になるまで**支給される経過的なものです。

| 要件 | |
|---|---|
| ① | **1年以上**の被保険者期間があること |
| ② | 老齢基礎年金の受給資格期間を満たしていること |
| ③ | **60歳以上**であること |
| ④ | 生年月日が支給開始年齢の引上げの対象であること |

| 生年月日 | 男性（一般） |
|---|---|
| 昭和28年4月2日〜昭和30年4月1日 | 61歳から**報酬比例部分** |
| 昭和30年4月2日〜昭和32年4月1日 | 62歳から |
| 昭和32年4月2日〜昭和34年4月1日 | 63歳から |
| 昭和34年4月2日〜昭和36年4月1日 | 64歳から |
| **昭和36年4月2日以後** | **支給なし**（65歳から本来の老齢厚生年金） |

> ★**女性は5年遅れ**（昭和41年4月2日以後生まれで支給なし）。**坑内員・船員**は男女とも昭和33年4月2日以後生まれで支給なしです。
> ★「**1年以上**」が必要な点が本来支給（1か月以上）と違います。

**長期加入者の特例・障害者の特例**：**44年（528月）以上**の被保険者期間がある者、または**障害等級3級以上**に該当する者は、報酬比例部分の支給開始年齢から**定額部分もあわせて**支給されます（障害者の特例は**請求**が必要）。

> ★長期加入者の特例は**請求不要**（職権）、障害者の特例は**請求が必要**。この差が問われます。
> ★いずれも**被保険者でないこと**が要件です（在職中は適用されません）。

### 年金額（43条）

```
老齢厚生年金 ＝ 報酬比例部分 ＋ 経過的加算 ＋ 加給年金額
```

**報酬比例部分**

```
平均標準報酬月額 × 7.125/1000 × 平成15年3月までの被保険者期間の月数
＋ 平均標準報酬額 × 5.481/1000 × 平成15年4月以後の被保険者期間の月数
```

| | |
|---|---|
| **平均標準報酬月額** | 平成15年3月まで（**賞与を含まない**）。**総報酬制導入前** |
| **平均標準報酬額** | 平成15年4月以後（**賞与を含む**）。**総報酬制導入後** |

> ★**7.125／5.481**は**新乗率**（平成15年改正）。生年月日に応じた**旧乗率**（9.5／7.308など）で計算した額のほうが高い場合はそちらが適用されます（従前額保障）。

**経過的加算**（差額加算）

```
定額部分の額 − 老齢基礎年金相当額（厚生年金の被保険者期間のうち20歳以上60歳未満の部分）
```

> ★**20歳前・60歳以後の厚生年金被保険者期間**は老齢基礎年金に反映されないため、その差額を厚生年金から補うものです。

### 在職定時改定（43条3項）★令和4年4月〜

**65歳以上**の在職中の被保険者について、**毎年9月1日（基準日）**を基準に、**前月まで**の被保険者期間を算入して**10月分**から年金額を改定します。

> ★従来は退職するまで年金額が増えませんでした。**65歳未満には適用されません**。

### 退職改定（43条2項）

被保険者資格を**喪失**し、かつ**被保険者となることなく1か月**を経過したとき、資格喪失日から起算して**1か月**を経過した日の属する月から年金額を改定します。

### 繰上げ・繰下げ

| | 繰上げ | 繰下げ |
|---|---|---|
| 期間 | **60歳以上65歳未満** | **66歳以後75歳まで** |
| 率 | **1月0.4%減**（最大24%減） | **1月0.7%増**（最大84%増） |
| 老齢基礎年金と | **同時**でなければならない | **別々**にできる |
| 加給年金額 | 繰上げても**65歳から** | 繰り下げても**増額されない**（待機中は支給されない） |

> ★特別支給の老齢厚生年金の**受給権者**は、その受給権があるうちは老齢厚生年金の**繰下げはできません**（65歳到達後の話）。
> ★**在職老齢年金により支給停止されている部分は繰下げによる増額の対象になりません**。

### 加給年金額（44条）

| 要件 | |
|---|---|
| 被保険者期間 | **240月（20年）以上**（中高齢の特例に該当する場合はその期間） |
| 対象 | **65歳未満の配偶者**、**18歳到達年度末までの子**（または20歳未満で1級・2級の障害の子） |
| 生計維持 | 受給権取得当時、生計を維持していること |

| 対象 | 加算額 |
|---|---|
| 配偶者 | **224,700円 × 改定率**（＋**特別加算**：受給権者の生年月日に応じ、**33,200円×改定率**から最大**165,800円×改定率**まで） |
| 子（1人目・2人目） | 各**224,700円 × 改定率** |
| 子（3人目以降） | 各**74,900円 × 改定率** |

**加給年金額が支給停止される場合**

- 配偶者が**老齢厚生年金（240月以上）・退職共済年金・障害年金**を受けられるとき
- 配偶者が**65歳**に達したとき（**振替加算**に切り替わる）

> ★配偶者の**加給年金額の特別加算**は、**受給権者本人の生年月日**が新しいほど**高く**なります（昭和18年4月2日以後生まれが最高額）。
> ★「配偶者が20年以上の老齢厚生年金を受けられるとき」は、**支給停止**であり**加算対象から外れる**わけではありません（配偶者が全額支給停止なら加給年金は支給されます）。

### 第3種被保険者期間の特例（坑内員・船員）

**坑内員・船員**（第3種被保険者）は、労働の過酷さを踏まえて**被保険者期間を割り増して数える**特例があります。

| 実際の期間 | 数え方 |
|---|---|
| **昭和61年3月31日以前** | **3分の4倍** ⚠️要確認 |
| **昭和61年4月1日〜平成3年3月31日** | **5分の6倍** ⚠️要確認 |
| **平成3年4月1日以後** | **実期間のまま**（特例なし） |

- 割り増した期間は、**受給資格期間**と**年金額**の計算に使います。
- ただし**経過的加算**（差額加算）の計算の基礎となる期間には、この特例を**適用しません**（実期間で見ます）。

> ★「第3種被保険者期間があれば**必ず**3分の4倍又は5分の6倍される」は**誤り**です。**平成3年4月1日以後は実期間**ですし、**経過的加算では割り増しません**。
> ★坑内員・船員は**55歳から**の特別支給がありました。今は男女とも**昭和33年4月2日以後生まれで支給なし**です。

### 中高齢者の期間短縮特例

**昭和26年4月1日以前生まれ**の者について、40歳（女性・坑内員・船員は35歳）以後の被保険者期間が**15年〜19年**あれば、受給資格期間を満たしたものとみなします。
