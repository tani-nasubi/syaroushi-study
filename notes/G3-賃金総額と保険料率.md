# 賃金総額と保険料率｜徴収の深掘り

### 一般保険料の額（11条）

```
一般保険料 ＝ 賃金総額 × 一般保険料率
```

「**賃金総額**」とは、事業主がその事業に**使用するすべての労働者**に支払う**賃金の総額**です。

> ★「被保険者に支払う」ではなく「**使用するすべての労働者**」です。雇用保険の被保険者でない者（週20時間未満のパート等）の賃金も、**労災分**の賃金総額には含まれます。

### 賃金に含まれるか

| 含まれる | 含まれない |
|---|---|
| 基本給、家族手当、通勤手当、住宅手当 | **役員報酬**（労働者としての賃金部分を除く） |
| **賞与**、期末手当 | **退職金**（退職を事由に支払われるもの） |
| **深夜・休日手当** | **結婚祝金・見舞金**（恩恵的なもの） |
| **休業手当**（労基法26条） | **休業補償**（労基法76条・平均賃金の60%） |
| 通勤定期券の現物支給 | **解雇予告手当** |
| 前払退職金（毎月支払われるもの） | 出張旅費、**制服・作業着** |
| 生産奨励金、能率手当 | 退職金の**打切支給** |

> ★**休業手当は含まれる／休業補償は含まれない**。この対比が最頻出です。
> ★通勤手当は**非課税分も含めて全額**が賃金です。税法上の扱いとは異なります。

### 賃金総額の特例（11条3項）

正確な把握が困難な事業について、**請負金額や素材生産量**から賃金総額を算定します。

| 事業 | 算定方法 |
|---|---|
| **請負による建設**の事業 | 請負金額 × **労務費率** |
| **立木の伐採**の事業 | 素材の生産量 × 生産量1立方メートルあたりの**労務費の額** |
| **造林、木炭・薪の生産**等の事業 | 厚生労働大臣が定める**平均賃金額** × 使用労働者の**延数** |

> ★建設の請負金額は**消費税相当額を除いた額**です。

### 保険料率（12条）

| 保険関係 | 一般保険料率 |
|---|---|
| 労災・雇用**両方** | **労災保険率 ＋ 雇用保険率** |
| **労災のみ** | 労災保険率 |
| **雇用のみ** | 雇用保険率 |

### 労災保険率

- **事業の種類ごと**に定められ、**最高1000分の88／最低1000分の2.5**
- **過去3年間**の災害率等を考慮して**厚生労働大臣**が定める
- 原則として**3年ごと**に改定
- **全額事業主負担**

労災保険率には**非業務災害率**（通勤災害・二次健康診断等給付に充てる分、**1000分の0.6**）が含まれます。メリット制で増減するのは**労災保険率から非業務災害率を減じた率**の部分です。

### 雇用保険率

3つの部分からできています（12条4項）。

| 部分 | 本則の率 | 負担 |
|---|---|---|
| **失業等給付費等**充当分 | 1000分の8（農林水産・清酒製造・建設は1000分の10） | **労使折半** |
| **育児休業給付費**充当分 | 1000分の5 | **労使折半** |
| **二事業費**充当分 | 1000分の3.5（建設は1000分の4.5） | **事業主のみ** |

実際に適用される率は、**弾力条項**により毎年度見直されます。令和8年度の率は [`05-徴収法.md`](05-徴収法.md) の一覧を見てください。

> ★**二事業（雇用安定事業・能力開発事業）分は事業主だけが負担**します。これが労使折半にならない理由です。最頻出の理屈です。

### 弾力条項

| 対象 | 発動要件 | 変更幅 |
|---|---|---|
| **雇用保険率**（失業等給付分） | 積立金 ÷ 失業等給付費 が**2を超え、または1を下る**に至った場合 | **1000分の4**の範囲内で変更（労働政策審議会の意見を聴く） |
| **育児休業給付**分 | 育児休業給付資金の状況により | **1000分の4**に変更できる |
| **二事業**分 | 雇用安定資金が一般保険料徴収額の**1000分の3.5**に相当する額の**1.5倍**を超えるとき | **1000分の0.5**を控除した率に変更 |

> ★「厚生労働大臣が**労働政策審議会の意見を聴いて**、**1年以内の期間**を定めて変更する」という枠組みが共通です。
