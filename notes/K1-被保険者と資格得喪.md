# 被保険者と資格得喪｜国年の深掘り

### 3種類の被保険者（7条）

| 種別 | 要件 | 年齢 |
|---|---|---|
| **第1号** | 日本国内に**住所**を有する20歳以上60歳未満の者で、第2号・第3号でない者 | **20歳以上60歳未満** |
| **第2号** | **厚生年金保険の被保険者** | **年齢制限なし**（ただし65歳以上で老齢年金の受給権を有する者は除く） |
| **第3号** | 第2号被保険者の**配偶者**であって主として第2号被保険者の**収入により生計を維持**する者（**被扶養配偶者**） | **20歳以上60歳未満** |

> ★**第2号だけ年齢制限がありません**。20歳未満で就職しても第2号被保険者です。
> ★第2号のうち**65歳以上で老齢厚生年金等の受給権を有する者**は、国年の第2号被保険者になりません（厚年の被保険者ではあります）。
> ★第3号の**国内居住要件**は令和2年4月から追加されました（例外は健保の被扶養者と同じ）。

### 任意加入被保険者（附則5条）

| 対象 | 年齢 |
|---|---|
| ① 日本国内に住所を有する**20歳以上60歳未満**の者で、**被用者年金の老齢給付等**を受けられる者 | 20〜60歳未満 |
| ② 日本国内に住所を有する**60歳以上65歳未満**の者 | 60〜65歳未満 |
| ③ 日本国籍を有し、**外国に居住**する20歳以上65歳未満の者 | 20〜65歳未満 |

**特例任意加入被保険者**（平成6年・16年改正法附則）：**昭和40年4月1日以前生まれ**で、**65歳以上70歳未満**の者。**老齢基礎年金の受給権を有しない**場合に限られ、**受給資格期間を満たした時点で資格を喪失**します。

> ★特例任意加入は**受給資格期間を満たすため**だけの制度で、**年金額を増やすためには使えません**。

### 資格取得・喪失の時期（8条・9条）

| 種別 | 取得 |
|---|---|
| 第1号 | 20歳に達した日、日本国内に住所を有するに至った日、第2号・第3号でなくなった日 |
| 第2号 | 厚生年金保険の被保険者となった日 |
| 第3号 | 第2号被保険者の被扶養配偶者となった日、20歳に達した日 |

| 喪失事由 | 喪失日 |
|---|---|
| **死亡** | **翌日** |
| **60歳**に達したとき（第1号・第3号） | **その日**（60歳の誕生日の**前日**） |
| 日本国内に住所を有しなくなったとき（第1号） | **翌日**（ただしその日にさらに第2号・第3号になったときは**その日**） |
| 第2号・第3号に該当したとき（第1号） | **その日** |
| 厚生年金保険の被保険者資格を喪失したとき（第2号） | **その日** |

> ★「**年齢到達はその日**」「**死亡・住所喪失は翌日**」が基本形です。
> ★年齢の到達は**誕生日の前日**です（年齢計算に関する法律）。4月1日生まれは3月31日に60歳に達します。

### 届出（12条・105条）

| 届出 | 期限 | 提出先 |
|---|---|---|
| **第1号**被保険者の資格取得・喪失・種別変更 | **14日以内** | **市町村長**（特別区長を含む） |
| **第3号**被保険者の資格取得・喪失・種別変更 | **14日以内** | **事業主を経由して厚生労働大臣**（＝日本年金機構） |
| 死亡の届出（戸籍法の届出義務者） | **10日以内** | 市町村長 |

> ★第1号は**市町村長**、第3号は**事業主経由**。ここが混同されます。
> ★第3号被保険者の**届出の特例**：届出が遅れた場合、**2年より前の期間**も、やむを得ない事由があると認められれば**保険料納付済期間**に算入されます（**時効の特例**）。

### 種別の変更

| 変更 | 例 |
|---|---|
| 第1号 → 第2号 | 自営業者が就職 |
| 第2号 → 第1号 | 会社員が退職して自営業に |
| 第2号 → 第3号 | 会社員が退職して配偶者の扶養に入る |
| 第3号 → 第1号 | 配偶者が退職・死亡、または本人の収入が増えた |

> ★**同月内に種別が変更**された場合、その月は**変更後の種別**の被保険者期間として扱います（11条の2）。
> ★同一月に**資格取得と喪失**があった場合、その月は**1か月として算入**されます（ただし同月中にさらに他の年金の被保険者となったときを除く）。

### 被保険者期間の計算（11条）

被保険者期間は**月を単位**とし、資格を取得した日の属する**月**から、資格を喪失した日の属する月の**前月**までを算入します。
