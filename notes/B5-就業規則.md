# 就業規則｜労基の深掘り

### 作成・届出・周知

| 項目 | 内容 |
|---|---|
| 義務 | 常時**10人以上**の労働者を使用する使用者 |
| 手続 | 労働者の過半数代表の**意見を聴く**（同意は不要）→ 意見書を添えて**所轄労働基準監督署長**に届出 |
| 周知 | 掲示・備付け・書面交付・電子的方法のいずれか |

> **意見を「聴く」だけでよい**のが引っかけの定番です。反対意見でも届出は受理されます。

### 不利益変更（労働契約法9条・10条）

原則は「労働者の合意なく不利益に変更できない」（9条）ですが、例外として10条があります。

> 変更後の就業規則を**周知**させ、かつ変更が**合理的**なものであるときは、労働条件は変更後の就業規則による

**合理性の判断要素**

1. 労働者の受ける**不利益の程度**
2. 労働条件の変更の**必要性**
3. 変更後の内容の**相当性**
4. **労働組合等との交渉の状況**
5. その他の事情

### 労働者が同意していた場合

就業規則の不利益変更に労働者が同意していても、それだけでは足りません。**賃金の相殺と同じ枠組み**が使われます。

> 同意が労働者の**自由な意思**に基づいてされたものと認めるに足りる**合理的な理由が客観的に存在**するか

→ [賃金の全額払いと相殺](#賃金の全額払いと相殺) と同じ型です。

### 効力の順序

```
法令 ＞ 労働協約 ＞ 就業規則 ＞ 労働契約
```

就業規則の基準に達しない労働契約は、その部分が無効となり、**就業規則の基準による**（労働契約法12条）。

### 作成・届出義務（89条）

**常時10人以上**の労働者を使用する使用者は、就業規則を作成し、**所轄労働基準監督署長に届け出**なければなりません。**変更した場合も同様**です。

「常時10人以上」は**事業場単位**で数えます。パート・アルバイトも含みます。

### 必要記載事項

| 区分 | 事項 |
|---|---|
| **絶対的必要記載事項** | ① **始業・終業の時刻、休憩時間、休日、休暇**、交替制の場合の就業時転換に関する事項<br>② **賃金**（臨時の賃金等を除く）の決定・計算・支払の方法、賃金の締切り・支払の時期、昇給に関する事項<br>③ **退職**に関する事項（**解雇の事由**を含む） |
| **相対的必要記載事項** | **退職手当**、**臨時の賃金等（賞与）・最低賃金額**、**食費・作業用品などの負担**、**安全衛生**、**職業訓練**、**災害補償・業務外の傷病扶助**、**表彰・制裁**、その他当該事業場の労働者すべてに適用される定め |

> ★**昇給は絶対的、退職手当と賞与は相対的**。ここが最頻出です。
> ★**制裁（懲戒）は相対的必要記載事項**です。定めがなければ懲戒できません。

### 意見聴取（90条）

> 使用者は、就業規則の作成または変更について、**労働者の過半数で組織する労働組合**がある場合においてはその労働組合、ない場合においては**労働者の過半数を代表する者**の**意見を聴かなければならない**。

届出の際には、**意見を記した書面を添付**します。

> ★**同意ではなく意見**です。**反対の意見でも届出は受理**されます。ここが最頻出です。
> ★意見書に**署名または記名押印**が必要ですが、労働者代表が意見書への署名を拒んだ場合でも、**意見を聴いたことが客観的に証明できれば**受理されます。

### 周知（106条）

作業場の見やすい場所への**掲示・備付け**、**書面の交付**、**電子的方法**（磁気テープ等に記録し常時確認できる機器を設置）のいずれかによります。

> ★**周知していない就業規則は労働契約の内容になりません**（労働契約法7条・10条）。届出をしていても周知していなければ効力が生じません。

### 制裁規定の制限（91条）

```
1回の額 ≦ 平均賃金の1日分の半額
総額     ≦ 一賃金支払期における賃金総額の10分の1
```

### 法令・労働協約との関係（92条）と効力の順序

> 就業規則は、**法令または当該事業場について適用される労働協約に反してはならない**。行政官庁は、法令または労働協約に**抵触する就業規則の変更を命ずる**ことができる。

```
法令 ＞ 労働協約 ＞ 就業規則 ＞ 労働契約
```

| 条 | 効力 |
|---|---|
| 労基法13条 | 労基法の基準に達しない**労働契約**は、その部分が無効。無効となった部分は**労基法の基準**による |
| 労基法93条／労働契約法12条 | 就業規則の基準に達しない**労働契約**は、その部分が無効。無効となった部分は**就業規則**による |
| 労組法16条 | 労働協約に定める基準に違反する**労働契約**の部分は無効。無効となった部分は**協約の基準**による |

> ★就業規則が労働契約より**有利**な場合は就業規則が勝ちますが、**労働契約のほうが有利**な場合は労働契約が勝ちます（労働契約法7条ただし書）。

### 不利益変更の合理性（労働契約法10条）

1. 労働者の受ける**不利益の程度**
2. 労働条件の**変更の必要性**
3. 変更後の就業規則の**内容の相当性**
4. **労働組合等との交渉の状況**
5. その他の就業規則の変更に係る事情

> ★秋北バス事件が原型で、**第四銀行事件**・**みちのく銀行事件**が判断枠組みを具体化しました。
