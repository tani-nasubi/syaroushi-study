# 就業規則｜労基の深掘り

### 作成・届出・周知

| 項目 | 内容 |
|---|---|
| 義務 | 常時**10人以上**の労働者を使用する使用者 |
| 手続 | 労働者の過半数代表の**意見を聴く**（同意は不要）→ 意見書を添えて**所轄労働基準監督署長**に届出 |
| 周知 | 掲示・備付け・書面交付・電子的方法のいずれか |

> **意見を「聴く」だけでよい**のが引っかけの定番です。反対意見でも届出は受理されます。

### 不利益変更（労働契約法9条・10条）

原則は「労働者の合意なく不利益に変更できない」（9条）ですが、例外として10条があります。

> 変更後の就業規則を**周知**させ、かつ変更が**合理的**なものであるときは、労働条件は変更後の就業規則による

**合理性の判断要素**

1. 労働者の受ける**不利益の程度**
2. 労働条件の変更の**必要性**
3. 変更後の内容の**相当性**
4. **労働組合等との交渉の状況**
5. その他の事情

### 労働者が同意していた場合

就業規則の不利益変更に労働者が同意していても、それだけでは足りません。**賃金の相殺と同じ枠組み**が使われます。

> 同意が労働者の**自由な意思**に基づいてされたものと認めるに足りる**合理的な理由が客観的に存在**するか

→ [賃金の全額払いと相殺](#賃金の全額払いと相殺) と同じ型です。

### 効力の順序

```
法令 ＞ 労働協約 ＞ 就業規則 ＞ 労働契約
```

就業規則の基準に達しない労働契約は、その部分が無効となり、**就業規則の基準による**（労働契約法12条）。
