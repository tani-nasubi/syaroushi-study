# 高年齢・短期雇用特例・日雇｜雇用の深掘り

一般被保険者以外の3類型は、**求職者給付が一時金**である点が共通します。

| | 高年齢求職者給付金 | 特例一時金 | 日雇労働求職者給付金 |
|---|---|---|---|
| 対象 | **高年齢**被保険者 | **短期雇用特例**被保険者 | **日雇労働**被保険者 |
| 要件（被保険者期間） | 離職前**1年間に6か月**以上 | 離職前**1年間に6か月**以上 | 前2か月に**通算26日分**以上の印紙保険料納付 |
| 額 | 基本手当日額の**30日分または50日分** | 基本手当日額の**30日分**（当分の間**40日分**） | 印紙保険料の納付状況による日額 |
| 待期 | **7日** | **7日** | — |
| 受給期限 | 離職の日の翌日から**1年** | 離職の日の翌日から**6か月** | — |

### 高年齢求職者給付金（37条の2〜37条の4）

**65歳以上**の高年齢被保険者が失業した場合の一時金です。

| 算定基礎期間 | 支給額 |
|---|---|
| **1年以上** | 基本手当日額の**50日分** |
| **1年未満** | 基本手当日額の**30日分** |

> ★**年金（老齢厚生年金）との併給調整はありません**。基本手当は特別支給の老齢厚生年金と併給できませんが、高年齢求職者給付金は**併給できます**。最頻出です。
> ★賃金日額の上限は「**45歳以上60歳未満**」の区分を用います。
> ★受給期限は離職の日の翌日から**1年**で、**延長の制度はありません**。

### 特例一時金（39条〜41条）

**季節的**に雇用される短期雇用特例被保険者が失業した場合の一時金です。

| | |
|---|---|
| 額 | 基本手当日額の**30日分**（**当分の間40日分**） |
| 受給期限 | 離職の日の翌日から**6か月** |
| 失業の認定 | **1回**だけ |

**公共職業訓練等を受ける場合**には、特例一時金に代えて**基本手当・技能習得手当・寄宿手当**が支給されます（40条4項）。

> ★受給期限内に訓練を受け始めると、一時金ではなく**通常の求職者給付**に切り替わります。
> ★受給期限は**6か月**（延長なし）。高年齢の1年と混同しやすいところです。

### 日雇労働被保険者（42条〜56条）

| 対象（42条） | |
|---|---|
| ① | **日々**雇用される者 |
| ② | **30日以内**の期間を定めて雇用される者 |

ただし、次の①②のいずれかに該当する必要があります（43条）。

1. 適用区域（特別区・公共職業安定所の所在する市町村等）に**居住**し、適用事業に雇用される者
2. 適用区域外に居住し、適用区域内の**適用事業に雇用**される者
3. 適用区域外に居住し、適用区域外の**厚生労働大臣が指定した適用事業**に雇用される者
4. 上記以外で、**公共職業安定所長の認可**を受けた者

**2か月の各月において18日以上**同一の事業主に雇用された場合、または**同一の事業主に継続して31日以上**雇用された場合は、原則として**日雇労働被保険者でなくなります**（一般被保険者等になる）。ただし**公共職業安定所長の認可**を受ければ日雇のままでいられます。

### 日雇労働求職者給付金

| 区分 | 内容 |
|---|---|
| **普通給付**（45条） | 失業の日の属する月の**前2月間**に印紙保険料が通算して**26日分以上**納付されていること。**1か月につき13日〜17日分**を限度に支給 |
| **特例給付**（53条） | 継続する**6か月間**に印紙保険料が各月11日分以上かつ通算**78日分以上**納付されていること。**4か月間**に**60日分**を限度 |

| 等級 | 日額 | 要件（前2月の印紙保険料） |
|---|---|---|
| **第1級** | **7,500円** | 第1級印紙保険料が**24日分以上** |
| **第2級** | **6,200円** | 第1級・第2級が**24日分以上**、または第1〜3級の平均が第2級以上 |
| **第3級** | **4,100円** | 上記以外 |

> ★普通給付は**日ごと**に失業の認定を受け、**その都度**支給されます。
> ★特例給付を受けようとする者は、**基礎期間の最後の月の翌月以後4か月以内**に公共職業安定所長に申出をします。
> ★普通給付と特例給付は**選択**であり、両方は受けられません。
