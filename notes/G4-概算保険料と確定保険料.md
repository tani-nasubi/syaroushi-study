# 概算保険料と確定保険料｜徴収の深掘り

労働保険料は**まず見込みで納め（概算）、後で精算する（確定）**しくみです。

### 概算保険料（15条）

| 区分 | 申告・納付期限 |
|---|---|
| 継続事業（保険年度の当初から） | その保険年度の**6月1日から40日以内**（＝**7月10日**） |
| 継続事業（保険年度の**中途に成立**） | 保険関係が成立した日から**50日以内** |
| **有期事業** | 保険関係が成立した日から**20日以内** |

賃金総額の**見込額**に保険料率を乗じて算定します。見込額が**直前の保険年度の賃金総額の100分の50以上100分の200以下**であるときは、**直前の保険年度の賃金総額**を用います。

> ★「50%以上200%以下なら前年度の額を使う」＝**大きく変わらなければ前年実績でよい**という趣旨です。

### 増加概算保険料（16条）

賃金総額の見込額が増加した場合、次の**両方**に該当すると、**増加した日から30日以内**に差額を申告・納付します。

1. 増加後の見込額が、当初の見込額の**100分の200を超える**こと
2. 増加後の概算保険料の額と当初の概算保険料の額との**差額が13万円以上**であること

> ★**2倍超かつ13万円以上**。片方だけでは対象になりません。
> ★見込額が**減少**した場合の手続はありません（確定精算で調整されます）。

### 確定保険料（19条）

| 区分 | 申告・納付期限 |
|---|---|
| 継続事業 | 次の保険年度の**6月1日から40日以内** |
| 継続事業（保険年度の**中途に消滅**） | 保険関係が消滅した日から**50日以内** |
| **有期事業** | 保険関係が消滅した日から**50日以内** |

**申告書の提出は義務**で、納付すべき額がない場合（概算で納めすぎていた場合）でも**申告書は提出**しなければなりません。

### 精算

| 状況 | 処理 |
|---|---|
| 概算 **＜** 確定 | **不足額**を確定保険料申告書に添えて納付 |
| 概算 **＞** 確定 | **充当**（次の概算保険料等に充てる）または**還付**（請求により） |

還付を受けるには**労働保険料還付請求書**の提出が必要です。請求がなければ**次期の概算保険料等に充当**されます。

### 認定決定と追徴金

| 場面 | 効果 |
|---|---|
| 申告書を**提出しない**、または記載に**誤り**がある | 政府が労働保険料の額を**決定**し事業主に**通知**（**認定決定**） |
| 通知を受けたとき | 通知を受けた日から**15日以内**に納付 |
| **確定保険料**についての認定決定 | 納付すべき額（1,000円未満切捨て）の**100分の10**の**追徴金** |

> ★追徴金がかかるのは**確定保険料**についてだけです。**概算保険料の認定決定には追徴金はありません**。ここが定番の引っかけです。
> ★事業主が**申告書を提出しなかった**場合でも、**天災その他やむを得ない理由**があるときは追徴金を徴収しません。

### 延納（分割納付）

| | 継続事業 | 有期事業 |
|---|---|---|
| 要件 | 概算保険料が**40万円以上**（労災・雇用の一方のみ成立なら**20万円以上**）、または**労働保険事務組合に委託**していること | 概算保険料が**75万円以上**、または労働保険事務組合に委託していること／かつ**事業期間が6か月を超える**こと |
| 期別 | 最大**3期**（4/1〜7/31、8/1〜11/30、12/1〜3/31） | 最大**3期**（各期は原則4か月） |
| 各期の納期限 | **7月10日／10月31日／翌年1月31日**（事務組合委託の場合は**11月14日／2月14日**） | 最初の期は成立日から**20日以内**、以後は**3月31日／11月30日**等 |

> ★継続事業で**10月1日以降**に保険関係が成立した場合は**延納できません**（残り期間が1期しかないため）。
> ★事務組合に委託していると、第2期・第3期の納期限が**2週間延びます**。

### 端数処理

| 対象 | 処理 |
|---|---|
| 賃金総額 | **1,000円未満切捨て** |
| 保険料の額 | **1円未満切捨て** |
| 延納の各期の額（割り切れないとき） | **最初の期**に加算 |
| 追徴金・延滞金の基礎額 | **1,000円未満切捨て** |
| 追徴金・延滞金の額 | **100円未満切捨て** |
