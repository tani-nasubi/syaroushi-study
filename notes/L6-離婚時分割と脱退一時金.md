# 離婚時分割・3号分割と脱退一時金｜厚年の深掘り

### 合意分割（78条の2〜78条の12）

**離婚等**をした場合に、婚姻期間中の**標準報酬**を当事者間で分割する制度です（平成19年4月〜）。

| 項目 | 内容 |
|---|---|
| 対象期間 | **婚姻期間中**の厚生年金の被保険者期間 |
| 請求 | **当事者双方**（またはその一方）が請求 |
| 按分割合 | **当事者の合意**または**裁判所の決定**による。**2分の1が上限**、**第2号改定者の持分割合を下回らない**こと |
| 請求期限 | **離婚等をした日の翌日から2年以内** |
| 効果 | 標準報酬月額・標準賞与額そのものを改定（**年金額ではなく記録を分ける**） |

| 用語 | |
|---|---|
| **第1号改定者** | 標準報酬が**減る**側（多いほう） |
| **第2号改定者** | 標準報酬が**増える**側（少ないほう） |

> ★**上限は2分の1**です。「2分の1が自動的に分割される」わけではありません。合意または裁判所の決定が必要です。
> ★分割後の記録は**第2号改定者自身の被保険者期間**になりますが、**老齢厚生年金の受給資格期間（加入期間）には算入されません**。ここが最頻出です。
> ★**離婚時みなし被保険者期間**は、**加給年金額の240月**の判定にも**算入されません**。

**情報提供の請求**：当事者の一方は、**離婚前でも**、按分割合を定めるために必要な**情報の提供**を実施機関に請求できます。

### 3号分割（78条の13〜78条の21）

**特定期間**（平成20年4月1日以後の**国民年金第3号被保険者**であった期間）について、**相手方の同意なく**、**2分の1**を自動的に分割する制度です。

| 項目 | 内容 |
|---|---|
| 対象期間 | **平成20年4月1日以後**の第3号被保険者期間（**特定期間**） |
| 請求 | **第3号被保険者であった者（特定被保険者の配偶者）が単独**で請求できる |
| 按分割合 | **2分の1**（固定。合意不要） |
| 請求期限 | **離婚等をした日の翌日から2年以内** |

> ★**平成20年3月以前の第3号期間は3号分割の対象外**です（合意分割で対応）。
> ★**相手方の合意は不要**です。ここが合意分割との最大の違いです。
> ★合意分割の請求をしたとき、**特定期間があれば3号分割の請求も同時にあったものとみなされます**。
> ★**特定被保険者が障害厚生年金の受給権者**であり、その障害厚生年金の額の計算の基礎となった期間については、**3号分割は行われません**。

### 合意分割と3号分割の対比

| | 合意分割 | 3号分割 |
|---|---|---|
| 対象期間 | 婚姻期間**全体** | 平成20年4月以後の**第3号期間** |
| 相手方の同意 | **必要**（または裁判所の決定） | **不要** |
| 割合 | **2分の1が上限** | **2分の1固定** |
| 請求できる者 | 当事者双方または一方 | **第3号被保険者であった者**のみ |
| 期限 | 離婚等の翌日から**2年** | 同左 |

### 脱退一時金（附則29条）

| 要件 | |
|---|---|
| 対象 | **日本国籍を有しない**者で、**被保険者期間が6か月以上**あり、**老齢厚生年金の受給資格期間を満たしていない**者 |
| 状況 | **被保険者資格を喪失**し、日本国内に住所を有しなくなった日から**2年以内**に請求 |
| 除外 | **障害厚生年金等の受給権を有したことがある**者、日本国内に住所を有する者 |

```
脱退一時金 ＝ 平均標準報酬額 × 支給率
支給率 ＝ 保険料率 × 2分の1 × 被保険者期間に応じた数
```

| 被保険者期間 | 上限 |
|---|---|
| 上限 | **60月（5年）**（令和3年4月〜。それ以前は36月） |

> ★脱退一時金の支給を受けた期間は、**厚生年金保険の被保険者でなかったものとみなされます**。
> ★**社会保障協定**を締結している国の国民は、協定により期間通算ができるため、脱退一時金を受けるかどうかは慎重な判断が必要です（受けると期間が消えます）。

### 未支給の保険給付（37条）

受給権者が死亡した場合、その者に支給すべき保険給付でまだ支給されていないものがあるときは、**その者の死亡当時生計を同じくしていた**次の者が、**自己の名**で請求できます。

| 順位 | 配偶者 → 子 → 父母 → 孫 → 祖父母 → 兄弟姉妹 → **これらの者以外の三親等内の親族** |
|---|---|

> ★**三親等内の親族**まで含まれます（国民年金法19条も同じ）。労災は兄弟姉妹までです。

### 時効・不服申立て

| | |
|---|---|
| **時効**（92条） | 保険給付を受ける権利は**5年**、保険料その他の徴収金を徴収する権利は**2年** |
| **不服申立て**（90条） | 被保険者資格・標準報酬・保険給付に関する処分 → **社会保険審査官**に審査請求 → **社会保険審査会**に再審査請求 |
| 保険料等の処分 | **社会保険審査会**に**直接**審査請求（1審制） |
| 審査請求の期間 | 処分があったことを知った日の翌日から**3か月以内** |

> ★**給付関係は2審制、保険料関係は1審制**。ここが最頻出です。
> ★**時効の起算**：年金給付を受ける権利は**支分権**（各支払期月ごと）が5年、**基本権**（裁定を受ける権利）は時効消滅しないものとして扱われます（年金時効特例法）。
