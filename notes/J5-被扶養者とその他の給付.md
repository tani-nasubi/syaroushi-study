# 被扶養者とその他の給付｜健保の深掘り

### 被扶養者の範囲（3条7項）

| 号 | 範囲 | 同一世帯の要否 |
|---|---|---|
| 1号 | **直系尊属、配偶者**（事実婚を含む）、**子、孫、兄弟姉妹** | **不要**（生計維持だけでよい） |
| 2号 | 被保険者の**三親等内の親族**で1号以外の者 | **必要** |
| 3号 | 被保険者の**事実婚の配偶者の父母および子** | **必要** |
| 4号 | 3号の配偶者の**死亡後**におけるその父母および子 | **必要** |

> ★**兄弟姉妹**は同一世帯不要（平成28年改正）。**孫**も不要です。「兄弟姉妹は同居が必要」は誤りです。
> ★**三親等内**の親族が範囲です（四親等はどんな場合も不可）。

### 収入要件

| 区分 | 要件 |
|---|---|
| **同一世帯**の場合 | 年間収入が**130万円未満**（**60歳以上**または**障害厚生年金の受給要件に該当する程度の障害者**は**180万円未満**）、かつ**被保険者の年間収入の2分の1未満** |
| **同一世帯でない**場合 | 上記の収入未満、かつ**被保険者からの援助額より少ない**こと |

> ★収入には**雇用保険の基本手当・公的年金・傷病手当金**などの**非課税の収入も含まれます**。所得税法上の扶養とは基準が違います。
> ★2分の1以上でも、被保険者の収入により生計を維持していると保険者が認めれば被扶養者となる場合があります。

### 国内居住要件（令和2年4月〜）

被扶養者は、原則として**日本国内に住所を有する**ことが必要です。

**例外**（国内に住所がなくても被扶養者となる）。

1. **外国において留学**をする学生
2. 外国に**赴任する被保険者に同行**する者
3. **観光、保養またはボランティア活動**その他就労以外の目的で一時的に海外に渡航する者
4. 被保険者が外国に赴任している間に**当該被保険者との身分関係が生じた者**で、2号に相当すると認められるもの
5. 上記のほか、**渡航目的その他の事情を考慮して日本国内に生活の基礎があると認められる**者

逆に、日本に住所があっても**医療滞在ビザ**・**観光等の目的で一時的に滞在する者**は被扶養者になりません。

### 家族に関する給付

| 給付 | 内容 |
|---|---|
| **家族療養費**（110条） | 被扶養者の療養。**保険者が被扶養者に対して支給**する（形式上は被保険者に支給） |
| **家族訪問看護療養費**（111条） | 被扶養者の訪問看護 |
| **家族移送費**（112条） | 被扶養者の移送 |
| **家族埋葬料**（113条） | 被扶養者が死亡したとき**5万円** |
| **家族出産育児一時金**（114条） | 被扶養者が出産したとき **50万円**（産科医療補償制度に未加入の場合は48.8万円） |

> ★**傷病手当金・出産手当金には家族版がありません**。被扶養者は所得保障の対象外です。ここが最頻出です。

### 埋葬料・埋葬費（100条）

| | |
|---|---|
| **埋葬料** | 被保険者が死亡したとき、**埋葬を行う者**（被保険者により生計を維持していた者）に**5万円** |
| **埋葬費** | 埋葬料を受けるべき者がいないとき、**実際に埋葬を行った者**に、埋葬に要した費用に相当する額（**5万円を上限**） |

> ★埋葬料の受給者は「生計維持関係のある者」で、**同一世帯である必要はなく、親族でなくてもかまいません**。
> ★資格喪失後**3か月以内**に死亡したときも埋葬料が支給されます（105条）。

### 出産育児一時金（101条）

| | |
|---|---|
| 額 | **50万円**（産科医療補償制度に加入していない医療機関等での出産は**48.8万円**） |
| 対象 | **妊娠4か月（85日）以上**の出産。**死産・流産・人工妊娠中絶**も含む |
| 直接支払制度 | 保険者から医療機関へ直接支払う |

> ★**妊娠85日以上**であれば生産・死産を問いません。ここが問われます。
> ★資格喪失後**6か月以内**の出産についても支給されます（106条）。ただし**任意継続被保険者となった場合を除く**などの取扱いに注意。

### 移送費（97条）・訪問看護療養費（88条）

| 給付 | 要件 |
|---|---|
| **移送費** | 療養の給付を受けるため**病院・診療所に移送**されたとき。**保険者が必要と認める場合**に、最も経済的な通常の経路・方法による**実費**を支給 |
| **訪問看護療養費** | **居宅**において継続して療養を受ける状態にある者が、**指定訪問看護事業者**から訪問看護を受けたとき。**主治医の指示**が必要 |

> ★移送費は**現金給付**、訪問看護療養費は**現物給付**です。

### 給付制限（116条〜122条）

| 条 | 事由 | 効果 |
|---|---|---|
| 116条 | **故意の犯罪行為**により、または**故意**に給付事由を生じさせたとき | 保険給付を**行わない** |
| 117条 | **闘争、泥酔または著しい不行跡**によって給付事由を生じさせたとき | 保険給付の**全部または一部を行わないことができる** |
| 118条 | **少年院等に収容**されたとき、**刑事施設等に拘禁**されたとき | 疾病・負傷・出産についての給付を**行わない**（**埋葬料・家族給付は除く**） |
| 119条 | 正当な理由なく**療養に関する指示に従わない**とき | 保険給付の**一部を行わないことができる** |
| 120条 | 正当な理由なく**保険者の届出・書類提出・質問・診断**に応じないとき | 保険給付の**全部または一部を行わないことができる** |
| 121条 | **保険料の滞納**（任意継続被保険者等） | 保険給付の**全部または一部の支給を一時差し止めることができる** |

> ★**故意は絶対的**（行わない）、**故意の犯罪行為も絶対的**。**闘争・泥酔・不行跡は裁量的**。この区別が問われます。
> ★**自殺未遂**による傷病は、**精神疾患等に起因する場合は「故意」に当たらない**として給付対象になります。

### 法人の役員に係る保険給付の特例（53条の2）

被保険者またはその被扶養者が**法人の役員**であるときは、その**法人の役員としての業務**に起因する疾病・負傷等については、**保険給付を行いません**。

**ただし、被保険者の数が5人未満**である適用事業所に使用される法人の役員としての業務であって、**一般の従業員が従事する業務と同一**であると認められるものについては、**保険給付が行われます**。

> ★「法人の役員」には、**相談役・顧問その他名称を問わず、取締役等と同等以上の支配力を有すると認められる者**を含みます。
> ★**5人未満**という規模と「一般従業員と同一の業務」の2つが例外の要件です。

### 指定訪問看護の事業の運営に関する基準（92条）

指定訪問看護事業者は、訪問看護事業所ごとに、厚生労働省令で定める基準に従い**厚生労働省令で定める員数の看護師その他の従業者**を有しなければなりません。事業の運営に関する基準は**厚生労働大臣**が定め、**指定訪問看護の取扱いに関する部分**を定めようとするときは**中央社会保険医療協議会に諮問**します。

### 徴収に関する通則（183条）

> 保険料等は、この法律に別段の規定があるものを除き、**国税徴収の例**により徴収する。

徴収の優先順位は**国税および地方税に次ぐ**ものとされています（182条）。

### 基金等への事務の委託（205条の4）

保険者は、**保険給付の支給に関する事務**等を、**社会保険診療報酬支払基金**または**国民健康保険団体連合会**に委託することができます。

> ★審査・支払を行う機関に、給付事務そのものを委託できるという規定です。

### 日雇特例被保険者（3条2項・123条〜）

| | |
|---|---|
| 対象 | **臨時に使用される者で日々雇い入れられる者**など、健保の適用除外に当たるが**日雇特例被保険者手帳**の交付を受けた者 |
| 保険者 | **全国健康保険協会** |
| 保険料 | **健康保険印紙**を手帳に貼付して納付（労使折半） |
| 給付 | 療養の給付（**初めて療養を受ける月の前2か月に通算26日分**または**前6か月に通算78日分**の保険料納付が必要） |
| 給付期間 | 同一の疾病について**1年**（**厚生労働大臣が指定する疾病は5年**） |

**日雇拠出金**（173条・174条）：厚生労働大臣は、日雇特例被保険者に係る健康保険事業に要する費用に充てるため、**日雇関係組合**（日雇特例被保険者を使用する事業主が設立する健康保険組合）から**日雇拠出金**を徴収します。当該年度の額は**概算日雇拠出金**の額とし、後に**確定日雇拠出金**で精算します。

> ★「概算・確定」で精算する仕組みは労働保険料と同じ考え方です。

### 健康保険組合（8条〜)

| 種類 | 内容 |
|---|---|
| **単一組合** | 1つの適用事業所（常時**700人以上**） |
| **総合組合** | 2以上の適用事業所（合算して常時**3,000人以上**） |
| **地域型健康保険組合** | 同一都道府県内の複数の健康保険組合が**合併**して設立するもの（**厚生労働大臣の認可**） |

**調整保険料率**：健康保険組合連合会が行う**交付金交付事業**の財源として、一般保険料率のうち**調整保険料率**に応ずる部分を拠出します。

> ★組合の設立には、被保険者となるべき者の**2分の1以上の同意**と**厚生労働大臣の認可**が必要です。

### そのほかの用語

| 用語 | 内容 |
|---|---|
| **高齢受給者証** | **70歳以上75歳未満**の被保険者・被扶養者に交付され、**負担割合**を示す |
| **後発医薬品**（ジェネリック） | 先発医薬品と有効成分が同一のもの。**長期収載品**（後発品のある先発医薬品）を希望した場合の差額は**選定療養**として自己負担（令和6年10月〜） |
| **匿名診療等関連情報**（150条の2〜） | レセプト等を匿名化した情報。**厚生労働大臣**が利用者に提供できる |
| **保険医等** | **保険医・保険薬剤師**。厚生労働大臣の**登録**を受ける |
| **社会保障審議会** | 保険料率の変更、療養の給付の範囲など、重要事項について**諮問**を受ける |
