# 保険者と費用負担｜健保の深掘り

### 2つの保険者（4条）

| | 全国健康保険協会（協会けんぽ） | 健康保険組合 |
|---|---|---|
| 対象 | 健康保険組合の**組合員でない**被保険者 | 組合員である被保険者 |
| 性格 | **法人**（政府ではない） | **法人**（公法人） |
| 意思決定 | **運営委員会**（事業主・被保険者・学識経験者 各**3人以内**） | **組合会** |
| 執行 | **理事長**（厚生労働大臣が任命） | **理事長**（**理事**が互選） |
| 支部 | **都道府県ごと**に支部。**評議会**を置く（事業主・被保険者・学識経験者 各**同数**） | — |

> ★協会は**政府管掌健康保険**を引き継いだ法人で、**政府そのものではありません**。
> ★**保険料率の決定**は協会（支部ごとの都道府県単位保険料率）が行い、**厚生労働大臣の認可**を受けます。

### 協会の役員（7条の10〜7条の14）

| | |
|---|---|
| 役員 | **理事長1人、理事6人以内、監事2人** |
| **理事長・監事** | **厚生労働大臣**が任命 |
| **理事** | **理事長**が任命（厚生労働大臣の認可を受ける） |
| 任期 | 理事長・理事は**3年**、監事は**2年** |

**解任**（7条の14）

| 場面 | 誰が | どうなる |
|---|---|---|
| 欠格条項に該当するに至ったとき | 厚生労働大臣・理事長 | **解任しなければならない**（義務） |
| 心身の故障で職務に堪えない、職務上の義務違反その他役員たるに適しないと認めるとき | 厚生労働大臣・理事長 | **解任することができる**（裁量） |

> ★**「しなければならない」と「することができる」の書き分け**が問われます。欠格事由に当たれば**必ず解任**、適格性の問題なら**解任できる**です。
> ★任命した者が解任します。**理事長が任命した理事は理事長が解任**します。

### 協会の組織・財務（7条の6〜7条の39）

択一で毎年のように1肢は出ます。**数字と「誰が」**だけ押さえます。

| 条 | 中身 | 引っかけ |
|---|---|---|
| **7条の6** 定款 | 目的・名称・**事務所の所在地**・役員・運営委員会・評議会・保健事業・福祉事業・財務等を定める。定款の変更は**厚生労働大臣の認可**（省令で定める事項は**届出**）。認可・届出のいずれも遅滞なく**公告** | 変更のすべてが認可ではない |
| **7条の15** 役員の兼職禁止 | 役員（**非常勤の者を除く**＝常勤役員）は、営利団体の役員となり、又は自ら営利事業に従事してはならない。**厚生労働大臣の承認**を受けたときを除く | 非常勤役員は対象外 |
| **7条の16** 代表権の制限 | 協会と**理事長又は理事**との利益が相反する事項について、これらの者は代表権を有しない。この場合は**監事**が協会を代表する | 代表するのは監事 |
| **7条の28** 財務諸表等 | 決算は翌事業年度の**5月31日まで**に完結。財務諸表に事業報告書・決算報告書を添え、**監事及び会計監査人の意見**を付けて、**決算完結後2か月以内**に厚生労働大臣に提出し**承認**を受ける。承認後、遅滞なく**官報に公告** | 「2か月以内」「5月31日」 |
| **7条の29** 会計監査人 | 監事の監査の**ほか**、会計監査人の監査を受ける。会計監査人は**厚生労働大臣が選任**し、**公認会計士又は監査法人**でなければならない | 協会が選任するのではない |
| **7条の31** 借入金 | **厚生労働大臣の認可**を受けて**短期借入金**ができる。**当該事業年度内に償還**。償還できないときはその金額に限り認可を受けて**借換え**でき、借り換えたものは**1年以内**に償還 | 「当該事業年度内」「1年以内」 |
| **7条の34** 重要な財産の処分 | 省令で定める**重要な財産**を譲渡し、又は担保に供しようとするときは、**厚生労働大臣の認可** | 届出ではない |
| **7条の35** 役員の報酬等 | 報酬及び退職手当は**役員の業績が考慮される**ものでなければならない。支給の基準を定め、厚生労働大臣に**届け出るとともに公表**する。変更したときも同様 | **承認**ではなく**届出**。「承認を得た後に公表」は誤り |
| **7条の37** 秘密保持義務 | （下記） | |
| **7条の39** 監督 | 厚生労働大臣は、事業・財産の管理執行が法令等に違反する等のとき、期間を定めて**協会又はその役員**に必要な措置を命ずることができる。命令違反→**役員の解任を命令**→なお違反→**厚生労働大臣が解任** | 命令→解任命令→解任、の**3段** |

> ★**認可**（定款変更・短期借入金）と**届出**（報酬の支給基準）と**承認**（財務諸表・兼職）を混ぜた肢がよく出ます。

### 健康保険組合の設立（8条〜）

| 種類 | 要件 |
|---|---|
| **単一組合** | 1つの適用事業所で常時**700人以上** |
| **総合組合** | 2以上の適用事業所で合算して常時**3,000人以上** |

設立には、被保険者の**2分の1以上の同意**を得て規約を作り、**厚生労働大臣の認可**を受けます。2以上の適用事業所で設立する場合、同意は**各適用事業所ごと**に得なければなりません。

| 手続 | 同意 |
|---|---|
| **設立** | 被保険者の**2分の1以上** |
| **強制設立**（12条） | 厚生労働大臣が設立を**命ずる**ことができる |
| **解散**（26条） | 組合会議員の**4分の3以上**の多数による議決、または事業の継続不能、厚生労働大臣の**解散命令** |
| **合併・分割** | 組合会議員の**4分の3以上**の議決＋厚生労働大臣の認可 |

> ★設立は**2分の1**、解散・合併は**4分の3**。任意適用事業所（加入2分の1・取消4分の3）と同じ形です。

### 組合会（18条〜）

| | |
|---|---|
| 議員 | **事業主が選定した議員**と**被保険者が互選した議員**が**同数** |
| 理事 | 議員が互選（事業主選定議員・被保険者互選議員から**同数**ずつ） |
| **理事長** | **事業主選定議員である理事**のうちから互選 |
| 監事 | 議員のうちから、事業主選定議員・被保険者互選議員それぞれ**1人ずつ** |

> ★理事長は**事業主側の理事**から選ばれます。「被保険者側から選ぶ」は誤りです。
> ★**監事は理事・組合の職員と兼ねることができません**。

### 組合独自のしくみ

| 制度 | 内容 |
|---|---|
| **付加給付**（53条） | 法定給付に上乗せして規約で定める給付。**協会けんぽにはない** |
| **保険料率**（160条13項） | **1000分の30〜1000分の130**の範囲で組合が決定 |
| **事業主負担割合**（161条） | 規約で**2分の1を超えて**事業主負担とすることができる |
| **調整保険料率** | 健康保険組合連合会の**交付金交付事業**の財源 |

### 秘密保持義務（7条の37）

> 協会の**役員若しくは職員又はこれらの職にあった者**は、健康保険事業に関して**職務上知り得た秘密**を、**正当な理由がなく**漏らしてはならない。

- 2項で**運営委員会の委員**（委員であった者を含む）にも準用されます。
- 違反した者は**1年以下の拘禁刑又は100万円以下の罰金**（207条の2）。

> ★「**正当な理由がなく**」が付きます。「理由の如何を問わず漏らしてはならない」は**誤り**です。
> ★この条は**協会**の規定です。**健康保険組合**の役職員については、8条の2以下に同趣旨の準用があります。条番号を入れ替えた肢に注意します。

### 特定健康診査等への国庫補助（154条の2）

> 国庫は、151条及び前2条に規定する費用のほか、**予算の範囲内**において、健康保険事業の執行に要する費用のうち、**特定健康診査等の実施に要する費用の一部**を補助することができる。

> ★**一部**です。「全部を補助することができる」は**誤り**（令和7年・平成30年に2度出ました）。
> ★事務費の国庫負担（151条〜154条）とは**別枠**で、こちらは「**補助することができる**」という任意規定です。

### 費用の負担（151条〜155条の2）

| 区分 | 負担 |
|---|---|
| **事務費**（153条・154条） | **国庫が負担**（毎年度、予算の範囲内） |
| **給付費等**（153条） | 協会けんぽについて、国庫が**給付費等の1000分の164**を補助（当分の間。本則は1000分の130〜200の範囲で政令) |
| **健康保険組合** | 給付費への国庫補助は**予算の範囲内**で、事務費のみが原則 |

> ★**事務費は健保組合にも国庫負担**があります。**給付費への補助は協会けんぽだけ**です。ここが最頻出です。

### 健康保険組合への国庫負担金（152条）

> **1項** 健康保険組合に対して交付する国庫負担金は、各健康保険組合における**被保険者数を基準**として、**厚生労働大臣が算定**する。
> **2項** 前項の国庫負担金については、**概算払をすることができる**。

> ★基準は**被保険者数**です。「保険料収入」「給付費」ではありません。
> ★**概算払ができる**点が問われます。

### 保険料（156条〜)

```
保険料額 ＝（標準報酬月額 ＋ 標準賞与額）×（一般保険料率 ＋ 介護保険料率）
一般保険料率 ＝ 基本保険料率 ＋ 特定保険料率
```

| 率 | 何に充てるか |
|---|---|
| **基本保険料率** | 保険給付・保健事業など |
| **特定保険料率** | **前期高齢者納付金等・後期高齢者支援金等・介護納付金**など |

> ★協会けんぽの一般保険料率は**都道府県単位**（支部ごと）です。全国一律ではありません。
> ★**介護保険料率は全国一律**です。

### 日雇特例被保険者の費用

**日雇拠出金**（173条）を**日雇関係組合**から徴収します。当該年度の**概算日雇拠出金**を徴収し、後に**確定日雇拠出金**で精算します。
