# 賃金日額と基本手当日額｜雇用の深掘り

### 賃金日額（17条）

```
賃金日額 ＝ 算定対象期間（被保険者期間として計算された最後の6か月）に
　　　　　　支払われた賃金の総額 ÷ 180
```

| 含む | 含まない |
|---|---|
| 基本給、諸手当、通勤手当 | **臨時に支払われる賃金** |
| | **3か月を超える期間ごとに支払われる賃金**（＝賞与） |

> ★労基法の平均賃金は「3か月・暦日数」、雇用保険の賃金日額は「**6か月・180**」。分母の考え方が違います。
> ★**賞与は入りません**。ここが最頻出です。

**最低保障**：日給・時給・出来高払で計算した額が上記より高いときは、その額（労働日数で除して70%を乗じた額）を賃金日額とします。

### 上限額・下限額

賃金日額には**年齢区分ごとの上限額**と、**全年齢共通の下限額**が定められ、毎年8月1日に**毎月勤労統計の平均給与額の変動**に応じて改定されます（18条）。

| 区分 | |
|---|---|
| 上限額 | **29歳以下／30〜44歳／45〜59歳／60〜64歳**の4区分 |
| 下限額 | **全年齢共通**（1つだけ） |

> ★上限は4区分、下限は1つ。**65歳以上**は「60〜64歳」ではなく「**45〜59歳**」の区分を使います（高年齢求職者給付金）。

### 基本手当日額（16条）

```
基本手当日額 ＝ 賃金日額 × 給付率
```

給付率は**賃金日額が低いほど高く**なります（**逆スライド**）。

| 離職時の年齢 | 給付率 |
|---|---|
| **60歳未満**（および65歳以上） | **100分の50〜100分の80** |
| **60歳以上65歳未満** | **100分の45〜100分の80** |

> ★60歳以上65歳未満だけ下限が**45%**です。**在職老齢年金・高年齢雇用継続給付との調整**があるためです。
> ★上限の80%は共通です。「60歳以上は上限も45%」は誤りです。

基本手当日額にも、年齢区分ごとの**上限額**が定められています。

### 自動変更対象額（18条）

賃金日額の上限額・下限額、および控除額は、**毎年8月1日**に、**毎月勤労統計の平均給与額**が前年度と比べて**上下したときにその比率に応じて**変更されます。

> ★労災の給付基礎日額のスライドは「110%超／90%未満」という幅がありますが、雇用保険は**上下すれば変更**します。

### 減額（19条）

失業の認定に係る期間中に**自己の労働によって収入**を得た場合、次のように減額されます。

```
収入の1日分の額 － 控除額 ＝ Ａ
Ａ ＋ 基本手当日額 と 賃金日額の80% を比べる
```

| 状況 | 支給額 |
|---|---|
| Ａ＋基本手当日額 ≦ 賃金日額の**80%** | **全額**支給 |
| 超える場合 | 超えた額を基本手当日額から**減じた額**を支給 |
| 減じた結果が**0以下** | **不支給** |

> ★「収入があれば一律不支給」ではありません。**賃金日額の80%**が判定の物差しです。
> ★1日の労働時間が**4時間以上**なら「就職」とみなされてその日は基本手当が支給されず（就業促進手当の対象）、**4時間未満**なら「内職・手伝い」として上の減額計算が適用されます。

### 待期中の扱い

待期期間（7日）中に収入を得ても、**待期は進行**します。ただし、**1日の労働時間が4時間以上**なら失業していないので、その日は待期の日数に**算入されません**。
