# 面接指導とストレスチェック｜安衛の深掘り

### 長時間労働者への面接指導（66条の8）

| 区分 | 要件 | 実施 |
|---|---|---|
| **一般の労働者**（66条の8） | 休憩時間を除き1週40時間を超えて労働させた時間が**1か月あたり80時間を超え**、かつ**疲労の蓄積が認められる**者 | 労働者の**申出**により実施（**義務**） |
| **研究開発業務**従事者（66条の8の2） | 上記の時間が**1か月あたり100時間を超える**者 | **申出を要せず**実施（**義務**） |
| **高度プロフェッショナル**制度対象者（66条の8の4） | **健康管理時間**が1週40時間を超えた時間について**1か月あたり100時間を超える**者 | **申出を要せず**実施（**義務**） |
| 上記以外で健康への配慮が必要な者 | 事業場で定める基準に該当する者 | **努力義務** |

> ★一般は**80時間＋申出**、研究開発と高プロは**100時間・申出不要**。この対比が最頻出です。
> ★事業者は、**タイムカード・パソコンの使用時間の記録等の客観的な方法**その他の適切な方法により**労働時間の状況を把握**しなければなりません（66条の8の3）。**管理監督者・裁量労働制の適用者も対象**です。
> ★時間の算定は**毎月1回以上、一定の期日**を定めて行い、超えた労働者には**速やかに**その時間に関する情報を**通知**しなければなりません。

### 面接指導の実施と事後措置

| 条 | 内容 |
|---|---|
| 66条の8第2項 | 労働者は、事業者の指定した医師の面接指導を受けなければならない（**他の医師**の面接指導を受けて証明する書面を提出した場合を除く） |
| 66条の8第3項 | 面接指導の**結果を記録**し**5年間**保存 |
| 66条の8第4項 | 面接指導の結果に基づき、**医師の意見を聴く**（面接指導が行われた後**遅滞なく**） |
| 66条の8第5項 | 必要があると認めるときは**就業場所の変更・作業の転換・労働時間の短縮・深夜業の回数の減少**等の措置を講ずる |

> ★申出は、要件に該当した労働者が**遅滞なく**行い、事業者は申出があった後**遅滞なく**面接指導を行います（おおむね1か月以内）。

### ストレスチェック（66条の10）

| | |
|---|---|
| 実施義務 | 常時**50人以上**の労働者を使用する事業場（**50人未満は努力義務**） |
| 頻度 | **1年以内ごとに1回** |
| 実施者 | **医師、保健師**、厚生労働大臣が定める研修を修了した**歯科医師・看護師・精神保健福祉士・公認心理師** |
| 対象 | 常時使用する労働者（**契約期間1年未満、週の所定労働時間が通常の労働者の4分の3未満**の者は対象外） |

**検査項目**は次の3領域です。

1. 職場における当該労働者の**心理的な負担の原因**に関する項目
2. 当該労働者の心理的な負担による**心身の自覚症状**に関する項目
3. 職場における**他の労働者による当該労働者への支援**に関する項目

### 結果の取扱い（プライバシー保護）

| 場面 | 取扱い |
|---|---|
| 検査結果 | **検査を行った医師等から直接労働者本人に通知**される |
| 事業者への提供 | **あらかじめ労働者の同意**を得なければ、事業者に提供してはならない |
| 記録の保存 | 労働者の同意を得て事業者に提供された場合、事業者は**5年間**保存 |
| **面接指導の申出** | 検査の結果、**心理的な負担の程度が高い**者であって、面接指導を受ける必要があると医師等が認めた者が**申出**をしたとき、事業者は面接指導を行わなければならない |
| 不利益取扱い | 面接指導の**申出をしたことを理由**として不利益な取扱いをしてはならない |

> ★**本人の同意なく事業者に結果を渡すことはできません**。ここが最頻出です。
> ★面接指導の申出をした時点で「高ストレス者である」と事業者に知られるため、**申出をもって結果の提供に同意したものとみなす**運用がとられています。
> ★面接指導の結果の記録は**5年間**保存、医師の意見聴取は**遅滞なく**（面接指導後**1か月以内**が目安）。

### 報告

常時50人以上の事業場は、**心理的な負担の程度を把握するための検査結果等報告書**を**1年以内ごとに1回**、所轄労働基準監督署長に提出します。

### 健康情報の取扱い（104条）

事業者は、労働者の**心身の状態に関する情報**を収集・保管・使用するにあたっては、**労働者の健康の確保に必要な範囲内**で収集し、当該目的の範囲内で保管・使用しなければなりません（本人の同意がある場合等を除く）。

厚生労働大臣は、この取扱いに関して事業者が適切に対処するための**指針**を公表します。

> ★令和7年の改正で、ストレスチェックの実施義務が**50人未満の事業場**にも拡大される方向で検討が進んでいます（施行は公布後3年以内）。出題される可能性があります。
