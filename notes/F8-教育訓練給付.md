# 教育訓練給付｜雇用の深掘り

### 3種類（60条の2）

| 種類 | 給付率 | 上限 |
|---|---|---|
| **一般教育訓練給付金** | 受講費用の**20%** | **10万円** |
| **特定一般教育訓練給付金** | 受講費用の**40%** | **20万円** |
| **専門実践教育訓練給付金** | 受講費用の**50%**（＋資格取得等で**20%**、さらに賃金上昇で**10%**） | 最大**80%** |

> ★令和6年10月から、専門実践に**賃金が5%以上上昇した場合の追加10%**が加わり、上限が**最大80%**になりました。

### 支給要件期間

| 区分 | 必要な支給要件期間 |
|---|---|
| **初めて**受給する場合 | **1年以上**（専門実践・特定一般は**2年以上**） |
| **2回目以降** | **3年以上** |

「支給要件期間」は、**同一の事業主に引き続き雇用された期間**ではなく、**被保険者であった期間を通算**したものです。前回の教育訓練給付を受けた場合は、その受講開始日**以後**の期間だけを数えます。

> ★**離職後1年以内**（適用対象期間の延長があればその期間内）に受講を開始すれば、離職者でも受給できます。
> ★受講開始日に**被保険者でない者**は、離職日の翌日から受講開始日までが**1年以内**であることが必要です。妊娠・出産・育児・疾病等により引き続き30日以上教育訓練を受けられない場合は、**最大20年**まで延長できます。

### 専門実践教育訓練の対象

| 例 |
|---|
| 業務独占資格・名称独占資格の取得を目標とする課程（**看護師、介護福祉士、保育士、社会福祉士、美容師、調理師**など） |
| **専門学校**の職業実践専門課程 |
| **専門職大学院**（MBA、法科大学院、教職大学院など） |
| 一定の**ITスキル**に関する講座（ITSSレベル3以上） |
| **第四次産業革命スキル習得講座** |

**受講前**に、**訓練対応キャリアコンサルタント**による**キャリアコンサルティング**を受け、**ジョブ・カード**を作成して、受講開始日の**1か月前まで**に申請します。

> ★一般教育訓練にはキャリアコンサルティングの義務はありませんが、**特定一般教育訓練**には**必要**です。

### 教育訓練支援給付金（附則11条の2）

**45歳未満**で専門実践教育訓練を受ける**離職者**に、訓練期間中、**基本手当日額の80%**（令和7年4月から**60%**）に相当する額を支給する制度です。

| 要件 | |
|---|---|
| 年齢 | 受講開始時に**45歳未満** |
| 状況 | **離職中**で、基本手当の支給を受け終わっていること |
| 期間 | 令和8年3月31日以前に受講開始する場合（暫定措置） |

> ★**専門実践**だけが対象です。一般・特定一般では支給されません。

### 教育訓練休暇給付金（令和7年10月1日創設）

**在職中**の被保険者が、教育訓練のために**無給の休暇**を取得した場合に、**基本手当に相当する額**を支給する新しい給付です。

| 要件 | |
|---|---|
| 被保険者期間 | **5年以上** |
| 休暇 | 事業主から**賃金の支払を受けずに**教育訓練のための休暇を取得すること |
| 給付日数 | 被保険者であった期間に応じ**90日・120日・150日** |

> ★**求職者給付ではなく教育訓練給付**に位置づけられます。失業していなくても受けられる点が新しいところです。

### 支給申請

| 種類 | 申請期限 |
|---|---|
| 一般・特定一般 | 受講修了日の翌日から**1か月以内** |
| 専門実践（受講中） | 受講開始日から**6か月ごと**の期間の末日の翌日から**1か月以内** |
| 専門実践（追加給付） | 資格取得等をして被保険者となった日の翌日から**1か月以内** |

> ★申請は**本人が住所を管轄する公共職業安定所**に行います。事業主経由ではありません。
