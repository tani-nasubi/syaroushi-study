# 年金額の改定とマクロ経済スライド｜年金の深掘り

**国民年金と厚生年金に共通**の仕組みです。国年27条の2〜27条の5、厚年43条の2〜43条の5が同じ構造で書かれています。

### 平成16年改正の枠組み

| 従来 | 平成16年改正後 |
|---|---|
| **給付水準**を先に決め、必要な保険料を集める（給付水準固定方式） | **保険料水準**を先に固定し、その範囲で給付を調整する（**保険料水準固定方式**） |

| 固定された保険料 | |
|---|---|
| 国民年金 | **17,000円**（平成16年度価格）× 保険料改定率 |
| 厚生年金 | **1000分の183.00**（平成29年9月に到達して固定） |

**国庫負担は2分の1**（平成21年度〜）です。

### 改定率（国年27条の2）

> **平成16年度における改定率は、1とする。**

改定率は毎年度、次を基準に改定され、その年度の**4月以降**の年金に適用されます。

| 用語 | 意味 |
|---|---|
| **物価変動率** | 前々年の全国消費者物価指数に対する**前年**の物価指数の比率 |
| **名目手取り賃金変動率** | 物価変動率 ×（**2〜4年度前の実質賃金変動率の3年平均**）×（**可処分所得割合変化率**） |

| 受給権者 | 用いる指標（27条の2・27条の3） |
|---|---|
| **新規裁定者**（67歳到達年度前） | **名目手取り賃金変動率** |
| **既裁定者**（68歳到達年度以後＝基準年度以後） | **物価変動率**（物価変動率が名目手取り賃金変動率を**上回るとき**は名目手取り賃金変動率） |

> ★**新規裁定者は賃金、既裁定者は物価**。境目は「**65歳に達した日の属する年度の初日の属する年の3年後**」＝実質**68歳**です。
> ★既裁定者は、物価が賃金を上回るとき**低いほう（賃金）**に合わせられます。「高いほうを採る」は誤りです。

### マクロ経済スライド（国年27条の4・27条の5）

**調整期間**の間、改定率の上昇を**調整率**の分だけ抑えます。

```
調整率 ＝ 公的年金被保険者総数の変動率（3年平均） × 0.997
```

| 要素 | 中身 |
|---|---|
| 第1号 | 5年前年度の**公的年金被保険者総数**に対する前々年度の総数の比率の**3乗根** |
| 第2号 | **0.997**（**平均余命の伸び**を反映した一定率） |

> ★**0.997**は条文に直接書かれた数字です。選択式で狙われます。
> ★「公的年金の被保険者」とは、**国民年金法または厚生年金保険法の被保険者**をいいます。

### 3つの場面（名目下限）

| 状況 | 扱い |
|---|---|
| ① 賃金・物価の伸びが**調整率より大きい** | **フルにスライド調整**する |
| ② 賃金・物価の伸びが**調整率より小さい**（ただしプラス） | 調整は**前年度の年金額を下回らない範囲**にとどめる（**名目額は下げない**） |
| ③ 名目手取り賃金変動率が**1を下回る**（マイナス） | **マクロ経済スライドを行わず**、名目手取り賃金変動率のみで改定する |

> ★**名目下限**が守られるため、マクロ経済スライドで**前年度より名目額が下がることはありません**。

### キャリーオーバー（特別調整率／平成30年4月〜）

②③で**調整しきれなかった分**は、翌年度以降に繰り越され（**未調整分**）、賃金・物価の伸びが大きい年度にまとめて調整されます。

条文上は「**当該年度の前年度の特別調整率**」を乗じる形で表現されています（27条の4第1項）。

> ★キャリーオーバーがあっても、**その年度の名目額が前年度を下回ることはありません**。

### 調整期間（国年16条の2）

> 政府は、**財政均衡期間**の終了時に**給付の支給に支障が生じない**と見込まれるまでの間、**年金たる給付の額を調整する**ものとし、その**開始年度を定める**。

| | |
|---|---|
| 調整期間の**開始** | 政令で定める（**平成17年度**から開始） |
| 調整期間の**終了** | **財政の現況及び見通し**を作成するときに、終了年度の見通しを示す |

### 財政の現況及び見通し（財政検証／国年4条の3）

| | |
|---|---|
| 作成 | 政府が**少なくとも5年ごと** |
| 財政均衡期間 | 作成される年以降**おおむね100年間** |
| 公表 | 作成したときは**遅滞なく公表** |

> ★**5年ごと**・**おおむね100年**。直近は令和6年（2024年）の財政検証です。

### 年金積立金の運用

| | |
|---|---|
| 運用主体 | **年金積立金管理運用独立行政法人（GPIF）** |
| 基本方針 | **専ら被保険者の利益のために、長期的な観点から、安全かつ効率的に**行う |
| 厚生労働大臣 | **積立金基本指針**を定める |

> ★積立金は**年金給付の財源の一部**であって、給付の大部分は**その時々の保険料と国庫負担**でまかなわれます（**賦課方式**が基本）。

### 端数処理

| 対象 | 処理 |
|---|---|
| 年金額 | **1円未満**を四捨五入 |
| 各支払期月の額 | **1円未満**を切り捨て、切り捨てた額の合計を**翌年2月**の支払期月に加算 |
| 改定率・再評価率 | 小数点以下**1位未満**を四捨五入（政令の定めによる） |
