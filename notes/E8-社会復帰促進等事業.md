# 社会復帰促進等事業と二次健康診断｜労災の深掘り

### 3つの柱（29条1項）

政府は、適用事業に係る労働者およびその遺族について、次の事業を行うことが**できる**（義務ではない）。

| 号 | 事業 | 具体例 |
|---|---|---|
| 1号 | **社会復帰促進事業** | 労災病院・医療リハビリテーションセンターの設置運営、義肢等補装具の支給 |
| 2号 | **被災労働者等援護事業** | **特別支給金**、労災就学援護費、休業補償特別援護金、労災就労保育援護費、アフターケア |
| 3号 | **安全衛生確保等事業** | 未払賃金の**立替払**、災害防止対策の援助、健康診断施設の設置運営 |

> ★**未払賃金の立替払**（賃金支払確保法）は3号に基づく事業です。労一の賃確法と関連して問われます。
> ★1号のうち労災病院等の運営は**独立行政法人労働者健康安全機構**に行わせます（29条3項）。

### 特別支給金の位置づけ

**保険給付ではありません**。ここから次の帰結が出ます。

| | 特別支給金 |
|---|---|
| 支給制限（12条の2の2） | **受けない** |
| 第三者行為の求償・控除 | **対象外** |
| 費用徴収（31条） | 対象外 |
| 不服申立て（38条） | **対象外**（審査請求できない） |
| 事業主からの損害賠償額との調整 | **対象外** |
| 譲渡・差押えの禁止、公課の禁止 | 労災法の規定は**適用されない**（社会復帰促進等事業支給金支給規則による） |

### 労災就学援護費と最高裁

労災就学援護費の支給・不支給の決定は、**行政処分に当たり抗告訴訟の対象となる**とされました（最判平成15年9月4日）。

要綱に基づく給付であっても、支給要件が明確に定められ、支給が受給権を発生させるものである以上、処分性が認められるという判断です。

### 二次健康診断等給付（26条）

**平成13年**に創設された、**過労死の予防**を目的とする給付です。

#### 対象者

**労働安全衛生法66条1項**の**定期健康診断等（一次健康診断）**において、次の**4項目すべて**に異常の所見があると診断された労働者。

1. **血圧**の測定
2. **血中脂質**検査（LDL・HDLコレステロールまたは血清トリグリセライドの量）
3. **血糖**検査
4. **腹囲**の検査または**BMI**の測定

> ★「いずれかに異常」ではなく**すべてに異常**です。ここが最頻出です。
> ★既に**脳血管疾患・心臓疾患の症状を有する**と認められる者は対象外です。

#### 給付の内容

| 給付 | 内容 | 回数 |
|---|---|---|
| **二次健康診断** | 脳血管・心臓の状態を把握するための医師による検査 | **1年度につき1回**（同一の一次健診に基づき1回） |
| **特定保健指導** | 二次健康診断の結果に基づく、医師・保健師による**面接**での栄養・運動・生活指導 | 二次健康診断**1回につき1回** |

いずれも**現物給付**（労災指定の健診給付病院等で受ける）で、費用の支給はありません。

#### 請求

**一次健康診断を受けた日から3か月以内**に、**健診給付病院等を経由して所轄都道府県労働局長**に請求します（労災則18条の19第4項）。天災その他やむを得ない理由があるときはこの限りではありません。

> ★請求先は**労働基準監督署長ではなく都道府県労働局長**です。経由も**健診給付病院等**です。
> ★特別加入者は二次健康診断等給付を**受けられません**（労働者ではないため安衛法の健康診断の対象外）。

#### 事業主への通知

労働者から二次健康診断の結果の提出を受けた事業主は、**安衛法66条の4**により**医師の意見を聴き**、必要に応じて就業場所の変更・労働時間の短縮等の措置を講じなければなりません。

### 費用と財源

社会復帰促進等事業に要する費用は、**労災保険率**に含まれる分（一般保険料）でまかなわれます。**国庫負担**は労災保険には原則としてありません（事務の執行に要する費用の一部を除く）。

> ★「労災保険の保険給付に要する費用に国庫負担がある」は誤りです。健保・国年・厚年との横断で問われます。
