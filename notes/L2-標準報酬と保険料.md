# 標準報酬と保険料｜厚年の深掘り

### 標準報酬月額（20条）

**第1級88,000円 〜 第32級650,000円**の**32等級**です。

> ★健保は**50等級（58,000円〜1,390,000円）**。等級数と上下限が違います。

**等級の改定**：毎年3月31日における全被保険者の標準報酬月額を平均した額の**2倍**に相当する額が最高等級の標準報酬月額を超える場合、その年の**9月1日**から**政令**で等級を追加できます。

### 標準賞与額（24条の4）

賞与額から**1,000円未満を切り捨て**、**1回につき150万円**が上限です。

> ★健保は**年度累計573万円**。厚年は**1回150万円**。同じ月に2回以上支給されたときは合算して150万円が上限です。

### 決定・改定（21条〜23条の3）

健康保険とほぼ同じですが、次の点が異なります。

| | |
|---|---|
| **定時決定**（21条） | 毎年**7月1日**現在の被保険者について、**4・5・6月**の報酬の平均。**9月から翌年8月**まで |
| **随時改定**（23条） | 固定的賃金の変動＋**継続した3か月**（各月17日以上）＋**2等級以上**の差。**4か月目**から |
| **育児休業等終了時改定**（23条の2） | 2等級以上の差は不要。**4か月目**から |
| **産前産後休業終了時改定**（23条の3） | 同上 |
| **3歳未満の子を養育する期間の特例**（26条） | **従前の標準報酬月額**を年金額の計算に用いる |

### 養育期間の従前標準報酬月額のみなし措置（26条）

**3歳未満の子を養育**する被保険者の標準報酬月額が、**養育開始月の前月の標準報酬月額（従前標準報酬月額）を下回る**場合、**申出**により、年金額の計算では**従前の標準報酬月額**を用います。

| | |
|---|---|
| 対象 | **男女を問わない**（父も対象） |
| 申出 | 事業主を経由して**厚生労働大臣**に |
| 効果 | **年金額の計算のみ**。**保険料は実際の（下がった）標準報酬月額**で計算される |
| さかのぼり | 申出日の属する月の**前月まで2年間**さかのぼれる |

> ★**保険料は安くなり、年金額は下がらない**という被保険者に有利な措置です。「保険料も従前の額で計算する」は誤りです。
> ★**育児休業を取得していなくても**、時短勤務等で報酬が下がれば対象になります。

### 保険料（81条）

```
保険料額 ＝（標準報酬月額 ＋ 標準賞与額）× 保険料率
```

**保険料率は1000分の183.00**（平成29年9月以降**固定**）。**労使折半**です。

> ★平成16年改正で毎年0.354%ずつ引き上げられ、**平成29年9月に18.3%で固定**されました。以後は上がりません。

### 産前産後休業・育児休業中の免除（81条の2・81条の2の2）

| 休業 | 免除される期間 |
|---|---|
| **産前産後休業** | 開始月から終了日の翌日が属する月の**前月**まで |
| **育児休業等** | 同上。**同一月内に14日以上**取得した場合はその月も免除。**賞与**に係る保険料は**1か月を超える**育児休業の場合に免除 |

> ★免除期間は**保険料を納めたものとして年金額に反映**されます。
> ★申出は**事業主が厚生労働大臣に**行います。

### 保険料の納付（83条）と源泉控除（84条）

| | |
|---|---|
| 納付義務 | **事業主**（被保険者負担分を含む） |
| 納期限 | **翌月末日** |
| 控除 | **前月分**を報酬から控除できる（**前月分控除の原則**）。賞与は**その月**の分 |
| 通知 | 保険料の額を**事業主に通知**する |

**繰上徴収**（85条）：次のときは、納期前であっても**すべての保険料を徴収**できます。

1. **納付義務者が、国税・地方税その他の公課の滞納により滞納処分**を受けるとき
2. **強制執行**を受けるとき
3. **破産手続開始の決定**を受けたとき
4. 企業担保権の実行手続の開始があったとき
5. **競売**の開始があったとき
6. **法人が解散**したとき
7. 被保険者の**使用される事業所が廃止**されたとき

### 督促・延滞金（86条・87条）

| | |
|---|---|
| 督促状の指定期限 | 発する日から**10日以上**経過した日 |
| 滞納処分 | **国税滞納処分の例**。厚生労働大臣は**財務大臣に権限を委任**できる |
| 延滞金 | 年**14.6%**（納期限の翌日から**3か月**を経過する日までは年**7.3%**） |

> ★厚年・国年の延滞金は「**3か月**」を境にします。健保は**2か月**、徴収法も**2か月**です。ここは横断で必ず問われます。

### 保険料の滞納と給付

厚生年金保険では、**事業主が保険料を滞納しても被保険者の給付は減りません**（事業主から徴収する）。国民年金の第1号被保険者が未納だと年金額に反映されないのとは対照的です。

### 拠出金（基礎年金拠出金）

厚生年金保険の実施機関は、**基礎年金の給付に要する費用**に充てるため、**基礎年金拠出金**を負担・納付します（国年法94条の2）。

拠出金の額は、**第2号被保険者および第3号被保険者の数**に応じて按分されます。

> ★**第3号被保険者の分も厚生年金全体で負担**しています。第3号被保険者が保険料を納めなくてよい根拠です。

### 基礎年金拠出金と国庫負担（84条の5・84条の6）

**実施機関**は、毎年度、**拠出金**（基礎年金拠出金）を納付します。拠出金算定対象額から実施機関が納付する拠出金の合計額等を控除した額は、**政府が負担**します。

**財政の現況及び見通し**（財政検証）が作成されるときは、厚生労働大臣は、実施機関が納付すべき拠出金および政府の負担について、**将来にわたる予想額を算定**します。

> ★拠出金を納付するのは**実施機関**（厚生労働大臣・各共済組合等）です。事業主や被保険者が直接納めるものではありません。

### 財務大臣・国税庁長官への権限の委任（100条の5・100条の6）

厚生労働大臣は、**滞納処分等**の権限の全部または一部を**財務大臣に委任**することができます。財務大臣は、その権限を**国税庁長官**に委任し、国税庁長官は**国税局長**に委任することができます。

財務大臣は、権限を行ったときは、**執行の状況および結果を厚生労働大臣に報告**します。

> ★**日本年金機構では回収困難な高額・悪質な滞納**を国税当局に引き継ぐ仕組みです。

### 機構への事務の委託（100条の7・100条の10）

厚生労働大臣は、**日本年金機構**に、被保険者の資格・標準報酬・保険給付・保険料の徴収に関する事務を**行わせる**（委任・委託する）ことができます。

機構が行う**滞納処分等**は、**あらかじめ厚生労働大臣の認可**を受け、**機構の理事長が任命した徴収職員**に行わせなければなりません。

> ★機構は**厚生労働大臣の権限を代行**する立場です。処分の名義や不服申立ての相手方は**厚生労働大臣**です。

### 市町村への交付金（86条5項）

保険料等を**市町村税の例によって処分**した場合、厚生労働大臣は**徴収金の100分の4に相当する額**を当該市町村に交付しなければなりません。

> ★厚生労働大臣は、滞納者の居住地等の**市町村に対し、その処分を請求**することができます（86条5項）。市町村が市町村税の例により処分したときの手数料にあたるのが**100分の4**です。
> ★国民年金にも同じしくみがあります（国年95条・96条）。
