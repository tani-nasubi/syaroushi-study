# 労働時間の適用除外｜労基の深掘り

### 41条（管理監督者等）

次の者には**労働時間・休憩・休日**の規定が適用されません。**深夜業と年次有給休暇は適用されます**。

1. 農業・畜産・養蚕・水産の事業に従事する者
2. **監督若しくは管理の地位にある者**又は機密の事務を取り扱う者
3. **監視又は断続的労働**に従事する者で、**所轄労働基準監督署長の許可**を受けた者

> ③だけ**許可が必要**です。①②は許可不要。ここが引っかけになります。

### 管理監督者かどうかの判断

役職名ではなく**実態**で判断します。

| 要素 | 内容 |
|---|---|
| 職務内容・責任と権限 | 労務管理について経営者と一体的な立場にあるか |
| 勤務態様 | 出退勤について**厳格な制限を受けていない**か |
| 待遇 | その地位にふさわしい**待遇**がなされているか |

### 41条の2（高度プロフェッショナル制度）

**深夜業も含めて**労働時間規制が適用されない唯一の制度です。

| 要件 | 内容 |
|---|---|
| 手続 | **労使委員会の5分の4以上**の決議＋届出 |
| 本人同意 | **必要**（撤回もできる） |
| 対象業務 | 高度の専門的知識等を要し、時間と成果の関連性が高くない業務 |
| 年収 | **1,075万円以上** |
| 健康確保 | **年104日以上かつ4週4日以上**の休日を確実に確保 ＋ 選択的措置 |
