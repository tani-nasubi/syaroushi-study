# 労働時間の適用除外｜労基の深掘り

### 41条（管理監督者等）

次の者には**労働時間・休憩・休日**の規定が適用されません。**深夜業と年次有給休暇は適用されます**。

1. 農業・畜産・養蚕・水産の事業に従事する者
2. **監督若しくは管理の地位にある者**又は機密の事務を取り扱う者
3. **監視又は断続的労働**に従事する者で、**所轄労働基準監督署長の許可**を受けた者

> ③だけ**許可が必要**です。①②は許可不要。ここが引っかけになります。

### 管理監督者かどうかの判断

役職名ではなく**実態**で判断します。

| 要素 | 内容 |
|---|---|
| 職務内容・責任と権限 | 労務管理について経営者と一体的な立場にあるか |
| 勤務態様 | 出退勤について**厳格な制限を受けていない**か |
| 待遇 | その地位にふさわしい**待遇**がなされているか |

### 41条の2（高度プロフェッショナル制度）

**深夜業も含めて**労働時間規制が適用されない唯一の制度です。

| 要件 | 内容 |
|---|---|
| 手続 | **労使委員会の5分の4以上**の決議＋届出 |
| 本人同意 | **必要**（撤回もできる） |
| 対象業務 | 高度の専門的知識等を要し、時間と成果の関連性が高くない業務 |
| 年収 | **1,075万円以上** |
| 健康確保 | **年104日以上かつ4週4日以上**の休日を確実に確保 ＋ 選択的措置 |

### 41条が定める3つの類型

> 労働時間、休憩および休日に関する規定は、次の者については適用しない。

| 号 | 対象 |
|---|---|
| **1号** | **農業・畜産業・養蚕業・水産業**（別表第1第6号・第7号）に従事する者 |
| **2号** | **監督もしくは管理の地位にある者**（管理監督者）または**機密の事務を取り扱う者** |
| **3号** | **監視または断続的労働**に従事する者で、**所轄労働基準監督署長の許可**を受けたもの |

> ★**除外されるのは労働時間・休憩・休日だけ**です。**深夜業（37条4項）と年次有給休暇（39条）は適用されます**。ここが最頻出です。
> ★**林業は除外されません**（別表第1第6号から林業が外れています）。「農林水産業だから除外」は誤りです。
> ★許可が必要なのは**3号だけ**です。管理監督者に許可は要りません。

### 管理監督者の判断（2号）

**名称にとらわれず、実態に即して**判断します。

| 判断要素 | 内容 |
|---|---|
| ① **職務内容・責任と権限** | 労務管理について経営者と一体的な立場にあるか。**採用・解雇・人事考課**等に関与しているか |
| ② **勤務態様** | **出退勤について厳格な規制を受けていない**か（遅刻・早退で減給されないか） |
| ③ **待遇** | 基本給・手当・賞与について、**地位にふさわしい待遇**がなされているか |

> ★**日本マクドナルド事件**（店長）では、①〜③のいずれも満たさないとして管理監督者性が否定されました。
> ★スタッフ職（経営上の重要事項に関する企画立案等の業務を担当する者）についても、**ライン管理職と同格以上に位置づけられていれば**管理監督者として扱えます。

### 監視・断続的労働（3号）

| 種類 | 内容 |
|---|---|
| **監視に従事する者** | 一定部署にあって**監視するのを本来の業務**とし、**常態として身体の疲労または精神的緊張の少ない**もの（守衛、駐車場の監視員など） |
| **断続的労働に従事する者** | 作業自体が間欠的で**手待時間が多く実作業時間が少ない**もの（役員専属の運転手、寄宿舎の賄人など） |

> ★**交通関係の監視、危険物取扱いの監視、プラント等の計器類の監視**は許可されません。
> ★**宿直・日直**（施行規則23条）も**所轄労働基準監督署長の許可**が必要です。宿日直の許可があれば、その時間は労働時間として扱われません。

### 高度プロフェッショナル制度（41条の2）

| 要件 | 内容 |
|---|---|
| 手続 | **労使委員会**の**5分の4以上**の決議＋**届出** |
| 同意 | **本人の同意**（書面）。同意の**撤回**ができること |
| 対象業務 | **金融商品の開発、ディーリング、アナリスト、コンサルタント、研究開発**の5業務 |
| 年収要件 | **1,075万円以上**（基準年間平均給与額の3倍を相当程度上回る水準） |
| **健康管理時間**の把握 | 客観的な方法による |
| **年104日以上かつ4週4日以上**の休日確保 | **義務** |
| 選択的措置（いずれか1つ） | ① 勤務間インターバル11時間以上＋深夜業の回数制限 ② 健康管理時間の上限 ③ **1年に1回以上の連続2週間の休日** ④ 臨時の健康診断 |
| 健康・福祉確保措置 | 選択的措置の残りなどから1つ以上 |

**高プロ対象者には、労働時間・休憩・休日に加えて深夜業の割増賃金も適用されません**。

> ★41条の管理監督者は**深夜業が適用される**、41条の2の高プロは**深夜業も適用されない**。この差が最頻出です。
> ★健康管理時間が1か月100時間を超えた対象者には、**申出を要せず医師による面接指導**を行わなければなりません（安衛法66条の8の4）。
