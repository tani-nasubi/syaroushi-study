## 1. 全科目共通｜拘禁刑への一本化

刑法改正（令和4年成立・**令和7年6月1日施行**）により「懲役」「禁錮」が**拘禁刑**に一本化。
これに伴い労働・社会保険諸法令の罰則も改正された。

- **刑期の年数・罰金額そのものに変更はない**
- 条文を丸暗記している場合、選択式で「拘禁刑」と書けるかがポイント
- 例：労基法5条（強制労働の禁止）＝「**1年以上10年以下の拘禁刑**又は20万円以上300万円以下の罰金」

## 2. 厚生年金保険法 ★今年の最重要

### 2-1. 在職老齢年金の支給停止調整額 → **65万円**（令和8年4月1日）

令和7年年金制度改正法により、令和6年度価格で **50万円 → 62万円** に引上げ。
令和8年度の実額が **65万円**。

```
支給停止額（月額）＝（基本月額 ＋ 総報酬月額相当額 － 65万円）× 1/2
```

| 用語 | 定義 |
|---|---|
| 基本月額 | 老齢厚生年金（**加給年金額を除く**）の額 ÷ 12 |
| 総報酬月額相当額 | その月の標準報酬月額 ＋ その月以前1年間の標準賞与額の合計 ÷ 12 |

- 停止されるのは**報酬比例部分のみ**。老齢基礎年金・経過的加算は停止されない
- 報酬比例部分が全額停止されると**加給年金額も支給されない**
- 計算式そのものは改正されていない（変わったのは金額だけ）

### 2-2. 年金分割の請求期限 2年 → **5年**（令和8年4月1日）⚠️要確認

- **合意分割**：合意又は裁判手続で按分割合を決定。上限**2分の1**
- **3号分割**：平成20年4月1日以後の第3号被保険者期間。**合意不要・一律2分の1**
- どちらも請求期限が離婚等をした日の翌日から起算して**5年**に延長

### 2-3. 遺族厚生年金の見直し ★**令和10年4月1日施行＝未施行**

- 20〜30歳代で子のない配偶者への遺族厚生年金を**5年間の有期給付**に
- 夫の55歳以上という年齢要件を撤廃し**男女差を解消**
- 20年かけて段階的に対象年齢を引上げ

**今年は未施行**なので、条文問題では現行（夫・父母・祖父母は55歳以上、30歳未満の子のない妻は5年有期）で解答する。

### 2-4. 適用拡大 ★**令和9年10月〜段階的＝未施行**

企業規模要件（現行 被保険者数常時51人以上）の撤廃：
令和9年10月 36〜50人 → 令和11年10月 21〜35人 → 令和14年10月 11〜20人 → 令和17年10月 10人以下

賃金要件（月額8.8万円以上）の撤廃も含め、**令和8年度試験では未施行**。

## 3. 国民年金法｜令和8年度の年金額改定

| 項目 | 値 |
|---|---|
| 物価変動率 | ＋3.2％ |
| 名目手取り賃金変動率 | ＋2.1％ |
| マクロ経済スライド調整率 | 基礎▲0.2％／報酬比例▲0.1％ |
| **基礎年金の改定率** | **＋1.9％** |
| **厚生年金（報酬比例）の改定率** | **＋2.0％** |
| **老齢基礎年金 満額** | 月額 **70,608円**（年額 **847,300円**） |
| 国民年金保険料 | 月額 **17,920円** ⚠️ |

### 改定ルール（毎年変わらない＝選択式頻出）
- 新規裁定者（68歳到達年度前）→ **名目手取り賃金変動率**
- 既裁定者（68歳到達年度以後）→ **物価変動率**
- ただし「**物価 ＞ 賃金**」のときは既裁定者も**名目手取り賃金変動率**を用いる

令和8年度は物価＋3.2％ ＞ 賃金＋2.1％ だったので**全員が賃金基準**。
そこにマクロ経済スライドを適用して ＋1.9％／＋2.0％。

※令和5年度に改定率が分岐したため、**昭和31年4月1日以前生まれ**は 月額**70,408円**／年額**844,900円**（月200円低い）。

## 4. 雇用保険法 ★改正が集中＝過去問が役に立たない科目

### 4-1. 給付制限の短縮（令和7年4月1日）

| 事由 | 期間 |
|---|---|
| 正当な理由のない自己都合離職 | **1か月**（従来2か月） |
| 5年間に**3回以上**の自己都合離職 | **3か月** |
| 離職期間中等に**自ら教育訓練を受けた** | **給付制限なし** |
| 自己の責めに帰すべき重大な理由による解雇 | **3か月** |

いずれも**待期7日の満了後**から起算する。

### 4-2. 教育訓練休暇給付金の創設（令和7年10月1日）

**離職していないのに基本手当相当額が支給される**という点が新しい。

- **一般被保険者**が、就業規則等の制度に基づき**30日以上の無給**の教育訓練休暇を取得した場合に支給
- 休暇開始前**2年間に被保険者期間12か月以上**、かつ**5年以上**の雇用保険加入期間
- 1日あたりの額は基本手当の日額と同じ算定方法
- 給付日数：5年以上10年未満**90日**／10年以上20年未満**120日**／20年以上**150日**
- 支給されるのは休暇開始日から起算して**1年以内**に取得した日

**「無給」「30日以上」「加入5年以上」の3つが要件**。ここが引っかけになりやすい。

### 4-3. 高年齢雇用継続給付の引下げ（令和7年4月1日）

- 最大 **15％ → 10％**
- **令和7年3月31日までに60歳に達した者**には従前の15％（経過措置）
- 高年齢再就職給付金も同様
- 「いつ60歳に達したか」で率が変わる

### 4-4. 育児関係の新設給付（令和7年4月1日）

| 給付 | 内容 |
|---|---|
| **出生後休業支援給付金** | 被保険者とその配偶者の双方が子の出生直後に14日以上の育休を取得した場合、休業開始時賃金日額の**13％**を最大28日間。育休給付67％と合わせて**80％＝手取り10割相当** |
| **育児時短就業給付金** | 2歳未満の子を養育するための時短勤務中、支払われた賃金額の**10％** |

配偶者が一定の場合（ひとり親等）は配偶者要件が不要。

### 4-5. 就業促進給付の見直し（令和7年4月1日）

- **就業手当は廃止**
- 就業促進定着手当の上限を引下げ（基本手当日額×支給残日数×**10分の2**）

### 4-6. 適用拡大 ★**令和10年10月1日＝未施行**

被保険者となる週所定労働時間の下限を **20時間 → 10時間** に引下げ。
**今年は未施行**なので現行の週20時間以上で解答する。

## 6. 労働安全衛生法（令和8年4月1日）

### 6-1. 個人事業者等に対する安全衛生対策
建設アスベスト訴訟の最高裁判決（令和3年）を受けた改正。労働者以外の作業従事者にも保護を及ぼす。

- **注文者**の措置義務の対象を個人事業者等に拡大（31条等）
- **機械等貸与者**の措置を個人事業者への貸与にも適用
- **建築物貸与者**の対象範囲を拡大（倉庫・物流センター、商業施設バックヤード等）⚠️
- **元方安全衛生管理者**に作業従事者・関係請負人の労災防止の権限 ⚠️

### 6-2. 高年齢労働者の労働災害防止 → **努力義務**
身体機能低下等に対応した作業環境の改善等を講ずるよう**努めなければならない**。
国が指針（エイジフレンドリーガイドラインの格上げ）を策定。

**「義務／努力義務」の入替えが定番の引っかけ**。

### 6-3. 化学物質関係
SDS通知について、営業秘密に該当する場合に**代替化学名**による通知を認め、記録を**5年間**保存 ⚠️

### 6-4. ストレスチェック 50人未満への義務化 ★**未施行**
改正法は成立済みだが、施行は公布から3年以内の政令で定める日（**令和10年5月まで**の予定）。
**今年は50人未満は努力義務のまま**。

## 7. 労働一般常識

### 7-1. 女性活躍推進法（令和8年4月1日）

| 規模 | 義務 |
|---|---|
| **101人以上** | 一般事業主行動計画の策定・届出、**情報公表**（女性管理職比率・男女賃金差異を含む） |
| 100人以下 | 努力義務 |

- 男女賃金差異の公表義務が **301人以上 → 101人以上** に拡大
- **女性管理職比率**が公表項目に追加
- 同法の有効期限を**10年延長**
- 女性の健康支援の取組を評価する認定（**えるぼしプラス**）を新設 ⚠️名称要確認

### 7-2. 労働施策総合推進法（令和8年4月1日）
治療と仕事の両立支援について、ガイドラインを法律に基づく**指針**に格上げし、事業主の**努力義務**を明記。

### 7-3. カスタマーハラスメント対策 ★**令和8年10月1日＝未施行**

- 改正労働施策総合推進法（令和7年6月11日公布）
- 労働者を1人でも雇用する**全ての事業主**に適用、経過措置なし
- 指針は「方針の明確化・相談体制・事後対応・抑止措置」の4つの柱
- **求職者等に対するセクハラ対策**の義務化も同日施行

**今年は未施行**なので条文問題の対象外。ただし時事的出題に備えて内容は押さえる。

### 7-4. 育児・介護休業法

**令和7年4月1日**
- 子の看護休暇 → **子の看護等休暇**（対象を**小学校第3学年修了**まで拡大）
- 取得事由に**感染症に伴う学級閉鎖等**、**入園（学）式・卒園（業）式**を追加
- 労使協定による除外から「継続雇用期間6か月未満」を撤廃
- 所定外労働の制限（残業免除）の対象を **3歳未満 → 小学校就学の始期**まで拡大
- 介護に直面した労働者への**個別周知・意向確認**、40歳到達時等の**情報提供**を義務化

**令和7年10月1日**
- **柔軟な働き方を実現するための措置**：①始業時刻等の変更 ②テレワーク等 ③保育施設の設置運営等 ④養育両立支援休暇 ⑤短時間勤務 のうち事業主が**2以上**を措置し、労働者が**1つ**を選択して利用
- 3歳になるまでの適切な時期に**個別の意向聴取・配慮**を義務化

**混同注意**：看護等休暇は**小3修了**まで／残業免除は**小学校就学前**まで。範囲が異なる。

### 7-5. 最低賃金（令和7年度）
- 全国加重平均 **1,121円**（前年1,055円、**＋66円**）
- 引上げ額66円は昭和53年度の目安制度開始以降で**最高額**
- **全都道府県で1,000円を突破**
- 令和8年度の改定は10月頃＝**試験後**なので、試験対象は令和7年度の数値
