# 給付の通則と受給権の保護｜厚年の深掘り

保険給付に共通するルールです。老齢・障害・遺族のどれにも効くので、まとめて押さえます。

### 裁定（33条）

> 保険給付を受ける権利は、**その権利を有する者の請求に基づいて、実施機関が裁定**する。

> ★**請求がなければ裁定されません**（労災の傷病補償年金のような職権支給はありません）。
> ★2以上の種別の被保険者期間を有する者は、**どの実施機関の窓口でも請求できます**（ワンストップサービス）。裁定は各実施機関が行い、額を**合算**して支給します。

### 支給期間と支払期月（36条）

| | |
|---|---|
| 支給開始 | 受給権が発生した日の属する月の**翌月**から |
| 支給終了 | 権利が消滅した日の属する月**まで** |
| 支給停止 | 停止事由が生じた月の**翌月**から、消滅した月**まで** |
| 支払期月 | **毎年2月・4月・6月・8月・10月・12月**の6期に、それぞれの**前月分まで**を支払う |

**前支払期月に支払うべきであった年金や、権利が消滅した場合の未払分**は、**支払期月でない月**でも支払うことができます。

> ★「翌月から、その月まで」。**発生月は払わず、消滅月は払う**という非対称です。

### 端数処理（35条）

| 対象 | 処理 |
|---|---|
| 年金額 | **1円未満**を四捨五入 |
| 各支払期月の支払額 | **1円未満**を切り捨て |
| 切り捨てた額の合計 | **翌年2月**の支払期月に加算して支払う |

### 未支給の保険給付（37条）

受給権者が死亡し、まだ支給されていない保険給付があるときは、**死亡当時その者と生計を同じくしていた**次の者が、**自己の名**で請求できます。

```
配偶者 → 子 → 父母 → 孫 → 祖父母 → 兄弟姉妹 → これらの者以外の三親等内の親族
```

> ★**三親等内の親族**まで含まれます（国民年金法19条も同じ）。労災は兄弟姉妹まで、範囲が違います。
> ★**生計維持ではなく生計同一**が基準です。
> ★同順位者が2人以上いるときは、**そのうちの1人がした請求は全員のためにその全額につきしたもの**とみなされ、**1人に対してした支給は全員に対してしたもの**とみなされます。

### 受給権の保護と公課（41条）

| 項 | 内容 |
|---|---|
| 1項 | 保険給付を受ける権利は、**譲り渡し、担保に供し、または差し押さえることができない**。ただし、**年金たる保険給付を受ける権利を国税滞納処分により差し押さえる場合**は、この限りでない |
| 2項 | **租税その他の公課**は、保険給付として支給を受けた金銭を標準として課することができない。ただし**老齢厚生年金**については、この限りでない |

> ★**老齢厚生年金は課税**、**障害厚生年金・遺族厚生年金は非課税**。国年（老齢基礎年金・付加年金が課税）と同じ考え方です。

### 不正利得の徴収（40条）

**偽りその他不正の手段**により保険給付を受けた者があるときは、実施機関は**受給額に相当する金額の全部または一部を徴収**することができます。

**事業主が虚偽の届出・報告・証明**をしたためであるときは、実施機関は**事業主に対し、受給者と連帯して徴収金を納付すべきことを命ずる**ことができます。

### 第三者行為による損害賠償との調整（40条2項・3項）

| 順序 | 効果 |
|---|---|
| **実施機関が先に給付**したとき | 給付の**価額の限度**で、受給権者が第三者に対して有する**損害賠償請求権を取得**する |
| **受給権者が先に損害賠償**を受けたとき | その**価額の限度**で保険給付を**行わないことができる** |

> ★労災の求償・控除と同じ形ですが、労災には「**災害発生後3年以内**」という期間の限定があるのに対し、厚年・国年にはこの限定がありません。

### 支給の停止・差止め（78条ほか）

| 事由 | 効果 |
|---|---|
| **正当な理由なく届出をせず、または書類等を提出しない**とき | 保険給付の**支払を一時差し止める**ことができる |
| **正当な理由なく診断を受けない**とき（障害の程度の診査） | 保険給付の**額の全部または一部につき、その支給を停止する**ことができる |
| **受給権者の所在が1年以上明らかでない**とき | 同順位者・次順位者の申請により**支給を停止**（遺族厚生年金） |

### 併給の調整（38条）と1人1年金

**同一の支給事由**でない2以上の年金給付の受給権を得たときは、**いずれか1つを選択**し、他は支給停止されます。**選択替え**はいつでもできます。

**65歳以後の例外**は [`L4-在職老齢年金と支給停止.md`](L4-在職老齢年金と支給停止.md) にまとめています。

### 脱退手当金（旧法の経過措置）

昭和61年3月以前に**脱退手当金**を受けた期間は、原則として**年金額に反映されません**が、一定の要件のもとで**合算対象期間**（カラ期間）として受給資格期間に算入されます。
