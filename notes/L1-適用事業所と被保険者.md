# 適用事業所と被保険者｜厚年の深掘り

### 適用事業所（6条）

健康保険とほぼ同じ枠組みです。

| 区分 | 内容 |
|---|---|
| **強制**適用 | ① **法人**の事業所（業種・人数を問わない）<br>② **個人**経営で常時**5人以上**の従業員を使用する**法定17業種**の事業所<br>③ **船舶**（船員法の船員が乗り組むもの） |
| **任意**適用 | 従業員の**2分の1以上**の同意を得て事業主が申請し、**厚生労働大臣の認可** |

> ★**船舶は当然に適用事業所**です（人数・業種を問わない）。健保にはない厚年独自の規定です。
> ★任意適用の取消しは**4分の3以上**の同意と認可が必要です。

### 被保険者（9条）

適用事業所に使用される**70歳未満**の者。

> ★健保には年齢上限がなく（75歳で後期高齢者医療へ）、**厚年は70歳未満**です。ここが最頻出の対比です。

### 適用除外（12条）

| 号 | 除外される者 |
|---|---|
| 1号 | **臨時**に使用される者で、**日々雇い入れられる者**（1か月を超えて引き続き使用されるに至った場合を除く） |
| 2号 | 臨時に使用される者で、**2か月以内**の期間を定めて使用される者（所定の期間を超えて引き続き使用されることが**見込まれる**場合を除く） |
| 3号 | **所在地が一定しない**事業所に使用される者 |
| 4号 | **季節的業務**（継続して**4か月**を超えて使用されるべき場合を除く）に使用される者 |
| 5号 | **臨時的事業の事業所**（継続して**6か月**を超えて使用されるべき場合を除く）に使用される者 |

**短時間労働者の適用拡大**の5要件は健康保険と同じです（週20時間以上、月額8.8万円以上、2か月超の見込み、学生でない、特定適用事業所＝被保険者50人超）。

### 4種類の被保険者

| 種類 | 内容 |
|---|---|
| **当然**被保険者 | 通常の被保険者 |
| **任意単独**被保険者（10条） | **適用事業所以外**の事業所に使用される70歳未満の者が、**事業主の同意**を得て**厚生労働大臣の認可**を受けたとき |
| **高齢任意加入**被保険者（附則4条の3・4条の5） | **70歳以上**で老齢給付等の**受給権を有しない**者が、受給資格期間を満たすまで加入するもの |
| **第4種**被保険者（旧法の経過措置） | 昭和61年3月以前の任意継続 |

| | 適用事業所に使用される場合 | 適用事業所以外に使用される場合 |
|---|---|---|
| 高齢任意加入の申出先 | **厚生労働大臣**（実施機関）。**事業主の同意は不要** | 厚生労働大臣。**事業主の同意が必要** |
| 保険料 | 原則**全額本人負担**。ただし**事業主が同意すれば折半** | **折半**（事業主も負担） |

> ★適用事業所に勤める高齢任意加入被保険者は**事業主の同意なしに加入でき、保険料は原則全額本人負担**。ここが定番です。

### 実施機関（2条の5）

| 種別 | 実施機関 |
|---|---|
| **第1号**厚生年金被保険者（民間被用者） | **厚生労働大臣**（日本年金機構が事務を行う） |
| **第2号**（国家公務員共済） | **国家公務員共済組合**および**国家公務員共済組合連合会** |
| **第3号**（地方公務員共済） | **地方公務員共済組合**、**全国市町村職員共済組合連合会**、**地方公務員共済組合連合会** |
| **第4号**（私学共済） | **日本私立学校振興・共済事業団** |

平成27年10月の**被用者年金一元化**により、公務員・私学教職員も厚生年金の被保険者となりました。

> ★**共済年金の職域加算は廃止**され、**年金払い退職給付**に移行しました。
> ★**2以上の種別の被保険者期間**を有する者の年金は、**各期間ごとに実施機関が計算**し、**合算**して支給します（「ワンストップサービス」でどの窓口でも請求できます）。

### 資格の得喪（13条・14条）

| 取得 | 喪失 |
|---|---|
| 適用事業所に**使用されるに至った日** | **死亡**した日の翌日／使用されなくなった日の**翌日** |
| 事業所が適用事業所となった日 | **適用除外**に該当した**その日** |
| 適用除外に該当しなくなった日 | **70歳**に達した**その日**（誕生日の前日） |
| 任意単独・高齢任意加入は**認可・申出**があった日 | 任意適用事業所の取消しの認可があった日の**翌日** |

> ★**同月得喪**（同一月に取得と喪失）の場合、厚年では**その月の保険料は徴収されません**（令和2年〜。ただし同月内に国民年金第1号被保険者となったときはそちらを納付）。健保は徴収するので違いに注意します。

### 届出（27条）

事業主は、**被保険者の資格取得・喪失、報酬月額、賞与額**等を**厚生労働大臣に届け出**なければなりません。

| 届出 | 期限 |
|---|---|
| 資格取得届・喪失届 | **5日以内**（船員は10日以内） |
| 算定基礎届 | **7月10日**まで |
| 月額変更届 | **速やかに** |
| 賞与支払届 | **5日以内** |
| **70歳以上の使用される者**の届出 | 5日以内 |

> ★健保・厚年の事業主の届出は**5日以内**、国年第1号は**14日以内**（市町村長へ）、雇用保険の資格取得届は**翌月10日**まで。それぞれ違います。

### 適用事業所以外の70歳以上の者

**70歳以上で被保険者でない者**も、適用事業所に使用され、老齢厚生年金等の受給権を有する場合は、**在職老齢年金の対象**になります。このため事業主は「**70歳以上被用者該当届**」を提出します。

### 記録と訂正の請求（28条・28条の2）

実施機関は**被保険者に関する原簿**（＝**厚生年金保険原簿**）を備え、氏名・資格の取得喪失の年月日・**標準報酬**・**基礎年金番号**その他を記録します。

**第1号厚生年金被保険者**であり、またはあった者は、原簿に記録された自己に係る**特定厚生年金保険原簿記録**が事実でない、または記録がないと思料するときは、**厚生労働大臣に訂正の請求**をすることができます。

| | |
|---|---|
| 請求先 | **厚生労働大臣** |
| 死亡した場合 | **配偶者・子・父母・孫・祖父母・兄弟姉妹**が請求できる（準用） |
| 決定に対する不服 | **社会保険審査官への審査請求の対象外**（行政不服審査法による） |

> ★訂正請求の決定は、**年金記録の訂正**についての判断であり、通常の給付に関する処分とは扱いが違います。
> ★**年金証書**は、受給権者に対し**裁定**をしたときに交付されます。

### 事業主の義務と調査

| 条 | 内容 |
|---|---|
| **27条** | 資格の取得・喪失、報酬月額・賞与額の**届出** |
| **29条** | 被保険者に対する**通知**（実施機関からの通知を事業主が被保険者に伝える） |
| **100条** | **文書の提出・出頭**の命令、**当該職員による質問・立入検査**（事業所調査） |
| **98条** | 事業主・被保険者の**届出義務**、被保険者からの**確認の請求** |

> ★**日本年金機構が行う滞納処分等**は、**滞納処分等実施規程**を作成し、**厚生労働大臣の認可**を受けて行います（100条の6）。

---

### 船長等の代理（厚年則29条の2）

> 船員被保険者の**資格の取得・喪失、標準報酬に関する届出**（厚年則が定めるもの）については、**船舶所有者は船長又は船長の職務を行う者を代理人として処理させることができる**。

- 対象は**船員被保険者**に係る資格の取得・喪失、標準報酬に関する届出などです。
- 船舶が航行中で船舶所有者が手続をとれない場面を想定した規定です。

> ★代理人になれるのは**船長又は船長の職務を行う者**です。「機関長」等ではありません。
> ★あくまで**できる**規定であって、義務ではありません。
