## 1. 社会保険労務士法

### 業務（2条）

| 号 | 内容 | 独占業務 |
|---|---|---|
| **1号** | 労働社会保険諸法令に基づく**申請書等の作成**、行政機関等への**提出手続の代行**、**事務代理** | **○** |
| **2号** | **帳簿書類の作成**（就業規則、労働者名簿、賃金台帳等） | **○** |
| **3号** | 労務管理その他の労働・社会保険に関する事項についての**相談・指導** | **×** |

> **★引っかけ**：3号業務（コンサルティング）は**独占業務ではない**。誰でもできる。
> 禁止されるのは「**他人の求めに応じ報酬を得て、業として**」行うこと。報酬を得ないなら可。

### 特定社会保険労務士
紛争解決手続代理業務（あっせん、調停、仲裁等）を行える。
**紛争の目的の価額が120万円を超える**事件は**弁護士との共同受任**が必要。

### 登録・法人・懲戒

| 項目 | 内容 |
|---|---|
| **登録** | **全国社会保険労務士会連合会**に備える名簿に登録。登録すると当然に**都道府県社労士会の会員** |
| 社会保険労務士法人 | 社員は社労士に限る。社員は**競業避止義務**、法人の債務について**連帯無限責任** |
| **懲戒** | **厚生労働大臣**が行う。① **戒告** ② **1年以内の業務の停止** ③ **失格処分** |
| 義務 | 信用失墜行為の禁止、**秘密を守る義務**（社労士でなくなった後も）、名義貸しの禁止、帳簿の備付け（**2年間保存**） |

### 国民健康保険法

| 項目 | 内容 |
|---|---|
| 保険者 | **都道府県が市町村とともに**行う（平成30年4月〜）＋ 国民健康保険組合 |
| **都道府県の役割** | 財政運営の**責任主体**、国保運営方針の策定、市町村ごとの**国民健康保険事業費納付金**の決定、**標準保険料率**の算定 |

| 給付 | 療養の給付、高額療養費、出産育児一時金、葬祭費 等（**傷病手当金・出産手当金は任意給付**） |
| 不服申立て | **国民健康保険審査会**（都道府県・一審制） |

### 高齢者医療確保法

| 項目 | 内容 |
|---|---|
| **後期高齢者医療** | 保険者＝**後期高齢者医療広域連合**（都道府県単位で全市町村が加入） |
| 被保険者 | **75歳以上**の者、及び**65歳以上75歳未満**で一定の障害の状態にある旨の**広域連合の認定**を受けた者 |
| 広域連合の役割 | 保険料率の決定、資格管理、**保険給付** |
| 市町村の役割 | **保険料の徴収**、申請・届出の受付 |
| 一部負担金 | 原則**1割**、一定以上所得者**2割**、現役並み所得者**3割** |
| **前期高齢者（65〜74歳）** | 独立した制度ではなく、各保険者間の**財政調整**の仕組み |
| 特定健康診査・特定保健指導 | **40歳以上75歳未満**の加入者に対し、保険者が実施 |

> **★引っかけ**：後期高齢者は**独立した制度**／前期高齢者は**財政調整のみ**。

## 3. 介護保険法

### 保険者・被保険者

| 項目 | 内容 |
|---|---|
| **保険者** | **市町村及び特別区** |
| **第1号被保険者** | **65歳以上**。原因を問わず給付。保険料は**年金からの特別徴収**が原則（年額**18万円以上**） |
| **第2号被保険者** | **40歳以上65歳未満**の**医療保険加入者**。**特定疾病**（末期がん、関節リウマチ等**16種**）が原因の場合に限り給付。保険料は**医療保険者が医療保険料と一体で徴収** |

> **★引っかけ**：第2号は「**医療保険加入者**」が要件。生活保護受給者（国保未加入）は第2号被保険者にならない。

### 要介護認定

| 項目 | 内容 |
|---|---|
| 申請 | 市町村に申請。**指定居宅介護支援事業者等が代行可** |
| 判定 | 認定調査＋主治医意見書 → **介護認定審査会**（市町村に設置）の審査判定 |
| 期間 | 申請から原則**30日以内**に認定 |
| 効力 | **申請時にさかのぼる** |
| 有効期間 | 新規原則**6か月**、更新原則**12か月** |
| 区分 | 要支援1・2／要介護1〜5 |

### 給付

| 対象 | 給付 |
|---|---|
| 要介護者 | **介護給付** |
| 要支援者 | **予防給付** |
| それ以外 | 介護予防・日常生活支援総合事業 |

- 利用者負担：原則**1割**（一定以上所得者2割、特に高い所得者3割）
- **高額介護サービス費**、高額医療合算介護サービス費、特定入所者介護サービス費（補足給付）

### 地域支援事業（115条の45）★頻出

| 事業 | 内容 |
|---|---|
| ① **介護予防・日常生活支援総合事業** | 介護予防・生活支援サービス事業、一般介護予防事業 |
| ② **包括的支援事業** | 地域包括支援センターの運営（総合相談支援、権利擁護、包括的・継続的ケアマネジメント支援、第1号介護予防支援事業）、在宅医療・介護連携推進事業、生活支援体制整備事業、認知症総合支援事業、地域ケア会議推進事業 |
| ③ **任意事業** | 介護給付等費用適正化事業、家族介護支援事業 等 |

> ⚠️令和8年度改正で包括的支援事業に**被保険者情報の共有・活用促進事業**が追加（要確認）。

### 財源構成
公費**50％**（国25％・都道府県12.5％・市町村12.5％）＋保険料50％

### 不服申立て
**介護保険審査会**（都道府県に設置・**一審制**）

## 4. 年金関連（社一で問われるもの）

### 確定拠出年金法

| 項目 | 内容 |
|---|---|
| 企業型年金 | 事業主が実施。加入者は厚生年金被保険者で**70歳未満** |
| 個人型年金（iDeCo） | 国民年金基金連合会が実施。**65歳未満**（国民年金被保険者であること） |
| 給付 | 老齢給付金（原則**60歳**から。通算加入者等期間が10年未満なら段階的に繰下げ）、障害給付金、死亡一時金、脱退一時金 |
| 運用 | 加入者自身が指図。**運用リスクは加入者が負う** |

**拠出限度額（月額）** ⚠️要確認

| 区分 | 限度額 |
|---|---|
| 企業型DC（他制度なし） | 55,000円 |
| 企業型DC（DB等あり） | 27,500円 |
| iDeCo（第1号被保険者） | 68,000円（国民年金基金・付加保険料と合算） |
| iDeCo（第3号被保険者） | 23,000円 |

### 確定給付企業年金法
事業主が給付を約束。**規約型**（信託会社等と契約）と**基金型**（企業年金基金を設立）。**給付減額には厳格な要件**。

### 国民年金基金
第1号被保険者の上乗せ年金。**地域型**（都道府県単位 → 令和元年に全国国民年金基金へ統合）と**職能型**。
加入は**任意だが、加入したら任意脱退できない**。付加保険料を納付する者は加入できない。

## 7. 社会保障統計 — 順位と傾向だけ

| 統計 | 押さえどころ |
|---|---|
| **国民医療費** | 財源：**保険料 ＞ 公費 ＞ 患者負担**。診療種類別は**医科診療医療費が最大**。年齢階級別は**65歳以上が6割超**。対GDP比は上昇傾向 |
| **社会保障給付費** | 部門別：**年金 ＞ 医療 ＞ 福祉その他**（福祉その他が医療に接近）。機能別：**高齢 ＞ 保健医療 ＞ 家族** |
| 介護保険事業状況報告 | 要介護（要支援）認定者数は増加。**要介護1・2が多い**。第1号被保険者数も増加 |
| 医療施設調査 | 一般診療所数 ＞ 歯科診療所数 ＞ 病院数。病院数は**減少傾向** |
| 人口動態統計 | 出生数の減少、合計特殊出生率の低下、死亡数の増加（自然減） |

> 「何が一番大きいか」「増えているか減っているか」を問われることが多い。実数の暗記は不要。

### 保険料の徴収方法（特別徴収と普通徴収）

介護保険・後期高齢者医療は、**年金からの天引き（特別徴収）**が原則です。

| 区分 | 要件 |
|---|---|
| **特別徴収**（年金天引き） | **老齢等年金給付**の額が**年額18万円以上** |
| **普通徴収**（納付書・口座振替） | 年額18万円未満のとき／**保険料と介護保険料の合算額が年金額の2分の1を超える**とき |

- **老齢等年金給付**には、老齢（退職）年金だけでなく**遺族年金・障害年金も含まれます**
- 徴収するのは**市町村**（後期高齢者医療は市町村が徴収し、**広域連合に納付**する）
- 年金保険者が天引きして市町村に納入する仕組みです

> ★令和5年度の択一（一般常識 問10）で、この「老齢等年金給付」「2分の1」が問われました。
> **「年額18万円以上」と「2分の1を超えない」の2つ**がそろって特別徴収です。片方だけの記述は誤りです。
