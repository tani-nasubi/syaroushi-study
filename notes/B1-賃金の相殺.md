# 賃金の相殺｜労基の深掘り

### 前提となる原則

労基法24条1項の**全額払いの原則**は、使用者が労働者に対して持つ債権（貸付金・損害賠償など）と賃金を**一方的に相殺すること**を禁じています。

> 賃金全額払の原則の趣旨は、使用者が一方的に賃金を控除することを禁止し、労働者に賃金の全額を確実に受領させ、**労働者の経済生活を脅かすことのないようにしてその保護を図る**ことにある

### では労働者が同意したら？（日新製鋼事件）

**事案**は住宅ローンの清算でした。

1. 労働者が会社の提携ローンで住宅資金を借りた
2. 「退職するときは**退職金で残債務を一括返済する**」と約束していた
3. 退職時、会社が退職金から借入金分を差引いて金融機関に払った
4. その後この労働者が**破産**し、破産管財人が「全額払い違反で無効、退職金を返せ」と主張

**判旨**

> 労働者がその**自由な意思**に基づき当該相殺に同意した場合において、その同意が労働者の自由な意思に基づいてされたものであると認めるに足りる**合理的な理由が客観的に存在する**ときは、その同意を得てした相殺は24条1項に違反しない

### 「合理的な理由が客観的に存在」とは具体的に何か

最高裁が挙げた事実がそのまま判断材料になります。

| 認定された事実 |
|---|
| 相殺の合意が**労働者から自発的に**なされた |
| 会社による**強要にわたる事情がなかった** |
| 労働者が関係書類への署名押印に**異議なく応じていた** |
| 借入金は住宅取得という**労働者自身の利益**になるものだった |
| 退職時に退職金で一括返済する約束を**十分認識していた** |

**同意書にハンコがあるだけでは足りません。** その同意が本当に自発的だったと外から見て言えるかを、事情を総合して**厳格かつ慎重に**判断します。

### 同じ枠組みが3か所で使われる — 3つの判例

「労働者が**自分から不利益を受け入れた**ように見えるとき、それを本当に有効と認めてよいか」を扱う判例が3つあります。**場面は違うのに判断の言い回しが同じ**なので、まとめて覚えます。

#### ① シンガー・ソーイング・メシーン事件（最判昭48.1.19）— 賃金債権の**放棄**

| | |
|---|---|
| **事案** | 退職する労働者が、会社の営業秘密を漏らした等の疑いを持たれ、**退職金を請求しない旨の書面**に署名した。あとで「全額払いの原則に反して無効だ」と退職金を請求した |
| **判旨** | 放棄の意思表示が**労働者の自由な意思に基づくものであると認めるに足りる合理的な理由が客観的に存在する**ときは、24条1項に違反しない |
| **結論** | **有効**（在職中の行為について責任を感じており、再就職の紹介を受ける等の事情があった） |

> ★**放棄**の話です。相殺ではありません。

#### ② 日新製鋼事件（最判平2.11.26）— 賃金からの**相殺の合意**

上で見たものです。住宅ローンの残債を**退職金から差し引く**合意が争われました。

| | |
|---|---|
| **事案** | 会社の提携ローンで住宅資金を借り、「退職時は退職金で一括返済する」と約束していた。退職時に会社が退職金から差し引いて金融機関に払った |
| **判旨** | 労働者が**自由な意思**に基づき相殺に同意した場合において、その同意が自由な意思に基づくと認めるに足りる**合理的な理由が客観的に存在する**ときは、24条1項に違反しない |
| **結論** | **有効** |

#### ③ 山梨県民信用組合事件（最判平28.2.19）— **就業規則の不利益変更**への同意

| | |
|---|---|
| **事案** | 信用組合の合併に際し、**退職金の支給基準を大幅に引き下げる**変更に、労働者が同意書へ署名した。実際には支給額がほぼゼロになる内容だった |
| **判旨** | 同意の有無は、**変更により受ける不利益の内容・程度**、労働者が**同意するに至った経緯・態様**、労働者への**情報提供・説明の内容**等に照らして、**自由な意思に基づいてされたものと認めるに足りる合理的な理由が客観的に存在するか**という観点から判断すべき |
| **結論** | **同意は認められない**（不利益の内容を具体的に説明していなかった）として差戻し |

> ★3つのうち**山梨県民信用組合事件だけが「同意を認めなかった」**側です。署名があっても、**不利益の中身を説明していなければ同意とは言えない**という判断です。
> ★①②は**労基法24条**（賃金）、③は**労働契約法8条・9条**（就業規則の不利益変更）の話ですが、**判断の枠組みは同じ**です。

| 場面 | 判例 | 結論 |
|---|---|---|
| 賃金債権の**放棄** | シンガー・ソーイング・メシーン事件 | 有効 |
| 賃金の**相殺**への同意 | 日新製鋼事件 | 有効 |
| **就業規則の不利益変更**への同意 | 山梨県民信用組合事件 | **認められず** |

いずれも「**自由な意思に基づくと認めるに足りる合理的な理由が客観的に存在するか**」で判断します。

### 混同しやすい別枠：調整的相殺（過払賃金の清算）

**先月払いすぎた賃金を、今月の賃金から差し引く**場合です。ここには**労働者の同意が要りません**。判断の枠組みそのものが違います。

#### なぜ同意が要らないのか

**そもそも「相殺」として扱われないから**です。

24条1項が禁じているのは、賃金と**別口の債権**（貸付金・損害賠償など）をぶつけることです。過払いの清算は、

```
先月 20万円と計算して払った  → 本当は18万円だった
今月 18万円のところ 16万円払う → 2か月合わせれば 36万円で正しい額
```

というだけで、**賃金額そのものを正しく計算し直しているにすぎません**。別の債権を持ち出しているわけではないので、賃金の**清算調整**であって、労働者の同意を要する相殺には当たらない、という理屈です。

#### ただし無制限ではない（福島県教組事件・最判昭44.12.18）

> 過払のあつた時期と**合理的に接着した時期**においてされ、かつ、あらかじめ労働者にそのことが**予告**されるとか、その額が**多額にわたらない**とか、労働者の**経済生活の安定をおびやかすおそれのない**場合には、24条1項に違反しない

| 見るところ | 中身 |
|---|---|
| **時期** | 過払いから**間をおかず**に行うこと（何年も後はだめ） |
| **方法** | あらかじめ**予告**すること |
| **金額** | **多額でない**こと |

> ★**「自由な意思」の話と混ぜないでください。**調整的相殺は**同意を問題にせず、時期・方法・金額**で判断します。
> ★逆に、貸付金や損害賠償との相殺は、**同意があっても**「自由な意思に基づく合理的な理由」が要ります。

| | 同意 | 判断基準 |
|---|---|---|
| **調整的相殺**（過払いの清算） | **不要** | 時期・方法・金額 → 経済生活の安定を脅かさないか |
| **別口の債権との相殺** | **必要** | その同意が自由な意思に基づくと認めるに足りる合理的な理由が客観的に存在するか |

### 試験での問われ方

- 択一の誤り肢：「使用者は労働者の同意なく相殺できる」→ **誤り**
- 択一の誤り肢：「労働者の同意があれば**直ちに**有効」→ **誤り**（合理的な理由が客観的に必要）
- 択一の誤り肢：「**過払賃金の清算も労働者の同意が必要**」→ **誤り**（調整的相殺は同意不要）
- 択一の誤り肢：「過払賃金であれば**いつでも・いくらでも**控除できる」→ **誤り**（時期・方法・金額の制限がある）
- 選択式：「**自由な意思**」「**合理的な理由が客観的に存在**」が空欄
