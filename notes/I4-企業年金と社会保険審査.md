# 企業年金・船員保険・審査制度｜社一の深掘り

## 確定給付企業年金法

### 2つの形態（3条）

| 形態 | 内容 |
|---|---|
| **規約型** | 事業主が**労使合意**に基づく**規約**を定め、**厚生労働大臣の承認**を受け、**信託会社・生命保険会社等**と契約して外部で積み立てる |
| **基金型** | **企業年金基金**という**法人**を設立し（**厚生労働大臣の認可**）、基金が年金資産を管理・運用する |

> ★規約型は**承認**、基金型は**認可**。用語が違います。
> ★基金の設立には、**加入者となるべき被用者年金被保険者の2分の1以上の同意**（労働組合があればその同意）が必要です。

### 加入者（25条）

**実施事業所に使用される厚生年金保険の被保険者**が加入者となります。規約で**一定の資格**（職種、勤続期間、年齢、希望する者）を定めることができます。

### 給付（29条）

| 給付 | 支給要件 |
|---|---|
| **老齢給付金** | **60歳以上70歳以下**の規約で定める年齢に達したとき、または**50歳以上**で規約で定める年齢に達した日以後に退職したとき |
| **脱退一時金** | 加入者期間が**3年以上**の者が退職したとき（**3年を超える期間を要件とすることはできない**） |
| **障害給付金**（任意） | 規約で定めることができる |
| **遺族給付金**（任意） | 規約で定めることができる |

> ★老齢給付金・脱退一時金は**必ず定める**、障害給付金・遺族給付金は**任意**です。
> ★**脱退一時金の要件を3年を超える加入者期間とすることはできません**。頻出です。

### 掛金（55条）

**事業主が拠出**します。規約で定めるところにより、**加入者が掛金の一部を負担**することができます（**本人の同意**が必要）。加入者の負担は**掛金の2分の1**が上限です。

### リスク分担型企業年金

事業主が**リスク対応掛金**を拠出し、財政状況の変動を**事業主と加入者で分担**する仕組みです（平成29年〜）。

## 確定拠出年金法

### 2つの形態

| 形態 | 実施主体 | 加入対象 |
|---|---|---|
| **企業型年金** | **事業主**（労使合意による規約、**厚生労働大臣の承認**） | 厚生年金保険の被保険者（**70歳未満**） |
| **個人型年金**（iDeCo） | **国民年金基金連合会** | **国民年金の被保険者**（第1号・第2号・第3号）、**任意加入被保険者**（65歳未満） |

### 拠出限度額（令和8年時点の枠組み）

| 区分 | 限度額（月額） |
|---|---|
| 企業型（他制度なし） | **55,000円** |
| 企業型（確定給付企業年金等あり） | 55,000円 − 他制度掛金相当額 |
| 個人型・**第1号**被保険者 | **68,000円**（国民年金基金・付加保険料と**合算**） |
| 個人型・**第2号**（企業年金なし） | **23,000円** |
| 個人型・**第3号**被保険者 | **23,000円** |

> ★令和6年12月から、企業型・個人型の限度額の算定方法が**他制度掛金相当額を差し引く方式**に統一されました。最新の額は [`07-社会保険一般常識.md`](07-社会保険一般常識.md) を確認してください。

### 給付（28条）

| 給付 | 内容 |
|---|---|
| **老齢給付金** | **60歳**（通算加入者等期間10年以上）から。10年に満たない場合は期間に応じて**61〜65歳**に繰下げ。請求は**75歳**までに |
| **障害給付金** | **障害認定日**から**70歳**に達する日の前日までの間に請求 |
| **死亡一時金** | 遺族に支給。順位は配偶者→子・父母・孫・祖父母・兄弟姉妹（生計維持）→その他 |
| **脱退一時金** | 厳しい要件（**個人別管理資産が一定額以下**等）を満たす場合に限る |

> ★老齢給付金は**60歳前には受けられません**。「いつでも引き出せる」は誤りです。

### 運用（23条・25条）

運営管理機関は、**3以上**（簡易企業型年金は2以上）の**運用の方法**を選定し提示しなければなりません（うち1つ以上は**元本確保型**である必要は令和2年に撤廃）。

加入者は**少なくとも3か月に1回**、運用の方法を**変更できる**機会が与えられなければなりません。

**指定運用方法**：加入者が運用の指図を行わない場合にあらかじめ定めた方法で運用されます。

## 船員保険法

| | |
|---|---|
| **保険者** | **全国健康保険協会** |
| **被保険者** | **船員法1条に規定する船員**として船舶所有者に使用される者 |
| **給付** | **職務外**の事由による**疾病・負傷・出産・死亡**（＝健康保険相当）＋ **独自給付**（行方不明手当金、休業手当金の上乗せ等） |
| **職務上の災害** | **労災保険**（平成22年1月から労災保険に統合） |

**独自給付**の例。

| 給付 | 内容 |
|---|---|
| **行方不明手当金** | 被保険者が職務上**行方不明**となったとき、**被扶養者**に対し**1か月以上**行方不明である場合に、**最大3か月**を限度に支給 |
| **傷病手当金** | 支給期間は**3年**（健保は1年6か月）。**下船後3か月以内**の療養は職務外でも対象 |
| **葬祭料** | 標準報酬月額の**2か月分**（最低5万円） |

> ★行方不明手当金は**船員保険独自**の給付です。

## 社会保険審査官及び社会保険審査会法

### 2審制と1審制

| 対象 | 手続 |
|---|---|
| **健保・厚年・国年の給付、被保険者資格、標準報酬**に関する処分 | **社会保険審査官**（地方厚生局に置かれる）に審査請求 → **社会保険審査会**（厚生労働省に置かれる）に再審査請求（**2審制**） |
| **保険料その他の徴収金**に関する処分 | **社会保険審査会**に直接審査請求（**1審制**） |

> ★**給付は2審、保険料は1審**。この対比が最頻出です。

| | |
|---|---|
| 審査請求の期間 | 処分があったことを**知った日の翌日**から起算して**3か月以内** |
| みなし棄却 | 審査請求をした日から**2か月**以内に決定がないときは、**棄却したものとみなす**ことができる |
| 再審査請求の期間 | 決定書の謄本が送付された日の翌日から起算して**2か月以内** |
| 社会保険審査会の構成 | **委員長1人**および**委員5人**。両議院の同意を得て**厚生労働大臣**が任命。任期**3年** |
| 公開 | **審理は公開**（当事者の申立てがあったときは公開しないことができる） |

> ★健保・厚年・国年の**みなし棄却は2か月**、労災・雇用（労働保険審査官）は**3か月**。ここが横断で問われます。

### 基金の分割・解散と企業年金連合会（確定給付企業年金法77条・85条・91条の5）

**数字が引っかけ**になります。

| 条 | 中身 | 引っかけ |
|---|---|---|
| **77条** 基金の分割 | 分割には**厚生労働大臣の認可**が必要。分割は**実施事業所の一部について行うことはできない** | 「一部について行うことができる」は**誤り** |
| **85条** 基金の解散 | 代議員会において**代議員の定数の4分の3以上**の多数で議決したとき、又は**事業の継続が不可能**となったときに、**厚生労働大臣の認可**を受けて解散できる | 「**3分の2以上**」は**誤り** |
| **91条の5** 連合会の発起人 | 企業年金連合会を設立するには、会員となろうとする**20以上の事業主等**が発起人とならなければならない | 「**10以上**」は**誤り** |

> ★**4分の3**（解散の議決）と**20以上**（連合会の発起人）を押さえます。
> ★基金の**合併**（74条）も厚生労働大臣の認可が必要です。分割と違い、合併は**一部**という概念がありません。

### 実施事業所の増減（確定給付企業年金法78条）

事業主等が実施事業所を**増加させ、または減少させよう**とするときは、その増減に係る**厚生年金適用事業所の事業主の全部の同意**および**労働組合等の同意**を得なければなりません。

**基金**が実施事業所を減少させるときは、減少後も**加入者の数が政令で定める数以上**であるか、そうなることが見込まれなければなりません。

> ★**事業主の「全部」の同意**が必要です。過半数ではありません。

### 企業年金連合会の業務報告（確定給付企業年金法100条の2）

> 連合会は、**毎事業年度終了後6か月以内**に、省令で定めるところにより、**その業務についての報告書**を作成し、**厚生労働大臣に提出**しなければならない。

> ★**6か月以内**です。事業主等の決算に関する報告（100条）とは別建てです。

### 支払基金の高齢者医療制度関係業務（高齢者医療確保法141条ほか）

> **支払基金**は、高齢者医療制度関係業務に関し、**当該業務の開始前に、業務方法書を作成し、厚生労働大臣の認可**を受けなければならない。**変更するときも同様**。

- 社会保険診療報酬支払基金は、後期高齢者医療の**後期高齢者交付金の交付**と**後期高齢者支援金の徴収**を行います。
- 業務方法書に記載すべき事項は**厚生労働省令**で定めます。

> ★**認可**であって届出ではありません。**業務の開始前**に作成します。

### 確定拠出年金の関係者と規約

| 用語 | 内容 |
|---|---|
| **企業型年金規約** | 事業主が**労使合意**により作成し、**厚生労働大臣の承認**を受ける |
| **個人型年金規約** | **国民年金基金連合会**が作成し、**厚生労働大臣の承認**を受ける |
| **確定拠出年金運営管理機関** | **記録関連業務**（加入者の記録管理、給付の裁定）と**運用関連業務**（運用商品の選定・提示、情報提供）を行う。**厚生労働大臣および内閣総理大臣の登録**が必要 |
| **資産管理機関** | 企業型年金の資産を事業主の財産と**分別して管理**する（信託会社・生命保険会社等） |
| **企業型年金加入者掛金**（マッチング拠出） | 加入者本人が拠出する掛金。**事業主掛金の額を超えず**、かつ**事業主掛金との合計が拠出限度額以内** |
| **個人型年金加入者掛金** | iDeCoの加入者本人の掛金。**月額5,000円以上**、1,000円単位 |
| **個人型年金加入者期間** | 老齢給付金の受給開始年齢を決める**通算加入者等期間**の一部 |

> ★**マッチング拠出は事業主掛金を超えられません**。ここが最頻出です。
> ★運営管理機関の登録は**厚生労働大臣と内閣総理大臣の共同**です。片方だけとする肢は誤りです。

### 介護保険のそのほかの用語

| 用語 | 内容 |
|---|---|
| **要介護状態区分** | 要支援1・2／要介護1〜5 |
| **要介護更新認定** | 有効期間満了前に申請。**有効期間満了日の60日前**から申請できる |
| **基準費用額** | 施設サービスの**食費・居住費**について、平均的な費用として国が定める額。**補足給付**（特定入所者介護サービス費）の計算に使う |
| **利用者負担額** | 1割〜3割 |

### 私立学校教職員共済

**日本私立学校振興・共済事業団**が運営し、平成27年10月から**第4号厚生年金被保険者**となりました。**短期給付**（医療）は健康保険に相当する給付を行います。

### 社会保障審議会

厚生労働省に置かれ、**社会保障制度**に関する重要事項を調査審議します。年金部会・医療保険部会・介護保険部会などが置かれ、**保険料率や給付の見直し**はここで議論されます。

### 船員保険の保険料率

```
保険料額 ＝（標準報酬月額 ＋ 標準賞与額）×（疾病保険料率 ＋ 災害保健福祉保険料率）
```

| 保険料率 | 内容 | 負担 |
|---|---|---|
| **疾病保険料率** | 職務外の疾病等に係る給付（＝健康保険相当）に充てる | **労使折半**（船舶所有者と被保険者） |
| **災害保健福祉保険料率** | **独自給付**（行方不明手当金、休業手当金の上乗せ等）および保健福祉事業に充てる | **船舶所有者が全額負担** |

> ★**災害保健福祉保険料率の分は船舶所有者が全額負担**します。雇用保険の二事業分と同じ考え方です。
> ★船員保険の**標準報酬月額**は健康保険と同じ**50等級**です。
