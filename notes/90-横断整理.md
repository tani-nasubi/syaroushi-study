# 横断整理｜2026年度（第58回）社労士試験

科目をまたいで「数字と主体が入れ替わる」ところだけを集めた表。
本試験の引っかけはほぼここから作られる。**8/13と8/20に通しで読む**こと。

> ⚠️ 年度依存の金額は `91-数値暗記.md` に分離してある。この資料は年度が変わっても使える構造だけを載せている。

---

## 1. 時効

| 科目 | 保険給付・給付を受ける権利 | 保険料・徴収金 |
|---|---|---|
| **労災** | 障害・遺族＝**5年**／療養・休業・葬祭料・介護・二次健診＝**2年** | （徴収法により2年） |
| **雇用** | **2年**（不正受給の返還・納付命令も2年） | （徴収法により2年） |
| **徴収** | — | **2年** |
| **健保** | **2年** | **2年** |
| **国年** | **5年** | **2年** |
| **厚年** | **5年** | **2年** |

**覚え方**：年金給付（国年・厚年）と労災の障害・遺族だけが5年。あとは全部2年。

- 時効の起算日は「これを行使することができる時」。
- 年金給付は**支分権**（各支払期月の年金を受ける権利）が5年。基本権（受給権そのもの）は時効消滅しない扱い。
- 保険料の**督促**は時効の更新（中断）事由。

## 2. 不服申立て

| 科目 | 第一審 | 第二審 | 備考 |
|---|---|---|---|
| **労災・雇用** | 労働者災害補償保険審査官／雇用保険審査官 | **労働保険審査会** | 都道府県労働局に審査官 |
| **健保・厚年・国年** | 社会保険審査官 | **社会保険審査会** | 地方厚生局に審査官 |
| **介護保険** | **介護保険審査会**（都道府県） | — | **一審制** |
| **国保・後期高齢者医療** | **国民健康保険審査会**（都道府県） | — | **一審制** |
| **徴収法（保険料）** | 行政不服審査法による審査請求 | — | 労働保険審査会ではない |

### 期限と前置
- 審査請求：処分があったことを知った日の翌日から **3か月以内**
- 再審査請求：決定書の謄本が送付された日の翌日から **2か月以内**
- 審査請求から **3か月**を経過しても決定がないときは、棄却されたものとみなして再審査請求できる
- **処分取消しの訴え**は、審査請求の**決定を経た後**でなければ提起できない（審査請求前置）
- ★例外：**被保険者資格・標準報酬・保険料に関する処分**は、審査請求の決定後に**再審査請求を経ずに訴訟提起できる**（健保・厚年・国年）

## 5の3. 過料（科料・罰金ではない）

**過料**は行政上の秩序罰で、**前科になりません**。条例で定めるものと法律で定めるものがあります。

| 法令 | 対象 | 額 |
|---|---|---|
| **健保218条** | **健康保険組合の設立を命ぜられた事業主**が、正当な理由がなく指定期日までに設立の認可を申請しなかったとき | 遅延した期間、その負担すべき**保険料額の2倍**に相当する金額以下 |
| **介護保険214条1項** | 市町村が**条例**で、第1号被保険者が**届出をしない・虚偽の届出**をしたときに定められる | **10万円以下** |
| **介護保険214条**（別項） | 市町村が**条例**で、**保険料の徴収を免れた者**に定められる | 徴収を免れた金額の**5倍**に相当する金額以下 |
| **国年113条の4** | **日本年金機構の役員**が、認可を受けるべき場合に受けなかったとき等 | **20万円以下** |
| **国年113条の2ほか** | 被保険者・受給権者等が届出をせず、又は虚偽の届出をしたとき | **10万円以下** |
| **社労士法** | 社会保険労務士法人が届出等を怠ったとき | **100万円以下**（25条の23の2ほか） |

> ★**過料**（行政上の秩序罰）と**科料**（刑罰・1,000円以上1万円未満）は**別物**です。読みも「あやまちりょう／とがりょう」と区別されます。
> ★介護保険は**市町村が条例で定めることができる**という形です。法律が直接科すのではありません。

## 19. 直前チェック：間違えやすい対比10選

## 20. 選択式で数値を絞るための「取りうる値の範囲」

初見の数値空欄は、**制度上ありえない値を切る**ことでしか絞れません。
「この論点で出る数字はこれしかない」という範囲を持っておくと、20択が数択になります。

### 時効 — **2年 か 5年 の二択しかない**

| 5年 | 2年 |
|---|---|
| 労災の**障害・遺族**／国年・厚年の**年金給付**／労基法の**賃金請求権**（当分の間3年） | 労災のその他／雇用／徴収／健保の給付・保険料／国年・厚年の**保険料** |

> 「10年」「3年」「7年」が語群にあれば**まず切れます**（労基の賃金請求権の経過措置を除く）。

### 割合 — 出る分数は6つだけ

| 分数 | 主な用例 |
|---|---|
| **2分の1** | 在職老齢年金の停止、全額免除の反映、年金分割の上限、健保組合設立の同意 |
| **3分の2** | 傷病手当金・出産手当金、障害基礎年金の納付要件 |
| **4分の3** | 遺族厚生年金、中高齢寡婦加算、寡婦年金、労働協約の一般的拘束力、任意適用の脱退 |
| **100分の60** | 休業手当、労災の休業補償、平均賃金の最低保障 |
| **100分の125** | 障害年金1級 |
| **8分の5／8分の6／8分の7** | 一部免除の反映割合 |

### 日数・期間 — 頻出値

| 値 | 用例 |
|---|---|
| **3日** | 労災の待期、健保の待期 |
| **5日** | 健保・厚年の資格取得届／喪失届、年休の時季指定義務 |
| **7日** | 雇用の待期 |
| **10日** | 徴収法の各種届出、雇用の資格喪失届、督促状の指定期限 |
| **14日** | 試用期間の解雇予告、国年の種別変更届、特に危険な仕事の計画届 |
| **20日** | 任意継続の申出、有期事業の概算保険料 |
| **30日** | 解雇予告、安衛の計画届、受給期間延長の要件 |
| **40日／50日** | 年度更新／年度中途の成立・消滅 |
| **1か月** | 日雇の解雇予告適用、給付制限（自己都合） |
| **3か月** | 平均賃金の算定期間、健診後の医師意見聴取、審査請求の期限、給付制限（重責解雇） |
| **6か月** | 年休の継続勤務、継続給付の要件（1年）と対で覚える |

### 人数 — 安衛と健保に集中

| 値 | 用例 |
|---|---|
| **10人** | 就業規則、安全衛生推進者、特例事業 |

**13／15／18／20／40／45／50／55／60／64／65／70／75歳** のいずれか。
これ以外の年齢（例：「35歳」「48歳」）が語群にあれば、ほぼダミーです。
