# 業務災害の認定｜労災の深掘り

### 二つの物差し

業務災害と認められるには、**業務遂行性**と**業務起因性**の両方が要ります。順番は遂行性が先です。

| | 意味 |
|---|---|
| **業務遂行性** | 労働者が労働契約に基づき**事業主の支配下にある**状態で起きたこと |
| **業務起因性** | その業務に**内在する危険が現実化**したものといえること |

遂行性が無ければ起因性を検討するまでもなく否定されます。逆に、遂行性があっても起因性が無ければ（私的な喧嘩、天災の単なる巻き添えなど）業務災害になりません。

### 業務遂行性の3類型

| 類型 | 例 | 起因性の判断 |
|---|---|---|
| ① 支配下かつ管理下で**業務に従事中** | 作業中の負傷 | 原則として認められる |
| ② 支配下かつ管理下だが**業務に従事していない** | 休憩中、就業前後 | 原則として否定。**施設の欠陥**によるものなら認められる |
| ③ 支配下だが**管理下を離れている** | 出張中、社用外出中 | 出張の**全過程**が対象。積極的な私的行為の間を除き認められる |

> ★③の出張は「宿泊先で就寝中」も含みます。「事業場を離れているから業務災害ではない」は誤りです。

### よく問われる個別事例

| 事例 | 結論 |
|---|---|
| 休憩時間中の**私的行為**による負傷 | 業務災害ではない |
| 休憩時間中でも**事業場施設の欠陥**による負傷 | 業務災害 |
| **通勤途上**でも事業主の提供する専用交通機関の利用中 | **業務災害**（通勤災害ではない） |
| 会社主催の**運動会・宴会**への参加 | 参加が**強制**されていれば業務災害 |
| **天災地変**による被災 | 事業場の立地・作業条件で危険が加重されていれば業務災害 |
| 他人の**故意**による加害（私的怨恨） | 業務災害ではない |
| **療養の一環としての機能回復訓練中**の負傷（医師の指示に基づく） | **業務災害**（例：脊髄損傷で入院加療中、手動式自転車の乗車訓練中に第三者にはねられた） |
| **療養がほぼ終わった後**、私的行為で再度負傷 | 業務災害では**ない**（例：骨折のゆ合がほぼ完全でマッサージのみの者が、友人のバイクに乗って転倒し再骨折） |
| **労働争議中**（ストライキ・ロックアウト中）の行為 | 争議行為そのものは業務ではないため、原則として業務災害では**ない**。ただし**使用者の支配下**にある状態での事故は個別に判断 |
| **出張中**（用務地への移動・宿泊を含む） | 原則として**全過程**が業務遂行性を有する。**積極的な私的行為**の間を除く |

### 業務上の疾病

労基法75条2項・**労基則別表第1の2**に列挙されています。列挙されたものに当たれば原則として業務起因性が推定されます。

| 号 | 内容 |
|---|---|
| 1号 | 業務上の負傷に起因する疾病 |
| 2号 | **物理的因子**による疾病（紫外線・赤外線・電離放射線・騒音・高温低温など） |
| 3号 | **身体に過度の負担のかかる作業態様**に起因する疾病（腰痛、頸肩腕障害など） |
| 4号 | **化学物質等**による疾病 |
| 5号 | **粉じん**を飛散する場所における業務による**じん肺症**等 |
| 6号 | **細菌・ウイルス等の病原体**による疾病 |
| 7号 | **がん原性物質**・がん原性因子・がん原性工程における業務による疾病 |
| 8号 | **長期間にわたる長時間の業務**その他血管病変等を著しく増悪させる業務による**脳・心臓疾患** |
| 9号 | 人の生命にかかわる事故への遭遇その他**心理的に過度の負担**を与える事象を伴う業務による**精神及び行動の障害** |
| 10号 | 前各号のほか、**厚生労働大臣の指定する疾病** |
| 11号 | その他**業務に起因することの明らかな**疾病 |

> ★10号と11号を入れ替える肢が出ます。**大臣指定が10号、包括規定が11号**の順です。

### 上肢障害（上肢作業に基づく疾病）の認定

キーパンチャー、電話交換手など**上肢を過度に使用する業務**による疾病の認定です。

> 業務以外の**個体要因**（年齢、素因、体力等）や**日常生活要因**（家事労働、育児、スポーツ等）をも検討した上で、**上肢作業者が、業務により上肢を過度に使用した結果発症したと考えられる場合**に、業務に起因することが明らかな疾病として取り扱う。

- 労基則別表第1の2の**第3号4**（上肢に負担のかかる作業による運動器障害）に当たります。
- **業務以外の要因を検討したうえで**判断する、という組立てがそのまま出題されます。

> ★脳・心臓疾患や精神障害の認定と同じく、**業務以外の要因（個体要因・日常生活要因）との比較**をする構造です。

### 脳・心臓疾患（いわゆる過労死）の認定

| 区分 | 目安 |
|---|---|
| 異常な出来事 | 発症**直前から前日**まで |
| 短期間の過重業務 | 発症前**おおむね1週間** |
| **長期間**の過重業務 | 発症前**おおむね6か月**。発症前1か月に**おおむね100時間**、または2〜6か月平均で**月おおむね80時間**を超える時間外労働 |

> ★数字を入れ替える誤り肢が定番です。**1か月100時間／2〜6か月平均80時間**の組合せで覚えます。

#### 労働時間以外の負荷要因（令和3年9月改正）

改正前は時間数がほぼすべてでしたが、**時間だけでは足りないとき**に併せて見る要因が明記されました。**時間数がやや足りなくても、これらが重なれば業務起因性が認められます**。

| 負荷要因 | 具体的に見るもの |
|---|---|
| **拘束時間の長い勤務** | 拘束時間数、**実労働時間数**、**労働密度**（実作業時間と手待時間の割合）、業務内容、**休憩・仮眠時間数**、休憩・仮眠施設の状況 |
| **休日のない連続勤務** | 連続労働日数、休日の間隔 |
| **勤務間インターバルが短い勤務** | おおむね**11時間未満**の勤務間インターバルが多いか |
| **不規則な勤務・交替制勤務・深夜勤務** | 予定の変更の頻度・程度、**深夜時間帯**の勤務 |
| **出張の多い業務** | 出張の頻度、移動時間、時差 |
| **心理的負荷を伴う業務** | 精神障害の認定基準の別表に準じて評価 |
| **身体的負荷を伴う業務** | 重量物の運搬など |
| **作業環境** | **温度環境**（寒冷・暑熱）、**騒音** |

> ★**作業環境（温度・騒音）は「短期間の過重業務」「異常な出来事」では重視しますが、「長期間の過重業務」では付加的にみる**とされています。
> ★「拘束時間の長い勤務」の中身に**労働密度・仮眠施設の状況**まで含まれる点がそのまま出題されました（令和元年）。

### 精神障害の認定

次の3つをすべて満たすことが必要です。

1. 認定基準の対象となる精神障害を発病していること
2. 発病前**おおむね6か月**の間に業務による**強い心理的負荷**が認められること
3. 業務以外の心理的負荷・個体側要因により発病したとは認められないこと

**自殺**については、業務による精神障害を発病した者が自殺を図った場合、**故意（12条の2の2）には当たらない**ものとして扱われます。

### 複数業務要因災害

令和2年9月施行。2以上の事業に使用される**複数事業労働者**について、**一の事業のみでは業務と疾病等との因果関係が認められない**場合に、**すべての就業先の負荷を総合的に評価**して判断します（7条1項2号）。

給付基礎日額も**すべての就業先の賃金額を合算**して算定します。

> ★「一の事業で業務災害と認められる場合」は通常の業務災害として扱い、複数業務要因災害にはなりません。

### 複数業務要因災害の認定の進め方

| 手順 | 内容 |
|---|---|
| ① | まず**それぞれの事業場ごと**に業務災害として認定できるかを判断する |
| ② | いずれの事業場でも認定できない場合に、**すべての就業先の業務上の負荷を総合的に評価**する |

**負荷要因**（労働時間、勤務形態、作業環境、心理的負荷など）を合算し、**過重負荷**があったといえるかを見ます。

| 用語 | 意味 |
|---|---|
| **災害発生事業場** | 労働者が被災した事業場 |
| **非災害発生事業場** | それ以外の就業先。ここの負荷も**全体評価**に含める |

> ★**給付基礎日額もすべての就業先の賃金を合算**して算定します。
> ★複数業務要因災害の対象となるのは、**脳・心臓疾患**と**精神障害**が中心です（負荷の合算がなじむもの）。
