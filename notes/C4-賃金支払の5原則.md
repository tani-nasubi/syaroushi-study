# 賃金支払の5原則｜労基の深掘り

### 5原則（24条）

| 原則 | 例外 |
|---|---|
| **通貨**払 | 法令・労働協約に別段の定め／**労働者の同意**による銀行振込・証券総合口座・**資金移動業者の口座**（令和5年4月から） |
| **直接**払 | 例外なし（**使者**への支払は可、代理人は不可）／差押えは民事執行法による |
| **全額**払 | 法令に定めがある場合（所得税・社会保険料）／**労使協定**がある場合 |
| **毎月1回以上**払 | 臨時の賃金・賞与・1か月を超える期間の精勤手当等 |
| **一定期日**払 | 同上 |

> **直接払だけ「労使協定による例外がない」**のが特徴です。
> 未成年者の賃金を親権者が受け取ることもできません（59条）。

### 非常時払（25条）

労働者が**出産・疾病・災害**その他厚生労働省令で定める非常の場合の費用に充てるため請求したときは、**支払期日前**であっても、**既往の労働に対する賃金**を支払わなければなりません。

- 「既往の労働に対する」＝**まだ働いていない分は対象外**
- 省令で定める場合：本人又は収入によって生計を維持する者の**結婚・死亡**、やむを得ない事由による**1週間以上の帰郷**

### 休業手当（26条）

**使用者の責めに帰すべき事由**による休業のとき、**平均賃金の100分の60以上**を支払います。

| 論点 | 内容 |
|---|---|
| 範囲 | 民法536条2項の「債権者の責めに帰すべき事由」より**広い**。経営障害（資材不足・監督官庁の勧告等）も含む |
| 天災事変 | **不可抗力**は含まない（休業手当は不要） |
| 一部休業 | 1日の一部を休業した場合も、その日の賃金が平均賃金の6割に満たなければ差額を支払う |
| 民法との関係 | 民法536条2項に当たるなら**賃金全額**を請求できる。26条は最低保障 |

### 出来高払制の保障給（27条）

出来高払その他の請負制で使用する労働者には、**労働時間に応じ一定額の賃金の保障**をしなければなりません。金額の定めはありませんが、行政解釈では**平均賃金の6割程度**が望ましいとされています。

### 通貨払の例外｜賃金のデジタル払い（施行規則7条の2）

**令和5年4月1日**から、**厚生労働大臣の指定を受けた資金移動業者**の口座（**第二種資金移動業に係る口座**）への資金移動による支払が認められました。

使用者が取れる方法は3つです。

| 号 | 方法 |
|---|---|
| 1号 | 労働者が指定する**銀行その他の金融機関**への**預金・貯金の振込み** |
| 2号 | 労働者が指定する**金融商品取引業者**への**預り金**（証券総合口座）への払込み |
| 3号 | **厚生労働大臣の指定を受けた資金移動業者**の口座への**資金移動**（＝デジタル払い） |

**3号（デジタル払い）だけに上乗せの要件**があります。

1. 労働者が**1号または2号の方法を選択できる**ようにすること
2. 3号イ〜ヘの**要件について説明**したうえで、**当該労働者の同意**を得ること

指定資金移動業者の主な要件（3号イ〜ヘ）。

| | 内容 |
|---|---|
| **イ** | 口座残高（労働者に対して負担する**為替取引に関する債務の額**）が**100万円を超えない**ようにする措置、または**超えた場合に速やかに100万円以下とする**措置を講じていること |
| **ロ** | **破産手続開始の申立て**等により債務の履行が困難となったときに、**労働者に対し負担する債務の全額を速やかに弁済**できる仕組みを有していること |
| **ハ** | 労働者の**故意・過失によらず**債務の額が減少したときに、**その損失を補償**する仕組みを有していること |
| **ニ** | **最後に口座残高が変動した日から少なくとも10年間**は、**払出しができる**こと |
| **ホ** | **1円単位**で、**手数料等を負担することなく（少なくとも毎月1回）**、口座への資金移動に係る額の**払出し**ができること |
| **ヘ** | 賃金の支払に関する業務を**適正かつ確実に行うことができる**技術的能力・社会的信用を有すること |

> ★上限は**100万円**です。「500万円」「50万円」に書き換える肢が出ます。
> ★**労働者の同意が必要**であり、**強制はできません**。1号・2号を選べるようにすることも要件です。
> ★**現金による直接払**が原則であることは変わりません。デジタル払いは**通貨払の原則の例外**です。
