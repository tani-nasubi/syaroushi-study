# 安全衛生管理体制｜安衛の深掘り

安衛法の最頻出分野です。**業種と規模**の組合せで、選任すべき者が決まります。

### 総括安全衛生管理者（10条）

事業場を**統括管理する者**をもって充てます。

| 業種 | 規模 |
|---|---|
| **林業、鉱業、建設業、運送業、清掃業** | **常時100人以上** |
| **製造業**（物の加工業を含む）、電気業、ガス業、熱供給業、水道業、通信業、各種商品卸売業・小売業、家具等卸売業・小売業、燃料小売業、旅館業、ゴルフ場業、自動車整備業、機械修理業 | **常時300人以上** |
| **その他の業種** | **常時1,000人以上** |

> ★**100／300／1,000**。この3段階が基本の型です。
> ★資格要件はなく「**当該事業場においてその事業の実施を統括管理する者**」です。安全衛生の知識は要りません。
> ★都道府県労働局長は、**労働災害を防止するため必要があると認めるとき**は、総括安全衛生管理者の**業務の執行について事業者に勧告**することができます。

### 安全管理者（11条）

| 業種 | 規模 |
|---|---|
| **林業、鉱業、建設業、運送業、清掃業、製造業**、電気業、ガス業、熱供給業、水道業、通信業、各種商品卸売業・小売業、家具等卸売業・小売業、燃料小売業、旅館業、ゴルフ場業、自動車整備業、機械修理業 | **常時50人以上** |

> ★**その他の業種（金融業・保険業、医療業、教育業、飲食店など）には安全管理者は不要**です。衛生管理者はすべての業種で必要です。
> ★一定の業種・規模（建設業・有機化学工業製品製造業等で常時300人以上など）では、**少なくとも1人を専任**の安全管理者としなければなりません。

### 衛生管理者（12条）

**業種を問わず**、常時**50人以上**の労働者を使用する事業場で選任します。

| 事業場の規模 | 選任数 |
|---|---|
| 50人以上200人以下 | **1人** |
| 200人超500人以下 | **2人** |
| 500人超1,000人以下 | **3人** |
| 1,000人超2,000人以下 | **4人** |
| 2,000人超3,000人以下 | **5人** |
| 3,000人超 | **6人** |

**専任**の衛生管理者が必要な場合。

1. 常時**1,000人**を超える労働者を使用する事業場
2. 常時**500人**を超える労働者を使用する事業場で、**坑内労働**または一定の**健康上有害な業務**に常時**30人以上**従事させるもの

**衛生工学衛生管理者**：常時**500人**を超え、一定の**有害業務**に常時**30人以上**従事させる事業場では、**1人を衛生工学衛生管理者免許**を受けた者から選任します。

> ★衛生管理者は原則として**その事業場に専属**の者から選びます。ただし**2人以上**選任する場合で、そのうち1人が**労働衛生コンサルタント**であるときは、その者は専属でなくてもかまいません。

### 産業医（13条）

**業種を問わず**、常時**50人以上**で選任します。

| 規模 | 選任 |
|---|---|
| 50人以上 | **1人以上** |
| 常時**1,000人以上**、または一定の有害業務に常時**500人以上** | **専属**の産業医 |
| 常時**3,000人**を超える | **2人以上** |

> ★事業者は、産業医に対し**労働者の労働時間に関する情報**その他必要な情報を提供しなければなりません（13条4項）。
> ★産業医は、労働者の健康を確保するため必要があると認めるときは、**事業者に対し勧告**できます。事業者は勧告を**尊重**しなければならず、**衛生委員会に報告**する義務があります。
> ★産業医を選任した事業者は、その業務の内容等を**労働者に周知**させなければなりません。

### 安全衛生推進者・衛生推進者（12条の2）

常時**10人以上50人未満**の労働者を使用する事業場で選任します。

| 業種 | 選任するもの |
|---|---|
| 安全管理者を選任すべき業種 | **安全衛生推進者** |
| その他の業種 | **衛生推進者** |

選任すべき事由が発生した日から**14日以内**に選任し、**氏名を作業場の見やすい箇所に掲示する等**により関係労働者に周知します（**選任報告は不要**）。

> ★総括安全衛生管理者・安全管理者・衛生管理者・産業医は、選任すべき事由発生から**14日以内**に選任し、遅滞なく**所轄労働基準監督署長に報告**します。推進者は**報告不要**です。

### 委員会（17条〜19条）

| 委員会 | 設置すべき事業場 |
|---|---|
| **安全委員会** | 林業・鉱業・建設業・製造業の一部等で**50人以上**、その他一定業種で**100人以上** |
| **衛生委員会** | **業種を問わず50人以上** |
| **安全衛生委員会** | 両方を設けなければならないときは、**代えて**設置できる |

| 構成 | |
|---|---|
| 議長 | **総括安全衛生管理者**または事業の実施を統括管理する者（もしくはこれに準ずる者）**1人** |
| その他の委員 | **半数**については、**労働者の過半数で組織する労働組合**（ないときは労働者の過半数を代表する者）の**推薦に基づき**指名 |
| 開催 | **毎月1回以上** |
| 議事録 | **3年間**保存 |

> ★議長は**指名ではなく法定**です。議長を除く委員の**半数**が労働者側の推薦に基づきます。「委員の半数」ではなく「**議長以外の委員の半数**」です。

## 次に読むもの

### 法令等の周知（101条）

安全衛生管理体制を作ったら、**その中身を労働者に知らせる**ところまでが義務です。1項と2項で対象が違います。

| 項 | 周知するもの | 規模の要件 |
|---|---|---|
| **1項** | この法律**及びこれに基づく命令の要旨** | **なし**（すべての事業場） |
| **2項** | **産業医の業務の内容**その他産業医の業務に関する事項（省令で定めるもの） | **なし**（産業医を選任した事業場） |
| **3項** | 2項を、13条の2の者（**産業医を選任しない50人未満**の事業場で健康管理等を行わせる医師等）に準用 | **努力義務**に読み替え |
| **4項** | 57条の2で通知された事項（**SDSの通知事項**） | なし（その物を取り扱う作業場） |

方法はいずれも「**常時各作業場の見やすい場所に掲示し、又は備え付けること**その他の厚生労働省令で定める方法」です。

> ★**規模の要件は一つもありません。**「常時10人以上」「常時100人以上」と付いていたら誤りです。ここが令和3年に択一1問まるごと使われました。
> ★2項で周知するのは**産業医の業務の内容**です。**産業医への健康相談の申出の方法**も省令（安衛則98条の2）で周知事項に入っています。
> ★**安全管理者・衛生管理者の業務内容**の周知義務は**ありません**。101条にあるのは**産業医だけ**です。
> ★**労働災害の発生状況・原因**の周知義務も101条には**ありません**（労基署への報告義務は別にあります）。

| 出題 | 正誤 |
|---|---|
| 法令の要旨の周知は常時10人以上の事業場に課される | **誤**（規模を問わない） |
| 産業医の業務に関する事項の周知は常時100人以上の事業場に課される | **誤**（規模を問わない） |
| 安全管理者・衛生管理者の業務内容を周知させる義務がある | **誤**（産業医のみ） |
| 労働者が死亡・4日以上休業したときの発生状況を周知させる義務がある | **誤** |

> ★労基法106条（法令・就業規則・労使協定の周知）と**同じ構図**です。労基法は「法令は要旨、就業規則と労使協定は全文」、安衛法は「法令は要旨、産業医の業務内容」と覚えます。
