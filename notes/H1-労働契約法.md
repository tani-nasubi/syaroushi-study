# 労働契約法｜労一の深掘り

**9年で7回以上**出題される労一の最重要法令です。**罰則も行政監督もない民事的ルール**であることが出発点です。

### 基本原則（3条）

| 項 | 原則 |
|---|---|
| 1項 | **労使対等**の立場における**合意**に基づいて締結・変更すべき |
| 2項 | **就業の実態に応じて均衡**を考慮しつつ締結・変更すべき |
| 3項 | **仕事と生活の調和**にも配慮しつつ締結・変更すべき |
| 4項 | 労働者・使用者は、労働契約を遵守するとともに、**信義に従い誠実に権利を行使し義務を履行**しなければならない |
| 5項 | 労働者・使用者は、労働契約に基づく**権利の行使に当たっては、それを濫用することがあってはならない** |

> ★1〜3項は「**すべきものとする**」（努力を促す規定）、4〜5項は「**しなければならない／あってはならない**」。語尾の違いがそのまま問われます。

### 労働契約の成立（6条・7条）

| 条 | 内容 |
|---|---|
| **6条** | 労働契約は、労働者が使用者に**使用されて労働し**、使用者がこれに対して**賃金を支払う**ことについて、**労働者及び使用者が合意することによって成立**する |
| **7条** | 労働者及び使用者が労働契約を締結する場合において、使用者が**合理的な労働条件**が定められている**就業規則**を労働者に**周知**させていた場合には、労働契約の内容は、**その就業規則で定める労働条件による** |

7条ただし書：労働契約において、労働者及び使用者が**就業規則の内容と異なる労働条件を合意していた部分**については、**12条に該当する場合を除き**、その合意による。

> ★**書面は不要**です（6条）。労基法15条の労働条件明示義務とは別の話です。
> ★7条の効力は「**合理的**」かつ「**周知**」の両方が必要です。

#### 7条本文で契約内容にならないもの

就業規則に書いてあれば何でも労働契約の内容になるわけではありません。**「労働条件」を定めた部分**だけです。

| 契約内容にならない例 |
|---|
| 就業規則の**制定趣旨や根本精神を宣言した規定**（前文・理念など） |
| **労使協議の手続に関する規定** |
| **企業の組織や職制に関する規定**のうち、労働条件といえないもの |

> ★これらは**7条本文によっても労働契約の内容にはならない**とされています（通達）。
> ★逆に、**労働条件を定めた部分**は、①**合理的な労働条件**が定められ、②**労働者に周知**させていた、の2つを満たせば契約内容になります。

### 就業規則による労働条件の変更（8条〜10条）

| 条 | 内容 |
|---|---|
| **8条** | 労働者及び使用者は、その**合意**により、労働契約の内容である労働条件を変更することができる |
| **9条** | 使用者は、労働者と合意することなく、**就業規則を変更することにより**、労働者の**不利益に**労働契約の内容である労働条件を**変更することはできない**（10条の場合を除く） |
| **10条** | 使用者が就業規則の変更により労働条件を変更する場合において、変更後の就業規則を**周知**させ、かつ、就業規則の変更が**合理的**なものであるときは、労働契約の内容は、**変更後の就業規則に定めるところによる** |

**10条の「合理性」の判断要素**（条文に列挙されています）。

1. 労働者の受ける**不利益の程度**
2. 労働条件の**変更の必要性**
3. 変更後の就業規則の**内容の相当性**
4. **労働組合等との交渉の状況**
5. その他の就業規則の変更に係る事情

> ★この5要素は**選択式の空欄**になりやすいところです。順番も含めて覚えます。
> ★10条ただし書：**労働契約において、就業規則の変更によっては変更されない**こととした部分については、12条の場合を除き、変更されません。

### 就業規則の最低基準効（12条）

> 就業規則で定める基準に達しない労働条件を定める労働契約は、**その部分については、無効**とする。この場合において、無効となった部分は、就業規則で定める**基準による**。

> ★労基法93条と同じ構造です（労基法13条の「法律の基準」の就業規則版）。

### 出向・懲戒・解雇（14条〜16条）

| 条 | 内容 |
|---|---|
| **14条**（出向） | 使用者が労働者に出向を命ずることができる場合において、当該命令が、その必要性、対象労働者の選定に係る事情その他の事情に照らして、その**権利を濫用したものと認められる場合には、当該命令は無効** |
| **15条**（懲戒） | 使用者が労働者を懲戒することができる場合において、当該懲戒が、労働者の行為の性質及び態様その他の事情に照らして、**客観的に合理的な理由を欠き、社会通念上相当であると認められない場合は、その権利を濫用したものとして、当該懲戒は無効** |
| **16条**（解雇） | 解雇は、**客観的に合理的な理由を欠き、社会通念上相当であると認められない場合**は、その権利を濫用したものとして、**無効** |

> ★14条は「**権利を濫用したものと認められる場合**」、15条・16条は「**客観的に合理的な理由を欠き、社会通念上相当であると認められない場合**」。表現の違いが問われます。
> ★16条は**旧労基法18条の2**が移されたものです。

### 有期労働契約（17条〜20条）

| 条 | 内容 |
|---|---|
| **17条1項** | 使用者は、期間の定めのある労働契約について、**やむを得ない事由がある場合でなければ**、その契約期間が満了するまでの間において、労働者を解雇することができない |
| **17条2項** | 使用者は、有期労働契約について、その労働契約により労働者を使用する**目的に照らして、必要以上に短い期間を定めることにより、その労働契約を反復して更新することのないよう配慮**しなければならない |
| **18条** | **無期転換ルール**（下記） |
| **19条** | **雇止め法理**（下記） |

> ★17条1項の「やむを得ない事由」は、労基法の解雇（客観的合理性＋社会通念上の相当性）よりも**厳格**とされています。

### 無期転換ルール（18条）

同一の使用者との間で締結された**2以上の有期労働契約**の**通算契約期間が5年**を超える労働者が、**現に締結している有期労働契約の契約期間が満了する日までの間に**、無期労働契約の締結の**申込み**をしたときは、使用者は**その申込みを承諾したものとみなす**。

| ポイント | |
|---|---|
| 転換の時期 | **申込み時の有期契約が満了する日の翌日**から無期労働契約が成立 |
| 労働条件 | 別段の定めがない限り**従前と同一**（無期になるだけで、正社員になるわけではない） |
| **クーリング** | 契約がない期間が**6か月以上**（直前の通算期間が1年未満の場合はその2分の1以上）あると、それ以前の期間は通算されない |
| 特例 | **有期雇用特別措置法**により、高度専門的知識等を有する者（**上限10年**）と**定年後継続雇用**の高齢者は、無期転換申込権が発生しない |

> ★**5年を超える**（5年ちょうどでは足りません）。
> ★令和6年4月から、**無期転換申込権が発生する契約更新のタイミングごとに、その旨を書面で明示**することが労基法上の義務になりました。

### 雇止め法理（19条）

次のいずれかに該当し、労働者が**契約期間の満了までの間に更新の申込みをした場合**（または**満了後遅滞なく締結の申込みをした場合**）に、使用者が申込みを拒絶することが**客観的に合理的な理由を欠き、社会通念上相当であると認められない**ときは、使用者は**従前と同一の労働条件で申込みを承諾したものとみなす**。

| 号 | 類型 | 判例 |
|---|---|---|
| 1号 | 反復更新により、**実質的に無期労働契約と同視できる**もの | **東芝柳町工場事件** |
| 2号 | 契約期間の満了時に更新されるものと**期待することについて合理的な理由がある**もの | **日立メディコ事件** |

> ★**申込みは必要**です。黙っていれば自動的に更新されるわけではありません。
> ★平成24年改正で**判例法理が条文化**されたものです。

### 20条の削除

旧20条（期間の定めがあることによる**不合理な労働条件の禁止**）は、平成30年改正により**パートタイム・有期雇用労働法8条に移されました**（令和2年4月施行）。

> ★「労働契約法20条により不合理な相違が禁止される」は**現在では誤り**です。根拠条文はパート・有期法8条です。

### 就業規則の変更に係る手続（11条）

> 就業規則の変更の手続に関しては、**労働基準法第89条及び第90条**の定めるところによる。

労働契約法は民事的な効力（7条・10条・12条）を定めるだけで、**作成・届出・意見聴取の手続は労基法**に委ねられています。

> ★労働契約法には**罰則も行政監督もありません**。届出義務違反を問えるのは労基法だけです。

### 適用除外（21条・22条）

| 対象 | 扱い |
|---|---|
| **国家公務員・地方公務員** | 適用しない |
| **使用者が同居の親族のみを使用する場合**の労働者 | 適用しない |
| **船員** | 12条・18条〜20条などの一部規定を除き適用（船員法との調整あり） |

### 最低賃金法の目的と地域別最低賃金

> **1条（目的）** この法律は、**賃金の低廉な労働者**について、**賃金の最低額を保障**することにより、**労働条件の改善**を図り、もつて、**労働者の生活の安定、労働力の質的向上及び事業の公正な競争の確保**に資するとともに、**国民経済の健全な発展**に寄与することを目的とする。

> **9条（地域別最低賃金の原則）** 地域別最低賃金は、**あまねく全国各地域**について決定されなければならない。

| | |
|---|---|
| 決定の考慮要素（9条2項） | ① 労働者の**生計費** ② 労働者の**賃金** ③ 通常の事業の**賃金支払能力** |
| 生計費の考慮（9条3項） | **生活保護**に係る施策との**整合性**に配慮する |
| 決定する者 | **厚生労働大臣**または**都道府県労働局長**（最低賃金審議会の調査審議を求め、その意見を聴く） |
| 効力 | 最低賃金に達しない賃金を定める労働契約は**その部分が無効**。**最低賃金と同様の定めをしたもの**とみなす（4条2項） |
| 派遣労働者 | **派遣先**の事業場の所在地の最低賃金が適用される |

**適用除外ではなく「減額の特例」**（7条）

精神・身体の障害により著しく労働能力が低い者、試の使用期間中の者、認定職業訓練を受ける者、軽易な業務に従事する者、断続的労働に従事する者は、**都道府県労働局長の許可**を受けて**減額**できます。

> ★**令和6年度の選択式**で「**賃金の最低額を保障**」「**最低限度の生活**」の言い回しが問われています。
> ★**適用除外ではなく減額**です。「最低賃金が適用されない」は誤りです。
> ★**特定（産業別）最低賃金**は、地域別最低賃金を**上回る**額でなければなりません。
