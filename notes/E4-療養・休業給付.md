# 療養給付と休業給付｜労災の深掘り

### 療養補償給付（13条）

**療養の給付**（現物）が原則、**療養の費用の支給**（現金）が例外です。

> 政府が必要と認める場合に限り、療養の費用を支給することができる。

労災指定医療機関で受ける場合が現物給付、そうでない場合が費用の支給です。

範囲は次のとおりで、**政府が必要と認めるものに限られます**。

1. 診察
2. 薬剤または治療材料の支給
3. 処置、手術その他の治療
4. 居宅における療養上の管理およびその療養に伴う世話その他の看護
5. 病院・診療所への入院およびその療養に伴う世話その他の看護
6. 移送

**期間の制限はなく**、傷病が**治ゆ**するまで行われます。健康保険のような一部負担金もありません（通勤災害の200円を除く）。

> ★労災でいう「治ゆ」は、**症状が固定し、医療効果が期待できなくなった状態**を指します。完全に元どおりになることではありません。

### 休業補償給付（14条）

**次の3要件をすべて満たす日**について、**第4日目**から支給されます。

1. 業務上の負傷・疾病による**療養**のため
2. **労働することができない**ため
3. **賃金を受けない**

```
1日につき　給付基礎日額 × 60/100
（＋休業特別支給金 20/100 ＝ 合計 80/100）
```

### 待期3日間

| | 待期の扱い |
|---|---|
| **業務災害** | 事業主が労基法76条の**休業補償**を行う（平均賃金の60%） |
| **通勤災害** | 事業主の補償義務は**ない** |

待期3日間は**連続である必要はなく通算**されます。所定休日も含まれます。

> ★「3日間連続していなければならない」は誤りです。

### 一部労働した日（部分算定日）

所定労働時間の一部だけ労働した日、または賃金の支払われる休暇の日については、

```
（給付基礎日額 − その日に支払われる賃金額）× 60/100
```

> ★給付基礎日額そのものに60%を掛けるのではなく、**差額に**掛けます。

### 障害厚生年金・障害基礎年金との調整（14条2項）

同一の事由により障害厚生年金・障害基礎年金を受けられるときは、**政令で定める率を乗じて減額**します。

休業補償給付には、**傷病補償年金について定める率**を用います（14条2項）。

| 併給される年金 | 休業補償給付・傷病補償年金 | （参考）障害補償年金 |
|---|---|---|
| 障害厚生年金＋障害基礎年金 | **0.73** | **0.73** |
| 障害厚生年金のみ | **0.88** | **0.83** |
| 障害基礎年金のみ | **0.88** | **0.88** |

遺族補償年金は、遺族厚生年金＋遺族基礎年金で**0.80**、遺族厚生年金のみで**0.84**、遺族基礎年金のみで**0.88**です。

減額後の額が、**年金を加えても調整前の労災給付額を下回る**ことのないよう最低保障があります。

> ★減額されるのは**労災側**です。厚生年金・国民年金側は減額されません。
> ★**特別支給金は調整の対象外**です。

### 傷病補償年金（12条の8第3項）

療養開始後**1年6か月**を経過した日、またはその後において、

1. 傷病が**治っていない**こと
2. 障害の程度が**傷病等級**（第1級〜第3級）に該当すること

の**いずれにも該当**するとき、その状態が続く間支給されます。

| 特徴 | |
|---|---|
| 請求 | **不要**（政府の**職権**で決定する） |
| 休業補償給付との関係 | 傷病補償年金に**切り替わる**（併給されない） |
| 労基法19条の解雇制限 | 療養開始後**3年**を経過した日に打切補償を支払ったものと**みなされる**（労災法19条） |

> ★傷病補償年金は**請求に基づかない**唯一の保険給付です。「請求に基づいて行う」は誤りです。

### 傷病等級に変更があったとき（18条の2）

> 傷病補償年金を受ける労働者の障害の程度に変更があったため、**新たに別表第一中の他の傷病等級に該当するに至った**場合には、政府は、**新たに該当するに至った傷病等級に応ずる傷病補償年金を支給するものとし**、その後は、**従前の傷病補償年金は、支給しない**。

> ★「**支給するものとする**」＝**義務**です。「所轄労働基準監督署長は、**裁量により**…支給する決定ができる」は**誤り**。
> ★**請求は要りません**。傷病補償年金はもともと**職権**（署長の決定）で支給されるので、変更も職権です。
> ★障害補償年金の額の改定（15条の2）は請求によることもある点と対比されます。

### 介護補償給付（12条の8第4項）

**障害補償年金または傷病補償年金**を受ける権利を有する者のうち、**第1級のすべて**と**第2級の精神・神経／胸腹部臓器の障害**の者が対象です。

現に介護を受けている月から支給され、**常時介護**と**随時介護**で上限額が異なります。次の間は支給されません。

- **障害者支援施設**に入所している間（生活介護を受けている場合に限る）
- 障害者支援施設に準ずる施設として厚生労働大臣が定めるものに入所している間
- **病院・診療所に入院**している間

> ★月を単位として支給され、**支給開始月には最低保障額がない**（実際に支出した額）点が問われます。
