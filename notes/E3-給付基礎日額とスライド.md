# 給付基礎日額とスライド｜労災の深掘り

### 原則（8条）

給付基礎日額は、原則として**労基法12条の平均賃金に相当する額**です。

```
算定事由発生日以前3か月間の賃金総額 ÷ その期間の総日数（暦日数）
```

算定事由発生日は、**負傷・死亡の原因である事故が発生した日**、または**診断によって疾病の発生が確定した日**です。

> ★「療養を開始した日」ではありません。ここを入れ替える肢が出ます。

複数事業労働者については、**すべての就業先の賃金額を合算**して算定します。

### 特別加入者

特別加入者には賃金がないため、**給付基礎日額は申請に基づき厚生労働大臣が定める額**（3,500円〜25,000円の範囲で選択）になります。平均賃金は使いません。

### 3つの日額の使い分け

| | 使う場面 | スライドと限度額 |
|---|---|---|
| **休業給付基礎日額**（8条の2） | 休業補償給付等 | 四半期ごとのスライド／療養開始後**1年6か月**経過後は年齢階層別の最低・最高限度額 |
| **年金給付基礎日額**（8条の3） | 年金たる保険給付 | **年度**ごとのスライド／**当初から**年齢階層別の最低・最高限度額 |
| **一時金の給付基礎日額** | 障害一時金・遺族一時金など | 年金給付基礎日額に準ずる |

### 休業給付基礎日額のスライド（8条の2第1項2号）

**毎月勤労統計の平均給与額**が、算定事由発生日の属する四半期の平均給与額の**110%を超え、または90%を下る**に至った場合に改定します。

適用は、上昇・低下した四半期の**翌々四半期**に属する最初の日以後に支給すべき事由が生じた分からです。

> ★「翌四半期」ではなく**翌々四半期**。「100分の110／100分の90」の数字も頻出です。

### 年齢階層別の最低・最高限度額

| | 休業給付基礎日額 | 年金給付基礎日額 |
|---|---|---|
| 適用開始 | 療養開始日から**1年6か月**経過後 | **当初から** |
| 基準日 | 四半期の初日における年齢 | 8月1日における年齢 |

年齢階層は**5歳きざみ**で区分されます。最低限度額は、賃金月額の低い順に**20の階層**に区分したうちの最も低い階層の上限額を基礎に定めます（8条の2第3項）。

### 年金給付基礎日額のスライド（8条の3）

算定事由発生日の属する年度の**翌々年度の8月**以後に支給する分から、**毎月勤労統計の平均給与額の変動率**に応じて改定します。休業のような110%／90%の幅はなく、**変動があれば必ず改定**します。

### 特別支給金

保険給付とは別に、**社会復帰促進等事業**として支給されます（29条）。

| 種類 | 内容 |
|---|---|
| 休業特別支給金 | 休業4日目から**給付基礎日額の20%** |
| 障害特別支給金 | 障害等級に応じた**一時金**（1級342万円〜14級8万円） |
| 遺族特別支給金 | **300万円**（遺族の数にかかわらず一律） |
| 傷病特別支給金 | 傷病等級に応じ100万円〜114万円 |
| **ボーナス特別支給金**（障害特別年金など） | **算定基礎日額**（特別給与の総額÷365）を基礎とする |

> ★特別支給金は**保険給付ではない**ため、**支給制限・不服申立て・第三者行為求償の対象外**です。ここが最頻出の引っかけです。
> ★休業特別支給金と休業補償給付を合わせると給付基礎日額の**80%**になります。
