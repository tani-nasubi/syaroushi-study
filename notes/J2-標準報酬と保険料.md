# 標準報酬と保険料｜健保の深掘り

### 標準報酬月額（40条）

**第1級58,000円 〜 第50級1,390,000円**の**50等級**に区分されています。

> ★厚年は**第1級88,000円〜第32級650,000円の32等級**。健保との違いが最頻出です。

**等級の改定**：毎年3月31日における全被保険者の標準報酬月額を平均した額の**2倍**に相当する額が、最高等級の標準報酬月額を超える状態が継続すると認められるときは、その年の**9月1日**から、**政令**で等級を追加できます。

### 報酬（3条5項）と賞与（3条6項）

| | 定義 |
|---|---|
| **報酬** | 賃金、給料、俸給、手当、賞与その他いかなる名称であるかを問わず、**労働者が労働の対償として受けるすべてのもの**。ただし**臨時に受けるもの**および**3か月を超える期間ごとに受けるもの**を除く |
| **賞与** | 上記のうち**3か月を超える期間ごとに受けるもの** |

> ★区切りは「**3か月を超える期間ごと**」。年4回以上支給される賞与は**報酬**に含めます（＝標準報酬月額の対象）。年3回以下なら**賞与**です。
> ★**現物給与**（食事・住宅等）も報酬に含まれ、**厚生労働大臣が定める価額**（都道府県ごと）で換算します。

### 4つの決定・改定

| 種類 | 条 | 時期 | 内容 |
|---|---|---|---|
| **資格取得時決定** | 42条 | 資格取得時 | 月給制は**その月の報酬額**、日給・時給制は**同様の業務に従事し同様の報酬を受ける者の報酬の平均額**から算定 |
| **定時決定** | 41条 | **毎年7月1日**現在 | **4月・5月・6月**に受けた報酬の平均。**その年の9月から翌年8月**まで適用 |
| **随時改定** | 43条 | 随時 | 固定的賃金の変動等により、**継続した3か月間**の報酬の平均が**2等級以上**変動したとき。**4か月目**から改定 |
| **育児休業等終了時改定** | 43条の2 | 育休終了時 | 育休終了日の翌日が属する月以後**3か月間**の報酬の平均。**2等級以上の変動は不要**。4か月目から |
| **産前産後休業終了時改定** | 43条の3 | 産休終了時 | 同上 |

**定時決定の対象外**（41条1項但書）。

- **6月1日から7月1日**までに被保険者の資格を取得した者
- **7月・8月・9月**に随時改定・育休終了時改定・産休終了時改定が行われる（または行われるべき）者

**随時改定の3要件**（すべて必要）。

1. **固定的賃金**の変動または**賃金体系**の変更があったこと
2. 変動月以後の**継続した3か月間**の各月とも、支払基礎日数が**17日以上**であること
3. 3か月間の報酬の平均による標準報酬月額と現在のものとの間に**2等級以上**の差が生じたこと

> ★**残業手当の増減だけ**では随時改定は行われません（固定的賃金の変動が必要）。
> ★定時決定では、支払基礎日数**17日未満**の月を除いて平均します。**短時間労働者**は**11日以上**、パートタイム（4分の3基準を満たす者）は3か月とも17日未満なら**15日以上**の月で算定します。

### 標準賞与額（45条）

賞与額から**1,000円未満を切り捨てた額**。

| | 上限 |
|---|---|
| **健康保険** | **年度（4月1日〜翌年3月31日）の累計で573万円** |
| **厚生年金保険** | **1回につき150万円** |

> ★健保は**年度累計573万円**、厚年は**1回150万円**。ここは必ず問われます。

### 保険料（156条）

```
保険料額 ＝（標準報酬月額 ＋ 標準賞与額）×（一般保険料率 ＋ 介護保険料率）
```

| 保険料率 | 内容 |
|---|---|
| **一般保険料率** | **基本保険料率 ＋ 特定保険料率**。協会けんぽは**都道府県単位**で1000分の**30〜130**の範囲 |
| **特定保険料率** | 後期高齢者支援金・前期高齢者納付金等に充てる分 |
| **介護保険料率** | **介護保険第2号被保険者**（40歳以上65歳未満）である被保険者について |

**健康保険組合**は、規約で**事業主負担割合を2分の1を超えて**定めることができます（協会けんぽは**労使折半**が原則）。

> ★**任意継続被保険者は全額自己負担**です。

### 保険料の納付（161条・164条）

| | |
|---|---|
| 納付義務者 | **事業主**（被保険者負担分も含めて納付する） |
| 納期限 | **翌月末日** |
| 控除 | 事業主は、被保険者に**通貨をもって報酬を支払う際**に、前月分の保険料を控除できる（**前月分控除の原則**） |
| 賞与からの控除 | 賞与を支払う際は**その月**の標準賞与額に係る保険料を控除できる |

> ★**資格喪失月の保険料は徴収されません**（月末退職の場合、喪失日は翌月1日なので、その月の保険料は徴収されます）。
> ★**同月得喪**（同じ月に資格取得と喪失）の場合、健保では**1か月分の保険料を徴収**します（厚年は令和2年から徴収しない扱いに変更）。

### 一部納付があったときの按分（159条の2）

> 厚生労働大臣が保険料を徴収する場合において、適用事業所の事業主から**保険料・厚生年金保険料・子ども・子育て拠出金の一部の納付**があったときは、事業主が納付すべきこれらの**額を基準として按分した額**に相当する保険料の額が納付されたものとする。

- 3つはまとめて年金事務所が徴収するので、**足りないときにどれから充てるか**を決めた規定です。
- 「健康保険料から先に充当する」といった優先順位は**ありません**。**額に応じて按分**します。
- 厚生年金保険法にも**同じ規定**があります（厚年法86条の2）。

### 産前産後休業・育児休業中の免除（159条・159条の3）

| 休業 | 免除される期間 |
|---|---|
| **産前産後休業** | 開始月から終了日の翌日が属する月の**前月**まで |
| **育児休業等** | 同上。ただし**同一月内に14日以上**の育児休業を取得した場合はその月も免除。**賞与**に係る保険料は**1か月を超える**育児休業の場合に免除 |

> ★免除されるのは**事業主負担分も含めた全額**です。免除期間中も**被保険者資格は継続**し、**保険料を納めたものとして扱われます**。

### 任意継続被保険者の保険料（161条・165条）

| | |
|---|---|
| 負担 | **全額自己負担**（事業主負担はない） |
| 徴収する者 | 協会けんぽの任意継続被保険者の保険料は**協会が徴収**する（161条2項） |
| 納付 | その月の**10日まで**（初めて納付すべき保険料は保険者が指定する日まで） |
| 納付しないとき | **納付期日の翌日**に資格を喪失（正当な理由があるときを除く） |

**前納**（165条）

> 任意継続被保険者は、**将来の一定期間の保険料を前納することができる**。

| | |
|---|---|
| 前納できる期間 | **4月から9月まで**／**10月から翌年3月まで**／**年度をまたぐ場合は当該年度末まで**（則139条） |
| 割引 | 各月の保険料額から**政令で定める額を控除**した額（**年4分の複利現価法**による） |
| 前納した保険料 | 各月の**初日が到来したとき**に、その月の保険料が納付されたものとみなす |

> ★前納できるのは**任意継続被保険者**です。一般の被保険者に前納の制度はありません。
> ★資格喪失等で前納期間が残ったときは、**残りの分が還付**されます。
