# 選択式の解き方｜初見問題から4点をもぎ取る手順

| 項目 | 内容 |
|---|---|
| 配点 | 8問40点（1科目5点） |
| 時間 | 80分（1問あたり10分） |
| 合格基準 | 総得点22〜27点程度 **かつ 各科目3点以上**（科目により1点／2点に補正） |
| **狙う点** | **各科目4点**。3点ギリギリだと1問外した瞬間に基準点割れ |

> この資料は、過去9年分（第49〜57回）の選択式72問・360空欄を実際に集計して書いています。
> 精神論は書きません。**確率を上げる手順**だけです。

---

## 1. まず現実を数字で押さえる

### ① 過去問だけでは半分しかカバーできない

各年度の選択式の正答語が、それ以前の過去問に出ていたかを調べた結果：

| 回 | 既出率 | 回 | 既出率 |
|---|---|---|---|
| 第57回 | 59.0% | 第53回 | 41.0% |
| 第56回 | 62.2% | 第52回 | 64.1% |
| 第55回 | 65.8% | 第51回 | 31.6% |
| 第54回 | 28.9% | 第50回 | 25.0% |

**平均47.1%。約53%は過去問だけでは初見です。**

これは「過去問をやっても無駄」という意味ではありません。**初見が前提の試験だと理解して、初見用の手順を持て**という意味です。

### ② 9年中7回、いずれかの科目で基準点が引き下げられている

| 回 | 補正された科目 |
|---|---|
| 第57回 | 労災・**労一**・**社一** |
| 第56回 | **労一** |
| 第55回 | なし |
| 第54回 | なし |
| 第53回 | **労一**・国年 |
| 第52回 | **労一**・**社一**・健保 |
| 第51回 | **社一** |
| 第50回 | **社一**・国年 |
| 第49回 | 雇用・健保 |

| 科目 | 補正回数 |
|---|---|
| **社会保険に関する一般常識** | **4回 / 9年** |
| **労務管理その他の労働に関する一般常識** | **4回 / 9年** |
| 健康保険法 | 2回 |
| 国民年金法 | 2回 |
| 雇用保険法 | 1回 |
| 労働者災害補償保険法 | 1回 |

**誰も解けない問題は救済されます。** 落ちるのは「みんなが取れた問題を落とした人」です。
だから狙いは**満点ではなく、取れる空欄を確実に取ること**。

## 2. 得点構造を理解する

```
40点満点 → 合格ラインは22〜27点
1科目5点 → 基準点は3点。ただし狙うのは【4点】
```

**3点ギリギリを狙ってはいけません。** 1問落とした瞬間に基準点割れです。
**4点を狙えば、1つ外しても3点が残ります。** これが唯一のリスク緩衝です。

一方で、**最初から5点を狙うのも失敗**です。難問1つに時間を吸われて、
他の科目の易しい空欄を落とすのが典型的な負けパターンです。

正しいのは **「第1巡で確実な3点 → 第2巡で4点目を取りにいく」** という2段構えです。

### 80分の使い方

| 段階 | 時間 | やること |
|---|---|---|
| 第1巡 | 40分 | 8問すべてを見て、**各科目の易しい3点を確保**（守り）。難しい空欄は仮マークして即通過 |
| **第2巡** | **25分** | **4点目を取りにいく**（攻め）。ここが基準点割れのリスクを下げる本体 |
| 第3巡 | 10分 | **全空欄が埋まっているか確認**。空欄ゼロにする |
| 予備 | 5分 | マークシートのズレ確認 |

> **白紙は0点。埋めれば当たる可能性がある。** 最後の5分で全部埋まっていることを必ず確認する。

### 第2巡で4点目をどこから取るか（優先順）

1. **同じ記号が2回以上出ている空欄**（全体の11%）… 文脈が2倍取れる。最優先
2. **数値の空欄**（32%）… [`90-横断整理.md`](90-横断整理.md) 第20節「取りうる値の範囲」で切る
3. **機関・主体の空欄**（3%）… 語群に4語程度しかない
4. **条文の文末**（義務／裁量／努力義務）… [`93-判例.md`](93-判例.md) の型

「3点取れたから次」ではなく、**「この科目であと1点どこから取れるか」を必ず1回考える**。
それをやるかやらないかで、8科目分では**+3〜5点**の差になります。

## 3. 語群は20択ではない — 実質12択、うち2割は4択

### データ

| 事実 | 数値 |
|---|---|
| 出題形式 | 20語の共通語群 **64問** ／ 空欄ごとの選択肢 **8問** |
| 正答が「文言」 | 320空欄中 **204空欄（64%）** |
| 正答が「数値系」（期間・金額・割合・人数） | **104空欄（32%）** |
| 正答が「機関・主体」 | **11空欄（3%）** |
| **正答と同じ種類の語は語群20語中 平均11.7語** | → **種類で切るだけで20択→約12択** |
| 4語以下まで絞れたケース | 320空欄中 **67空欄（21%）** |

**まず種類で切る。これだけで正答率が5%→9%になり、2割のケースでは25%まで上がります。**

## 4. 絞り込みの7つの技術

### 技術1｜種類で切る（最初に必ずやる）

語群を眺めて、空欄に入りうる**種類**を判定する。

| 空欄の位置 | 入る種類 |
|---|---|
| 「〜は、…することができる」の主語 | **機関・主体**（大臣／局長／署長／裁判所／政府） |
| 「〜から起算して【 】を経過したとき」 | **期間**（○年・○か月・○日） |
| 「その超える額の【 】に相当する額」 | **割合**（2分の1・3分の2） |
| 条文の途中の長い節 | **文言**（長文の選択肢） |

> 語群の長さもヒント。**長文の選択肢は長文の空欄にしか入りません。**

### 技術2｜助詞と活用でつながらない語を切る

空欄の直前直後の助詞・語尾を見て、**日本語として接続しない語を機械的に落とす**。

- 「【 】は、」→ 名詞（主体）しか入らない
- 「【 】に相当する額」→ 割合か金額
- 「【 】場合に限り」→ 連体形で終わる語
- 「【 】、又は設置してはならない」→ 動詞の連用形

**これは法律知識がゼロでもできます。** 初見問題で最も効く技術です。

### 技術3｜同じ空欄記号が2回以上出たら必ず取りにいく

360空欄中 **39空欄（11%）** は、同じ記号が本文中に2回以上登場します。
**文脈が2倍取れる**ので、片方で意味が通らなければ即座に切れます。ここは確実に取る。

### 技術4｜語群のペア構造を読む

出題者は**紛らわしいペア**を必ず仕込みます。逆に言えば、**ペアになっている語のどちらかが正解**である可能性が高い。

- 対義：「することができる」⇔「しなければならない」
- 程度違い：「2分の1」「3分の1」「3分の2」
- 機関違い：「厚生労働大臣」「都道府県労働局長」「労働基準監督署長」
- 動詞の組合せ違い：「譲渡し、貸与し」「譲渡し、展示し」「販売し、賃貸し」

**孤立している語（ペアのない語）はダミーである可能性が高い。**

### 技術5｜条文の「型」で決める

社労士試験の条文は、文末の型が限られています。

| 型 | 意味 | 例 |
|---|---|---|
| 〜しなければならない | **義務** | 事業者は…措置を講じなければならない |
| 〜することができる | **裁量・権限** | 政府は…行わないことができる |
| 〜するよう努めなければならない | **努力義務** | 高年齢労働者の労災防止措置 |
| 〜してはならない | **禁止** | 譲渡し、貸与し、又は設置してはならない |
| 〜するものとする | **原則の宣言** | — |

**義務／努力義務／裁量の書き分けは、法改正論点で必ず狙われます**（`00-法改正-令和8年度.md` 参照）。

### 技術6｜数字は「制度の骨格」から逆算する

数値の空欄は104空欄（32%）あります。丸暗記していなくても、**制度の趣旨から矛盾する数字を切れます。**

- 給付の待期が「30日」はあり得ない（実務が回らない）
- 時効が「10年」は社労士法令には存在しない（**2年か5年**）
- 割合は **2分の1／3分の2／4分の3／100分の60** のどれか

> `91-数値暗記.md` で年度依存の数値を、`90-横断整理.md` で「時効は2年か5年」といった**取りうる値の範囲**を押さえておくと、この技術が効きます。

### 技術7｜白書・統計は「順位」で答える

労一・社一の統計問題は、実数を覚えていなくても**大小関係**で答えられることが多い。

- 国民医療費の財源：**保険料 ＞ 公費 ＞ 患者負担**
- 社会保障給付費：**年金 ＞ 医療 ＞ 福祉その他**
- 「約7割」「約8割」の二択なら、**制度の常識で妥当なほう**を選ぶ

統計の空欄で悩んだら**深追いせず仮マークして次へ**。ここは補正が入る領域です。

## 5. 実例で手順を追う — 令和7年度 労基・安衛

### 問題文（抜粋）

> 労働基準法第114条は、**【A】** は、同法第37条の規定に違反した使用者に対して、労働者の請求により、…未払金のほか、これと同一額の **【B】** の支払を命ずることができる旨規定している。
>
> 労働安全衛生法第42条は、「特定機械等以外の機械等で…厚生労働大臣が定める規格又は安全装置を具備しなければ、**【E】**、又は設置してはならない。」と定めている。

### 語群20語（実際のもの）

```
①慰謝料 ②厚生労働大臣 ③裁判所 ④作業管理
⑤使用者に労働者の仕事と生活の調和にも配慮することを規定している趣旨を…
⑥上記権利等を保障した趣旨を実質的に失わせるものと認められる
⑦譲渡し、貸与し ⑧譲渡し、展示し ⑨生産管理 ⑩遅延損害金
⑪同法等に違反する行為に罰則を設けている意味を没却させる ⑫都道府県労働局長
⑬賠償金 ⑭販売し、賃貸し ⑮販売し、販売のために展示し ⑯付加金
⑰有害物管理 ⑱労働基準監督署長 ⑲労働時間管理
⑳労働条件は労働者と使用者が対等の立場において決定すべきものとしている意味を没却させる
```

### 絞り込みの実際

**【A】**（技術1＋2）
「【A】は、…支払を命ずることができる」→ **機関・主体**。語群の機関は ②厚生労働大臣 ③裁判所 ⑫都道府県労働局長 ⑱労働基準監督署長 の**4語だけ**。20択が**4択**になりました。
そこから「**支払を命ずる**」のは行政庁ではなく**司法**。→ **③裁判所**

**【B】**（技術1＋4）
「未払金のほか、これと同一額の【B】の支払」→ **金銭の名称**。語群の金銭は ①慰謝料 ⑩遅延損害金 ⑬賠償金 ⑯付加金 の**4語**。
「未払金と同一額を制裁的に命じる」制度の名前 → **⑯付加金**

**【E】**（技術1＋2＋4）
「【E】、又は設置してはならない」→ **動詞の連用形の組合せ**。語群は ⑦譲渡し、貸与し ⑧譲渡し、展示し ⑭販売し、賃貸し ⑮販売し、販売のために展示し の**4語**。
安衛法42条は「譲渡・貸与・設置」の3つを禁じる条文 → **⑦譲渡し、貸与し**

### この問題から学ぶこと

**5点満点のうち3点は、「種類で切る」だけで4択まで落ちています。**
残りの【C】【D】（判例の判示部分・作業管理）が難しくても、**3点は確保できる設計**になっています。

これが「まず3点を確保する」の実際です。第2巡では【C】【D】に戻り、4点目を取りにいきます。

## 6. 捨てる技術

### 捨ててよい空欄の見分け方

| 特徴 | 判断 |
|---|---|
| 白書・統計の**実数**（「◯◯万人」「◯◯％」） | 覚えていなければ捨てる。カテゴリ内で最も常識的な値を仮マーク |
| 判例の**判示部分の長文**（40字超の選択肢） | 2択まで絞れなければ捨てる |
| 見たことのない**法律名・制度名** | 捨てる。補正の可能性が高い |
| 条文の**数値**で語群に近い値が3つ以上 | 深追いしない |

### 捨てるときのルール

1. **必ず何かをマークしてから捨てる**（白紙は0点）
2. カテゴリで絞った中から選ぶ（当てずっぽうでも1/4〜1/12）
3. **時間を戻さない**。捨てた空欄に第2巡で戻るのは、他が全部終わってから

## 7. 科目別のリスクと構え

| 科目 | 補正回数 | 構え |
|---|---|---|
| **社一** | 4回 | **最も危険**。条文がある法律（介護保険法・国保法・社労士法・確定拠出年金法）で3点を取りにいく。統計は捨ててよい |
| **労一** | 4回 | 同上。労働契約法・派遣法・育介法・最賃法の**条文**で勝負。労働経済の実数は捨てる |
| 健保 | 2回 | 目的条文・給付の要件から。数値は `91-数値暗記.md` |
| 国年 | 2回 | 条文の言い回しが素直。**取りにいく科目** |
| 雇用 | 1回 | 令和7年改正が集中。改正部分は `00-法改正-令和8年度.md` |
| 労災 | 1回 | 条文の文言をそのまま覚えるのが最も効率的 |
| 労基安衛 | 0回 | **9年間で一度も補正されていない＝落とせない科目**。目的条文・判例・数値を確実に |
| 厚年 | 0回 | 同上。**在職老齢年金65万円**は今年の最有力 |

> **労基安衛と厚年は9年間で一度も補正されていません。** ここで3点を割ると、ほぼ確実に不合格です。
> 逆に社一・労一は「割れても救済されうる」ので、時間をかけすぎないこと。
