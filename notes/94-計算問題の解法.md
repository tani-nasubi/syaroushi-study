## 1. 平均賃金（労基法12条）★すべての基礎

```
平均賃金 ＝ 算定事由発生日以前3か月間の賃金総額 ÷ その期間の総日数（暦日数）
```

### 手順

1. **起算日を決める**
   - 算定事由発生日の**前日**からさかのぼる
   - 賃金締切日があるときは、**直前の締切日**からさかのぼる
2. **3か月間の総日数（暦日数）**を数える ← 所定労働日数ではない
3. **賃金総額**を出す（下記の控除に注意）
4. 割る
5. **最低保障額と比較**する（日給・時間給・出来高払制の場合のみ）

### 賃金総額から控除するもの
- 臨時に支払われた賃金
- **3か月を超える期間ごとに支払われる賃金**（賞与）
- 通貨以外のもので法令・労働協約の定めに基づかないもの

### 期間と賃金の両方から控除するもの
- 業務上の傷病による**療養休業期間**
- **産前産後休業**期間
- **使用者の責に帰すべき休業**期間
- **育児介護休業**期間
- **試の使用期間**

### 最低保障（日給・時間給・出来高払制）

```
最低保障 ＝ その期間の賃金総額 ÷ 実労働日数 × 60/100
```
原則の額と比べて**高いほう**を採る。

### 例題（第57回 労基 問2の形式）

> 日給1万円、毎月20日締切・当月25日支払。7月15日に算定事由発生。
> 1月支払分〜6月支払分はいずれも労働日数10日・支払額10万円。控除期間なし。

1. 起算日：算定事由発生日（7/15）の直前の締切日＝**6月20日**からさかのぼる
2. 3か月間＝3/21〜6/20 → 総日数 **92日**（3月11日＋4月30日＋5月31日＋6月20日）
3. 賃金総額＝この期間に支払われた賃金。4月・5月・6月支払分の30万円
4. 30万円 ÷ 92日 ＝ **約3,260円**
5. 日給制なので最低保障を確認：30万円 ÷ 実労働日数30日 × 60/100 ＝ **6,000円**
6. 高いほうを採る → **6,000円**

> **ポイント**：日給制では最低保障のほうが高くなることが多い。**必ず両方計算する**。

### 平均賃金の使いどころ

| 用途 | 額 |
|---|---|
| 解雇予告手当 | **30日分**以上 |
| 休業手当 | **100分の60**以上 |
| 年次有給休暇の賃金 | 平均賃金／通常の賃金／標準報酬日額 のいずれか |
| 災害補償（休業補償） | 100分の60 |
| 打切補償 | **1,200日分** |
| 減給の制裁 | 1回の額が**1日分の半額**、総額が一賃金支払期の賃金総額の**10分の1** |

## 2. 休業手当（労基法26条）

```
休業手当 ＝ 平均賃金 × 60/100 以上
```

**1日の一部を休業した場合**
その日に現実に支払われた賃金が平均賃金の60％に満たなければ、**差額**を支払う。

> 例：平均賃金1万円、半日勤務で4,000円支払 → 6,000円（＝1万×0.6）に満たないので**2,000円**を追加。

## 3. 割増賃金（労基法37条）

```
1時間あたりの賃金 ＝ 月の所定賃金（除外賃金を除く）÷ 1か月平均所定労働時間
割増賃金 ＝ 1時間あたりの賃金 × 割増率 × 時間数
```

### 割増率

| 種類 | 率 |
|---|---|
| 時間外 | 2割5分以上 |
| 休日 | 3割5分以上 |
| 深夜 | 2割5分以上 |
| 月60時間超の時間外 | **5割以上** |
| 時間外＋深夜 | 5割以上 |
| **休日＋深夜** | **6割以上** |

> **休日労働に時間外割増は重複しません**（休日に法定労働時間の概念がないため）。
> 月60時間超の規制も**休日労働には及びません**。

### 算定基礎から除外できる7つ（限定列挙）
家族手当／通勤手当／別居手当／子女教育手当／住宅手当／臨時に支払われた賃金／1か月を超える期間ごとに支払われる賃金

> **一律支給の家族手当・通勤手当は除外できません**（名称ではなく実態で判断）。

## 4. 労災：給付基礎日額と各給付

### 給付基礎日額
原則として**労基法12条の平均賃金**に相当する額。3つの調整がかかる。

| 調整 | 適用対象 |
|---|---|
| スライド制 | 全給付 |
| **年齢階層別の最低・最高限度額** | 年金給付／療養開始後**1年6か月経過後**の休業給付 |
| 最低保障額 | 休業・年金給付基礎日額 |

### 休業補償給付

```
1日あたり ＝ 給付基礎日額 × 60/100
（＋ 休業特別支給金 20/100 ＝ 合計8割）
```
- **第4日目**から支給（待期3日は継続・断続を問わない）
- 一部労働した日：**（給付基礎日額 － 実労働に対して支払われる賃金額）× 60/100**

### 障害・遺族・傷病

| 給付 | 日数 |
|---|---|
| 障害補償年金 | 1級**313日** / 2級277 / 3級245 / 4級213 / 5級184 / 6級156 / 7級**131日** |
| 傷病補償年金 | 1級313 / 2級277 / 3級245（**障害と同じ**） |
| 障害補償一時金 | 8級**503日** … 14級**56日** |
| 遺族補償年金 | 遺族1人**153日** / 2人201 / 3人223 / 4人以上**245日** |
| 遺族補償一時金 | **1,000日分** |
| 葬祭料 | **330,000円＋30日分** と **60日分** の**高いほう** ⚠️ |

> 葬祭料は「高いほう」を採る点が計算問題の定番。給付基礎日額が**11,000円**を境に逆転します
> （330,000＋30d と 60d が等しくなるのは d＝11,000円）。

## 5. 雇用：賃金日額と基本手当

```
賃金日額 ＝ 被保険者期間として計算された最後の6か月間の賃金総額 ÷ 180
基本手当日額 ＝ 賃金日額 × 給付率
```

- 賞与等（3か月を超える期間ごとに支払われる賃金）は**算入しない**
- 給付率は賃金日額が低いほど高い：**80％〜50％**（60歳以上65歳未満は**80％〜45％**）
- 上限額・下限額は毎年**8月1日**改定

### 所定給付日数

**一般の離職者（年齢を問わない）**

| 算定基礎期間 | 日数 |
|---|---|
| 1年以上10年未満 | **90日** |
| 10年以上20年未満 | **120日** |
| 20年以上 | **150日** |

**特定受給資格者・特定理由離職者**：年齢と算定基礎期間で細分、最大**330日**
**就職困難者**：45歳未満300日／45歳以上65歳未満**360日**

### 被保険者期間の数え方（事例問題の頻出）
離職日から**1か月ごとに区切り**、賃金支払基礎日数が**11日以上**の月を1か月とする。
11日以上の月がない場合は、賃金支払の基礎となった**労働時間数が80時間以上**の月も1か月と数える。

> 「◯年◯月〜◯年◯月まで勤務、途中◯か月休業」という事例で、**被保険者期間が12か月あるか**を判定させる問題が出ます。区切りは**離職日から逆算**する点に注意。

## 6. 健保：傷病手当金・出産手当金・高額療養費

### 傷病手当金・出産手当金（同じ算式）

```
1日あたり ＝ 支給開始日以前の直近の継続した12か月間の各月の標準報酬月額の平均 ÷ 30 × 2/3
```

- 12か月に満たない場合は、①当該期間の平均 ②全被保険者の平均標準報酬月額 の**いずれか少ない額**
- 傷病手当金：待期**継続した3日**、支給期間は**通算1年6か月**
- 出産手当金：出産日以前**42日**（多胎**98日**）〜出産日後**56日**
- 両方受けられるときは**出産手当金が優先**、傷病手当金は差額のみ

### 高額療養費

```
自己負担限度額 ＝ 定額 ＋（総医療費 － 一定額）× 1％   ※所得区分による
```

**計算の順序**
1. **同一月・同一医療機関・同一診療**で自己負担額を集計（入院と外来、医科と歯科は別）
2. 所得区分に応じた限度額を計算
3. 限度額を超える分が高額療養費
4. **世帯合算**：同一世帯で**21,000円以上**の自己負担が複数あれば合算（70歳以上は金額を問わず）
5. **多数回該当**：直近12か月に**3回以上**該当していれば、4回目から限度額が下がる

## 7. 厚年：在職老齢年金・年金額

### 在職老齢年金 ★令和8年度の最重要

```
支給停止額（月額）＝（基本月額 ＋ 総報酬月額相当額 － 65万円）× 1/2
```

| 用語 | 定義 |
|---|---|
| **基本月額** | 老齢厚生年金（**加給年金額を除く**）の額 ÷ 12 |
| **総報酬月額相当額** | その月の標準報酬月額 ＋ **その月以前1年間の標準賞与額の合計 ÷ 12** |

**手順**
1. 基本月額を出す（**加給年金額は除く**）
2. 総報酬月額相当額を出す（**賞与を12で割って足す**のを忘れない）
3. 合計から65万円を引く。マイナスなら**支給停止なし**
4. 超過分の**2分の1**が停止額
5. 停止されるのは**報酬比例部分のみ**。老齢基礎年金・経過的加算は停止されない
6. 報酬比例部分が**全額停止**されると**加給年金額も支給されない**

> **引っかけ**：加給年金額を基本月額に含めてしまう／賞与を足し忘れる。この2つが定番です。

### 報酬比例部分

```
平均標準報酬月額 × 7.125/1000 × 平成15年3月以前の月数
＋ 平均標準報酬額 × 5.481/1000 × 平成15年4月以後の月数
```
総報酬制の導入が**平成15年4月**。前後で乗率と基礎が変わります。

### 障害厚生年金・遺族厚生年金

| 給付 | 額 |
|---|---|
| 障害厚生年金1級 | 報酬比例の年金額 × **1.25** ＋ 配偶者加給 |
| 障害厚生年金2級 | 報酬比例の年金額 ＋ 配偶者加給 |
| 障害厚生年金3級 | 報酬比例の年金額（**最低保障額あり**、配偶者加給なし） |
| 障害手当金 | 報酬比例の年金額 × **2**（一時金） |
| **遺族厚生年金** | 報酬比例の年金額の **4分の3** |

**300月みなし**：被保険者期間が300月未満なら**300月**とみなす。
ただし遺族厚生年金は**短期要件のみ**。長期要件には適用されません。

## 8. 国年：老齢基礎年金

```
年金額 ＝ 満額 × （保険料納付済月数 ＋ 免除月数 × 反映割合）÷ 480
```

### 反映割合（平成21年4月以後）

| 区分 | 反映 |
|---|---|
| 納付済期間・**産前産後免除** | **1** |
| 全額免除 | **2分の1** |
| 4分の3免除 | **8分の5** |
| 半額免除 | **8分の6** |
| 4分の1免除 | **8分の7** |
| 学生納付特例・納付猶予 | **0**（受給資格期間には算入） |

> 平成21年3月以前は国庫負担が3分の1だったため、全額免除は**3分の1**。
> 事例問題では「平成21年3月まで」と「4月以後」で分けて計算させます。

### 繰上げ・繰下げ

| 制度 | 率 | 例 |
|---|---|---|
| 繰上げ | 0.4％／月 | 60歳0か月＝60月 → **24％減** |
| 繰下げ | 0.7％／月 | 75歳0か月＝120月 → **84％増** |

## 9. 保険料の計算（出題最多・7問）

### 労働保険料（徴収法）

```
一般保険料 ＝ 賃金総額 ×（労災保険率 ＋ 雇用保険率）
```

**賃金総額に含める／含めない**（→ [`05-徴収法.md`](05-徴収法.md)）

| 含む | 含まない |
|---|---|
| 賞与、**通勤手当（非課税分も含む）**、住宅手当、家族手当、**休業手当（労基法26条）** | 退職金、結婚祝金、**休業補償費（労災）**、傷病手当金、解雇予告手当、出張旅費 |

**雇用保険料の労使負担**（令和8年度・一般の事業 ⚠️）
合計 1000分の13.5 ＝ 労働者 **1000分の5** ＋ 事業主 **1000分の8.5**
（差の1000分の3.5は**二事業分＝事業主のみ負担**）

### 社会保険料（健保・厚年）

```
保険料 ＝ 標準報酬月額 ×（健保料率 ＋ 介護料率 ＋ 子ども・子育て支援金率 ＋ 厚年料率）
```
- **労使折半**（健保組合は事業主負担を2分の1超にできる）
- 厚年は全国一律 **1000分の183.00**
- 介護保険料率と支援金率は**全国一律**、健保の一般保険料率は**都道府県ごと**
- 控除は**前月分**を当月報酬から（賞与は**当月分**）

## 10. 標準報酬の決定・改定

### 定時決定
**4・5・6月**に受けた報酬の平均 → その年の**9月から翌年8月**まで適用

### 随時改定（月変）の3要件（すべて必要）
1. **固定的賃金の変動**
2. 変動月以後**継続した3か月**の平均で**2等級以上**の差
3. 3か月とも支払基礎日数**17日以上**（短時間労働者は11日以上）

→ 変動月から起算して**4か月目**に改定

### 育児休業等終了時改定・産前産後休業終了時改定
**本人の申出**により、**1等級**の差でも改定される。

## 本番での立ち回り

1. **計算問題は後回しでよい**。他の問題を先に片付けてから戻る
2. ただし**手順を知っている型なら即やる**（確実な1点）
3. 5分かけて答えが出なければ**捨てる**。選択肢の中で最も妥当なものにマークして次へ
4. 選択肢が**等間隔に並んでいる**とき（例：90日・120日・150日・180日・210日）は、
   制度上ありえない値を切るだけで2〜3択になる

- [ ] 被保険者期間は**離職日から逆算**、賃金支払基礎日数**11日以上**
