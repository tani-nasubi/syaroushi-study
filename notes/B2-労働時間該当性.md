# 労働時間該当性｜労基の深掘り

### 判示の核

> 労働基準法上の労働時間とは、**労働者が使用者の指揮命令下に置かれている時間**をいい、労働契約・就業規則・労働協約等の定めのいかんにより決定されるべきものではない

後半が重要です。**当事者の合意で「これは労働時間ではない」と決めても無効**であり、**客観的に**定まります。

### なぜ争いになるか

「働いている」とも「休んでいる」とも言いにくい時間があるからです。

| 場面 | 結論 | 理由 |
|---|---|---|
| 始業前の**作業服・保護具の着脱** | 使用者から**義務付けられ、又は余儀なくされた**ときは労働時間 | 使用者の指揮命令下にある |
| **仮眠時間**（不活動時間） | **労働からの解放が保障されていない**ときは労働時間 | 現に作業していなくても、必要が生じれば直ちに対応すべき状態なら指揮命令下 |
| **手待時間** | 労働時間 | 同上 |
| 移動時間（通勤） | 原則として労働時間でない | 指揮命令下にない |
| 移動時間（業務命令による物品運搬等） | 労働時間 | 指揮命令下にある |

### 覚えるキーワード

「**指揮命令下**」「**労働からの解放**」「**客観的に定まる**」

★令和6年度の選択式で「指揮命令下」「労働からの解放」が正答になっています。

### 判断の順序

労働時間かどうかは、**当事者の合意や就業規則の定めではなく、客観的に定まります**（三菱重工長崎造船所事件）。

```
① 使用者の指揮命令下に置かれているか
② 労働からの解放が保障されているか（休憩・仮眠）
```

### 個別の類型

| 類型 | 結論 | 理由 |
|---|---|---|
| **作業服・保護具の着脱** | 事業所内での**義務付け**があれば労働時間 | 三菱重工長崎造船所事件 |
| **仮眠時間** | 警報等への**対応義務**があれば労働時間 | 大星ビル管理事件 |
| **手待時間**（来客待ち・電話番） | **労働時間** | 労働から解放されていない |
| **通勤時間** | 労働時間**でない** | 指揮命令下にない |
| **出張中の移動** | 原則として労働時間**でない**（物品の監視等の 特別の義務があれば別） | |
| **研修・教育** | **参加が義務**なら労働時間。自由参加なら労働時間でない | |
| **健康診断** | **一般健診**は労使協議による／**特殊健診**は労働時間 | |
| **安全衛生教育** | **労働時間**（費用も事業者負担） | |

### 労働時間の通算（38条）

> 労働時間は、**事業場を異にする場合においても**、労働時間に関する規定の適用については通算する。

「事業場を異にする場合」には、**事業主を異にする場合も含まれます**（行政解釈）。

| 場面 | 割増賃金を払う者 |
|---|---|
| 副業・兼業で法定労働時間を超えた | **時間的に後から労働契約を締結した使用者**（原則）。ただし所定外労働の順序による |

> ★「同一事業主内でのみ通算する」は誤りです。**副業先の時間も通算**します。

### 労働時間の適正な把握

**労働安全衛生法66条の8の3**により、事業者は**タイムカード・パソコンの使用時間の記録等の客観的な方法**で労働時間の状況を把握する義務があります（**管理監督者・裁量労働制の適用者も対象**）。

> ★労基法上の「労働時間」と、安衛法上の「労働時間の状況」は別の概念です。安衛法の把握義務は**健康確保**が目的なので、労基法41条の管理監督者にも及びます。
