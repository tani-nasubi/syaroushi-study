# 労働時間該当性｜労基の深掘り

### 判示の核

> 労働基準法上の労働時間とは、**労働者が使用者の指揮命令下に置かれている時間**をいい、労働契約・就業規則・労働協約等の定めのいかんにより決定されるべきものではない

後半が重要です。**当事者の合意で「これは労働時間ではない」と決めても無効**であり、**客観的に**定まります。

### なぜ争いになるか

「働いている」とも「休んでいる」とも言いにくい時間があるからです。

| 場面 | 結論 | 理由 |
|---|---|---|
| 始業前の**作業服・保護具の着脱** | 使用者から**義務付けられ、又は余儀なくされた**ときは労働時間 | 使用者の指揮命令下にある |
| **仮眠時間**（不活動時間） | **労働からの解放が保障されていない**ときは労働時間 | 現に作業していなくても、必要が生じれば直ちに対応すべき状態なら指揮命令下 |
| **手待時間** | 労働時間 | 同上 |
| 移動時間（通勤） | 原則として労働時間でない | 指揮命令下にない |
| 移動時間（業務命令による物品運搬等） | 労働時間 | 指揮命令下にある |

### 覚えるキーワード

「**指揮命令下**」「**労働からの解放**」「**客観的に定まる**」

★令和6年度の選択式で「指揮命令下」「労働からの解放」が正答になっています。

### 判断の順序

労働時間かどうかは、**当事者の合意や就業規則の定めではなく、客観的に定まります**（三菱重工長崎造船所事件）。

```
① 使用者の指揮命令下に置かれているか
② 労働からの解放が保障されているか（休憩・仮眠）
```

### 個別の類型

| 類型 | 結論 | 理由 |
|---|---|---|
| **作業服・保護具の着脱** | 事業所内での**義務付け**があれば労働時間 | 三菱重工長崎造船所事件 |
| **仮眠時間** | 警報等への**対応義務**があれば労働時間 | 大星ビル管理事件 |
| **手待時間**（来客待ち・電話番） | **労働時間** | 労働から解放されていない |
| **通勤時間** | 労働時間**でない** | 指揮命令下にない |
| **出張中の移動** | 原則として労働時間**でない**（物品の監視等の 特別の義務があれば別） | |
| **研修・教育** | **参加が義務**なら労働時間。自由参加なら労働時間でない | |
| **健康診断** | **一般健診**は労使協議による／**特殊健診**は労働時間 | |
| **安全衛生教育** | **労働時間**（費用も事業者負担） | |

### 労働時間の通算（38条）

> 労働時間は、**事業場を異にする場合においても**、労働時間に関する規定の適用については通算する。

「事業場を異にする場合」には、**事業主を異にする場合も含まれます**（行政解釈）。

| 場面 | 割増賃金を払う者 |
|---|---|
| 副業・兼業で法定労働時間を超えた | **時間的に後から労働契約を締結した使用者**（原則）。ただし所定外労働の順序による |

> ★「同一事業主内でのみ通算する」は誤りです。**副業先の時間も通算**します。

### 労働時間の適正な把握

**労働安全衛生法66条の8の3**により、事業者は**タイムカード・パソコンの使用時間の記録等の客観的な方法**で労働時間の状況を把握する義務があります（**管理監督者・裁量労働制の適用者も対象**）。

> ★労基法上の「労働時間」と、安衛法上の「労働時間の状況」は別の概念です。安衛法の把握義務は**健康確保**が目的なので、労基法41条の管理監督者にも及びます。

### 出向と労働時間

| 種類 | 労働契約 | 労基法上の使用者 |
|---|---|---|
| **在籍型出向** | 出向元・出向先の**両方**と労働契約がある | **出向元と出向先の双方**が、それぞれ権限を持つ事項について使用者となる |
| **移籍型出向**（転籍） | 出向元との労働契約を**終了**し、出向先とのみ | **出向先**のみ |

**出向労働者**については、出向元・出向先・本人の**三者間の取決め**により、労働時間・休日・休暇などの管理をどちらが行うかを定めます。

> ★在籍型出向では、**賃金は出向元、労働時間は出向先**というように、事項ごとに使用者が分かれます。

### 定額残業代（固定残業代）

「基本給に残業代◯時間分を含む」「営業手当を残業代とする」という扱いです。

#### なぜ許されるのか

**労基法37条が定めているのは割増賃金の「額」だけで、支払い方を決めていない**からです。実際に働いた時間から計算した法定額**以上**が支払われていれば、その渡し方が定額であってもかまいません。

> ★条文上「定額残業代」という制度があるわけではありません。**37条を満たす払い方の一つ**として、判例が枠をはめてきたものです。

#### 有効とされるための3つ

| | 要件 | 中身 |
|---|---|---|
| **①** | **判別できること**（明確区分性） | **通常の労働時間の賃金**の部分と**割増賃金**の部分とが判別できること |
| **②** | **対価性** | その手当が**時間外労働の対価**として支払われるものであること |
| **③** | **差額の支払** | 定額分を**超えた**割増賃金が生じたら、**必ず差額を払う**こと |

②の判断は、**雇用契約書等の記載内容**、**労働者への説明の内容**、**実際の勤務状況**などを考慮します（**日本ケミカル事件**・最判平30.7.19）。

> ★同事件は、**「何時間分の残業代か」を明示することまでは求めていません**。原審が「対応する時間数を明示すべき」としたのを最高裁が否定しました。ここが引っかけになります。
> ★逆に、**歩合給の計算過程で割増賃金相当額を差し引く**しくみは、**割増賃金を支払ったことにならない**とされました（**国際自動車事件**・最判令2.3.30）。差し引けば結局いくら働いても総額が変わらず、①の判別ができないためです。

#### 使用者にとっての意味

超えた分は必ず払うので、**残業代が安くなるわけではありません**。それでも使われるのは次の理由です。

| | |
|---|---|
| **計算事務が減る** | 毎月の実額計算をしなくても、定額の範囲内なら精算だけで済む |
| **人件費の見通しが立つ** | 一定額までは月々の賃金が動かない |
| **提示額を高く見せられる** | 求人票の月給が大きくなる（そのため**求人での明示が義務**づけられています） |

> ★**「定額を払っているから、いくら残業させても追加は不要」は誤りです。** ③の差額精算は絶対です。
> ★**求人の場面では扱いが違います。** 職業安定法5条の3（労働条件等の明示）とこれに基づく省令・指針により、募集時には**基本給の額**、**定額残業代に当たる手当の額とそれが何時間分か**、**超えた分を追加で支払う旨**を明示しなければなりません。**労基法上は時間数の明示が不要**（日本ケミカル事件）なのに対し、**求人では必要**という対比になります。

#### 試験での問われ方

- 「定額残業代の合意があれば、実際の時間外労働時間にかかわらず追加の支払は不要」→ **誤り**
- 「有効となるには、割増賃金に当たる部分が**何時間分か**を明示しなければならない」→ **誤り**（労基法上は不要）
- 「通常の労働時間の賃金と割増賃金とを**判別**できることが必要」→ **正しい**

### 懲戒処分の種類

**戒告・けん責 → 減給 → 出勤停止 → 降格 → 諭旨退職（諭旨解雇） → 懲戒解雇**

> ★**減給**には労基法91条の制限（1回の額は平均賃金1日分の半額、総額は一賃金支払期の賃金総額の10分の1）がかかります。
> ★**出勤停止**の期間中に賃金が支払われないのは、労務提供がないためであり、91条の減給には当たりません。
> ★**諭旨退職**は、本人の願い出による退職の形をとらせるものです。
