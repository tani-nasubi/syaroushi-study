# 社会保険労務士法｜社一の深掘り

**9年で毎年出題**される社一の最頻出法令です。

### 目的（1条）

> この法律は、社会保険労務士の制度を定めて、その業務の適正を図り、もつて**労働及び社会保険に関する法令の円滑な実施**に寄与するとともに、**事業の健全な発達と労働者等の福祉の向上**に資することを目的とする。

### 職責（1条の2）

> 社会保険労務士は、**常に品位を保持**し、**業務に関する法令及び実務に精通**して、**公正な立場**で、誠実にその業務を行わなければならない。

> ★「品位・法令実務の精通・公正な立場」の3つ。選択式で狙われます。

### 業務（2条）

| 区分 | 内容 | 独占性 |
|---|---|---|
| **1号業務**（申請書等の作成・提出代行・事務代理） | 労働社会保険諸法令に基づく申請書等の作成、行政機関等への**提出代行**、**事務代理** | **独占業務** |
| **2号業務**（帳簿書類の作成） | 労働社会保険諸法令に基づく**帳簿書類**（就業規則、労働者名簿、賃金台帳等）の作成 | **独占業務** |
| **3号業務**（コンサルティング） | 事業における**労務管理その他の労働に関する事項および労働社会保険諸法令に基づく社会保険に関する事項について相談に応じ、または指導**すること | **独占ではない** |

> ★**3号業務は独占業務ではありません**。社労士でなくても行えます。ここが最頻出です。

### 紛争解決手続代理業務（2条1項1号の4〜1号の6）

**特定社会保険労務士**（**紛争解決手続代理業務試験**に合格し、その旨の**付記**を受けた者）だけが行えます。

| 手続 | 上限 |
|---|---|
| **個別労働関係紛争解決促進法**に基づく**あっせん** | — |
| **均等法・育介法・パート有期法・労働施策総合推進法**に基づく**調停** | — |
| **都道府県労働委員会**が行うあっせん | — |
| **民間紛争解決手続**（ADR、厚生労働大臣が指定するもの） | 紛争の目的の価額が**120万円**を超える場合は**弁護士との共同受任**が必要 |

> ★**120万円**が境目です。「60万円」（司法書士の簡裁代理）と混同しないようにします。

### 補佐人（2条の2）

社会保険労務士は、事業における労務管理その他の労働に関する事項および労働社会保険諸法令に基づく社会保険に関する事項について、**裁判所において、補佐人として、弁護士である訴訟代理人とともに出頭し、陳述**をすることができます。

> ★平成27年改正。**特定社労士でなくてもよく、すべての社労士**が行えます。ここが頻出です。
> ★**弁護士である訴訟代理人とともに**出頭することが必要です。単独では出頭できません。
> ★補佐人の陳述は、**当事者または訴訟代理人が自ら陳述したものとみなされます**（当事者等が直ちに取り消し、または更正したときを除く）。

### 登録（14条の2〜）

| | |
|---|---|
| 登録機関 | **全国社会保険労務士会連合会** |
| 要件 | 社会保険労務士となる資格を有し、**2年以上の実務経験**（または**事務指定講習**の修了） |
| 入会 | 登録を受けた者は、**社会保険労務士会の会員**となる（当然入会） |
| 登録の**拒否** | 一定の事由に該当するとき。拒否するときは**資格審査会の議決**に基づく |

**欠格事由**（5条）の主なもの：未成年者、心身の故障により業務を適正に行うことができない者、破産手続開始の決定を受けて復権を得ない者、**禁錮以上の刑**に処せられ執行を終わってから**3年**を経過しない者、**失格処分**を受けて**3年**を経過しない者など。

### 登録拒否事由（14条の7）

**欠格事由**（14条の3・そもそも社労士になれない）とは別に、**登録を受けられない**事由があります。

| 号 | 事由 |
|---|---|
| **1** | **懲戒処分により、弁護士・公認会計士・税理士又は行政書士の業務を停止された者**で、**現にその処分を受けているもの** |
| **2** | 税理士法48条1項の決定を受けた者で、明らかにされた期間を経過しないもの |
| **3** | **心身の故障**により社会保険労務士の業務を行うことができない者 |
| **4** | 徴収法・健保法・船員保険法・厚年法・国保法・国年法・高齢者医療確保法等の**違反により処分を受けた者**等 |
| 〃 | ほか、**社会保険労務士の信用又は品位を害するおそれがある者**その他社会保険労務士の職責に照らし適当でないと認められる者 |

> ★1号に並ぶのは**弁護士・公認会計士・税理士・行政書士**の4つです。**司法書士・中小企業診断士は入りません**。
> ★「**現にその処分を受けている**」ことが必要です。停止期間が終わっていれば登録できます。

### 社会保険労務士法人の設立の手続（25条の11・25条の12）

> **25条の11** 社会保険労務士法人を設立するには、その社員になろうとする社会保険労務士が、**定款を定めなければならない**。定款には少なくとも**目的・名称・事務所の所在地・社員の氏名及び住所・社員の出資に関する事項・業務の執行に関する事項**を記載する。
> **25条の12** 社会保険労務士法人は、**その主たる事務所の所在地において設立の登記をすることによって成立する**。

- 成立するのは**登記の時**です。
- **厚生労働大臣の認可は要りません**。成立したら**2週間以内**に、登記事項証明書と定款の写しを添えて、主たる事務所の所在地の社労士会を経由して**連合会へ届け出ます**（25条の13）。

> ★「設立には**厚生労働大臣の認可**を受けなければならない」は**誤り**（令和6年に出ました）。認可が要るのは**健康保険組合や企業年金基金**であって、社労士法人は**準則主義**です。

### 業務の制限と義務

| 条 | 内容 |
|---|---|
| **15条** | 社会保険労務士でない者は、**他人の求めに応じ報酬を得て**、1号業務・2号業務を**業として行ってはならない**（**非社会保険労務士との提携の禁止**は23条の2） |
| **16条** | **信用失墜行為の禁止** |
| **19条** | **帳簿の備付け**（事件の名称、依頼者の氏名等を記載し、**閉鎖後2年間**保存） |
| **20条** | **依頼に応ずる義務**（正当な理由がある場合を除き、依頼を拒んではならない） |
| **21条** | **秘密を守る義務**（**社会保険労務士でなくなった後も同様**） |
| **22条** | **業務を行い得ない事件**（**特定社労士**が紛争解決手続代理業務で相手方の依頼を受けていた事件など） |
| **23条** | **非社会保険労務士との提携の禁止** |

> ★21条の守秘義務違反は**1年以下の拘禁刑または100万円以下の罰金**（**親告罪**）。
> ★15条違反（非社労士の業務）は**1年以下の拘禁刑または100万円以下の罰金**。

### 社会保険労務士法人（25条の6〜）

| | |
|---|---|
| 設立 | **社員は社会保険労務士**でなければならない。**社員1人でも設立可**（平成28年〜） |
| 業務 | 1号〜3号業務、および**労働社会保険諸法令に基づく事務の代理**等。**紛争解決手続代理業務**は**特定社労士である社員**がいる場合に限り行える |
| **責任** | 社員は、社会保険労務士法人の債務について**連帯して弁済する責任**を負う（無限連帯責任） |
| 定款・登記 | 主たる事務所の所在地で**設立の登記**をすることによって成立 |

### 懲戒（25条〜25条の3）

| 種類 | 内容 |
|---|---|
| **戒告** | |
| **1年以内の業務の停止** | |
| **失格処分** | 社会保険労務士の**資格を失わせる** |

処分するのは**厚生労働大臣**です。

| 事由 | 処分 |
|---|---|
| **不正行為の指示等**（25条） | 故意に真正の事実に反して申請書等を作成したとき等 → **失格処分または1年以内の業務停止**。**相当の注意を怠った**ときは**戒告または1年以内の業務停止** |
| **一般的な義務違反**（25条の2） | この法律・命令に違反したとき → **戒告、1年以内の業務停止、失格処分** |

> ★懲戒処分をするときは、**あらかじめ、その社会保険労務士に通知し、聴聞**を行わなければなりません。
> ★**何人も**、社会保険労務士に懲戒事由があると思料するときは、**厚生労働大臣に対しその事実を報告し、適当な措置をとるべきことを求めることができます**（25条の3の2）。

### 紛争解決手続代理業務試験（13条の3）

**社会保険労務士**（登録を受けている者）が受験でき、合格すると**全国社会保険労務士会連合会**が**社会保険労務士名簿に付記**します。

### 名簿（14条の3）

> 社会保険労務士名簿は、**連合会に備える**。社会保険労務士名簿の**登録は、連合会が行う**。

> ★備えるのも登録するのも**全国社会保険労務士会連合会**です。「厚生労働省に備える」は誤りです。

### 社会保険労務士法人の業務の範囲（25条の9）

社会保険労務士法人は、**2条1項1号から1号の3まで、2号および3号**の業務を行うほか、**定款で定めるところにより**次の業務を行うことができます。

1. **2条に規定する業務に準ずるもの**として厚生労働省令で定める業務の全部または一部
2. **紛争解決手続代理業務**

> ★**紛争解決手続代理業務は、社員のうちに特定社会保険労務士がある法人に限り**行うことができます（25条の9第2項）。

## 次に読むもの

### 社員の常駐（25条の16）

> 社会保険労務士法人の事務所には、**その事務所の所在地の属する都道府県**の区域に設立されている**社会保険労務士会の会員である社員**を**常駐**させなければならない。

- 主たる事務所だけでなく、**従たる事務所にも**必要です。
- 常駐させるのは「その**事務所の所在地**の都道府県の社労士会の会員である社員」です。本店所在地の会員ではありません。

> ★**紛争解決手続代理業務**は、**特定社会保険労務士である社員が常駐していない事務所**では取り扱えません（25条の9の2）。25条の16の常駐とは別の話で、こちらは**特定**社労士であることが要ります。

### 社員の競業の禁止（25条の18）

> **1項** 社会保険労務士法人の社員は、**自己若しくは第三者のために**その社会保険労務士法人の業務の範囲に属する業務を行い、又は**他の社会保険労務士法人の社員となつてはならない**。
> **2項** 社員が前項に違反して自己又は第三者のためにその業務を行つたときは、当該業務によつて当該社員又は第三者が**得た利益の額**は、社会保険労務士法人に生じた**損害の額と推定する**。

> ★禁止されるのは「**自己若しくは第三者のため**」の両方です。「第三者のためは駄目だが自己のためならよい」は**誤り**です。
> ★**他の社労士法人の社員になること**も禁止されます。
> ★2項は**損害額の推定**です。「得た利益を返還しなければならない」ではありません。

### 解散（25条の22）

| 解散事由 |
|---|
| 定款に定める理由の発生 |
| **総社員の同意** |
| 他の社会保険労務士法人との**合併** |
| 破産手続開始の決定 |
| 解散を命ずる裁判 |
| 25条の24第1項による**解散の命令**（厚生労働大臣） |
| **社員の欠亡** |

**合併以外**の事由で解散したときは、解散の日から**2週間以内**に、**主たる事務所の所在地の社労士会を経由して連合会に届け出**ます。

> ★解散・清算の監督は**裁判所**が行い、**検査役**を選任できます（会社法の準用）。検査役の選任の裁判には**不服を申し立てることができません**。「2週間以内に上級の裁判所へ控訴できる」は**誤り**です。
> ★裁判所が監督にあたり**厚生労働大臣に意見を求めなければならない**という定めもありません。求めることが**できる**にとどまります。「必ず」は誤りです。
