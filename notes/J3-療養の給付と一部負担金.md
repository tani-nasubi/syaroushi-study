# 療養の給付と一部負担金｜健保の深掘り

### 療養の給付（63条）

被保険者の**疾病・負傷**に関して、次の給付を**現物**で行います。

1. **診察**
2. **薬剤または治療材料**の支給
3. **処置、手術その他の治療**
4. **居宅**における療養上の管理およびその療養に伴う世話その他の看護
5. **病院・診療所への入院**およびその療養に伴う世話その他の看護

**給付されないもの**。

| 除外 | 理由 |
|---|---|
| **食事の提供**である療養（入院時食事療養費で対応） | 別建ての給付 |
| **生活療養**（療養病床に入院する65歳以上）（入院時生活療養費で対応） | 同上 |
| **評価療養・患者申出療養・選定療養**（保険外併用療養費で対応） | 同上 |

> ★**業務災害・通勤災害**は労災保険の対象なので、健保からは給付されません（55条）。
> ★令和4年から、**業務外の事由**であれば**副業・兼業先の業務**によるものも健保の対象です（従来の「業務上」の除外が労災の対象に限定された）。

### 保険医療機関・保険薬局（63条3項・65条）

被保険者は、次のいずれかで療養の給付を受けます。

1. **厚生労働大臣の指定**を受けた病院・診療所（**保険医療機関**）または薬局（**保険薬局**）
2. 特定の保険者が管掌する被保険者に対し療養の給付を行う**健康保険組合が開設する病院・診療所・薬局**
3. **健康保険組合である保険者**が開設する病院・診療所・薬局

| 手続 | |
|---|---|
| 指定 | **厚生労働大臣**が、病院・診療所・薬局の**開設者の申請**により行う |
| 有効期間 | **6年**（**申出がなければ自動更新**される場合がある） |
| 辞退 | **1か月以上の予告期間**を設けて辞退できる |
| 取消し | 厚生労働大臣。取消し後**5年**を経過しないものは再指定を拒否できる |

**保険医・保険薬剤師**は、**厚生労働大臣の登録**を受けた医師・歯科医師・薬剤師です（64条）。指定は「機関」、登録は「人」です。

> ★指定・登録の**取消し・拒否**をするときは、**地方社会保険医療協議会に諮問**しなければなりません。

### 一部負担金（74条）

| 年齢・区分 | 負担割合 |
|---|---|
| **義務教育就学前** | **2割** |
| **義務教育就学後〜70歳未満** | **3割** |
| **70歳以上75歳未満**（一般・低所得者） | **2割** |
| **70歳以上75歳未満**（**現役並み所得者**） | **3割** |

> ★健保の被保険者・被扶養者は**75歳になると後期高齢者医療**に移ります。
> ★「現役並み所得者」は、標準報酬月額**28万円以上**の者（一定の収入基準に該当すれば申請により2割になる場合があります）。

**一部負担金の減免（75条の2）**

保険者は、**災害その他の厚生労働省令で定める特別の事情**により一部負担金を支払うことが困難であると認められる者に対し、次の措置をとることができます。

1. **減額**
2. **支払を免除**
3. 保険医療機関等への支払に代えて、**直接徴収**することとし、その徴収を**猶予**

> ★「しなければならない」ではなく「**とることができる**」（**任意**）です。

### 保険外併用療養費（86条）

| 種類 | 内容 |
|---|---|
| **評価療養** | 先進医療、医薬品・医療機器の**治験**に係る診療、薬事承認後で保険収載前の使用など。**保険導入のための評価**を行うもの |
| **患者申出療養** | 高度の医療技術を用いた療養であって、**患者の申出**に基づき、**未承認薬等**を使用するもの（平成28年創設） |
| **選定療養** | **特別の療養環境**（差額ベッド）、**予約診療**、**時間外診療**、**200床以上**の病院の未紹介患者の初診、制限回数を超える医療行為、**長期収載品**の選定療養（令和6年10月〜）など。**保険導入を前提としない**もの |

基礎的部分は保険給付（保険外併用療養費）、上乗せ部分は**全額自己負担**です。

> ★**選定療養だけが「保険導入を前提としない」**。ここが最頻出です。

### 入院時食事療養費（85条）・入院時生活療養費（85条の2）

| | 対象 | 自己負担 |
|---|---|---|
| **入院時食事療養費** | 入院中の**食事**の提供 | **標準負担額**（一般：1食510円※令和8年度の額は最新の告示による） |
| **入院時生活療養費** | **療養病床に入院する65歳以上**の食事・**居住費** | 標準負担額 |

> ★**標準負担額は高額療養費の対象になりません**。ここが定番の引っかけです。

### 療養費（87条）

**現物給付が困難**であると保険者が認めるとき、または**保険医療機関以外**で診療を受けたことにつき**やむを得ない**と認めるときに、**現金**で支給されます。

| 例 |
|---|
| 保険証を持たずに受診し全額自己負担した |
| 海外で療養を受けた（**海外療養費**） |
| **柔道整復師**、**あん摩マッサージ指圧師・はり師・きゅう師**の施術（医師の同意が必要） |
| **治療用装具**（コルセット等）を購入した |

> ★療養費は**保険者が必要と認めた場合に支給される**もので、**被保険者に請求権があるわけではありません**（「支給することができる」）。

### 他の法令による給付との調整（55条・128条）

> **55条1項** 被保険者に係る療養の給付、入院時食事療養費・入院時生活療養費・保険外併用療養費・療養費・訪問看護療養費・移送費・**傷病手当金**・**埋葬料**・家族療養費・家族訪問看護療養費・家族移送費・家族埋葬料の支給は、**同一の疾病、負傷又は死亡**について、**労働者災害補償保険法・国家公務員災害補償法・地方公務員災害補償法（同法に基づく条例を含む）**によりこれらに相当する給付を受けることができる場合には、**行わない**。

| 相手 | 扱い |
|---|---|
| **労災保険・国家公務員災害補償法・地方公務員災害補償法** | 健保は**行わない**（55条1項）。**「受けることができる場合」**なので、実際に受けたかどうかを問いません |
| **公害健康被害の補償等に関する法律**（公害補償法） | 公害補償法による補償給付が支給された場合、**支給された価額の限度で**、健保の相当する給付は**行わない** |
| **介護保険法** | 訪問看護等が重なる範囲で調整（日雇特例被保険者は128条1項に明記） |
| **他の医療保険各法**（国保を除く） | 日雇特例被保険者について、二重に受けられる場合は**行わない**（128条1項） |

> ★55条は「**受けることができる場合**」です。**請求していなくても**健保からは出ません。ここが引っかけの定番です。
> ★**出産育児一時金・出産手当金**は55条1項の列挙に**入っていません**（業務上の出産という概念がないため）。日雇特例被保険者の128条には入っています。
> ★保険者は、傷病手当金の支給にあたって必要があるときは、**労災の保険者等に資料の提供を求める**ことができます（55条2項）。

### 交通事故（第三者行為災害）と自賠責保険

自動車事故によるけがは**第三者の行為による傷病**なので、原則として**加害者が賠償**します。ただし健康保険を使うこともできます。

| 場面 | 扱い |
|---|---|
| 通常 | **自賠責保険が先**。健康保険を使ったときは、保険者が**第三者に対して求償**する（57条） |
| **加害者が不明のひき逃げ**、自賠責の**補償の範囲を超える**賠償義務が生じた場合 | **被害者の加入する医療保険の保険者が給付を行う** |
| 手続 | **第三者の行為による傷病届**を保険者に提出する |
| 示談 | 示談が成立し賠償を受けたときは、その**限度で保険給付を行わない**（57条） |

> ★「業務外」であれば健康保険の対象です。**通勤中の事故は労災**なので健康保険からは給付されません。
