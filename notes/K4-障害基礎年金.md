# 障害基礎年金｜国年の深掘り

### 3つの請求のかたち

| 種類 | 条 | 内容 |
|---|---|---|
| **障害認定日**による請求 | 30条 | 障害認定日に**1級・2級**の障害の状態にあること |
| **事後重症**による請求 | 30条の2 | 障害認定日に該当しなかったが、その後**65歳に達する日の前日**までに該当したとき。**請求した日**に受給権が発生 |
| **基準障害**（初めて2級） | 30条の3 | 基準傷病以外の障害と**併合して初めて2級以上**になったとき |
| **20歳前傷病**による障害基礎年金 | 30条の4 | **初診日が20歳前**（国民年金の被保険者でない期間）にある場合 |

### 障害認定日（30条1項）

**初診日から起算して1年6か月**を経過した日、またはその期間内に**治った日**（症状が固定し治療の効果が期待できない状態に至った日を含む）。

**特例**（1年6か月を待たない）。

| 事由 | 認定日 |
|---|---|
| **人工透析**を行っている | 透析開始から**3か月**を経過した日 |
| **人工骨頭・人工関節**の挿入置換 | **挿入置換した日** |
| **心臓ペースメーカー・ICD・人工弁**の装着 | **装着した日** |
| **人工肛門・新膀胱**の造設 | 造設した日から**6か月**を経過した日 |
| **切断・離断**による肢体の障害 | **切断・離断した日** |
| **喉頭全摘出** | **摘出した日** |
| **在宅酸素療法**を開始 | **開始した日** |
| **遷延性植物状態** | その状態に至った日から**3か月**を経過した日 |

### 保険料納付要件（30条1項但書）

**初診日の前日**において、初診日の属する月の**前々月**までに、

- **保険料納付済期間＋保険料免除期間**が、被保険者期間の**3分の2以上**あること

**特例**（令和8年3月31日までに初診日がある場合）：初診日の属する月の前々月までの**直近1年間**に保険料の未納がないこと（**65歳未満**であること）。

> ★**「初診日の前日において」**という表現が重要です。初診日以後に慌てて納付しても納付要件を満たしません。
> ★**20歳前傷病**による障害基礎年金には**保険料納付要件がありません**。

### 年金額（33条）

| 等級 | 額 |
|---|---|
| **1級** | 2級の額 × **1.25** |
| **2級** | **老齢基礎年金の満額**と同額 |

**子の加算額**（33条の2）：**18歳到達年度の末日までの子**、または**20歳未満で障害等級1級・2級**の子がいるとき。

| 子 | 加算額 |
|---|---|
| **1人目・2人目** | 各**224,700円 × 改定率** |
| **3人目以降** | 各**74,900円 × 改定率** |

> ★障害基礎年金の子の加算は、**受給権発生後に生まれた子**についても加算されます（平成23年4月から）。遺族基礎年金の「死亡当時」とは違います。

### 20歳前傷病による障害基礎年金（30条の4）

**初診日が20歳前**（国民年金の被保険者でない期間）にある場合、**20歳に達した日**（障害認定日が20歳到達後ならその日）に受給権が発生します。

**保険料を納めていないため、次の支給停止があります**（36条の3・36条の4）。

| 事由 | 停止 |
|---|---|
| **所得**が政令で定める額を超えるとき | **10月から翌年9月**まで、全部または2分の1を停止 |
| **恩給法等による給付**を受けるとき | 停止 |
| **日本国内に住所を有しない**とき | 停止 |
| **刑事施設・労役場等に拘禁**されているとき | 停止 |
| **少年院等に収容**されているとき | 停止 |

> ★**所得制限があるのは20歳前傷病による障害基礎年金だけ**です。通常の障害基礎年金には所得制限がありません。
> ★**国内居住要件**があるのも20歳前傷病だけです。

### 併合・改定・失権

| 事由 | 効果 |
|---|---|
| **併合認定**（31条） | 2以上の障害基礎年金の受給権が発生したとき、**前後の障害を併合**した障害の程度による新たな受給権が発生し、**従前の受給権は消滅** |
| **額の改定**（34条） | 厚生労働大臣は**職権**で改定できる。受給権者は**改定請求**ができる（**受給権取得日または診査を受けた日から1年**を経過した後。ただし障害の程度が**明らかに増進**した場合は1年待たずに請求可） |
| **支給停止**（36条） | **障害の程度が3級以下**になったとき（**65歳に達した日以後、かつ3年経過**で失権） |
| **失権**（35条） | **死亡**したとき、**併合認定**により新たな受給権を取得したとき、**障害等級に該当しなくなって3年**を経過し、かつ**65歳**に達したとき |

> ★3級に下がっても**すぐには失権しません**。「**65歳到達**」と「**該当しなくなって3年経過**」の**両方**を満たしたときに失権します。

### 特別障害給付金

**国民年金に任意加入していなかった**ために障害基礎年金を受けられない者への福祉的措置です。

| 対象 | ① 平成3年3月以前の**学生**、② 昭和61年3月以前の**被用者年金加入者の配偶者** |
|---|---|
| 額 | 1級 **月額2級の1.25倍**、2級 障害基礎年金2級の**約2分の1**（令和8年度の額は告示による） |
| 財源 | **全額国庫負担**（年金ではなく給付金） |

> ★所得制限があります。**障害基礎年金とは別制度**です。
