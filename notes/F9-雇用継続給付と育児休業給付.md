# 雇用継続給付と育児休業給付｜雇用の深掘り

令和2年の改正で**育児休業給付は失業等給付から独立**しました。現在の体系は次のとおりです。

| 分類 | 給付 |
|---|---|
| **雇用継続給付**（失業等給付） | **高年齢雇用継続給付**／**介護休業給付** |
| **育児休業等給付**（独立） | **育児休業給付金**／**出生時育児休業給付金**／**出生後休業支援給付金**／**育児時短就業給付金** |

> ★育児休業給付は**失業等給付ではありません**。保険料率も別建て（育児休業給付費充当分1000分の5）です。

### 高年齢雇用継続給付（61条）★令和7年4月改正

| 種類 | 対象 |
|---|---|
| **高年齢雇用継続基本給付金** | 基本手当を受けずに継続雇用されている者 |
| **高年齢再就職給付金** | 基本手当を受給後、支給残日数**100日以上**を残して再就職した者 |

| 要件 | |
|---|---|
| 年齢 | **60歳以上65歳未満** |
| 被保険者であった期間 | **5年以上** |
| 賃金 | 60歳到達時等の賃金月額に比べて**75%未満**に低下したこと |

```
支給額 ＝ 支給対象月の賃金額 × 最大10%（令和7年3月までは15%）
```

賃金の低下率が**64%以下**のとき最大率、**64%超75%未満**では逓減します。

> ★令和7年4月1日から**15%→10%**に引き下げられました。低下率の境目も**61%→64%**に変わっています。
> ★支給対象月の賃金額と給付額の合計が**支給限度額**を超えるときは、超えた分が減額されます。

**高年齢再就職給付金の支給期間**

| 基本手当の支給残日数 | 支給期間 |
|---|---|
| **200日以上** | **2年**（65歳に達する月まで） |
| **100日以上200日未満** | **1年**（同上） |

> ★**再就職手当**と**高年齢再就職給付金**は**どちらか一方**を選択します。両方は受けられません。
> ★高年齢雇用継続給付を受けると、**在職老齢年金がさらに最大6%停止**されます（厚年との調整）。

### 介護休業給付（61条の4）

| 要件 | |
|---|---|
| 対象家族 | **配偶者（事実婚を含む）・父母・子・配偶者の父母・祖父母・兄弟姉妹・孫** |
| 状態 | **2週間以上**にわたり常時介護を必要とする状態 |
| 被保険者期間 | 休業開始日前**2年間に賃金支払基礎日数11日以上**の月が**12か月以上** |
| 期間 | 対象家族**1人につき通算93日**を限度に**3回**まで分割可 |

```
支給額 ＝ 休業開始時賃金日額 × 支給日数 × 67%
```

> ★育児と違い**67%のまま**（段階的な引下げはありません）。
> ★休業期間中に賃金が支払われた場合、賃金額が休業開始時賃金月額の**80%以上**なら不支給、**13%超80%未満**なら差額調整されます。

### 育児休業給付金（61条の7）

| 要件 | |
|---|---|
| 被保険者期間 | 休業開始日前**2年間に賃金支払基礎日数11日以上**（または就業時間80時間以上）の月が**12か月以上** |
| 対象 | **1歳未満**の子（一定の場合は**1歳2か月・1歳6か月・2歳**まで延長） |

```
支給額 ＝ 休業開始時賃金日額 × 支給日数 ×
　　　　　67%（休業開始から通算180日まで）／50%（181日目以後）
```

| 延長事由 | 上限 |
|---|---|
| **パパ・ママ育休プラス** | **1歳2か月**（1人あたりの上限は1年） |
| 保育所に入れない等 | **1歳6か月** → さらに**2歳** |

> ★支給単位期間中に**就業した日数が10日以下**（10日を超える場合は就業時間が80時間以下）であることが必要です。

### 出生時育児休業給付金（61条の8）

**産後パパ育休**（出生時育児休業）に対応する給付です。

| | |
|---|---|
| 期間 | 子の出生後**8週間以内**に**通算28日**を限度 |
| 分割 | **2回**まで |
| 率 | 休業開始時賃金日額 × 支給日数 × **67%** |

支給された日数は、育児休業給付金の**67%の期間（180日）に通算**されます。

### 出生後休業支援給付金（令和7年4月創設）

| 要件 | 被保険者**とその配偶者の双方**が、子の出生直後の一定期間に**14日以上**の育児休業を取得したこと |
|---|---|
| 率 | **13%**（最大**28日**） |
| 効果 | 育児休業給付67%と合わせて**80%**＝社会保険料免除と非課税を考慮すると**手取り10割相当** |

> ★配偶者が**いない**場合、配偶者が**育児休業を取得できない**場合（自営業、ひとり親等）は、**配偶者の要件が不要**になります。

### 育児時短就業給付金（令和7年4月創設）

| 要件 | **2歳未満**の子を養育するために**時短勤務**をしていること |
|---|---|
| 率 | 時短勤務中に支払われた**賃金額の10%** |
| 調整 | 賃金と給付の合計が時短前の賃金を超えないよう調整 |

> ★育児休業給付金や出生時育児休業給付金を受けている月は支給されません。

### 雇用保険二事業（62条・63条）

失業等給付とは別に、**事業主のみが負担する保険料**（二事業費充当分1000分の3.5）でまかなわれます。

| 事業 | 内容 |
|---|---|
| **雇用安定事業**（62条） | **雇用調整助成金**、労働移動支援助成金、特定求職者雇用開発助成金、**両立支援等助成金**、65歳超雇用推進助成金など |
| **能力開発事業**（63条） | 職業訓練の実施、**人材開発支援助成金**、公共職業能力開発施設の設置運営、技能検定の援助 |

**雇用調整助成金**は、**景気の変動、産業構造の変化その他の経済上の理由**により事業活動の縮小を余儀なくされた事業主が、**休業・教育訓練・出向**によって雇用を維持した場合に、休業手当等の一部を助成するものです。

> ★二事業は**事業主だけが負担**するので、**労働者は受給できません**（助成金は事業主に支給されます）。
> ★**求職者支援制度**（求職者支援法）の**職業訓練受講給付金**は、雇用保険の**被保険者でない求職者**が対象で、**国庫負担と雇用保険料**でまかなわれます。
