# 労働者性｜労基の深掘り

### なぜ争いになるか

労基法の保護を受けるかどうかが決まるからです。**契約の名称（請負・委任）ではなく実態**で判断します。

### 判断の枠組み（使用従属性）

| 要素 | 具体的な判断材料 |
|---|---|
| **指揮監督下の労働** | ① 仕事の依頼・業務従事の指示等に対する**諾否の自由**の有無 ② 業務遂行上の**指揮監督**の有無 ③ **時間的・場所的な拘束**の有無 ④ **代替性**の有無 |
| **報酬の労務対償性** | 報酬が**時間給を基礎として計算される**等、労務の対価としての性格が強いか |
| 補強要素 | **事業者性**（機械・器具の負担、報酬の額）、**専属性**の程度、**公租公課の負担** |

### 具体例

| 事例 | 結論 |
|---|---|
| 自己所有のトラックで運送する運転手 | 労働者性を**否定** |
| 工務店の大工 | 労働者性を**否定** |
| 研修医 | 病院の指揮監督下で医療行為に従事する以上、**労働者に当たる** |

**判示のキーワード**：「諾否の自由」「時間的、場所的な拘束」「報酬の支払方法、公租公課の負担」

### 判断の枠組み（昭和60年労働基準法研究会報告）

労基法9条の「労働者」に当たるかは、**使用従属性**があるかで判断します。

| 大区分 | 判断要素 |
|---|---|
| **① 指揮監督下の労働** | ⓐ 仕事の依頼・業務従事の指示等に対する**諾否の自由**の有無<br>ⓑ 業務遂行上の**指揮監督**の有無<br>ⓒ **勤務場所・勤務時間の拘束性**の有無<br>ⓓ **代替性**の有無（他人による代替が可能か） |
| **② 報酬の労務対償性** | 報酬が**時間給を基礎として計算される**など、労働の対償といえるか |
| **補強要素** | ⓔ **事業者性**（機械・器具の負担、報酬の額）<br>ⓕ **専属性**の程度<br>ⓖ **公租公課**の負担（源泉徴収、社会保険の加入） |

> ★**契約の名称（請負・委任）ではなく実態**で判断します。
> ★①②が**基本的な判断要素**、ⓔ〜ⓖは**判断が困難な場合の補強要素**です。

### 最高裁の結論

| 事案 | 結論 | 決め手 |
|---|---|---|
| **横浜南労基署長（旭紙業）事件**（トラック運転手） | **労働者でない** | 自己所有のトラックを持ち込み、運送以外の指揮監督を受けず、報酬も出来高。**時間的・場所的拘束が一般の従業員と比べ緩やか** |
| **藤沢労基署長（大工）事件** | **労働者でない** | 工具は自前、報酬は出来高、他の工務店の仕事もしていた |
| **関西医科大学研修医事件** | **労働者である** | 病院の指揮監督の下に医療行為に従事し、奨学金等の支給を受けていた |
| **新国立劇場運営財団事件**（合唱団員） | **労働組合法上の労働者である** | 労組法の労働者性は労基法より**広く**判断される |

> ★**労基法の労働者**と**労組法の労働者**は範囲が違います。労組法のほうが**広い**です。

### 労働者に当たるか（個別）

| 対象 | 結論 |
|---|---|
| **法人の役員** | 原則として労働者でない。**兼務役員**（部長等の職務を兼ねる）は、その部分について労働者 |
| **同居の親族**のみを使用する事業の親族 | **適用除外**（116条2項） |
| **家事使用人** | **適用除外**（116条2項）。ただし**家政婦紹介所から派遣され事業に使用される者**は労働者 |
| **インターンシップの学生** | 見学・体験が主なら労働者でない。**直接生産活動に従事し、その作業による利益・効果が事業場に帰属**するなら労働者 |
| **形式上は請負でも実質的に指揮命令下にある者** | 労働者 |

> ★令和6年11月から、**家事使用人**についても労働基準関係法令の保護のあり方が見直しの対象となっています。

### 使用者（10条）

> この法律で使用者とは、**事業主**または**事業の経営担当者**その他その事業の労働者に関する事項について、**事業主のために行為をするすべての者**をいう。

**実質的に権限を持っているか**で判断されます。名称にかかわらず、**部長・課長でも実質的な権限があれば使用者**であり、**権限がなければ使用者でない**とされます。

> ★労基法違反の責任は、**実際に違反行為をした者**（使用者）と、**事業主**の両方に及びます（**両罰規定**・121条）。
> ★事業主が違反の防止に必要な措置をした場合は、事業主は罰されません（121条1項ただし書）。
