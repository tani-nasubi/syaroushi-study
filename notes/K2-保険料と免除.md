# 保険料と免除｜国年の深掘り

### 保険料（87条）

**第1号被保険者**だけが納付します（第2号・第3号は**個別に納める必要がありません**）。

```
保険料月額 ＝ 保険料の基準額（17,000円※平成16年度価格）× 保険料改定率
```

**保険料改定率**は、名目賃金変動率に応じて毎年度改定されます。

| | |
|---|---|
| 納期限 | **翌月末日** |
| 納付義務者 | **被保険者本人**。**世帯主**および**配偶者**は**連帯して**納付義務を負う（88条2項・3項） |
| 時効 | **2年**（102条4項） |

> ★第2号・第3号の分は、厚生年金保険から**基礎年金拠出金**としてまとめて拠出されます。第3号被保険者は保険料を払わずに納付済期間になります。

### 前納と追納

| | 前納（93条） | 追納（94条） |
|---|---|---|
| 内容 | **将来**の期間の保険料を先に納める | **免除等を受けた期間**の保険料を後から納める |
| 割引・加算 | **政令で定める額を控除**（割引） | **3年度目以降**は加算額が上乗せ |
| 期間 | 最大**2年分** | 承認の日の属する月**前10年以内** |
| 承認 | 不要 | **厚生労働大臣の承認**が必要 |

> ★追納は**10年以内**。「2年以内」は保険料の時効と混同したものです。
> ★追納した期間は**保険料納付済期間**になります（免除の種類にかかわらず）。
> ★追納は**先に経過した期間から**行います（古いものから）。

### 法定免除（89条）

次に該当すると、**届出により**（該当した日の属する月の前月から）保険料が**免除されます**。

1. **障害基礎年金**または**障害厚生年金（1級・2級）**等の受給権者であるとき
2. **生活保護法の生活扶助**その他厚生労働省令で定める扶助を受けるとき
3. **国立ハンセン病療養所等**に入所しているとき

> ★**申請ではなく法定**です。要件に該当すれば当然に免除されます（届出は確認のため）。
> ★平成26年4月から、法定免除に該当する期間についても、**本人が申し出れば保険料を納付できます**。
> ★障害基礎年金の受給権者でも、**3級の障害厚生年金のみ**の受給権者は法定免除になりません。

### 申請免除（90条・90条の2）

**本人・配偶者・世帯主**の**前年所得**が一定以下である場合などに、**申請**して**厚生労働大臣の承認**を受けます。

| 種類 | 所得基準（4人世帯の目安） |
|---|---|
| **全額免除** | （扶養親族等の数＋1）×35万円＋32万円 |
| **4分の3免除** | 88万円＋扶養親族等控除額等 |
| **半額免除** | 128万円＋同上 |
| **4分の1免除** | 168万円＋同上 |

> ★**本人・配偶者・世帯主の3者すべて**が基準以下である必要があります。1人でも超えると免除されません。
> ★所得基準以外に、**失業・事業の廃止・天災**等による免除もあります（所得を問わない）。
> ★申請免除は**過去2年1か月前**までさかのぼって申請できます。

### 学生納付特例（90条の3）・納付猶予（附則）

| | 学生納付特例 | 納付猶予 |
|---|---|---|
| 対象 | **大学・専門学校等の学生**（夜間・通信を含む） | **50歳未満**の者 |
| 所得を見る者 | **本人のみ** | **本人と配偶者**（世帯主は見ない） |
| 老齢基礎年金 | **受給資格期間に算入／年金額に反映されない** | 同左 |
| 障害・遺族基礎年金 | **保険料納付済期間と同様に扱われる** | 同左 |

> ★**世帯主（親）の所得を見ない**のが学生納付特例の最大の特徴です。
> ★納付猶予は令和12年6月までの時限措置です。

### 産前産後期間の免除（88条の2）

**第1号被保険者**が出産した場合、**出産予定月の前月から4か月間**（多胎妊娠は**出産予定月の3か月前から6か月間**）の保険料が免除されます。

> ★この期間は**保険料納付済期間として年金額に反映されます**（他の免除と違い、満額扱い）。ここが最頻出です。
> ★届出は**出産予定日の6か月前**から可能です。

### 年金額への反映

| 期間 | 老齢基礎年金への反映 |
|---|---|
| **保険料納付済期間** | **1** |
| **産前産後免除期間** | **1**（全額反映） |
| **全額免除** | **2分の1**（平成21年3月以前は3分の1） |
| **4分の3免除**（4分の1納付） | **8分の5**（同 2分の1） |
| **半額免除**（半額納付） | **4分の3**（同 3分の2） |
| **4分の1免除**（4分の3納付） | **8分の7**（同 6分の5） |
| **学生納付特例・納付猶予** | **反映されない**（受給資格期間には算入） |
| **合算対象期間**（カラ期間） | **反映されない**（受給資格期間には算入） |

> ★分母は**国庫負担2分の1**の反映です。平成21年4月から国庫負担が3分の1→2分の1になったため、それ以前と分数が変わります。
> ★一部免除は、**残りの保険料を納付しなければ「未納」扱い**になります。免除されただけでは反映されません。

### 督促・延滞金（96条・97条）

| | |
|---|---|
| 督促 | 厚生労働大臣は、**期限を指定して督促**できる。督促状の指定期限は発する日から**10日以上**経過した日 |
| 滞納処分 | 督促を受けた者が指定期限までに納付しないときは、**国税滞納処分の例**による（厚生労働大臣は**財務大臣に委任**できる） |
| 延滞金 | 年**14.6%**（納期限の翌日から**3か月**を経過する日までは年**7.3%**） |

> ★国年の延滞金は**3か月**、健保・厚年・徴収法は**2か月**。ここが違います。

### 原簿・訂正請求・番号（14条・14条の2）

厚生労働大臣は**国民年金原簿**を備え、氏名・資格の取得喪失・**種別の変更**・**保険料の納付状況**・**基礎年金番号**その他を記録します。

被保険者・被保険者であった者は、**特定国民年金原簿記録**が事実でない、または記録がないと思料するときは、**厚生労働大臣に訂正の請求**ができます（14条の2）。

> ★**時効消滅不整合期間**（第3号被保険者の記録不整合により時効で保険料を納められなくなった期間）には、**特定期間該当届**と**特定保険料の納付**の特例があります。

### 納付の受託（92条の3〜92条の5）

次の者が、被保険者の**委託**を受けて保険料の納付事務を行えます。

1. **国民年金基金**または**国民年金基金連合会**（加入員に限る）
2. 納付事務を適正かつ確実に実施できると認められ、政令で定める要件に該当する者として**厚生労働大臣が指定**するもの（コンビニ等の**納付受託者**）

**保険料納付確認団体**（109条の3）は、被保険者の委託により**納付状況を確認**し、**納付を勧奨**する団体で、**厚生労働大臣が指定**します。

> ★**収納職員**（市町村の職員等）が保険料を収納する場合もあります。

### 国民年金基金（115条〜）

| | |
|---|---|
| 種類 | **地域型**（都道府県ごと→現在は**全国国民年金基金**）と**職能型**（同種の事業・業務に従事する者） |
| 加入できる者 | **第1号被保険者**および**任意加入被保険者**（**保険料免除者・滞納者は加入できない**） |
| 加入 | **口数制**。1口目は**終身年金**でなければならない |
| 脱退 | **任意に脱退できない**（第1号被保険者でなくなった等の場合に資格喪失） |
| **代議員会** | 基金の議決機関 |
| 掛金の上限 | 月額**68,000円**（**付加保険料・iDeCo**と合算） |

> ★国民年金基金の加入員は**付加保険料を納付できません**（基金の1口目に付加年金相当分が含まれるため）。
> ★**年金積立金管理運用独立行政法人（GPIF）**が年金積立金の管理運用を行います（厚年法79条の2〜、国年法76条）。
