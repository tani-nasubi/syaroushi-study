# 労働統計と実態調査｜労一の深掘り

## なぜ独立させたか

過去9年の一般常識を数えたところ、**労一の択一41問のうち23問（56%）が統計・実態調査**でした。**選択式はさらに高く9年中6回（67%）**です。ところが資料は法令に偏っていて、深掘りページは労働契約法・労働組合法・派遣法・均等法・高年齢者の**5本すべてが法令**、統計は`99-白書・統計.md`の1本だけ。分量にすると法令20,829字に対して統計4,626字で、**出題比率と逆**でした。

> ★**社一は「択一では法令、統計は選択式」**とはっきり分かれます。社一の択一49問のうち統計は2問（4%）ですが、**選択式は9年中5回（56%）が統計**です。しかも労一とは性質が違い、**毎年同じ顔ぶれの社会保障財政統計**なので、そちらは覚える価値があります（→ [`I5-社会保障の統計と財政.md`](I5-社会保障の統計と財政.md)）。

## 1. 出題の定位置

| 問 | 近年の枠（令和3〜7年度） |
|---|---|
| **問1〜3** | **統計・実態調査**（毎年2〜3問） |
| **問4** | 労働契約法等・労働関係法規（法令の横断） |
| 問5 | 社会保険労務士法（ここから社一） |
| 問6〜10 | 社会保険の各法令 |

> ★労一と社一の**問数は固定ではありません**。平成29・30年度は労一6問／社一4問でしたが、令和3年度以降は**労一4問／社一6問**に寄っています。統計の位置（問1〜3）は9年を通じて変わっていません。

**問1〜3を白紙にすると、一般常識択一10問中3問を捨てることになります。** 基準点（例年4点）に対して余裕がなくなるので、「捨てる」判断は成り立ちません。ただし**数値の暗記は不要**です。理由は次のとおりです。

## 2. どの調査が出るかには規則性がある

過去9年で参照された調査を、**出題年と調査年の差**で並べたものです。

| 出題年 | 問 | 参照された調査 | ラグ |
|---|---|---|---|
| 令和7 | 1 | 令和5年 外国人雇用実態調査 | **2年** |
| 令和7 | 2 | 令和5年度 障害者雇用実態調査 | **2年** |
| 令和7 | 3 | 令和4年 派遣労働者実態調査 | **3年** |
| 令和6 | 1 | 令和4年 労働安全衛生調査（実態調査） | **2年** |
| 令和6 | 2 | 令和4年 労使間の交渉等に関する実態調査 | **2年** |
| 令和6 | 9 | 令和5年版 厚生労働白書 | 1年 |
| 令和5 | 1 | 令和3年度 雇用均等基本調査 | **2年** |

| 令和4 | 2 | 令和3年 就労条件総合調査 | 1年 |
| 令和4 | 3 | 令和2年 転職者実態調査 | **2年** |

> ★**令和8年度（第58回）に使われるのは、令和5年・令和6年に実施された調査**です。令和7年の調査はまだ公表が間に合いません。

## 3. 「雇用の構造に関する実態調査」は一つのシリーズ

労一の統計問題で頻出する次の4つは、**別々の調査ではなく、同じ調査のテーマ違い**です。

> 雇用の構造に関する実態調査は、**その時々の雇用情勢に応じたテーマ**（若年者、派遣労働者、パートタイム労働者等）について、**事業所側、労働者側の双方から意識面を含めて**把握し、雇用政策の推進等に資することを目的として実施している調査
> （厚生労働省）

| テーマ | 実施年 | 周期 |
|---|---|---|
| **若年者雇用実態調査** | 平成17・21・25・30・**令和5** | 4〜5年おき（不定期） |
| **派遣労働者実態調査** | 平成16・20・24・29・**令和4** | 4〜5年おき（不定期） |
| **パートタイム・有期雇用労働者総合実態調査** | 平成28・**令和3** | 5年おき |
| **就業形態の多様化に関する総合実態調査** | 平成26・**令和元** | 5年おき |

- **事業所調査と個人（労働者）調査の2本立て**です。設問文に「（事業所調査）」と書かれていたら、聞かれているのは**事業所側の回答**です。個人側の数字とは違います。
- テーマが持ち回りなので、**同じテーマは9年に1〜2回しか出ません**。だから個別の数値を覚えても再利用が効きません。

> ★令和5年に**若年者雇用実態調査**が実施されています（前回は平成30年）。令和7年度には使われなかったので、**令和8年度の候補**です。

## 4. 調査カタログ — 「何を測る調査か」

数値を覚えていなくても、**どの調査が何を測るか**を知っていれば消去法が効きます。実態調査系は`99-白書・統計.md`に載っていなかったので、ここにまとめます。

### 毎年やっている調査

| 調査 | 実施 | 測るもの |
|---|---|---|
| **労働力調査** | **総務省**・毎月 | 完全失業率、就業者数、労働力人口、労働力率 |
| **毎月勤労統計調査** | 厚労省・毎月 | 現金給与総額、**実質賃金**、労働時間、常用雇用指数 |
| **賃金構造基本統計調査** | 厚労省・年1回 | 男女間賃金格差、年齢階級別賃金カーブ、企業規模別賃金 |
| **就労条件総合調査** | 厚労省・年1回 | **年次有給休暇の取得率**、所定労働時間、賃金制度、退職給付制度 |
| **雇用動向調査** | 厚労省・年2回 | 入職率・離職率、転職入職者の状況 |
| **能力開発基本調査** | 厚労省・年1回 | 教育訓練費、**OFF-JT**、自己啓発の実施状況 |
| **雇用均等基本調査** | 厚労省・年1回 | **育児休業取得率**、女性管理職割合、コース別雇用管理 |
| **労働組合基礎調査** | 厚労省・年1回 | **推定組織率**、組合員数、パート組合員 |
| **労働安全衛生調査（実態調査）** | 厚労省・年1回 | **ストレスチェック実施率**、メンタルヘルス対策、受動喫煙対策 |
| **労使間の交渉等に関する実態調査** | 厚労省・年1回 | 団体交渉の状況、労働争議、労使協議機関の有無 |

### 数年おきの調査

| 調査 | 周期 | 測るもの |
|---|---|---|
| **障害者雇用実態調査** | **5年ごと** | 障害種別の雇用者数、職業、賃金、雇用上の課題 |
| **外国人雇用実態調査** | 不定期（令和2・令和5） | 外国人労働者の在留資格別・職種別の状況、賃金 |
| **転職者実態調査** | 5年おき | 転職の理由、転職後の賃金・満足度 |
| **若年者雇用実態調査** | 4〜5年おき | 若年労働者の育成方針、定着状況、採用で重視した点 |
| **派遣労働者実態調査** | 4〜5年おき | 派遣先の受入れ状況、待遇情報の提供、派遣労働者の意識 |
| **パートタイム・有期雇用労働者総合実態調査** | 5年おき | 均衡・均等待遇の状況、説明義務の履行 |
| **就業形態の多様化に関する総合実態調査** | 5年おき | 正社員以外の労働者の割合・活用理由 |

> ★**引っかけの定番は「調査名と指標の入れ替え」**です。「完全失業率＝毎月勤労統計」は誤り（**労働力調査**）。「有給休暇の取得率＝毎月勤労統計」も誤り（**就労条件総合調査**）。
> ★**労働力調査だけが総務省**です。ほかは厚生労働省。**男女共同参画白書は内閣府**（平成29年に出題）。

## 5. 知らない調査でも解ける — 消去法の型

実態調査は9年に1〜2回しか回ってこないので、**初見で解くのが前提**です。誤り肢の作られ方には型があります。

| 型 | 見分け方 |
|---|---|
| **順位の入れ替え** | 「最も高いのは◯◯、次いで△△」の順を入れ替える。**常識的に多いほうが1位**であることがほとんど |
| **極端な断定** | 「すべての事業所で」「一貫して増加している」。実態調査でこの書き方はまず誤り |
| **桁違いの割合** | 「9割を超える」「1割に満たない」。**実態調査の割合は5〜7割に集まりやすい** |
| **主体の入れ替え** | 事業所調査の数字を「労働者の◯%が」と書く。設問文の**（事業所調査）／（個人調査）**を確認する |
| **調査名と指標の不一致** | 上のカタログで確認 |

### 迷ったときの拠りどころ

- **規模が大きい事業所ほど、制度は整っている**（教育訓練、育児支援、労働組合、退職給付）。「小規模のほうが実施率が高い」はまず誤り。
- **正社員のほうが、正社員以外より処遇・訓練機会が手厚い**。
- **「取組がある」「制度がある」の割合は、実際の「利用している」割合より高い**。
- 「課題がある」「困っている」を聞く設問は、**6割前後**に集まる。

> ★これらは統計の中身ではなく**調査というものの性質**なので、どの調査でも同じように効きます。

## 6. 令和8年度に向けて

**やること**

1. 上のカタログで**調査名と指標の対応**を覚える（30分）
2. `99-白書・統計.md`で**令和7年版の白書の副題と主要数値**を押さえる（選択式対策。ここは暗記の価値がある）
3. 消去法の型を頭に入れる

**やらないこと**

- 個別の調査の実数を覚える（次に同じ調査が出るのは4〜5年後）
- 過去問に出た年度の数値を追う（すでに古い）

> ★労一・社一は9年中4回ずつ基準点が補正されています（→ [`92-選択式の解き方.md`](92-選択式の解き方.md)）。**労一の択一の統計**は、この救済が効く可能性がある領域なので、投じる時間は上の3つまででかまいません。
> ★ただし**社一の選択式の統計は別**です。そちらは9年中5回出ていて、しかも**毎年同じ顔ぶれ**なので覚えれば得点になります（→ [`I5-社会保障の統計と財政.md`](I5-社会保障の統計と財政.md)）。同じ「統計」でも扱いを分けてください。

## 直前チェック

- [ ] **労働力調査は総務省**。ほかの労働統計は厚生労働省

- [ ] **障害者雇用実態調査は5年ごと**
- [ ] 出題されるのは**2〜3年前の調査**。白書だけ1〜2年前
- [ ] （事業所調査）と（個人調査）で数字が違う
- [ ] 「すべての」「一貫して」は誤り肢の合図
