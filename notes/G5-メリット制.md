# メリット制｜徴収の深掘り

### 趣旨

災害の発生状況に応じて**労災保険率**（または保険料額）を増減し、**保険料負担の公平**と**災害防止努力の促進**を図る制度です。

> ★**雇用保険率には適用されません**。労災保険率だけです。最頻出の引っかけです。
> ★増減するのは**労災保険率から非業務災害率（1000分の0.6）を減じた率**の部分です。非業務災害率の部分は増減しません。

### 収支率

```
　　　　　保険給付の額 ＋ 特別支給金の額
収支率 ＝ ──────────────────────── × 100
　　　　　　　保険料の額 × 調整率
```

**100分の85を超える**か、**100分の75以下**であるときに増減されます（12条3項）。

分子に含まれないもの（**業務災害以外**は入りません）。

- **通勤災害**に関する保険給付
- **二次健康診断等給付**
- **第三種特別加入者**（海外派遣者）に係る保険給付
- 特定の**遺族補償一時金**（労災法16条の6第1項2号の場合）
- **療養開始後3年**を経過した日以後の**傷病補償年金・障害補償年金**等（一定のもの）

### 継続事業のメリット制（12条3項）

**連続する3保険年度**の各保険年度において次のいずれかに該当し、かつ**最後の保険年度の3月31日（基準日）において労災保険の保険関係が成立した後3年以上**経過していることが要件です。

| 号 | 規模要件 |
|---|---|
| 1号 | **100人以上**の労働者を使用する事業 |
| 2号 | **20人以上100人未満**の労働者を使用する事業であって、労働者数×（労災保険率−非業務災害率）が**0.4以上**（**災害度係数**） |
| 3号 | **一括有期事業**（建設・立木の伐採）であって、確定保険料の額が**40万円以上** |

適用されるのは、**基準日の属する保険年度の次の次の保険年度**の労災保険率です。

増減幅は**100分の40**の範囲内です（建設の事業・立木の伐採の事業で確定保険料が一定額未満のものは**100分の30**の範囲内）。

> ★「連続する3保険年度」＋「成立後3年以上」＋「**次の次の**保険年度から適用」。3つの「3」に注意します。

### 有期事業のメリット制（20条）

**一括されていない単独の有期事業**が対象です。

| 要件 | |
|---|---|
| **建設**の事業 | 確定保険料の額が**40万円以上**、または請負金額（消費税抜き）**1億1,000万円以上** |
| **立木の伐採**の事業 | 確定保険料の額が**40万円以上**、または素材の生産量**1,000立方メートル以上** |

事業が**終了した日から3か月**を経過した日前の状況で収支率を算定し、**確定保険料の額そのもの**を100分の40の範囲内で増減します（率ではなく額を増減する点が継続事業と違います）。

### 特例メリット制（12条の2）

**中小事業主**が**労働者の安全・衛生を確保するための措置**を講じた場合の上乗せです。

| 要件 | |
|---|---|
| 規模 | 常時**100人未満**（金融業・保険業・不動産業・小売業は50人以下、卸売業・サービス業は100人以下という事務組合委託の規模とは別の基準） |
| 措置 | 厚生労働省令で定める**安全衛生措置**を講じたこと |
| 申告 | 措置を講じた保険年度の**次の保険年度の初日から6か月以内**に申告 |

増減幅が**100分の45**に拡大されます。

> ★通常のメリット制が**±40%**、特例メリット制が**±45%**。この5ポイントの差が問われます。

### 調整率

収支率の分母に掛ける率です。

| 区分 | 率 |
|---|---|
| **第一種調整率**（継続事業） | 事業の種類により定められる |
| **第二種調整率**（有期事業） | 立木の伐採の事業 **100分の43**／建設の事業 **100分の63**／港湾貨物取扱・港湾荷役 **100分の63**／船舶所有者の事業 **100分の35** |

> ★年金給付が長期にわたる分を織り込むための係数です。数値そのものが選択式で問われたことがあります。
