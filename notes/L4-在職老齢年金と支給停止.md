# 在職老齢年金と支給停止｜厚年の深掘り

### 在職老齢年金（46条）

**被保険者である間**（および**70歳以上の使用される者**である間）、**総報酬月額相当額**と**基本月額**の合計が**支給停止調整額**を超えると、超えた分の**2分の1**が支給停止されます。

```
支給停止額 ＝（総報酬月額相当額 ＋ 基本月額 − 支給停止調整額）× 1/2
```

| 用語 | 意味 |
|---|---|
| **総報酬月額相当額** | その月の**標準報酬月額** ＋ その月以前1年間の**標準賞与額の合計 ÷ 12** |
| **基本月額** | 老齢厚生年金（加給年金額を**除く**）の額 ÷ 12 |
| **支給停止調整額** | 令和8年度の額は [`10-厚生年金保険法.md`](10-厚生年金保険法.md) の一覧を参照（毎年度、名目賃金変動率に応じて改定） |

> ★**基本月額に加給年金額は含みません**。年金が全額停止されると加給年金額も停止されます。
> ★**老齢基礎年金は在職老齢年金の対象外**です。全額支給されます。
> ★**経過的加算も対象外**（支給停止されません）。

**令和4年4月から、60歳台前半（特別支給）の基準も65歳以後と同じ額に統一**されました（従来は28万円と47万円で別々でした）。

### 高年齢雇用継続給付との調整（附則11条の6）

**60歳以上65歳未満**の在職老齢年金受給者が、雇用保険の**高年齢雇用継続給付**を受けると、**在職老齢年金がさらに支給停止**されます。

| 賃金の低下率 | 年金の停止率 |
|---|---|
| **61%以下**（令和7年4月からは**64%以下**） | 標準報酬月額の**最大6%**（令和7年4月からは**最大4%**） |
| 61%超75%未満 | 逓減 |

> ★令和7年4月に高年齢雇用継続給付が**15%→10%**に下がったのに合わせ、調整の上限も**6%→4%**に下がりました。
> ★**在職老齢年金による停止が先**、その後に高年齢雇用継続給付による停止を行います。

### 雇用保険の基本手当との調整（附則11条の5）

**特別支給の老齢厚生年金**の受給権者が、**雇用保険の求職の申込み**をすると、**老齢厚生年金の全額**が支給停止されます。

| | |
|---|---|
| 停止期間 | 求職の申込みをした月の**翌月**から、**基本手当の受給期間が経過した月**または**所定給付日数を受け終わった月**まで |
| 事後精算 | 停止された月数が、**基本手当の支給を受けた日数を30で除して得た数（1未満切上げ）**を超えるときは、超えた月数分の年金を**さかのぼって支給** |

> ★**全額停止**です（一部ではありません）。
> ★**65歳以後の老齢厚生年金と高年齢求職者給付金は併給できます**。ここが最頻出の対比です。

### その他の支給停止

| 事由 | 効果 |
|---|---|
| **繰下げ待機中** | 支給されない |
| **障害厚生年金との併給** | **1人1年金**の原則により選択（65歳以後は例外あり） |
| **刑事施設への拘禁** | 老齢厚生年金は**停止されない**（20歳前傷病の障害基礎年金とは違う） |

### 併給調整の原則（38条）

**1人1年金**が原則です。2以上の年金給付の受給権を得たときは、**いずれか1つを選択**し、他は**支給停止**されます。

**65歳以後の例外（併給できる組合せ）**

| 基礎年金 | 併給できる厚生年金 |
|---|---|
| **老齢基礎年金** | 老齢厚生年金／**遺族厚生年金**／障害厚生年金（65歳以後） |
| **障害基礎年金** | 障害厚生年金／**老齢厚生年金**／**遺族厚生年金** |
| **遺族基礎年金** | 遺族厚生年金 |

> ★**障害基礎年金＋老齢厚生年金**、**障害基礎年金＋遺族厚生年金**は**65歳以後**に限り併給できます（平成18年4月〜）。
> ★**老齢基礎年金＋障害厚生年金**も65歳以後は併給できます。
> ★**遺族基礎年金＋老齢厚生年金**は併給できません。

### 65歳以後の遺族厚生年金との調整（60条・附則17条の2）

**65歳以上**で、**老齢厚生年金**と**遺族厚生年金**の両方の受給権があるときは、

1. **老齢厚生年金が全額支給**される
2. 遺族厚生年金は、次の**いずれか多い額**から老齢厚生年金の額を差し引いた額が支給される
   - 死亡した者の報酬比例部分の**4分の3**
   - （死亡した者の報酬比例部分の**2分の1**）＋（自分の老齢厚生年金の**2分の1**）

> ★**自分の老齢厚生年金が優先**され、遺族厚生年金は差額だけになります。「遺族厚生年金を選べば全額もらえる」は誤りです。
> ★この結果、**自分の老齢厚生年金が多いほど遺族厚生年金は少なくなり**、老齢厚生年金だけになることもあります。

### 支給停止の解除・年金の支払

| | |
|---|---|
| 支給停止 | 事由が生じた日の属する月の**翌月**から、消滅した日の属する月**まで** |
| 支払期月 | **偶数月**（2・4・6・8・10・12月）に前2か月分 |
| 端数処理 | 年金額に**1円未満**の端数が生じたときは**四捨五入**。各支払期の額に**1円未満**の端数が生じたときは**切り捨て**、その合計を**2月**の支払期に加算 |

> ★毎回の支払で切り捨てた分を**翌年2月にまとめて支払う**しくみです（平成23年〜）。
