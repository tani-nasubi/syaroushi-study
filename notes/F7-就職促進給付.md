# 就職促進給付｜雇用の深掘り

### 全体像（56条の3・58条・59条）

| 分類 | 給付 |
|---|---|
| **就業促進手当** | **再就職手当**／**就業促進定着手当**／**常用就職支度手当** |
| **移転費** | 公共職業安定所の紹介した職業に就くため、または指示された訓練を受けるため住所を変更する場合 |
| **求職活動支援費** | 広域求職活動費／短期訓練受講費／求職活動関係役務利用費 |

> ★**就業手当は令和7年4月1日に廃止**されました。「常用雇用等以外の形態で就業した場合に支給される」という肢は現在では誤りです。

### 再就職手当（56条の3第1項1号ロ）

**安定した職業に就いた**受給資格者に支給されます。

| 要件 | |
|---|---|
| 支給残日数 | 所定給付日数の**3分の1以上**残っていること |
| 就職の形態 | **1年を超えて**引き続き雇用されることが確実と認められる職業に就いたこと、または**事業を開始**したこと |
| 離職前事業主 | 離職前の事業主に**再び雇用されたものでない**こと（関連事業主も不可） |
| 給付制限 | 待期満了後**1か月**の間は、**公共職業安定所・職業紹介事業者の紹介**による就職であること（給付制限を受けた者） |
| 過去の受給 | 就職日前**3年以内**の就職について再就職手当・常用就職支度手当を受けていないこと |

```
再就職手当 ＝ 支給残日数 × 給付率 × 基本手当日額
```

| 支給残日数 | 給付率 |
|---|---|
| 所定給付日数の**3分の2以上** | **70%** |
| 所定給付日数の**3分の1以上**3分の2未満 | **60%** |

> ★**早く決まるほど率が高い**しくみです。3分の2で70%、3分の1で60%。
> ★基本手当日額には**上限**があります（60歳以上65歳未満は別の上限）。

### 就業促進定着手当

再就職手当を受けた者が、**同一の事業主**に**6か月以上**雇用され、かつ**みなし賃金日額**が離職前の賃金日額を**下回る**場合に支給されます。

```
就業促進定着手当 ＝（離職前の賃金日額 － みなし賃金日額）× 6か月間の賃金支払基礎日数
```

上限は、**基本手当日額 × 支給残日数 ×（100% － 再就職手当の給付率）**です（再就職手当と合わせて支給残日数分が限度）。

> ★申請は、6か月間の雇用が経過した日の**翌日から2か月以内**です。

### 常用就職支度手当（56条の3第1項1号イ）

**就職が困難な者**が安定した職業に就いた場合の給付です。

| 対象 | **障害者等の就職困難者**、**45歳以上**の受給資格者で再就職援助計画等の対象者など |
|---|---|
| 支給残日数 | 所定給付日数の**3分の1未満**であること（3分の1以上なら再就職手当） |

```
常用就職支度手当 ＝ 90（支給残日数が90日未満なら支給残日数、45日未満なら45）× 40% × 基本手当日額
```

> ★再就職手当と常用就職支度手当は**支給残日数で棲み分け**ています。3分の1が境目です。

### 移転費（58条）

**公共職業安定所の紹介**した職業に就くため、または**指示**された公共職業訓練等を受けるため、**住所または居所を変更**する場合に支給されます。

| 内訳 | 鉄道賃、船賃、航空賃、車賃、移転料、着後手当 |
|---|---|
| 要件 | 待期満了後であること、**受給資格者等**であること、公共職業安定所長が**必要と認める**こと |
| 支給されない場合 | **就職準備金その他これに準ずるもの**が就職先から支給されるとき（額が移転費に満たない場合を除く） |

> ★**職業紹介事業者の紹介**でも支給されます（平成30年改正）。
> ★申請は、移転の日の**翌日から1か月以内**です。

### 求職活動支援費（59条）

| 種類 | 内容 |
|---|---|
| **広域求職活動費** | 公共職業安定所の紹介により**遠隔地**の求人者を訪問して求職活動を行う場合。**鉄道賃等＋宿泊料** |
| **短期訓練受講費** | 教育訓練を受け**修了**した場合。受講費用の**20%**（上限**10万円**） |
| **求職活動関係役務利用費** | 求人者との**面接**等、または教育訓練の受講のため、**保育等サービス**を利用した場合。費用の**80%**（上限あり、面接等は**15日分**、訓練は**60日分**が限度） |

> ★広域求職活動費の「遠隔地」は、公共職業安定所から訪問先まで**往復200km以上**が目安です。
> ★短期訓練受講費は**教育訓練給付金の支給を受けていない**ことが要件です。
