# 高額療養費と傷病手当金｜健保の深掘り

### 高額療養費（115条）

**一部負担金等の額**が著しく高額であるときに、自己負担限度額を超えた分が支給されます。

| 70歳未満の所得区分 | 自己負担限度額（月額） |
|---|---|
| 区分ア（標準報酬月額**83万円以上**） | 252,600円＋(医療費−842,000円)×1% |
| 区分イ（**53万〜79万円**） | 167,400円＋(医療費−558,000円)×1% |
| 区分ウ（**28万〜50万円**） | 80,100円＋(医療費−267,000円)×1% |
| 区分エ（**26万円以下**） | **57,600円** |
| 区分オ（**低所得者**＝市町村民税非課税等） | **35,400円** |

> ★区分の境目は標準報酬月額**83／53／28**万円。医療費から引く額（842,000／558,000／267,000）は、それぞれ**限度額の×約1/300**の関係にあります。

**多数回該当**：直近**12か月**間に**3回以上**高額療養費が支給された場合、**4回目**から限度額が下がります（区分ウなら**44,400円**、区分オなら**24,600円**）。

**世帯合算**：同一世帯（同一の被保険者に係る被保険者・被扶養者）で、同一月に**21,000円以上**の自己負担が複数あるときは合算できます（70歳未満）。

> ★合算のハードルは**21,000円**。70歳以上には金額の制限がなく**すべて合算**できます。

**現物給付化**：**限度額適用認定証**（またはマイナ保険証によるオンライン資格確認）を提示すれば、窓口での支払が限度額までで済みます。

**対象外**：**入院時食事療養費・入院時生活療養費の標準負担額**、**保険外併用療養費の自己負担分（上乗せ部分）**、**差額ベッド代**などは対象になりません。

### 高額介護合算療養費（115条の2）

**8月1日から翌年7月31日**までの1年間に、**医療保険**と**介護保険**の自己負担の合計が著しく高額であるときに支給されます。

> ★期間が**8月〜翌年7月**である点、**医療と介護の合算**である点が問われます。

### 特定疾病の特例（長期高額疾病）

**毎月必ず高額の治療費がかかる病気**について、通常の高額療養費とは別に、**自己負担限度額を月1万円**に据え置く特例です（健保法施行令41条7項）。

| 対象の疾病 | 自己負担限度額（月額） |
|---|---|
| **人工腎臓**を実施する**慢性腎不全** | **10,000円**。ただし**70歳未満**で**標準報酬月額53万円以上**の者は**20,000円** ⚠️要確認 |
| **血友病**（第Ⅷ因子・第Ⅸ因子障害による**先天性血液凝固因子障害**） | **10,000円** |
| **抗ウイルス剤を投与している後天性免疫不全症候群**（血液製剤による**HIV感染**） | **10,000円** |

受けるには、保険者に申請して**特定疾病療養受療証**の交付を受け、窓口に提示します。

> ★**2万円になるのは人工透析だけ**です。血友病とHIVは所得にかかわらず**1万円**です。
> ★**70歳以上**は人工透析でも**1万円**です。
> ★通常の高額療養費のように**所得区分ごとの計算式は使いません**。定額です。
> ★**多数回該当**（4回目から引下げ）とは別のしくみです。

### 傷病手当金（99条）

**療養のため労務に服することができない**ときに、生活保障として支給されます。

| 要件 | |
|---|---|
| ① | **療養のため**であること（**保険給付として受ける療養に限りません**。自費診療でもよい） |
| ② | **労務に服することができない**こと |
| ③ | **継続した3日間**（**待期**）を経過していること |
| ④ | **報酬を受けていない**こと（受けていても傷病手当金より少なければ差額を支給） |

```
1日あたりの額 ＝ 支給開始日以前の継続した12か月間の各月の
　　　　　　　　標準報酬月額の平均額 ÷ 30 × 3分の2
```

被保険者期間が12か月に満たない場合は、**①資格取得月以後の各月の標準報酬月額の平均額**と、**②当該年度の前年度9月30日における全被保険者の標準報酬月額の平均額**（政令で定める額）の、**いずれか少ない額**を用います。

| | |
|---|---|
| **待期** | **継続した3日間**（**連続が必要**。労災の休業補償給付は通算でよいのと対照的） |
| **支給期間** | **支給を始めた日から通算して1年6か月** |

> ★令和4年1月から「**通算**」になりました。途中で出勤した期間があれば、その分だけ後ろに延びます。
> ★待期の3日間には、**有給休暇・公休日**も含まれます。報酬の有無は関係ありません。

### 調整（傷病手当金と他の給付）

| 併給 | 調整 |
|---|---|
| **出産手当金** | 出産手当金が優先。傷病手当金の額が出産手当金を超えるときは**差額**を支給 |
| **障害厚生年金** | 同一の傷病について、障害厚生年金の額（同一支給事由の障害基礎年金があればその合算額）の**360分の1**が傷病手当金の額より少ないときは**差額**を支給 |
| **障害手当金** | 傷病手当金の額の合計額が障害手当金の額に達するまで**支給されない** |
| **老齢退職年金給付**（資格喪失後の継続給付の場合） | 年金額の**360分の1**が傷病手当金より少ないときは**差額**を支給 |
| **労災の休業補償給付** | 同一の疾病・負傷について**傷病手当金は支給されない**（休業補償給付が優先） |

> ★調整は「**360分の1**」で日額に直して比べます。「365分の1」は誤りです。

### 資格喪失後の継続給付（104条）

| 要件 | |
|---|---|
| ① | 資格喪失の日の**前日**まで**引き続き1年以上**被保険者（任意継続被保険者・特例退職被保険者であった期間を除く）であったこと |
| ② | 資格喪失の際に**傷病手当金または出産手当金の支給を受けている**こと |

> ★①の「1年以上」は**継続**していることが必要です。合算ではありません。
> ★資格喪失時に**受けられる状態**にあればよく、実際に受給していなくても（待期が完成していれば）継続給付の対象になります。
> ★資格喪失後に**傷病が再発**しても、いったん労務可能になっていれば継続給付は受けられません。

### 出産手当金（102条）

**出産の日**（出産の日が出産の予定日後であるときは出産の予定日）**以前42日**（多胎妊娠の場合は**98日**）から、**出産の日後56日**までの間において労務に服さなかった期間について支給されます。

額の計算は傷病手当金と同じです。**待期はありません**。

> ★**42日・98日・56日**。出産が予定日より遅れた場合、遅れた期間も支給対象になります（産前は「予定日以前42日」で計算するため）。
