# 得点源リスト｜＋点を取るための優先順位

| 項目 | 内容 |
|---|---|
| 目的 | 基準点ギリギリではなく、**択一50点・選択各科目4点**を狙うための優先順位 |
| 根拠 | 過去9年（第49〜57回）の択一**630問**に、各論点が**何年分の試験に登場したか**を実測 |
| 使い方 | **S・Aランクを落とさない**ことが50点への最短路。Cランクは深追いしない |

---

## なぜ「50点」を狙うのか

択一の合格基準は**年により42〜45点**と変動します。42点狙いだと、基準点が45だった年（第55回）に当たった瞬間に落ちます。

一方、**選択式は上振れを作れません**。8問40点・各科目5点が上限で、1科目3点を割れば即不合格。
つまり**バッファは択一でしか作れない**。だから択一で基準点+5〜8点を狙います。

```
択一 50点 ＝ 7科目 × 7点強
選択 各科目4点 ＝ 1問落としても3点残る
```

## 選択式で4点を取る手順

`92-選択式の解き方.md` では「3点が埋まったら次の科目へ」と書きましたが、
これは**80分の第1巡**の話です。**第2巡で4点目・5点目を取りに戻ります。**

| 巡 | 時間 | やること |
|---|---|---|
| 第1巡 | 40分 | 8問すべてで**確実な3点**を確保。難しい空欄は仮マークして即通過 |
| **第2巡** | **25分** | **4点目を取りにいく**。種類で絞り、ペア構造を読み、消去法で詰める |
| 第3巡 | 10分 | 全空欄が埋まっているか確認。**白紙ゼロ** |
| 予備 | 5分 | マークのズレ確認 |

**3点は「守り」、4点目は「攻め」です。** 第2巡の25分をどう使うかで、基準点割れのリスクが変わります。

### 4点目をどこから取るか

1. **同じ記号が2回以上出ている空欄**（全体の11%）— 文脈が2倍取れる。最優先
2. **数値の空欄** — [`90-横断整理.md`](90-横断整理.md) 第20節「取りうる値の範囲」で切る
3. **機関・主体の空欄** — 語群に4語程度しかない。[`90-横断整理.md`](90-横断整理.md) 第9節
4. **条文の文末**（義務／裁量／努力義務）— [`93-判例.md`](93-判例.md) の型

## 択一で50点を取る配分

| 科目 | 目標 | 根拠 |
|---|---|---|
| 労基安衛 | **7点** | 9年間で選択式の基準点補正ゼロ＝標準的な難度 |
| 労災・徴収 | **7点** | 徴収3問は暗記で確実に取れる |
| 雇用・徴収 | **7点** | 令和7年改正が出れば得点源。徴収3問も同様 |
| 一般常識 | **5点** | 労一・社一とも補正の常連。**ここは5点で十分** |
| 健保 | **8点** | 条文が素直。得点源 |
| 厚年 | **8点** | 個数問題23%で時間はかかるが、論点は限定的 |
| 国年 | **8点** | 最も条文が素直。**最大の得点源** |
| **計** | **50点** | 基準点42〜45に対し **+5〜8のバッファ** |

**一般常識だけ5点に設定する**のがポイントです。ここは範囲が無限で費用対効果が悪い。
その分を**健保・厚年・国年（各10問＝30問）**に回すと、合計で+3〜6点になります。

## 事故を防ぐチェックリスト

- [ ] マークシートは**科目の切れ目ごと**に問題番号と照合する
- [ ] 択一は1問3分・1科目30分。飛ばすのは**個数問題だけ**（組合せは2肢で決まるので飛ばさない）

- [ ] 受験票が**8月6日**までに届かなければ、8月12日までに試験センターへ連絡

### 読み取れる3つの傾向

**① 個数問題が増え、組合せ問題が減っている（合計は横ばい）**
個数問題は前期5年の平均3.6問 → **直近4年5.0問**。
一方で組合せ問題は8.0問 → **6.5問**に減っています。
**合計は11.6問 → 11.5問でほぼ横ばい**です。

ただし**この2つは性質がまったく違います**。組合せは**2肢で98.5%正解が確定**するので時間を食いません。
全肢判断が要るのは個数問題だけなので、**実質的に重い問題が3.6問→5.0問に増えた**ことになります。
→ [`A1-個数・組合せ問題の解き方.md`](A1-個数・組合せ問題の解き方.md)

**② 判例が増えて定着した（1.0問 → 2.8問）**

## 「今年はここから出る」は予想できるか

**結論：ヤマを張るのは統計的に根拠が薄いです。**

過去9年で「ある年に出た論点が翌年も出た割合」を計算しました。

```
翌年も出た割合          44.7%（263/588）
再出題までの間隔        中央値 1年／平均 1.8年
```

| 再出題までの間隔 | 件数 | 割合 |
|---|---:|---:|
| 1年後 | 263件 | 59.5% |
| 2年後 | 88件 | 19.9% |
| 3年後 | 48件 | 10.9% |
| 4年後 | 25件 | 5.7% |
| 5年後 | 10件 | 2.3% |
| 6年後 | 5件 | 1.1% |
| 7年後 | 3件 | 0.7% |

**半数近くが翌年も出ています。**「去年出たから今年は出ない」は成立しません。
逆に「しばらく出ていない論点が来る」という予想も、3年以上空くのは
21%程度なので当てになりません。

### 根拠のある優先順位はこの3つだけ

| 根拠 | 内容 | 資料 |
|---|---|---|
| **① 法改正** | 改正された年はそこが問われる。過去問に存在しないので差がつく | [`00-法改正-令和8年度.md`](00-法改正-令和8年度.md) |
| **② 頻出論点** | S/Aランクは毎年出る。ヤマではなく確実性 | この資料の上の各章 |
| **③ 直近の方針** | 判例増・個数問題増・正しい形を問う方向 | 上の傾向分析 |

**ヤマを張る時間があるなら、S/Aランクを1周多く回すほうが期待値は高い**というのがデータの示すところです。
