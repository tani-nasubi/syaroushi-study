# 男女雇用機会均等法と育児・介護休業法｜労一の深掘り

## 男女雇用機会均等法

### 差別の禁止（5条・6条）

| 条 | 場面 |
|---|---|
| **5条** | **募集・採用**について、性別にかかわりなく**均等な機会**を与えなければならない |
| **6条** | **配置**（業務の配分および権限の付与を含む）、**昇進、降格、教育訓練**、**福利厚生**（住宅資金の貸付け等）、**職種・雇用形態の変更**、**退職の勧奨、定年、解雇、労働契約の更新**について、性別を理由として**差別的取扱いをしてはならない** |

> ★5条は「**均等な機会**」、6条は「**差別的取扱いの禁止**」。表現が違います。
> ★**賃金**は均等法ではなく**労基法4条**で規制されます。均等法6条に賃金は含まれません。ここが最頻出です。

### 間接差別（7条）

**性別以外の事由**を要件とする措置であって、**実質的に性別を理由とする差別となるおそれがある**ものとして厚生労働省令で定めるものは、**合理的な理由がある場合でなければ**講じてはなりません。

| 省令で定める3つ |
|---|
| ① **労働者の募集・採用**に当たって、労働者の**身長、体重または体力**を要件とするもの |
| ② **労働者の募集・採用、昇進、職種の変更**に当たって、**転居を伴う転勤**に応じることができることを要件とするもの |
| ③ **労働者の昇進**に当たって、**転勤の経験**があることを要件とするもの |

> ★**3つだけ**が省令で定められています。「募集・採用における転勤要件」は①ではなく②に含まれます。

### ポジティブ・アクション（8条）

**女性労働者に関して行う措置**で、**男女間の格差を解消することを目的**とするものは、5条〜7条の規定にかかわらず**違法とならない**。

> ★**女性を有利に扱う措置だけ**が許されます。男性を有利に扱う措置は許されません。

### 婚姻・妊娠・出産等を理由とする不利益取扱いの禁止（9条）

| 項 | 内容 |
|---|---|
| 1項 | **女性労働者が婚姻し、妊娠し、または出産したことを退職理由として予定する定め**をしてはならない |
| 2項 | **婚姻したこと**を理由として**解雇**してはならない |
| 3項 | **妊娠、出産、産前産後休業、その他厚生労働省令で定める事由**を理由として、**解雇その他不利益な取扱い**をしてはならない |
| 4項 | **妊娠中の女性労働者および出産後1年を経過しない女性労働者**に対してなされた**解雇は無効**。ただし、事業主が**妊娠等を理由とする解雇でないことを証明**したときはこの限りでない |

> ★4項の**立証責任は事業主**にあります。ここが最頻出です。

### ハラスメント対策（11条・11条の3）

| 条 | 内容 |
|---|---|
| **11条** | **セクシュアルハラスメント**（職場において行われる性的な言動に対する対応により労働条件につき不利益を受け、または就業環境が害されること）について、**雇用管理上必要な措置**を講じなければならない |
| **11条の2** | セクハラに関する**国・事業主・労働者の責務** |
| **11条の3** | **妊娠・出産等に関するハラスメント**（マタニティハラスメント）について雇用管理上必要な措置 |

> ★**措置義務は事業主の義務**（努力義務ではありません）。**すべての事業主**が対象で、規模による例外はありません。
> ★相談したこと等を理由とする**不利益取扱いは禁止**されています（11条2項）。

### 母性健康管理（12条・13条）

| 条 | 内容 |
|---|---|
| **12条** | 女性労働者が**保健指導または健康診査**を受けるために**必要な時間を確保**しなければならない |
| **13条** | 保健指導・健康診査に基づく**指導事項を守ることができるようにするため、勤務時間の変更、勤務の軽減等**必要な措置を講じなければならない |

> ★いずれも**義務**です。**妊娠中および出産後1年**が対象です。

### 紛争の解決

| | |
|---|---|
| **都道府県労働局長**の助言・指導・勧告（17条） | |
| **紛争調整委員会**による**調停**（18条）＝**機会均等調停会議** | |
| **勧告に従わない場合の公表**（30条） | 5条〜7条、9条、11条、11条の3、12条、13条の規定に違反している事業主に対し、**厚生労働大臣**が勧告し従わないときは**その旨を公表**できる |
| **報告徴収に応じない場合** | **20万円以下の過料** |

## 育児・介護休業法

### 育児休業（5条〜9条の7）

| 種類 | 内容 |
|---|---|
| **育児休業** | **1歳**に満たない子を養育するため。**2回**まで分割可 |
| **パパ・ママ育休プラス** | 父母ともに取得する場合、**1歳2か月**まで（1人あたりの上限は1年） |
| **延長** | 保育所に入れない等の場合、**1歳6か月**まで、さらに**2歳**まで |
| **出生時育児休業**（産後パパ育休） | 子の出生後**8週間以内**に**4週間（28日）**まで。**2回**まで分割可。**労使協定があれば休業中の就業も可能** |

| 対象外にできる者（**労使協定**による） | ① 引き続き雇用された期間が**1年未満** ② 申出の日から**1年以内**（1歳6か月・2歳までの休業は**6か月以内**）に雇用関係が終了することが明らかな者 ③ **1週間の所定労働日数が2日以下** |
|---|---|

**有期雇用労働者**は、**子が1歳6か月に達する日までに労働契約が満了することが明らかでない**ことが要件です（令和4年4月から「1年以上の雇用期間」の要件は撤廃）。

> ★申出は原則として**1か月前**まで（出生時育児休業は**2週間前**まで）。

### 介護休業（11条〜16条）

| | |
|---|---|
| 対象家族 | **配偶者（事実婚を含む）、父母、子、配偶者の父母、祖父母、兄弟姉妹、孫** |
| 状態 | **2週間以上**にわたり常時介護を必要とする状態（**要介護状態**） |
| 期間 | 対象家族**1人につき通算93日**、**3回**まで分割可 |
| 申出 | **2週間前**まで |

### その他の制度

| 制度 | 内容 |
|---|---|
| **子の看護等休暇**（16条の2） | **小学校3年生修了**まで（令和7年4月〜、従来は小学校就学前）の子1人につき年**5日**（2人以上は**10日**）。**時間単位**で取得可。**感染症による学級閉鎖・入園式等**にも使える |
| **介護休暇**（16条の5） | 対象家族1人につき年**5日**（2人以上は**10日**）。時間単位で取得可 |
| **所定外労働の制限**（16条の8） | **3歳**未満の子を養育する労働者、要介護状態の家族を介護する労働者の請求により残業免除 |
| **時間外労働の制限**（17条・18条） | 小学校就学前の子・要介護家族。**1か月24時間、1年150時間**を超える時間外労働の制限 |
| **深夜業の制限**（19条・20条） | 同上。午後10時〜午前5時 |
| **所定労働時間の短縮**（23条） | **3歳未満**の子（**義務**）。3歳以上小学校就学前は**努力義務**（令和7年10月から**始業時刻の変更等を含む2以上の措置**を講ずる義務に） |

> ★令和7年4月から、**子の看護休暇が「子の看護等休暇」に改称され、対象が小学校3年生修了まで**に拡大されました。
> ★令和7年4月から、**3歳未満の子を養育する労働者にテレワークを選択できるようにすることが努力義務**になりました。

### 不利益取扱いの禁止（10条等）

育児休業・介護休業等の申出をし、または取得したことを理由とする**解雇その他不利益な取扱いは禁止**されています。

### 育児休業取得状況の公表（22条の2）

常時雇用する労働者が**300人を超える**事業主は、**育児休業の取得の状況**を**年1回**公表しなければなりません（令和7年4月から1,000人超→300人超に拡大）。
