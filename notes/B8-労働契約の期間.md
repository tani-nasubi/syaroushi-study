# 労働契約の期間｜労基の深掘り

### 上限（14条）

| 区分 | 上限 |
|---|---|
| 原則 | **3年** |
| **専門的知識等**を有する労働者 | **5年** |
| **満60歳以上**の労働者 | **5年** |
| 一定の事業の完了に必要な期間を定めるもの | その期間（上限なし） |

> 期間の定めの**ない**契約は対象外です。「一定の事業の完了に必要な期間」は
> 有期でも上限がかからない点が引っかけになります。

### 途中解約

原則3年の契約で1年を超えた労働者は、**いつでも退職できます**（附則137条）。専門的知識等・60歳以上の5年契約にはこの規定が**適用されません**。

---

### なぜ上限があるのか

期間の定めのある契約は、**期間中は労働者も辞めにくい**（民法628条により、やむを得ない事由がなければ解除できない）。長すぎる拘束を防ぐため、労基法は上限を設けています。

逆に**期間の定めのない契約には上限がありません**。いつでも2週間前に申し出れば辞められるからです（民法627条）。

### 「一定の事業の完了に必要な期間」

ダム建設のように、**終わりが客観的に決まっている事業**なら3年を超えても構いません。

> 「有期契約は必ず3年以内」と書いてある肢は**誤り**です。この例外を落とすと引っかかります。

### 5年になる2つの区分（14条1項1号・2号）

| 号 | 対象 |
|---|---|
| 1号 | **専門的な知識、技術又は経験**であって高度のものを有する労働者（博士、公認会計士、医師、弁護士、一級建築士、システムアナリスト等で、一定の実務経験・年収要件を満たす者） |
| 2号 | **満60歳以上**の労働者 |

> 2号は「60歳以上」であればよく、**専門性は不要**です。

### 途中解約（附則137条）

原則3年の契約で**1年を経過した日以後**は、労働者は**いつでも退職を申し出られます**。使用者は拒めません。

**ただし、5年契約（専門的知識等・60歳以上）にはこの規定が適用されません。**

```
3年契約 → 1年経過後はいつでも辞められる
5年契約 → 附則137条の適用なし（やむを得ない事由が必要）
```

### 労働契約法18条との関係（無期転換）

労基法14条は「1本の契約の長さ」の話、労働契約法18条は「**通算**5年を超えたら無期に転換できる」という別の話です。混同しないでください。

| | 労基法14条 | 労働契約法18条 |
|---|---|---|
| 何の話か | 1回の契約期間の上限 | 通算期間による無期転換 |
| 数字 | 原則3年・例外5年 | 通算**5年**超 |
| 効果 | 上限を超える定めは3年（5年）に短縮 | 労働者の**申込み**により無期契約に転換 |

### 契約期間についての行政の配慮（14条2項・3項）

厚生労働大臣は、**有期労働契約の締結・更新・雇止め**に関して、使用者が講ずべき措置について**基準**を定めることができ、行政官庁はその基準に関して使用者に**助言及び指導**を行うことができます。

> 「命令」「勧告」ではなく**助言及び指導**です。
