# 36協定と上限規制｜労基の深掘り

### 手続の流れ

```
過半数組合（なければ過半数代表者）と書面で協定
  → 所轄労働基準監督署長に届出   ← 届出て初めて免罰効果が生じる
```

**協定を結んだだけでは足りず、届出が効力要件**です。

### 何を数える時間なのか

**法定労働時間（1日8時間・1週40時間）を超えた時間**です。所定労働時間を超えた時間ではありません。

36条1項が「**第32条から第32条の5まで若しくは第40条の労働時間**…に関する規定にかかわらず」と書いており、ここでいう労働時間は**法定労働時間**だからです。

| 所定労働時間 | その日に働いた時間 | 扱い |
|---|---|---|
| 7時間 | 8時間 | **法定内残業**。36協定も上限規制も**不要**、労基法37条の**割増賃金も不要**（賃金そのものは支払う） |
| 7時間 | 9時間 | 8時間を超えた**1時間**だけが時間外労働。上限規制に数えるのもこの1時間 |
| 8時間 | 10時間 | **2時間**が時間外労働 |

> ★「所定を超えた時間」で数える誤り肢が定番です。**法定**を超えた分だけを数えます。
> ★就業規則で「所定を超えた分に割増を払う」と定めるのは自由です。ただしそれは**契約上の上乗せ**であって、労基法の時間外労働ではありません。
> ★**変形労働時間制**でその日の所定労働時間が8時間を超えて設定されているときは、**その所定時間**を超えた分が時間外労働になります（法定を超える所定が適法に設定されているため）。

### 時間外労働と休日労働は別枠

**法定休日**（週1日または4週4日）の労働は**休日労働**であって、時間外労働ではありません。数え方が枠ごとに違います。

| 上限 | 休日労働を |
|---|---|
| 月45時間・年360時間（限度時間） | **含まない** |
| 年720時間 | **含まない** |
| 月100時間未満 | **含む** |
| 2〜6か月平均80時間以内 | **含む** |

> ★**720時間だけが休日労働を含まない**、100時間・80時間は**含む**。ここが最頻出です。

### 上限は2段になっている

まず**原則の枠**（限度時間）があり、それを超えたいときだけ**特別条項**を結ぶ、という2段です。

```
① 原則の枠（限度時間・36条4項）
      1か月 45時間 ／ 1年 360時間
      ここまでは、特別の事情がなくても36協定で定められる
              │
              │ 臨時的な特別の事情があるときだけ、超える定めができる
              ↓
② 特別条項を結んだときの絶対的上限（36条6項）
      年720時間 ／ 月100時間未満 ／ 2〜6か月平均80時間以内
      45時間を超えてよいのは 年6回まで
      ここを超えると、協定があっても違法（罰則あり）
```

**45時間・360時間は「原則いくらまで働かせてよいか」**、**100時間・80時間・720時間は「特別条項を使っても、ここから先は絶対にだめ」**という線です。役割が違います。

### ① 限度時間（36条4項）＝ 原則の枠

| 期間 | 原則 | 1年単位の変形労働時間制（対象期間3か月超） |
|---|---|---|
| 1か月 | **45時間** | 42時間 |
| 1年 | **360時間** | 320時間 |

特別条項を結ばないなら、36協定で定められるのはここまでです。

### ② 特別条項を結んだときの絶対的上限（36条5項・6項）

**臨時的な特別の事情**（予算・決算業務、大規模なクレームへの対応、機械のトラブルへの対応など）があるときに限り、限度時間を超える定めができます。ただし次の4つは**協定で定めても超えられません**。

| 何が | 上限 | 休日労働を |
|---|---|---|
| 1年の時間外労働 | **720時間**以内 | 含まない |
| 1か月の時間外労働＋休日労働 | **100時間未満** | **含む** |
| 2・3・4・5・6か月のどの平均をとっても | **80時間**以内 | **含む** |
| 月45時間を超えてよい回数 | **年6回**まで | — |

> ★「100時間**未満**」と「80時間**以内**」で言い回しが違います。**100時間はちょうど100でアウト、80時間はちょうど80でセーフ**。
> ★**年6回**までなので、残りの**6か月は45時間以内**に収めなければなりません。
> ★**720時間だけが休日労働を含みません**。100時間と80時間は含みます。

**数え方の例**（月45時間を超えた月が年6回、うち1か月は休日労働20時間）

| | 時間外 | 休日 | 合計 | 判定 |
|---|---|---|---|---|
| その月 | 85時間 | 20時間 | **105時間** | ✕ 100時間未満に反する |
| その月 | 75時間 | 20時間 | **95時間** | ○（2〜6か月平均も見る） |

> ★**1日の上限はありません**。1日の延長時間は36協定で定めますが（36条2項4号）、罰則付きの絶対的上限は**1か月と1年**だけです。
> ただし**坑内労働その他健康上特に有害な業務**だけは、**1日について2時間**を超えられません（36条6項1号）。

### 45時間を超えて働かせたらどうなるか

超え方によって、違反する条文が変わります。

| 状況 | どうなるか | 根拠 |
|---|---|---|
| **特別条項がない**のに月45時間を超えて働かせた | 協定で定めた時間を超えているので、**36協定の免罰効果が及ばない**。法定労働時間を超えて働かせたことになり **32条違反** | 32条／119条 |
| **特別条項があり**、年6回以内・720時間以内などの枠に収まっている | **適法**。ただし月60時間を超えた分は**5割以上**の割増賃金が必要 | 37条1項ただし書 |
| **特別条項があっても**、月100時間以上・2〜6か月平均80時間超・年720時間超・45時間超が年7回目 | **36条6項違反**。協定があっても違法 | 36条6項／119条 |

**罰則はどちらも 6か月以下の拘禁刑または30万円以下の罰金**（119条）です。

> ★**限度時間（45時間・360時間）そのものには直接の罰則がありません**。36条3項が「協定で定める延長時間は**限度時間を超えない時間に限る**」と定めているので、限度時間を超える協定は**その部分が無効**になり、結果として**32条違反**になる、という筋道です。
> ★これに対し**36条6項は「〜しなければならない」と使用者を直接縛る規定**で、違反すればそのまま罰則がかかります。**協定の内容が適法でも、実際の労働時間が6項を超えれば違法**です。
> ★**割増賃金の5割は「月60時間超」**です。45時間でも100時間でもありません。**中小企業も令和5年4月から適用**されています。

### 似た数字との区別

**80時間・100時間**は他の科目にも出ますが、数える対象が違います。

| どこの数字か | 何を数えるか |
|---|---|
| **労基法36条6項**（この上限規制） | **法定労働時間を超えた時間＋法定休日労働** |
| **安衛法66条の8**（医師の面接指導） | 休憩を除き**1週40時間を超えて労働させた時間**が月80時間超＋**本人の申出** |
| **労災の過労死認定基準** | 発症前1か月に**おおむね100時間**、または2〜6か月平均で月**おおむね80時間**を超える時間外労働 |

> ★どれも「**法定の40時間を超えた分**」を数える点は同じです。違うのは、面接指導は**申出が要る**（研究開発業務と高プロは100時間超で申出不要）、認定基準は「**おおむね**」が付くところです。

### 割増賃金率

| 種類 | 率 |
|---|---|
| 時間外 | **2割5分**以上 |
| 時間外が月**60時間**超の部分 | **5割**以上 |
| 休日 | **3割5分**以上 |
| 深夜（22時〜5時） | **2割5分**以上 |
| 時間外＋深夜 | 5割以上（2割5分＋2割5分） |
| 休日＋深夜 | 6割以上（3割5分＋2割5分） |

> **休日労働に時間外の割増は重ねません。** 休日は8時間を超えても3割5分のままです。

### 割増賃金の算定基礎から除外できる賃金（限定列挙）

1. 家族手当　2. 通勤手当　3. 別居手当　4. 子女教育手当　5. 住宅手当
6. 臨時に支払われた賃金　7. 1か月を超える期間ごとに支払われる賃金

**この7つ以外は全て算入します。** さらに①②⑤は**実態に応じて支給されるもの**に限られ、扶養家族数や距離に関係なく**一律支給**なら名称にかかわらず**算入必要**です。
