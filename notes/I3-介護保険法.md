# 介護保険法｜社一の深掘り

### 保険者（3条）

**市町村および特別区**が保険者です。

| 支える主体 | 役割 |
|---|---|
| **国** | 基本指針の策定、**調整交付金**の交付 |
| **都道府県** | **財政安定化基金**の設置、事業者の指定（居宅サービス・施設）、介護保険審査会の設置 |
| **医療保険者** | **介護給付費・地域支援事業支援納付金**の納付 |
| **社会保険診療報酬支払基金** | 納付金の徴収と**交付金**の交付 |

> ★**介護保険審査会は都道府県**に置かれます。保険者は市町村ですが、審査会は都道府県です。

### 被保険者（9条）

| 区分 | 要件 | 保険料 |
|---|---|---|
| **第1号被保険者** | 市町村の区域内に住所を有する**65歳以上**の者 | **市町村が徴収**（年額18万円以上の年金からの**特別徴収**が原則） |
| **第2号被保険者** | 市町村の区域内に住所を有する**40歳以上65歳未満**の**医療保険加入者** | **医療保険者が医療保険料と一体で徴収** |

> ★第2号被保険者は**医療保険に加入していること**が要件です。生活保護受給者（国保に加入していない者）は第2号被保険者になりません。

### 受給要件

| 区分 | 給付が受けられる場合 |
|---|---|
| **第1号** | **原因を問わず**、要介護・要支援状態にあること |
| **第2号** | **加齢に伴って生ずる心身の変化に起因する疾病**（**特定疾病**、**16種類**）によること |

**特定疾病**の例：がん（末期）、関節リウマチ、筋萎縮性側索硬化症、後縦靱帯骨化症、骨折を伴う骨粗鬆症、初老期における認知症、パーキンソン病関連疾患、脊髄小脳変性症、脊柱管狭窄症、早老症、多系統萎縮症、糖尿病性神経障害・腎症・網膜症、**脳血管疾患**、閉塞性動脈硬化症、慢性閉塞性肺疾患、両側の膝関節または股関節に著しい変形を伴う変形性関節症。

> ★**交通事故による障害は第2号被保険者では給付対象になりません**（加齢に起因しないため）。

### 要介護認定（27条〜）

```
市町村に申請
　↓
認定調査（市町村の職員等）＋ 主治医意見書
　↓
コンピュータによる一次判定
　↓
介護認定審査会（市町村に設置）による二次判定
　↓
市町村が認定（申請日から30日以内）→ 申請日にさかのぼって効力
```

| | |
|---|---|
| 区分 | **要支援1・2**、**要介護1〜5** |
| **有効期間** | 新規は原則**6か月**（12か月まで延長可）、更新は原則**12か月**（**48か月**まで延長可、令和6年4月〜） |
| **認定の効力** | **申請のあった日にさかのぼって**生ずる |

> ★**申請日にさかのぼる**ので、認定前でも暫定ケアプランでサービスを利用できます。
> ★**介護認定審査会は市町村**、**介護保険審査会は都道府県**。名前が似ているので注意します。

### 給付の種類

| 区分 | 内容 |
|---|---|
| **介護給付**（要介護者） | 居宅介護サービス費、地域密着型介護サービス費、施設介護サービス費、居宅介護福祉用具購入費、居宅介護住宅改修費、居宅介護サービス計画費、高額介護サービス費、特定入所者介護サービス費 など |
| **予防給付**（要支援者） | 介護予防サービス費、地域密着型介護予防サービス費 など（**施設サービスはない**） |
| **市町村特別給付** | 市町村が**条例**で定める独自の給付（配食サービス等）。財源は**第1号保険料** |

> ★**要支援者は施設サービスを利用できません**。ここが最頻出です。

### 施設サービス

| 施設 | 特徴 |
|---|---|
| **介護老人福祉施設**（特別養護老人ホーム） | 原則**要介護3以上** |
| **介護老人保健施設** | 在宅復帰を目指すリハビリ中心 |
| **介護医療院** | 長期療養＋生活施設（介護療養型医療施設は令和6年3月末で廃止） |

### 利用者負担

| 区分 | 割合 |
|---|---|
| 一般 | **1割** |
| 一定以上の所得 | **2割** |
| 特に所得の高い者 | **3割** |

**高額介護サービス費**：1か月の利用者負担が上限を超えたとき支給されます。

### 財源（121条〜）

| 財源 | 割合 |
|---|---|
| **公費** | **50%**（**居宅給付費**：国25%・都道府県12.5%・市町村12.5%／**施設等給付費**：国20%・都道府県17.5%・市町村12.5%） |
| **第1号保険料** | **23%**（令和6〜8年度） |
| **第2号保険料** | **27%**（令和6〜8年度） |

> ★国の25%のうち**5%は調整交付金**です（市町村間の格差調整）。
> ★**施設等給付費では都道府県の割合が17.5%に上がる**（国が20%に下がる）。ここが問われます。

### 地域支援事業（115条の45）

| 事業 | 内容 |
|---|---|
| **介護予防・日常生活支援総合事業** | 訪問型・通所型サービス、一般介護予防事業 |
| **包括的支援事業** | **地域包括支援センター**の運営（総合相談支援、権利擁護、包括的・継続的ケアマネジメント、**介護予防ケアマネジメント**）、在宅医療・介護連携推進、生活支援体制整備、**認知症総合支援**、地域ケア会議推進 |
| **任意事業** | 介護給付等費用適正化、家族介護支援 など |

### 事業者の指定

| 種類 | 指定権者 |
|---|---|
| **居宅サービス事業者、介護予防サービス事業者、介護保険施設** | **都道府県知事** |
| **地域密着型サービス事業者、地域密着型介護予防サービス事業者、居宅介護支援事業者、介護予防支援事業者** | **市町村長** |

> ★**地域密着型と居宅介護支援（ケアプラン）は市町村長**。それ以外は都道府県知事です。

### 不服申立て（183条）

**保険給付に関する処分**、**保険料その他の徴収金に関する処分**に不服がある者は、**介護保険審査会**（**都道府県**に設置）に審査請求できます。

介護保険審査会の委員：**市町村代表**3人、**被保険者代表**3人、**公益代表**3人以上。
