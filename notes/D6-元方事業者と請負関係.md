# 元方事業者と請負関係｜安衛の深掘り

### 用語の整理（15条）

| 用語 | 意味 |
|---|---|
| **元方事業者** | 一の場所で行う事業の仕事の一部を請負人に請け負わせているもの（**最も先次**の注文者） |
| **特定元方事業者** | 元方事業者のうち、**建設業・造船業**（＝特定事業）を行う者 |
| **注文者** | 仕事を他人に請け負わせている者（元方事業者を含む） |
| **関係請負人** | 元方事業者の請負人およびその請負人の請負人（下請すべて） |

### 統括安全衛生責任者（15条）

| 選任すべき者 | **特定元方事業者** |
|---|---|
| 規模 | 元請・下請あわせて常時**50人以上**（**ずい道の建設、圧気工法による作業、一定の橋梁の建設**は常時**30人以上**） |
| 資格 | 事業の実施を**統括管理する者** |
| 職務 | 30条1項の**特定元方事業者の講ずべき措置**を統括管理する、**元方安全衛生管理者**を指揮する |

> ★**製造業には統括安全衛生責任者はいません**（特定事業は建設業・造船業のみ）。製造業では**30条の2**の「**製造業等における元方事業者の講ずべき措置**」（作業間の連絡調整）があります。
> ★ずい道等・圧気工法・橋梁は**30人**。この例外が頻出です。

### 元方安全衛生管理者（15条の2）

**統括安全衛生責任者を選任した事業者**（**建設業のみ**）が、**その事業場に専属**の者から選任します。

| | |
|---|---|
| 対象 | **建設業**のみ（造船業には不要） |
| 資格 | 大学等で理科系の課程を修めて卒業後**3年以上**、高校等卒業後**5年以上**、その他厚生労働大臣が定める者で、建設工事の施工における**安全衛生の実務に従事した経験**を有する者 |
| 職務 | 統括安全衛生責任者が統括管理すべき事項のうち**技術的事項**を管理する |

### 安全衛生責任者（16条）

**統括安全衛生責任者を選任すべき事業者以外の請負人**（＝**下請**）で、当該仕事を**自ら行うもの**が選任します。

| 職務 |
|---|
| 統括安全衛生責任者との**連絡** |
| 統括安全衛生責任者から連絡を受けた事項の**関係者への連絡** |
| 当該事項のうち当該請負人に係るものの**実施についての管理** |
| 請負人がその仕事の一部を他の請負人に請け負わせている場合の、当該他の請負人の安全衛生責任者との**作業間の連絡調整** |

> ★選任したときは、**遅滞なく統括安全衛生責任者を選任すべき事業者に通報**しなければなりません。**労働基準監督署長への報告は不要**です。

### 店社安全衛生管理者（15条の3）

統括安全衛生責任者を選任すべき規模に**達しない**建設現場について、**店社**（本社・支店等）から現場を管理する者です。

| 対象工事 | 規模 |
|---|---|
| **ずい道等の建設、圧気工法による作業、一定の橋梁の建設** | 常時**20人以上30人未満** |
| **主要構造部が鉄骨造または鉄骨鉄筋コンクリート造**の建築物の建設 | 常時**20人以上50人未満** |

職務は、**少なくとも毎月1回**労働者が作業を行う場所を**巡視**すること、作業の種類・実施状況を**把握**すること、協議組織の会議に**随時参加**することなどです。

### 特定元方事業者の講ずべき措置（30条）

| 号 | 措置 |
|---|---|
| 1号 | **協議組織**の設置および運営 |
| 2号 | 作業間の**連絡および調整** |
| 3号 | 作業場所の**巡視**（**毎作業日に少なくとも1回**） |
| 4号 | 関係請負人が行う**安全衛生教育に対する指導および援助**（場所の提供、資料の提供等） |
| 5号 | 仕事の**工程に関する計画**および**機械・設備等の配置**に関する計画の作成、機械・設備等の使用に関する**指導** |
| 6号 | その他労働災害を防止するため必要な事項 |

> ★巡視は**毎作業日に少なくとも1回**。「毎月1回」は店社安全衛生管理者です。
> ★協議組織には**すべての関係請負人が参加**しなければなりません。

### 注文者の講ずべき措置（31条）

**建設物・設備等を、自ら行う仕事の一部を請け負わせている請負人の労働者に使用させる**注文者は、その建設物等について**労働災害を防止するため必要な措置**を講じなければなりません。

該当する建設物等は、**くい打機・くい抜機、軌道装置、型枠支保工、アセチレン溶接装置、交流アーク溶接機、電動機械器具、潜函、ずい道等、足場、作業構台**などです（安衛則644条〜662条）。

> ★2以上の注文者があるときは、**最も先次の注文者**（＝元方事業者）が措置を講じます。

### 違法な指示の禁止（31条の4）・特定作業に係る措置（31条の3）

- 注文者は、請負人の労働者に、**この法律またはこれに基づく命令の規定に違反することとなる指示**をしてはなりません。
- **機械等を用いる特定の作業**（くい打機、移動式クレーン等）で、同一の場所において複数の事業者の労働者が作業を行うときは、**特定作業に係る仕事を自ら行う発注者または元請負人**が、作業に関し必要な措置を講じます。

### 違法な建設物等の使用禁止（32条以下）

**関係請負人および関係請負人の労働者**は、元方事業者・注文者が講ずる措置に**応じて、必要な事項を守らなければなりません**（32条）。

> ★安衛法は**事業者だけでなく労働者にも義務**を課す点が労基法と違います（26条：労働者は、事業者が講ずる措置に応じて、必要な事項を守らなければならない）。
