# 労働者派遣法とパート・有期法｜労一の深掘り

## 労働者派遣法

### 定義（2条）

> **労働者派遣**とは、自己の雇用する労働者を、当該雇用関係の下に、かつ、**他人の指揮命令**を受けて、当該他人のために労働に従事させることをいい、**当該他人に対し当該労働者を当該他人に雇用させることを約してするものを含まない**。

> ★最後の一文により、**在籍出向は労働者派遣に当たりません**（出向先とも雇用関係があるため）。

### 適用除外業務（4条）

| 業務 |
|---|
| **港湾運送**業務 |
| **建設**業務 |
| **警備**業務 |
| **医療関係**業務（病院等における医師・看護師等。**紹介予定派遣、産休・育休の代替、へき地**等は例外） |

> ★**士業**（弁護士・社労士等）は法令上の適用除外ではなく、**業として行う場合に業務の性質上馴染まない**という整理です。

### 期間制限（35条の2・35条の3・40条の2）

| 区分 | 制限 |
|---|---|
| **事業所単位** | 同一の事業所に対し**3年**が限度。延長するには**過半数労働組合等からの意見聴取**が必要（**3年ごと**、**1回につき3年**を限度に延長可） |
| **個人単位** | 同一の派遣労働者を同一の**組織単位**（課など）に**3年**を超えて派遣してはならない |

**期間制限の対象外**

1. **無期雇用**の派遣労働者
2. **60歳以上**の派遣労働者
3. **有期プロジェクト**業務（終期が明確なもの）
4. **日数限定**業務（1か月の勤務日数が通常の労働者の**半分以下**かつ**10日以下**）
5. **産前産後休業・育児休業・介護休業**等の代替要員

> ★**無期雇用と60歳以上**は覚えやすい2つです。
> ★意見聴取は**義務**ですが、**同意までは不要**です。異議があれば**対応方針等を説明**しなければなりません。

### 労働契約申込みみなし制度（40条の6）

派遣先が次の**違法派遣**を受け入れた場合、その時点で、派遣先が派遣労働者に対し、**その労働条件と同一の労働条件を内容とする労働契約の申込みをしたものとみなされます**。

1. **適用除外業務**に従事させた
2. **無許可**の事業主から派遣を受け入れた
3. **事業所単位・個人単位の期間制限**に違反した
4. **偽装請負**等（労働者派遣法等の適用を免れる目的で、請負等の名目で契約を締結した）

> ★派遣先が**違法であることを知らず、かつ知らなかったことにつき過失がなかった**ときは適用されません。
> ★みなされた申込みは**1年間**撤回できず、派遣労働者が承諾すれば労働契約が成立します。

### 同一労働同一賃金（30条の3・30条の4）

派遣元事業主は、次の**いずれか**の方式により、派遣労働者の待遇を確保しなければなりません。

| 方式 | 内容 |
|---|---|
| **派遣先均等・均衡方式**（30条の3） | 派遣先の通常の労働者との間で、**不合理な待遇の相違**を設けてはならない（均衡待遇）、**職務の内容・配置の変更範囲が同一**なら差別的取扱いをしてはならない（均等待遇） |
| **労使協定方式**（30条の4） | 派遣元で**過半数労働組合等と労使協定**を締結し、**同種の業務に従事する一般労働者の平均的な賃金額**と同等以上の賃金等を定める |

> ★どちらを選ぶかは**派遣元**が決めます。労使協定方式では、協定を**書面で締結**し、**周知**が必要です。

### 許可・届出

労働者派遣事業は、**すべて許可制**（厚生労働大臣の許可）です。平成27年改正で**特定労働者派遣事業（届出制）は廃止**されました。

| | |
|---|---|
| 許可の有効期間 | **3年**（更新後は**5年**） |
| 欠格事由 | 禁錮以上の刑、労働関係法令違反等 |
| **日雇派遣の原則禁止**（35条の4） | 例外：**政令で定める業務**、**60歳以上**、**昼間学生**、**副業**（生業収入500万円以上）、**主たる生計者でない**（世帯収入500万円以上） |
| **離職後1年以内**の派遣の禁止（35条の5・40条の9） | **60歳以上の定年退職者を除く** |
| **グループ企業内派遣**（23条の2） | 関係派遣先への派遣割合を**8割以下**にしなければならない |

## パートタイム・有期雇用労働法

### 均衡待遇（8条）と均等待遇（9条）

| 条 | 内容 |
|---|---|
| **8条**（不合理な待遇の禁止・**均衡**） | 基本給、賞与その他の待遇のそれぞれについて、**①職務の内容 ②職務の内容・配置の変更の範囲 ③その他の事情**のうち、当該待遇の性質・目的に照らして適切と認められるものを考慮して、**不合理と認められる相違を設けてはならない** |
| **9条**（差別的取扱いの禁止・**均等**） | **職務の内容**が同一であり、かつ、当該事業主との雇用関係が終了するまでの全期間において**職務の内容および配置の変更の範囲**が同一であると見込まれる短時間・有期雇用労働者については、**短時間・有期雇用労働者であることを理由として**、待遇について**差別的取扱いをしてはならない** |

> ★**8条は「不合理な相違」を禁止（バランス）、9条は「差別的取扱い」を禁止（同一）**。9条は**①②が同一**であることが要件です（③その他の事情は見ません）。

### 待遇に関する説明義務（14条）

| 場面 | 説明する内容 |
|---|---|
| **雇入れ時** | 講ずる措置の内容（8条〜13条） |
| **求めがあったとき** | **通常の労働者との間の待遇の相違の内容および理由**、待遇の決定に当たって考慮した事項 |

説明を求めたことを理由とする**不利益取扱いは禁止**されます。

### 労働条件の文書交付（6条）

労基法15条の明示事項に加え、**特定事項**（**昇給の有無、退職手当の有無、賞与の有無、相談窓口**）を**文書の交付等**により明示しなければなりません。

> ★**4つの特定事項**。「通勤手当の有無」は含まれません。

### 紛争解決（22条〜27条）

**都道府県労働局長による助言・指導・勧告**、**紛争調整委員会による調停**の対象です。

> ★**均衡待遇（8条）も調停の対象**です（平成30年改正で追加）。

### 求職者等の個人情報の取扱い（職業安定法5条の5）

公共職業安定所、特定地方公共団体、**職業紹介事業者**、**求人者**、労働者の募集を行う者・募集受託者、**特定募集情報等提供事業者**、労働者供給事業者・労働者供給を受けようとする者は、その業務に関し、求職者等の個人情報を収集・保管・使用するにあたっては、**業務の目的の達成に必要な範囲内**で収集し、その目的の範囲内で保管・使用しなければなりません。

**本人の同意がある場合その他正当な事由がある場合**はこの限りではありません。また、求職者等の個人情報を**適正に管理するために必要な措置**を講じなければなりません。

> ★令和4年改正で**特定募集情報等提供事業者**（求人メディア等）が明記されました。
> ★収集してはならない個人情報の例：**人種・民族・社会的身分・門地・本籍・出生地**、**思想・信条**、**労働組合への加入状況**。
