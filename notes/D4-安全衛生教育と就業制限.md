# 安全衛生教育と就業制限｜安衛の深掘り

### 雇入れ時・作業内容変更時の教育（59条1項・2項）

事業者は、労働者を**雇い入れたとき**、および労働者の**作業内容を変更したとき**は、その従事する業務に関する**安全または衛生のための教育**を行わなければなりません。

| 項目（則35条） |
|---|
| ① 機械等・原材料等の危険性または有害性およびこれらの取扱い方法 |
| ② 安全装置・有害物抑制装置・保護具の性能および取扱い方法 |
| ③ 作業手順 |
| ④ 作業開始時の点検 |
| ⑤ 業務に関して発生するおそれのある**疾病の原因および予防** |
| ⑥ **整理、整頓および清潔**の保持 |
| ⑦ **事故時等における応急措置および退避** |
| ⑧ その他当該業務に関する安全または衛生のために必要な事項 |

> ★**令和6年4月1日から、業種を問わずすべての事業場で①〜④の項目も必要**になりました（従来は非工業的業種で省略可）。
> ★**臨時に雇い入れる労働者・パート・アルバイトにも必要**です。期間の長短は関係ありません。
> ★十分な知識・技能を有すると認められる労働者については、当該事項の教育を**省略できます**。

### 特別教育（59条3項）

事業者は、**危険または有害な業務**で厚生労働省令で定めるものに労働者を就かせるときは、**特別の教育**を行わなければなりません。

| 主な対象業務 |
|---|
| **アーク溶接**、**研削といし**の取替え、**動力プレス**の金型の取付け |
| **クレーン**（つり上げ荷重5トン未満）、**玉掛け**（つり上げ荷重1トン未満）、**フォークリフト**（最大荷重1トン未満） |
| **高圧・特別高圧の充電電路**の敷設等、**酸素欠乏危険場所**における作業 |
| **足場の組立て等**、**石綿等**が使用されている建築物の解体等 |
| **チェーンソー**を用いて行う立木の伐木等、**高さ2メートル以上のフルハーネス型墜落制止用器具**を用いる作業 |

> ★教育の**記録**（受講者、科目等）を作成し**3年間**保存しなければなりません。
> ★特別教育の**科目の全部または一部について十分な知識・技能を有する**と認められる労働者については、その科目の教育を**省略できます**。

### 職長等教育（60条）

**新たに職務に就くこととなった職長その他の作業中の労働者を直接指導または監督する者**（作業主任者を除く）に対する教育です。

| 対象業種 | **建設業、製造業**（一部を除く）、**電気業、ガス業、自動車整備業、機械修理業** |
|---|---|
| 内容 | ① 作業方法の決定および労働者の配置 ② 労働者に対する指導・監督の方法 ③ **危険性・有害性等の調査**およびその結果に基づき講ずる措置 ④ 異常時等における措置 ⑤ その他現場監督者として行うべき労働災害防止活動 |

> ★**作業主任者は除かれます**（作業主任者は別途、免許・技能講習が必要なため）。
> ★令和5年4月から、**食料品製造業（うま味調味料・動植物油脂製造業を除く）、新聞業、出版業、製本業、印刷物加工業**が対象に追加されました。

### 危険有害業務従事者への教育（60条の2）

事業者は、**危険または有害な業務に現に就いている者**に対し、その業務に関する安全衛生教育を行うよう**努めなければなりません**（**努力義務**）。

> ★59条・60条は**義務**、60条の2は**努力義務**。この区別が問われます。

### 就業制限（61条）

**クレーンの運転**その他の業務で政令で定めるものについては、次の者でなければ就かせてはなりません。

| 資格 | 例 |
|---|---|
| **免許**を受けた者 | クレーン（つり上げ荷重5トン以上）、移動式クレーン（同）、ボイラー技士、発破技士、ガス溶接作業主任者 |
| **技能講習**を修了した者 | **フォークリフト**（最大荷重1トン以上）、**玉掛け**（つり上げ荷重1トン以上）、車両系建設機械（機体重量3トン以上）、高所作業車（作業床の高さ10メートル以上）、**ガス溶接** |
| その他厚生労働省令で定める者 | |

**業務に従事するときは、これに係る免許証その他その資格を証する書面を携帯**していなければなりません。

> ★**特別教育**（59条3項）は事業者が自ら行える教育、**就業制限**（61条）は**免許・技能講習**という公的資格が必要な業務です。**規模の境目（5トン、1トン、3トン）**が問われます。
> ★職業能力開発促進法の**認定職業訓練**を受ける訓練生については、**厚生労働省令で定める資格を有する者**に含めることができる特例があります。

### 中高年齢者等への配慮（62条）

事業者は、**中高年齢者**その他労働災害の防止上その就業に当たって特に配慮を必要とする者については、これらの者の**心身の条件に応じて適正な配置**を行うように**努めなければなりません**（努力義務）。

### 安全衛生教育の費用と時間

安全衛生教育は**所定労働時間内**に行うのが原則で、**費用は事業者負担**です。所定労働時間外に行われた場合は**割増賃金の支払**が必要です。

> ★「教育に要する時間の賃金は労使の協議による」は誤りです。**労働時間**として扱います。
