# 解雇｜労基の深掘り

### 3つの層を分けて考える

混乱しやすいので、**層が3つある**ことを先に押さえてください。

| 層 | 内容 | 根拠 |
|---|---|---|
| ① できるか | 客観的に合理的な理由・社会通念上の相当性がなければ**権利濫用で無効** | 労働契約法16条 |
| ② 手続 | **30日前の予告**、または**30日分以上の平均賃金**（解雇予告手当） | 労基法20条 |
| ③ 時期の制限 | 業務上災害の療養休業中と産前産後休業中＋**その後30日間**は解雇できない | 労基法19条 |

### 解雇予告の除外

**予告も手当も不要**になるのは次の2つで、いずれも**所轄労働基準監督署長の認定**が必要です。

- 天災事変その他やむを得ない事由のために**事業の継続が不可能**となった場合
- **労働者の責めに帰すべき事由**による場合

> 認定は**効力要件ではなく確認行為**とされていますが、試験では「認定を受けなければならない」で出ます。

### 予告日数の短縮

予告手当を支払った日数分だけ予告期間を短縮できます。

```
20日前に予告 ＋ 10日分の平均賃金 ＝ 適法
```

### 解雇が無効だったときの中間収入

解雇期間中の賃金を支払うが、労働者が他で得た収入（中間収入）は**平均賃金の6割を超える部分から控除**できます。**6割は必ず保障**されます。

★令和元年度の選択式で「平均賃金の6割」が問われています。
