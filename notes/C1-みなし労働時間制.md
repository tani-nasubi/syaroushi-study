# みなし労働時間制｜労基の深掘り

### 3種類の使い分け

| | 事業場外<br>38条の2 | 専門業務型<br>38条の3 | 企画業務型<br>38条の4 |
|---|---|---|---|
| 対象 | 事業場外で労働し、**労働時間を算定し難い**とき | 厚生労働省令で定める**19業務** | 事業運営に関する**企画・立案・調査・分析** |
| 手続 | 原則不要（協定で定めるなら届出） | **労使協定**＋届出 | **労使委員会の5分の4以上**の決議＋届出 |
| 本人同意 | 不要 | **必要**（令和6年4月から） | **必要** |
| みなす時間 | 所定労働時間（通常必要なら協定で定めた時間） | 協定で定めた時間 | 決議で定めた時間 |

### 事業場外みなしが使えない場合

**「労働時間を算定し難い」**が要件なので、次のようなときは使えません。

- 何人かのグループで事業場外労働に従事し、**その中に労働時間を管理する者がいる**
- 無線や携帯電話等で**随時使用者の指示を受けながら**労働している
- **あらかじめ訪問先・帰社時刻等の具体的な指示**を受け、その指示どおりに労働している

> 携帯電話が普及した現在、この制度が認められる場面はかなり限られます。

### みなしても適用されるもの

みなし労働時間制でも、**休憩・休日・深夜業・年次有給休暇**の規定は適用されます。深夜に働けば深夜割増が必要です。

### 3種類の比較

| | 事業場外みなし（38条の2） | 専門業務型裁量労働制（38条の3） | 企画業務型裁量労働制（38条の4） |
|---|---|---|---|
| 対象 | **事業場外**で業務に従事し、**労働時間を算定し難い**とき | 厚生労働省令で定める**20業務** | **事業の運営に関する事項**についての企画・立案・調査・分析 |
| 手続 | 原則**不要**（所定労働時間を超える場合は労使協定で定めた時間） | **労使協定**＋届出 | **労使委員会の5分の4以上の決議**＋届出 |
| **本人同意** | 不要 | **必要**（令和6年4月〜） | **必要** |
| 定期報告 | 不要 | **必要**（6か月以内ごとに1回） | **必要**（6か月以内ごとに1回） |

### 事業場外みなし（38条の2）

> 労働者が労働時間の全部または一部について**事業場外で業務に従事した場合**において、**労働時間を算定し難いとき**は、**所定労働時間労働したものとみなす**。

**当該業務を遂行するために通常所定労働時間を超えて労働することが必要**な場合は、**当該業務の遂行に通常必要とされる時間**労働したものとみなします。この時間は**労使協定**で定めることができ、協定で定めた時間が法定労働時間を超える場合は**届出が必要**です。

**「算定し難い」といえない場合**（適用されない）。

1. **グループで事業場外労働**に従事し、その中に**労働時間を管理する者**がいる場合
2. 事業場外で業務に従事するが、**携帯電話等により随時使用者の指示を受けながら**労働している場合
3. 事業場において**訪問先・帰社時刻等当日の業務の具体的指示**を受けたのち、事業場外で指示どおりに業務に従事し、その後事業場に戻る場合

> ★**阪急トラベルサポート事件**（添乗員）では、旅程が詳細に決められ、携帯電話で随時指示を受けていたことから「算定し難い」とはいえないとされました。
> ★**休憩・深夜業・休日**に関する規定は**適用されます**。みなされるのは労働時間だけです。

### 専門業務型裁量労働制（38条の3）の20業務

新商品・新技術の**研究開発**、情報処理システムの**分析・設計**、記事の**取材・編集**、**デザイナー**、**プロデューサー・ディレクター**、コピーライター、**システムコンサルタント**、インテリアコーディネーター、ゲーム用ソフトウェアの創作、**証券アナリスト**、金融工学等の知識を用いる**金融商品の開発**、大学における**教授研究**、**M&Aアドバイザー**（令和6年4月追加）、**公認会計士・弁護士・建築士・不動産鑑定士・弁理士・税理士・中小企業診断士**。

**労使協定で定める事項**：対象業務、みなし労働時間、業務の遂行手段・時間配分の決定について**具体的な指示をしないこと**、**健康・福祉確保措置**、**苦情処理措置**、**本人同意を得ること**および**同意しなかった場合に不利益取扱いをしないこと**、**同意の撤回**の手続、有効期間、記録の保存（**5年間、当分の間3年間**）。

### 企画業務型裁量労働制（38条の4）

**労使委員会**を設置し、委員の**5分の4以上の多数**による決議をして**所轄労働基準監督署長に届け出る**ことが必要です。

| 労使委員会 | |
|---|---|
| 構成 | **委員の半数**は、過半数労働組合等に**任期を定めて指名**された者 |
| 議事録 | 作成し**5年間（当分の間3年間）**保存、労働者に**周知** |
| 決議 | **5分の4以上** |
| **定期報告** | 決議が行われた日から**6か月以内ごとに1回**、労働者の**労働時間の状況**および**健康・福祉確保措置の実施状況**を報告 |

> ★労使委員会の決議は、**36協定など他の労使協定に代えることができます**（届出が必要なものもあります）。
> ★**対象労働者の同意**と、**同意しなかった場合の不利益取扱いの禁止**は、企画業務型では当初から必要でした。専門業務型に同意要件が入ったのは**令和6年4月**です。
