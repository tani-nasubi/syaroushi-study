# 印紙保険料と特例納付｜徴収の深掘り

### 印紙保険料（22条）

**雇用保険の日雇労働被保険者**を使用する事業主が、**一般保険料に加えて**納付するものです。

```
印紙保険料 ＝ 日雇労働被保険者1人につき1日当たりの定額
```

| 等級 | 賃金日額 | 印紙保険料の額 |
|---|---|---|
| **第1級** | **11,300円以上** | **176円** |
| **第2級** | **8,200円以上11,300円未満** | **146円** |
| **第3級** | 8,200円未満 | **96円** |

負担は**労使折半**（端数は事業主負担）です。

> ★労災保険には印紙保険料はありません。**雇用保険だけ**の制度です。
> ★厚生労働大臣は、**失業等給付費等充当徴収保険率を変更した場合**などに、印紙保険料の額を変更することができます。

### 納付の方法

| 方法 | 内容 |
|---|---|
| **雇用保険印紙**を貼付・消印 | 原則。**日雇労働被保険者手帳**に貼って**消印** |
| **印紙保険料納付計器**による納付印の押なつ | あらかじめ**所轄都道府県労働局長の承認**を受ける |

**雇用保険印紙購入通帳**の交付を受けて、**日本郵便株式会社の営業所**（郵便局）で購入します。

| 手続 | 期限・要件 |
|---|---|
| 購入通帳の交付申請 | 事業主が所轄公共職業安定所長に申請 |
| 通帳の**有効期間** | 交付の日から**その日の属する保険年度の末日**まで |
| **買戻し**（印紙が不要になったとき） | 所轄公共職業安定所長の**確認**を受けて、日本郵便の営業所で買い戻す |
| **印紙保険料納付状況報告書** | 翌月末日までに所轄公共職業安定所長に提出 |
| **帳簿**の備付け | 印紙の受払状況を記載し、**翌年度の初日から3年間**保存 |

> ★買戻しには**公共職業安定所長の確認**が必要です。「都道府県労働局長」とする肢は誤りです。

### 印紙保険料の追徴金

事業主が印紙保険料を納付しなかったとき（貼付・消印を怠ったとき）、政府が**認定決定**を行い、その額の**100分の25**の追徴金が徴収されます。

> ★一般保険料の追徴金は**10%**、印紙保険料は**25%**。この違いが定番です。

### 特例納付保険料（26条）

**雇用保険の被保険者資格の確認**があった場合に、事業主が**過去にさかのぼって**保険料を納める制度です。

| 対象 | 内容 |
|---|---|
| きっかけ | 雇用保険法**22条5項**の規定により、**2年を超えてさかのぼって**被保険者であった期間が認められた者がいること |
| 誰が | 対象となる被保険者を使用していた**事業主**（保険料を納付していなかった者） |
| 手続 | 厚生労働大臣が事業主に**勧奨** → 事業主が**申出** → 政府が**額を決定・通知** → **納付** |
| 額 | さかのぼった期間のうち**時効により徴収できなくなった期間**に係る一般保険料額に相当する額＋その**100分の10**に相当する額 |

> ★事業主の**申出があってはじめて**納付義務が生じます。申出は任意で、強制はされません。
> ★通知を受けた事業主は、**通知を受けた日から30日以内**（指定された期限まで）に納付します。

### 口座振替（21条の2）

事業主から申出があり、政府が納付が確実と認め、かつ徴収上有利と認めるときは、**口座振替による納付**を承認できます。対象は**印紙保険料以外**の労働保険料です。

> ★印紙保険料は口座振替の対象外です。
> ★口座振替を利用すると、納期限が通常より**後ろ倒し**になります（概算・確定の第1期は9月上旬など）。

### 特例納付保険料の「特例対象者」

**雇用保険法22条5項**に規定する者、つまり**2年を超えてさかのぼって被保険者であった期間が認められた者**をいいます。

| | |
|---|---|
| 誰を雇っていた事業主が納められるか | **2年以内の算定基礎期間をさかのぼって計算できる特例対象者**を雇用していた事業主 |
| きっかけ | 厚生労働大臣が事業主に**勧奨** → 事業主の**申出** |
| 額 | 時効で徴収できなくなった期間の一般保険料相当額 ＋ その**100分の10** |
| 納付 | 通知を受けた日から**指定された期限**まで |

> ★**事業主の申出があってはじめて**納付義務が生じます。強制はされません。
> ★対象は**雇用保険**の話です。労災保険には特例納付の制度がありません。
