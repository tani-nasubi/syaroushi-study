## 目的条文

**1条**
> この法律は、労働者又はその被扶養者の**業務災害以外**の疾病、負傷若しくは死亡又は**出産**に関して保険給付を行い、もつて**国民の生活の安定と福祉の向上**に寄与することを目的とする。

**2条（基本的理念）**
> 健康保険制度については、これが**医療保険制度の基本**をなすものであることにかんがみ、高齢化の進展、疾病構造の変化、社会経済情勢の変化等に対応し、その他の医療保険制度及び**後期高齢者医療制度**並びにこれらに密接に関連する制度と併せてその**在り方に関して常に検討**が加えられ、その結果に基づき、**医療保険の運営の効率化**、給付の内容及び費用の負担の**適正化**並びに**国民が受ける医療の質の向上**を総合的に図りつつ、実施されなければならない。

> 「**業務災害以外**」が健保の守備範囲を決める。業務災害は労災の管轄。
> 2条は第50回の選択式で「疾病構造の変化」が正答になっている。

## 1. 保険者

| 保険者 | 管掌 |
|---|---|
| **全国健康保険協会**（協会けんぽ） | 健康保険組合の組合員でない被保険者 |
| **健康保険組合** | 組合の被保険者 |

### 全国健康保険協会
- 主たる事務所は**東京都**、従たる事務所（支部）は各都道府県
- **運営委員会**：事業主・被保険者・学識経験者を代表する委員**各3人**（計9人）
- 都道府県ごとに**評議会**を置く

### 健康保険組合

| 区分 | 設立要件 |
|---|---|
| **単一組合** | 常時**700人以上**の被保険者を使用する事業主 |
| **総合組合** | 同種同業の複数事業主が共同で設立。合算して常時**3,000人以上** |

- 設立には**厚生労働大臣の認可**と被保険者の**2分の1以上**の同意
- **組合会**が議決機関。組合会議員は**選定議員**（事業主が選定）と**互選議員**（被保険者が互選）が**同数**
- 理事は組合会において選定議員・互選議員がそれぞれ選挙。**理事長は選定議員である理事のうちから選挙**

## 2. 被保険者

### 適用事業所

| 区分 | 内容 |
|---|---|
| 強制適用 | **法人**の事業所（業種・人数を問わず）／**個人**で常時**5人以上**の法定17業種 |
| 非適用業種（個人・5人以上でも任意） | 農林水産業、**宗教業**、その他のサービス業（旅館、飲食店、理美容業等） |
| 任意適用 | 従業員の**2分の1以上**の同意＋厚生労働大臣の**認可**。取消しは**4分の3以上**の同意 |

> 令和4年10月から**士業**（弁護士・社労士等）は適用業種に追加。

### 適用除外（3条1項）

| 対象 | 除外が外れる要件 |
|---|---|
| 日々雇い入れられる者 | **1か月**を超えて引き続き使用 |
| 2か月以内の期間を定めて使用される者 | 当該期間を超えて使用されることが**見込まれる**場合 |
| **所在地が一定しない事業所**に使用される者 | **例外なし**（絶対的除外） |
| 季節的業務に使用される者 | 継続して**4か月**を超えて使用される予定 |
| 臨時的事業の事業所に使用される者 | 継続して**6か月**を超えて使用される予定 |
| **後期高齢者医療の被保険者等** | — |

### 短時間労働者（3条1項9号）

**特定適用事業所**（厚生年金保険の被保険者数が常時**51人以上**）に使用される短時間労働者は、次の**すべて**を満たすと被保険者。

① 週の所定労働時間が**20時間以上**
② 報酬月額が**88,000円以上**
③ 継続して**2か月を超えて**使用される見込み
④ **学生でない**こと

> ⚠️企業規模要件の撤廃は**令和9年10月から段階的**、賃金要件の撤廃も含め**令和8年度試験では未施行**。

### 任意継続被保険者（3条4項・37条・38条）

| 項目 | 内容 |
|---|---|
| 要件 | 資格喪失の日の**前日まで継続して2か月以上**被保険者 |
| 申出 | 資格を喪失した日から**20日以内** |
| 期間 | 最長**2年** |
| 保険料 | **全額自己負担**（事業主負担なし） |
| 標準報酬月額 | ① 資格喪失時の標準報酬月額 と ② 前年9月30日における全被保険者の平均標準報酬月額（⚠️令和8年度は要確認）の**いずれか低い額**。健保組合は規約で①とすることができる |
| 給付 | **傷病手当金・出産手当金は支給されない**（継続給付として受けるものを除く） |
| 資格喪失 | 保険料を納付期日までに納付しないと**翌日に喪失**／令和4年1月から**任意の資格喪失が可能**（申出が受理された日の属する月の末日） |

### 被扶養者（3条7項）★令和8年度改正

**年間収入の基準**

| 区分 | 基準 |
|---|---|
| 原則 | **130万円未満** |
| ★**19歳以上23歳未満** | **150万円未満**（新設）⚠️要確認 |
| 60歳以上／障害厚生年金の受給要件に該当する程度の障害者 | **180万円未満** |

加えて、**同一世帯**なら被保険者の年間収入の**2分の1未満**、**別世帯**なら被保険者からの**援助額より少ない**こと。

**被扶養者の範囲**

| 同一世帯要件 | 対象 |
|---|---|
| **不要** | 配偶者（**事実婚を含む**）、子、孫、**兄弟姉妹**、直系尊属 |
| **必要** | 上記以外の**三親等内の親族**、事実婚の配偶者の父母・子（配偶者死亡後も含む） |

**国内居住要件**：原則として日本国内に住所を有すること（留学生等は例外）。

## 3. 標準報酬

| 項目 | 健保 | （参考）厚年 |
|---|---|---|
| 等級数 | **50等級** | 32等級 |
| 下限 | 第1級 **58,000円** | 第1級 88,000円 |
| 上限 | 第50級 **1,390,000円** | 第32級 650,000円 |
| **標準賞与額の上限** | **年度累計 573万円**（4/1〜翌3/31） | 1か月 150万円 |

> **★引っかけ**：健保は**年度累計**、厚年は**1か月ごと**。

### 決定・改定

| 種類 | 内容 |
|---|---|
| **資格取得時決定** | 1月〜5月決定→その年の8月まで／6月〜12月決定→翌年8月まで |
| **定時決定** | 毎年**7月1日**現在の被保険者について、**4・5・6月**の報酬の平均で決定。その年の**9月から翌年8月**まで適用 |
| **随時改定（月変）** | ① **固定的賃金の変動** ② 変動月以後継続した**3か月**の平均で**2等級以上**の差 ③ 3か月とも支払基礎日数**17日以上**（短時間労働者は11日以上）→ 変動月から**4か月目**に改定 |
| **育児休業等終了時改定／産前産後休業終了時改定** | **本人の申出**により、**1等級**の差でも改定 |

**定時決定の対象外**：6月1日〜7月1日に被保険者となった者、7月〜9月に随時改定等が行われる者

**報酬・賞与**
- 報酬＝労働の対償として受けるすべてのもの。ただし**臨時に受けるもの**及び**3か月を超える期間ごとに受けるもの**を除く
- 賞与＝3か月を超える期間ごとに受けるもの

| 類型 | 内容 |
|---|---|
| **評価療養** | 先進医療、医薬品・医療機器の**治験**、薬事承認後・保険収載前の医薬品の使用 等（将来の保険導入を評価するもの） |
| **患者申出療養** | 国内未承認医薬品等の使用を希望する**患者の申出**を起点とする（平成28年4月創設） |
| **選定療養** | 特別の療養環境（**差額ベッド**）、予約診療、時間外診療、**大病院の初診・再診**、制限回数を超える医療行為、金属床総義歯、180日超の入院、**長期収載品**（令和6年10月〜） |

> **★引っかけ**：**患者申出療養は評価療養とは別の類型**。「評価療養に含まれる」は誤り。

### 高額療養費（115条）

| 項目 | 内容 |
|---|---|
| 計算単位 | **同一月・同一医療機関・同一診療**ごと（**入院と外来、医科と歯科は別**に計算） |
| 所得区分 | 70歳未満は標準報酬月額により**5区分**（83万円以上／53〜79万円／28〜50万円／26万円以下／低所得者） |
| **世帯合算** | 同一世帯で**21,000円以上**の自己負担が複数あれば合算（70歳以上は金額を問わず合算） |
| **多数回該当** | 直近**12か月**に**3回以上**該当すると、**4回目**から限度額が引き下げられる |
| 現物給付化 | **限度額適用認定証**の提示、又はオンライン資格確認により、窓口負担を限度額までにできる |
| 時効 | 診療月の翌月1日から**2年** |

**高額介護合算療養費**（115条の2）
毎年**8月1日から翌年7月31日**までの1年間の医療保険と介護保険の自己負担を合算し、限度額を超える分を支給。

### 傷病手当金（99条）

| 項目 | 内容 |
|---|---|
| 支給開始 | 労務に服することができなくなった日から起算して**3日**（**継続した**3日間＝待期）を経過した日から |
| **支給期間** | 支給を始めた日から**通算して1年6か月**（令和4年1月から通算化） |
| **額** | 支給開始日の属する月以前の**直近の継続した12か月間**の各月の標準報酬月額を平均した額 ÷ 30 × **3分の2** |
| 12か月未満の場合 | ① 当該期間の平均 と ② 全被保険者の平均標準報酬月額 のいずれか**少ない額** |
| 調整 | 報酬を受ける場合、**障害厚生年金・障害手当金**、老齢退職年金給付、**出産手当金**との併給調整 |

> 労災の休業補償給付の待期3日は**継続・断続を問わない**のに対し、健保は**継続した3日**が必要。

### 出産関係

| 給付 | 内容 |
|---|---|
| **出産手当金** | 出産の日以前**42日**（多胎**98日**）から出産の日後**56日**までの労務に服さなかった期間。額は傷病手当金と同じ算定 |
| **出産育児一時金** | 政令で定める額（⚠️近年50万円）。産科医療補償制度に加入する医療機関等での出産でない場合は減額 |
| 対象となる出産 | **妊娠4か月（85日）以上**（死産・流産を含む） |

> 労基法65条の産前6週間＝**42日**、多胎14週間＝**98日**、産後8週間＝**56日**と対応。
> 傷病手当金と出産手当金が同時に受けられるときは**出産手当金が優先**し、傷病手当金は差額のみ。

### 埋葬料（100条）
- **5万円**（定額）。被保険者により生計を維持していた者で埋葬を行うもの
- 受けるべき者がない場合は**埋葬費**として、埋葬料の金額の範囲内で実際に埋葬に要した費用
- 被扶養者の死亡は**家族埋葬料 5万円**

### 資格喪失後の給付

| 給付 | 要件 |
|---|---|
| **継続給付**（傷病手当金・出産手当金） | 資格喪失日の前日まで**引き続き1年以上**被保険者（**任意継続被保険者・共済組合員であった期間は算入しない**） |
| 資格喪失後の**出産育児一時金** | 上記の要件＋資格喪失後**6か月以内**の出産 |
| 資格喪失後の**埋葬料** | 資格喪失後**3か月以内**の死亡、又は継続給付を受けている間・受けなくなって3か月以内の死亡 |

> **1年以上／6か月以内／3か月以内** の3つの数字を給付と結びつけること。

### 給付制限（116条〜120条）

| 事由 | 効果 |
|---|---|
| **故意の犯罪行為・故意**による事故 | 保険給付を**行わない** |
| 闘争・泥酔・著しい不行跡 | **全部又は一部を行わないことができる** |
| 正当な理由なく療養に関する指示に従わない | **一部**を行わないことができる |
| 少年院・刑事施設等に拘禁 | 疾病・負傷・出産に係る給付を行わない（**家族給付は行う**） |

### 保険給付の調整

| 相手 | 調整 |
|---|---|
| **労災保険**（55条1項） | 業務災害・通勤災害として労災の給付を受けられるときは、**健康保険の給付は行わない** |
| 介護保険 | 訪問看護等で給付が重なる場合は**介護保険が優先** |
| 他の法令 | 国家公務員災害補償法等による給付があるときはその限度で行わない |
| **第三者行為**（57条） | 保険者は給付の価額の限度で**損害賠償請求権を代位取得**。先に賠償を受けたときはその限度で給付を行わない |

### 不正利得の徴収（58条）

| 対象 | 内容 |
|---|---|
| 被保険者等 | 偽りその他不正の行為で保険給付を受けた者から、給付の価額の**全部又は一部**を徴収できる |
| **事業主** | 虚偽の届出等が原因のときは、事業主に**連帯して**徴収金を納付させることができる |
| **保険医療機関等** | 不正に療養の給付に関する費用を受けたときは、**返還額に100分の40を加算**した額を徴収できる |

> 「100分の40の加算」は健保特有の数字。

## 5. 費用の負担

| 項目 | 内容 |
|---|---|
| 保険料 | 標準報酬月額・標準賞与額 ×（一般保険料率＋介護保険料率＋子ども・子育て支援金率） |
| 負担割合 | 原則**労使折半**。健保組合は規約で**事業主負担割合を2分の1超**とすることができる |
| 納付義務 | **事業主**（被保険者負担分を報酬から控除して納付） |
| 納期限 | 翌月**末日** |

### 令和8年度の保険料率 ⚠️要確認

| 項目 | 率 |
|---|---|
| 一般保険料率（協会けんぽ） | **都道府県ごと**（東京 9.85％、最高 佐賀県、最低 新潟県） |
| **法定範囲** | **1000分の30 〜 1000分の130** |
| **介護保険料率** | **全国一律 1000分の16.2**（令和7年度15.9から引上げ） |
| **子ども・子育て支援金率** ★令和8年4月〜 | **全国一律 1000分の2.3** |

> **★引っかけ**：一般保険料率は**都道府県単位**、介護保険料率と支援金率は**全国一律**。

### 保険料の免除

| 免除 | 内容 |
|---|---|
| **産前産後休業期間** | 事業主の申出により**労使双方**を免除 |
| **育児休業等期間** | 同上 |
| 免除期間の扱い | **被保険者期間に算入**される（年金額にも反映） |

**免除の対象月**
- その月の**末日が休業期間中**である月
- 育児休業等は、**同一月内に14日以上**取得した場合もその月が対象
- **賞与に係る保険料**は、育児休業等が**1か月を超える**場合に限り免除（令和4年10月〜）

## 5-2. 届出と保険料の徴収実務

### 主な届出（事業主が行う）

| 届出 | 期限 |
|---|---|
| 被保険者資格取得届・喪失届 | **5日以内**（船員は10日以内） |
| 被扶養者（異動）届 | **5日以内** |
| **報酬月額算定基礎届**（定時決定） | 毎年**7月10日**まで |
| 報酬月額変更届（随時改定） | 速やかに |
| **賞与支払届** | **5日以内** |
| 産前産後休業・育児休業等取得者申出書 | 休業期間中 |

### 保険料の徴収

| 項目 | 内容 |
|---|---|
| **納付義務者** | **事業主**（被保険者負担分を報酬から控除して納付） |
| 控除の時期 | **前月分**の保険料を当月の報酬から控除（167条）。**賞与からは当月分**を控除できる |
| 納期限 | 翌月**末日** |
| **繰上徴収**（172条） | 国税・地方税の滞納処分、強制執行、破産手続開始、法人の解散、事業の廃止 等の場合、納期前でも徴収できる |
| **督促**（180条） | 督促状の指定期限は、発する日から起算して**10日以上**経過した日 |
| **延滞金**（181条） | 年**14.6％**（納期限の翌日から**3か月**を経過する日までは年**7.3％**）。保険料額が**1,000円未満**なら徴収しない |
| 徴収の方法 | 保険料その他の徴収金は**国税徴収の例**による |

### 国庫負担・補助

| 区分 | 内容 |
|---|---|
| **国庫負担** | 健康保険事業の**事務の執行に要する費用** |
| **国庫補助** | 協会が管掌する健康保険の給付費等に対し、給付費等の**1000分の130〜1000分の200**の範囲内で政令で定める割合（当分の間**1000分の164**）⚠️要確認 |
| 健康保険組合 | 給付費等に対する国庫補助は**予算の範囲内**で行うことができる |

## 5-3. 健康保険組合の運営

| 事項 | 内容 |
|---|---|
| **設立** | 単一組合＝常時**700人以上**／総合組合＝合算して常時**3,000人以上**。被保険者の**2分の1以上**の同意＋**厚生労働大臣の認可** |
| **組合会** | 議決機関。選定議員（事業主が選定）と互選議員（被保険者が互選）が**同数**。理事長は**選定議員である理事**のうちから選挙 |
| **合併・分割** | 組合会の議決＋厚生労働大臣の**認可** |
| **解散** | ① 組合会議員の定数の**4分の3以上**の多数による議決 ② 健康保険事業の継続不能 ③ **厚生労働大臣による解散命令**。①②は厚生労働大臣の認可が必要 |
| 解散後 | 権利義務は**全国健康保険協会**が承継する |
| 規約 | 変更には厚生労働大臣の認可（軽微な事項は届出） |
| **調整保険料** | 財政窮迫組合への交付金等の財源として、健康保険組合連合会が徴収 |

### 保健事業・福祉事業（150条）
被保険者・被扶養者の健康の保持増進のため、**健康教育・健康相談・健康診査**その他必要な事業を行うよう努める。
**特定健康診査・特定保健指導**（高齢者医療確保法）は、**40歳以上75歳未満**の加入者に対し保険者が実施する義務を負う。

| 項目 | 内容 |
|---|---|
| **時効** | 保険給付を受ける権利・保険料を徴収する権利ともに**2年** |
| 届出期限 | 資格取得届・喪失届とも**5日以内**（船員は10日以内） |

### 保険医療機関・保険薬局／保険医・保険薬剤師（63条〜）

### 指定訪問看護（88条）

利用者は**基本利用料**（3割等）と、時間外等の**その他の利用料**を負担する。
