# 健康診断｜安衛の深掘り

### 一般健康診断（66条1項）

| 種類 | 対象 | 時期 |
|---|---|---|
| **雇入時**の健康診断 | 常時使用する労働者 | 雇入れの際 |
| **定期**健康診断 | 常時使用する労働者 | **1年以内ごとに1回** |
| **特定業務従事者**の健康診断 | 深夜業等の特定業務に常時従事する労働者 | 配置替えの際および**6か月以内ごとに1回** |
| **海外派遣労働者**の健康診断 | 6か月以上海外に派遣する労働者 | 派遣**前**および帰国後 |
| **給食従業員の検便** | 事業に附属する食堂・炊事場での給食業務従事者 | 雇入れの際、配置替えの際 |

> ★**深夜業**は「特定業務」に含まれ、**6か月以内ごとに1回**です。定期健診の1年と混同しやすいところです。
> ★**雇入時**の健康診断は、**医師による健康診断を受けた後3か月を経過しない者**が結果を証明する書面を提出したときは、その項目を省略できます。**定期健診と違い、医師が必要でないと認めても項目を省略できません**。

### 健康診断の項目（則44条）

1. 既往歴・業務歴の調査
2. 自覚症状・他覚症状の有無の検査
3. 身長・体重・**腹囲**・視力・聴力の検査
4. **胸部エックス線**検査・喀痰検査
5. **血圧**の測定
6. **貧血**検査
7. **肝機能**検査
8. **血中脂質**検査
9. **血糖**検査
10. **尿**検査
11. **心電図**検査

**定期**健康診断では、医師が必要でないと認めるときに一定の項目を省略できます（身長・腹囲・胸部エックス線・喀痰・貧血・肝機能・血中脂質・血糖・心電図）。

> ★**尿検査・血圧・体重・視力・聴力**は省略できません。

### 特殊健康診断（66条2項・3項）

**有害な業務**に従事する労働者に対して行う健康診断です。

| 対象 | 根拠 |
|---|---|
| **高気圧業務、放射線業務、特定化学物質、鉛、四アルキル鉛、有機溶剤、石綿** | 政令で定める有害業務（66条2項前段） |
| **じん肺健康診断** | じん肺法（同項後段） |
| **歯科医師による健康診断**（塩酸・硝酸・硫酸・亜硫酸・弗化水素・黄りん等のガス・蒸気・粉じんを発散する場所での業務） | 66条3項 |

原則として**6か月以内ごとに1回**（じん肺は管理区分に応じて1〜3年以内ごとに1回）です。

> ★**有害業務に従事させたことのある労働者で現に使用しているもの**（＝配置転換後）にも行う必要があります。「現に従事している者だけ」は誤りです。
> ★特殊健康診断は**労働時間として扱う**（費用も事業者負担）とされています。一般健康診断は費用は事業者負担ですが、**受診に要した時間の賃金支払は労使協議によるべき**とされ、義務ではありません。

### 労働者の受診義務（66条5項）

労働者は、事業者が行う健康診断を**受けなければなりません**。ただし、事業者の指定した医師等が行う健康診断を受けることを希望しない場合において、**他の医師等の行うこれらの規定による健康診断に相当する健康診断を受け、その結果を証明する書面を事業者に提出**したときは、この限りではありません。

> ★これを「**医師選択の自由**」といいます。**一般健康診断**についてのみ認められ、**特殊健康診断には認められません**。

### 結果の記録・通知・意見聴取

| 条 | 義務 |
|---|---|
| 66条の3 | **健康診断個人票**を作成し**5年間**保存（特殊健診は種類により7年・30年・40年） |
| 66条の4 | 異常の所見があると診断された労働者について、**医師等の意見を聴く**（健診が行われた日から**3か月以内**） |
| 66条の5 | 医師等の意見を勘案し、必要があると認めるときは**就業場所の変更・作業の転換・労働時間の短縮**等の措置を講ずる |
| 66条の6 | **健康診断の結果を労働者に通知**（異常の所見の有無にかかわらず**全員**に） |
| 66条の7 | **著しい健康の保持に努める必要がある**と認める労働者に対し、医師・保健師による**保健指導**を行うよう**努める** |
| 100条・則52条 | 常時**50人以上**の事業場は、**定期健康診断結果報告書**を所轄労働基準監督署長に提出 |

> ★通知は**全員**に対して行います。「異常のあった者にだけ」は誤りです。
> ★報告義務があるのは**常時50人以上**の事業場です（特殊健診・歯科健診は**規模を問わず**報告）。

### 健康管理手帳（67条）

**がんその他の重度の健康障害を生ずるおそれのある業務**に従事していた者のうち、**離職の際に、または離職の後に**、政令で定める要件に該当する者に対し、**都道府県労働局長**が交付します。

| | |
|---|---|
| 交付主体 | **都道府県労働局長**（本人の申請による） |
| 対象業務 | ベンジジン、ベータ―ナフチルアミン、**石綿**、**粉じん**（じん肺管理区分2・3）、クロム酸、三酸化砒素、コークス炉、ビス（クロロメチル）エーテル、塩化ビニル、ジアニシジン、1,2-ジクロロプロパン、オルト-トルイジン など |
| 効果 | **無料**で健康診断を受けられる（年**2回**または**1回**） |
| 譲渡・貸与 | **禁止** |

> ★交付は**都道府県労働局長**。労働基準監督署長ではありません。
> ★在職中でも要件を満たせば交付されます（「離職の際に又は離職の後に」）。
