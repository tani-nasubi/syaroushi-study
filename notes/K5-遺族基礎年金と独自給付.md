# 遺族基礎年金と第1号の独自給付｜国年の深掘り

### 遺族基礎年金の受給権者（37条の2）

**被保険者等の死亡当時、その者によって生計を維持していた**次の者。

| 順位 | 遺族 | 要件 |
|---|---|---|
| ① | **配偶者** | **子と生計を同じくする**こと |
| ② | **子** | **18歳到達年度の末日**までの間にあるか、**20歳未満で障害等級1級・2級**であって、かつ**現に婚姻していない**こと |

> ★**子のない配偶者には支給されません**。ここが遺族厚生年金との最大の違いです。
> ★平成26年4月から、**父子家庭**（夫）にも支給されるようになりました。それ以前は「妻」限定でした。

### 死亡者の要件（37条）

| 号 | 要件 |
|---|---|
| 1号 | **被保険者**が死亡したとき |
| 2号 | 被保険者であった者であって、**日本国内に住所**を有し、かつ**60歳以上65歳未満**の者が死亡したとき |
| 3号 | **老齢基礎年金の受給権者**（保険料納付済期間＋免除期間が**25年以上**の者に限る）が死亡したとき |
| 4号 | 保険料納付済期間＋免除期間が**25年以上**である者が死亡したとき |

**保険料納付要件**（1号・2号のみ）：死亡日の**前日**において、死亡日の属する月の**前々月**までに、保険料納付済期間＋免除期間が被保険者期間の**3分の2以上**（または令和8年3月31日までは直近1年間に未納なし）。

> ★3号・4号は**25年**が必要です。老齢基礎年金の受給資格期間が10年に短縮されても、**遺族基礎年金・寡婦年金の要件は25年のまま**です。ここが最頻出です。

### 年金額（38条・39条）

```
遺族基礎年金 ＝ 老齢基礎年金の満額 ＋ 子の加算額
```

| 受給者 | 加算 |
|---|---|
| **配偶者**が受給 | 子1人目・2人目は各**224,700円×改定率**、3人目以降は各**74,900円×改定率** |
| **子**が受給（配偶者がいない） | **2人目**から加算（1人目は本体に含まれる）。総額を**子の数で割った額**が各人に支給される |

### 死亡の推定（18条の3）

> 船舶が沈没・転覆・滅失・行方不明となった際、現にその船舶に乗っていた者、又は船舶に乗っていてその**航行中に行方不明**となった者の**生死が3か月間分からない**場合、又はこれらの者の**死亡が3か月以内に明らかとなり、かつ死亡の時期が分からない**場合には、**死亡を支給事由とする給付**の支給に関する規定の適用については、**その船舶が沈没等をした日**又は**その者が行方不明となった日**に死亡したものと**推定する**。航空機についても同様。

> ★推定される日は**事故の日／行方不明になった日**です。**3か月が経過した日ではありません**。
> ★「死亡を支給事由とする給付」なので、**遺族基礎年金・寡婦年金・死亡一時金**のすべてに及びます。
> ★厚年法59条の2は「**遺族厚生年金の支給に関する規定の適用について**」と対象が限定されています。書き分けに注意します。

### 失権（40条）

| 受給者 | 失権事由 |
|---|---|
| **配偶者** | 死亡、**婚姻**（事実婚を含む）、**直系血族・直系姻族以外の者の養子**となったとき、**すべての子**が加算対象でなくなったとき |
| **子** | 死亡、婚姻、直系血族・直系姻族以外の者の養子となったとき、**離縁**により死亡した者の子でなくなったとき、**18歳到達年度末**に達したとき（障害状態にあるときを除く）、障害状態に該当しなくなったとき（18歳年度末を過ぎているとき）、**20歳**に達したとき |

> ★**配偶者は、子が失権すると自分も失権**します（子と生計を同じくすることが要件のため）。

### 寡婦年金（49条）

| 要件 | |
|---|---|
| 死亡した夫 | **第1号被保険者**としての保険料納付済期間＋免除期間が**10年以上**あること（平成29年8月から25年→10年）、かつ**老齢基礎年金・障害基礎年金を受けたことがない**こと |
| 妻 | 夫の死亡当時**生計を維持**され、**婚姻期間が10年以上**継続していること |
| 支給期間 | 妻が**60歳から65歳**に達するまで |
| 額 | 夫の第1号被保険者期間だけで計算した**老齢基礎年金額の4分の3** |

> ★**夫が老齢基礎年金・障害基礎年金を受けたことがある**と支給されません。
> ★**婚姻期間10年以上**（事実婚を含む）が必要です。
> ★妻が**繰上げ支給の老齢基礎年金**を受けているときは支給されません。

### 死亡一時金（52条の2）

| 要件 | |
|---|---|
| 死亡者 | **第1号被保険者**としての保険料納付済期間（一部免除期間は月数を換算）が**36月以上**ある者が、**老齢基礎年金・障害基礎年金を受けないまま死亡**したこと |
| 遺族 | **生計を同じくしていた**配偶者・子・父母・孫・祖父母・兄弟姉妹（この順位） |
| 額 | 納付月数に応じ**120,000円〜320,000円**。付加保険料を**36月以上**納付していれば**8,500円**加算 |
| 時効 | **2年** |

> ★**遺族基礎年金を受けられるときは支給されません**（ただし、その年金が全額支給停止のときは支給される）。
> ★**寡婦年金と死亡一時金の両方の要件を満たすときは、いずれかを選択**します。
> ★死亡一時金の遺族の範囲は**生計同一**が基準で、**生計維持ではありません**。

### 付加年金（43条〜48条）

| | |
|---|---|
| 対象 | **第1号被保険者**および**任意加入被保険者**（**65歳以上の特例任意加入者を除く**） |
| 付加保険料 | **月額400円** |
| 年金額 | **200円 × 付加保険料納付月数** |
| 併給 | **老齢基礎年金と併せて**支給される（老齢基礎年金が支給停止のときは付加年金も停止） |

> ★**2年で元が取れる**しくみです（400円×n を納め、毎年200円×n を受ける）。
> ★**国民年金基金の加入員**は付加保険料を納付できません（基金に付加年金相当分が含まれるため）。
> ★付加年金には**物価スライドがありません**（改定率が乗じられない）。

### 短期在留外国人の脱退一時金（附則9条の3の2）

| 要件 | |
|---|---|
| 対象 | **日本国籍を有しない**者で、**第1号被保険者**としての保険料納付済期間等の月数が**6か月以上**あり、**老齢基礎年金の受給資格期間を満たしていない**者 |
| 請求 | 日本国内に住所を有しなくなった日から**2年以内** |
| 額 | 保険料納付済期間の月数に応じ、**最終月の属する年度の保険料額**を基礎に算定（上限**60月**＝5年） |

> ★上限が**36月→60月**に拡大されたのは令和3年4月からです。

### 過誤払による返還金債権への充当（21条の2）

年金給付の受給権者が**死亡**したため受給権が消滅したにもかかわらず、**死亡日の属する月の翌月以降の分**として過誤払が行われた場合、**返還金債権に係る債務の弁済をすべき者に支払うべき年金給付**があるときは、その**支払金の金額を返還金債権の金額に充当**することができます。

> ★死亡届が遅れて年金が振り込まれてしまった場合の精算規定です。労災法12条の2、厚年法も同じ仕組みを持ちます。

### 納付受託者（92条の3〜92条の5）

**コンビニエンスストア等**が保険料の納付を受託する仕組みです。納付受託者は**帳簿を備え付け**、納付事務に関する事項を記載・保存しなければなりません。厚生労働大臣は**報告**を求め、**立入検査**をさせることができます。

立入検査の職員は**身分を示す証明書を携帯**し、請求があるときは提示しなければならず、この権限は**犯罪捜査のために認められたものと解釈してはならない**とされています。

> ★納付受託者が保険料を**受託した日**に、保険料は**納付されたものとみなされます**（92条の4）。

### 戸籍事項の無料証明（104条）

**市町村長**（指定都市では区長・総合区長）は、厚生労働大臣または被保険者・被保険者であった者・受給権者に対して、**条例の定めるところにより**、被保険者等の**戸籍に関し無料で証明**を行うことができます。

### 不服申立て（101条）

| 対象 | 手続 |
|---|---|
| **被保険者の資格に関する処分、給付に関する処分、保険料その他の徴収金に関する処分** | **社会保険審査官**に審査請求 → **社会保険審査会**に再審査請求 |

> ★国民年金法では、**保険料に関する処分も社会保険審査官への審査請求（2審制）**です。厚生年金保険法では**保険料関係は社会保険審査会への直接審査請求（1審制）**であり、**ここが違います**。
> ★審査請求をした日から**2か月以内**に決定がないときは、**棄却されたものとみなす**ことができます（101条2項）。
> ★**14条の4**（被保険者記録の訂正請求に対する決定）については、この不服申立ての対象外です。

### 基金が支給する年金・一時金の下限（130条）

| | 下限 |
|---|---|
| 基金が老齢基礎年金の受給権者に支給する**年金の額** | **200円**（繰上げ・繰下げの受給権者については政令で定める額）に**加入員期間の月数**を乗じて得た額を**超える**ものでなければならない |
| 基金が支給する**一時金の額** | **8,500円**を**超える**ものでなければならない |

- 年金額は政令の定めるところにより算定されるものでなければなりません（1項）。
- 加入員期間は、**87条の保険料に係る保険料納付済期間である期間に限られます**（免除期間中は加入員になれないため）。

> ★**200円**は付加年金の「200円×納付月数」と、**8,500円**は死亡一時金の付加保険料加算と同じ数字です。**まとめて覚えます**。
> ★**繰下げ**の受給権者に支給する年金は「200円に増額率を乗じて得た額を200円に加えた額」を政令で定めています。

### 基金の年金と老齢基礎年金の支給停止（131条）

> 老齢基礎年金の受給権者に対し基金が支給する年金は、**当該老齢基礎年金がその全額につき支給を停止されている場合を除いては**、その支給を停止することができない。ただし、当該年金の額のうち、**200円**に当該基金に係る加入員期間の月数を乗じて得た額を超える部分については、この限りでない。

- 基金の年金は、原則として**止められません**。
- 止められるのは、①**老齢基礎年金が全額支給停止**されているとき、又は②**200円×加入員期間の月数を超える部分**、のいずれかです。

> ★**200円**です。「400円」は**誤り**（令和元年に出ました）。付加年金の額が「200円×納付月数」であることと同じ数字です。

### 国民年金基金の合併・分割（137条の3〜）

基金は、**厚生労働大臣の認可**を受けて、他の基金と**吸収合併**をすることができます。ただし、**地域型基金と職能型基金**との吸収合併は、**地区が全国である地域型基金が吸収合併存続基金となる場合**を除き、することができません。

合併をする基金は、**吸収合併契約**を締結しなければなりません。

> ★平成31年4月に**全国国民年金基金**が設立され、地域型基金の多くが合併しました。

### 生計維持の認定 — 年収850万円

「**その者によって生計を維持していた**」といえるには、**生計同一**であることに加えて、収入が**将来にわたって年収850万円未満**（所得655万5千円未満）であることが必要です。

| 場面 | 扱い |
|---|---|
| 死亡当時は850万円以上だが、**おおむね5年以内に850万円未満**になると認められる | **生計維持あり** |
| 死亡当時850万円以上で受給権を得られず、**その後に収入が下がった** | **さかのぼって受給権は生じない** |

> ★**過去9年で6回**、健保・厚年・国年をまたいで問われています。
> ★判定は**死亡当時**が基準です。「あとから下がれば受給権が発生する」は誤りです。
> ★**加給年金額・振替加算**の生計維持の判定も同じ基準です。
