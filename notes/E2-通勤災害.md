# 通勤災害｜労災の深掘り

### 通勤の定義（7条2項）

> 労働者が、**就業に関し**、次に掲げる移動を、**合理的な経路及び方法**により行うことをいい、**業務の性質を有するものを除く**。

| 号 | 移動 |
|---|---|
| 1号 | **住居と就業の場所**との間の往復 |
| 2号 | 就業の場所から**他の就業の場所**への移動（複数就業者） |
| 3号 | 1号の往復に**先行・後続する住居間の移動**（単身赴任者の帰省） |

要件は4つです。**①就業に関し ②住居と就業の場所等の移動 ③合理的な経路及び方法 ④業務の性質を有しない**。

> ★④を満たさないもの（事業主提供の専用バス、緊急呼出しでの出勤）は**業務災害**になります。「通勤災害である」とする肢は誤りです。

### 「就業に関し」

- 業務に就くため、または業務を終えたことによる移動であること
- **遅刻や早退**でも就業との関連は失われない
- 前日の**泊まり込み**の後の帰宅は、就業との関連が認められる
- **所定の就業日でない日**の出勤（休日出勤）も対象

### 住居

労働者が**居住して日常生活の用に供している家屋等の場所**で、本人の**就業のための拠点**となるところ。

| 事例 | 住居に当たるか |
|---|---|
| 通常は家族のいる自宅、天災等でやむを得ずアパートに宿泊 | **両方とも住居** |
| 単身赴任先のアパート | 住居 |
| 交通ストで会社近くのホテルに宿泊 | 住居 |

### 逸脱・中断（7条3項）

**逸脱**＝通勤の経路をそれること。**中断**＝経路上で通勤と関係のない行為を行うこと。

> **逸脱・中断の間およびその後の移動は、通勤としない**。

例外は2段構えです。

1. **ささいな行為**（経路上の公衆トイレ、駅売店での新聞購入、ごく短時間の立ち話など）は逸脱・中断に当たらない → **その間も通勤**
2. **日常生活上必要な行為をやむを得ない事由により最小限度**で行う場合は、**逸脱・中断の間を除き**、合理的経路に復した後は**再び通勤となる**

日常生活上必要な行為（労災則8条）は次の5つです。

| | 行為 |
|---|---|
| 1号 | 日用品の購入その他これに準ずる行為 |
| 2号 | 職業訓練・学校教育法上の教育その他これらに準ずる**教育訓練**（職業能力の開発向上に資するもの） |
| 3号 | **選挙権**の行使その他これに準ずる行為 |
| 4号 | **病院・診療所**での診察・治療その他これに準ずる行為 |
| 5号 | 要介護状態にある**配偶者・子・父母・孫・祖父母・兄弟姉妹**（配偶者の父母を含む）の**介護**（継続的・反復的に行われるもの） |

> ★5号の介護は「**継続的又は反復的に行われるもの**」に限られます。単発の介護は該当しません。

### 給付の種類と特徴

| 業務災害 | 通勤災害 |
|---|---|
| 療養**補償**給付 | 療養給付 |
| 休業**補償**給付 | 休業給付 |
| 障害**補償**給付 | 障害給付 |
| 遺族**補償**給付 | 遺族給付 |
| 葬祭料 | **葬祭給付** |
| 傷病**補償**年金 | 傷病年金 |
| 介護**補償**給付 | 介護給付 |

通勤災害には「補償」の2文字が付きません。**葬祭料／葬祭給付**の呼び分けも頻出です。

### 一部負担金（31条2項）

**療養給付**を受ける労働者は、**200円**（日雇特例被保険者は100円）を一部負担金として負担します。最初に支給される**休業給付から控除**されます（22条の2第3項）。

次の者は徴収されません。

- 第三者行為災害によるもの
- 療養開始後**3日以内に死亡**した者など休業給付を受けない者
- **同一の通勤災害**について既に一部負担金を徴収された者

> ★業務災害には一部負担金はありません。「療養補償給付でも200円を負担する」は誤りです。
