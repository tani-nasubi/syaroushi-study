# 社会保障の統計と財政｜社一の深掘り

## なぜ独立させたか

社一は「択一では法令、統計は選択式」とはっきり分かれます。過去9年を数えると次のとおりでした。

| | 択一 | 選択式 |
|---|---|---|
| **労一** | 41問中23問（**56%**）が統計 | 9回中6回（**67%**）が統計 |
| **社一** | 49問中2問（**4%**）が統計 | 9回中5回（**56%**）が統計 |

社一の択一だけを見ると「統計は出ない」と読めますが、**選択式では半分以上が統計**です。選択式は1問5点で**基準点3点**なので、ここを落とすと**それだけで不合格**になります。択一の1問とは重みが違います。

> ★**労一の統計とは性質が違います。** 労一は「◯◯実態調査」がテーマ持ち回りで初見が前提（→ [`H6-労働統計と実態調査.md`](H6-労働統計と実態調査.md)）。社一は**毎年同じ顔ぶれの社会保障財政統計**なので、**覚えれば得点になります**。

> ★**ラグは1〜3年**です。令和8年度なら**令和5〜6年度の数値**が使われます。

## 2. 5つの統計 — 誰が出して、何を測るか

| 統計 | 出しているところ | 測るもの |
|---|---|---|
| **社会保障費用統計** | **国立社会保障・人口問題研究所**（厚労省ではない） | 社会保障給付費（**ILO基準**）の総額、**部門別**（年金・医療・福祉その他）、**機能別** |
| **国民医療費** | 厚生労働省 | 医療費の総額、**財源別**、**診療種類別**、**年齢階級別**、対GDP比 |
| **国民生活基礎調査** | 厚生労働省 | 世帯構造、**所得**、**相対的貧困率**、**介護の状況**、健康 |
| **国民年金の加入・保険料納付状況** | 厚生労働省 | 第1号被保険者数、**現年度納付率**、**最終納付率**、免除・猶予の状況 |
| **厚生労働白書** | 厚生労働省 | 各年のテーマ（副題）と、白書が引用する各種調査 |

> ★**社会保障費用統計だけが「国立社会保障・人口問題研究所」**です。「厚生労働省の調査」と書いてあれば誤りです。ここは選択式でそのまま空欄になり得ます。
> ★**将来推計人口**も社人研です。

## 3. 順位と傾向 — ここが得点源

実数を毎年追う必要はありません。**順位と方向**は安定しています。

### 社会保障給付費

| 見方 | 順位 |
|---|---|
| **部門別** | **年金 ＞ 医療 ＞ 福祉その他**（福祉その他が医療に接近している） |
| **機能別** | **高齢 ＞ 保健医療 ＞ 家族** |
| 財源 | **社会保険料 ＞ 公費負担**。保険料は事業主拠出と被保険者拠出に分かれる |
| 対国民所得比 | **上昇傾向** |

### 国民医療費

| 見方 | 順位 |
|---|---|
| **財源別** | **保険料 ＞ 公費 ＞ 患者負担** |
| **診療種類別** | **医科診療医療費が最大**（うち入院＞入院外） |
| **年齢階級別** | **65歳以上が6割超** |
| 対GDP比 | 上昇傾向 |

### 国民生活基礎調査

| 項目 | 押さえどころ |
|---|---|
| **世帯構造** | **単独世帯が最も多く**、増加傾向。**高齢者世帯**も増加 |
| **1世帯当たり平均所得金額** | 減少傾向。背景は**高齢者世帯の割合の増加** |
| **相対的貧困率** | **等価可処分所得**（可処分所得÷世帯人員の**平方根**）の**中央値の半分**に満たない世帯員の割合 |
| **子どもの貧困率** | **17歳以下**の相対的貧困率 |
| **高齢者世帯の所得** | **公的年金・恩給が総所得に占める割合が100%**の世帯が最も多い区分（令和6年度に出題） |
| **主な介護者** | **同居**が最多。同居の中では**配偶者 ＞ 子 ＞ 子の配偶者** |

> ★**「高齢者世帯」＝65歳以上の者のみで構成するか、これに18歳未満の未婚の者が加わった世帯**です。定義そのものが空欄になります。

### 国民年金の納付状況

| 用語 | 意味 |
|---|---|
| **現年度納付率** | その年度分の保険料のうち、その年度中に納付されたものの割合 |
| **最終納付率** | 過年度分を含め、**2年経過後**までに納付されたものの割合。**現年度納付率より高くなる** |
| 傾向 | **いずれも上昇傾向**が続いている |

> ★**最終納付率は現年度納付率より必ず高くなります。** 逆に書いた肢は誤りです。時効（2年）を過ぎるまで納められるためです。

## 4. 社一の択一で統計が出るとき

9年で2問だけです。

| 出題年 | 形 |
|---|---|
| **令和6 問9** | 「令和5年版厚生労働白書を参照」と**但し書きあり**。公的年金制度の考え方を問う |
| **令和7 問10** | **但し書きなし**。「団塊ジュニア世代の全員が65歳以上となる令和22（2040）年頃を見通すと、**85歳以上人口が急増**し…**生産年齢人口が急減**する」と、白書・将来推計人口の記述が法令の肢に**混ざって**出た |

いずれも数値ではなく**制度の趣旨や見通しの向き**が問われています。**「◯◯調査を参照」の但し書きが無くても統計が混ざる**ことがある、というのが令和7年度の教訓です。

- 社一の択一は**法令が本体**です。国保法・介護保険法・高齢者医療確保法・確定拠出年金法・確定給付企業年金法・船員保険法・社労士法・社会保険審査官及び社会保険審査会法で6問が埋まります。
- 統計は選択式に回るので、**択一対策としては法令を優先**して問題ありません。

## 5. 令和8年度に向けて

**やること**

1. 上の**順位と傾向の表**を覚える（これで選択式の半分は絞れる）
2. **社会保障費用統計＝社人研**、ほかは厚労省という**主体の対応**
3. **最終納付率＞現年度納付率**、**高齢者世帯の定義**、**相対的貧困率の定義**
4. `99-白書・統計.md`で**令和7年版の厚生労働白書の副題**

**やらないこと**

- 総額の実数を桁まで覚える（毎年変わる。選択肢に幅があるので順位で絞れる）
- 過去問に出た年度の数値をそのまま覚える

> ★労一の統計と違い、こちらは**同じ統計が繰り返し出ます**。覚えた分がそのまま次に効きます。時間をかける価値があるのはこちらです。
